Once the pending set looks right:

  cd cloudflare-worker && npx wrangler deployments list --config ../wrangler.toml --env production
  cd ..
  npm run deploy ; echo "exit=$?"

Capture the deployment ID from that first command before deploying, for
rollback. Do NOT run `npx wrangler deploy` by hand, and do NOT run
`npm run deploy` from inside cloudflare-worker/ — both skip the migration
hook and ship the worker ahead of its schema. Do NOT set SKIP_LIVE_SMOKE=1.

npm run deploy exit 0 means migrations applied, the frontend built, the
worker uploaded, and the live smoke check passed — all four.
