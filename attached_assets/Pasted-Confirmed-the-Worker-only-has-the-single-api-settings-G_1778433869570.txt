## Replit Prompt AC — Personal Advisor chatbot (auto-fills pages, persona-aware)

```
Objective
  Replace the dashboard "Tell us about yourself" panel with a persistent
  Personal Advisor chatbot. It profiles each persona, answers questions
  about features, and *writes* the answers back into the right pages so
  users don't have to fill them manually. Acts as a tutor: every answer
  triggers a short explainer for the feature being filled, with a "More
  in Docs →" link. Tier and role aware: only suggests features the user
  can use; for paywalled features, explains the value and offers
  upgrade.

Personas + question banks (one file per persona,
                          frontend/src/lib/advisor/banks/)
  newFounder.ts
    - About you: name, location, time-zone, working FT/PT, prior ventures
    - Idea: 1-line problem, who hurts most, current solution, your wedge
    - Customer: target ICP (segment, size, geo), willingness to pay
    - Discovery: existing interviews, key quotes
    - Roadmap: top 3 outcomes for 90 days, top 3 deliverables this week
    - Team: any cofounder candidates? skill gaps?
    - Brand: working name, tagline, palette, voice
    - Deck: elevator pitch, why-now
    - Spin-Out Lab progress: which week milestones to unlock now
  existingFounder.ts
    - Company facts: legal name, entity, country, registration #, fiscal
      year-end, employees, website
    - Cap table: founders, vesting, options pool size, last round
    - Financials: MRR, burn, runway, last 3 months revenue
    - Pipeline: top 5 deals/customers and stages
    - Compliance: incorporated where, 83(b) filed?, IP assignments
    - Capital: amount raising, valuation cap or pre-money, target close
    - Roadmap: quarterly OKRs
    - Mentors needed: which expertise gaps
  investor.ts
    - Firm facts: name, role, AUM, fund vehicle, geos, sectors, stage
    - Thesis: one-line, allergies, must-haves
    - Tickets: typical, follow-on capacity, lead/follow
    - Pipeline: quarter target, current sourcing channels
    - Co-invest preferences, syndicate vs solo
    - Watchlist: sectors to flag opportunities for
  mentor.ts
    - Expertise tags, sectors, stages, weekly capacity hours
    - Comp preference: pro-bono, equity, cash, mixed
    - Calendar provider, timezones served, languages
    - Topics willing/unwilling to advise on
  partner.ts
    - Firm, role, services offered or capital available
    - Deal type interest (equity/services/revshare/capital — Prompt X)
    - Conflicts of interest disclosures
    - Deal-flow channels they bring

Tutor layer (every persona)
  Each question carries:
    {
      id, label, type: 'text'|'textarea'|'number'|'currency'|'select'|
                        'multiselect'|'date'|'range'|'toggle'|'file',
      explainer: short copy "Why we ask",
      doc_anchor:  '/docs#section/...',
      page_target: which page+field this answer fills,
      tier_required?: 'free'|'growth'|'studio'|'investor_pro'|...,
      validate: zod schema,
      followups?: question[] (conditional branches)
    }

Auto-fill engine
  cloudflare-worker/src/routes/advisor.ts
    POST /api/advisor/start              → creates conversation + returns
                                            persona-specific opening
                                            question, hydrated with any
                                            existing data already on
                                            file (so the chatbot doesn't
                                            re-ask).
    POST /api/advisor/answer
       body { conversation_id, question_id, value }
       → { saved_to: [{ table, column, row_id }], next_question, hint? }
       Persists the value via a write-router that knows which page+field
       maps to which D1 column (one map per persona). All writes go
       through the existing per-resource auth (founder can only write
       her own project, investor can only write his own profile, etc.).
    POST /api/advisor/skip { conversation_id, question_id }
    POST /api/advisor/explain { topic } → tutor response w/ doc link
    GET  /api/advisor/progress  → completion ring per page
    GET  /api/advisor/conversations/:id

  Write-router examples:
    newFounder.idea.problem      → projects.problem_statement (current
                                      project for this user, auto-create
                                      if none)
    newFounder.customer.icp      → projects.target_icp_json
    newFounder.discovery.interviews → discovery_interviews rows
    newFounder.roadmap.okrs       → roadmap_okrs rows
    existingFounder.financials.mrr→ score_evidence + projects.mrr_usd
    investor.thesis.allergies    → investor_profiles.allergies_text
    mentor.expertise.tags         → mentor_profiles.tags_json
    partner.deal_type             → partner_profiles + partner_deals.draft

  Side-effects:
    - When the answer would unlock a Spin-Out Lab milestone, the engine
      calls /api/spinout-lab/milestone automatically.
    - When an answer fills a contract merge-field (Prompt U), the
      contract auto-fill cache is refreshed.
    - When an answer is for a paywalled feature, the chatbot explains
      the feature anyway and offers an upgrade link instead of writing.

Tutor mode
  At any time the user can type "explain X" or click an "?" beside the
  current question. The chatbot calls /api/advisor/explain with the
  current topic and returns:
    - One-paragraph explanation
    - Why it matters in the user's persona context
    - "Open the page to see it" deep link
    - "Read more in docs" deep link

Frontend
  frontend/src/components/advisor/PersonalAdvisor.jsx
    - Pinned to the dashboard header column where the old
      "Tell us about yourself" lived.
    - Persistent: minimisable to a floating bubble; full-screen on
      mobile.
    - Shows a per-page completion ring on the right rail with deep
      links into pages.
    - Streaming responses (SSE) for reply latency under 1s.
  frontend/src/lib/advisor/router.js
    - Client-side mirror of the write-router for optimistic UI updates.
  frontend/src/lib/advisor/persona.js
    - Picks the bank by user.role + spinout_lab_active.
  frontend/src/pages/Dashboard.jsx
    - Mounts <PersonalAdvisor /> in the slot previously occupied by
      "Tell us about yourself".

Schema
  CREATE TABLE advisor_conversations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    persona TEXT NOT NULL,
    started_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_message_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
  CREATE TABLE advisor_messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    conversation_id INTEGER NOT NULL,
    role TEXT NOT NULL,                 -- 'system','user','assistant','tool'
    content TEXT NOT NULL,
    question_id TEXT,
    written_path TEXT,                   -- e.g. 'projects.problem_statement#42'
    model TEXT, latency_ms INTEGER,
    token_in INTEGER, token_out INTEGER,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
  CREATE TABLE advisor_answers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    persona TEXT NOT NULL,
    question_id TEXT NOT NULL,
    value_json TEXT,
    written_path TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, question_id)
  );

LLM details
  - Model default: claude-haiku-4-5-20251001 for Q&A, claude-sonnet-4-6
    for "explain" mode.
  - Prompt caching on system prompt + question bank (≥1024 tokens) →
    fast first-token latency.
  - Tool-use to call writeAnswer(...), explainTopic(...), openPage(...).
  - Server filters tool-result content for prompt injection before
    re-prompting.

Privacy
  - Never includes other users' PII in system prompt.
  - Refuses destructive actions (delete, void). Suggests + deep-links
    instead.
  - Stripe / Plaid / Crunchbase API responses pulled inside server-side
    tools, never sent through the LLM verbatim if they include PII.

Persona detection
  If users.role is null on first run (brand new account), the chatbot
  starts with a 3-question role detector that sets users.role and the
  Spin-Out Lab flag if applicable, then pivots to the persona bank.
  This subsumes the current "Tell us about yourself" panel entirely.

Acceptance
  - New Founder finishing the bank has a populated Project, ≥3
    discovery interviews, ≥3 OKRs, brand basics, a deck draft seed,
    and Spin-Out Lab Week 1 milestone unlocked — without opening any
    of those pages manually.
  - Existing Founder finishing their bank has corporate profile, cap
    table seeds, financial figures with evidence prompts, and
    quarterly OKRs filled.
  - Investor finishing the bank has investor_profiles populated and
    the Market Intel Investor Signals contributor flag set.
  - Mentor / Partner banks fill their respective profile rows.
  - Asking "what's a SAFE?" returns a tutor reply with a docs link.
  - Tier-locked answers don't write; instead show the feature
    explanation and an upgrade button.
  - Streaming, persistence, deep-links and minimise/restore all work.
```
