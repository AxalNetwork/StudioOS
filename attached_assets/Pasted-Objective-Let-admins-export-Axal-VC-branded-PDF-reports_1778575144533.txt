Objective
  Let admins export Axal-VC branded PDF reports and CSV extracts of
  any Market Intelligence section (advisor-derived or external) for
  publication, LP updates, founder distribution, or media.

Endpoints (cloudflare-worker/src/routes/admin_publications.ts)
  POST /api/admin/publications/draft
       body { section, filters, title, subtitle, audience,
              include_charts: bool, include_methodology: bool }
       → { draft_id }
  GET  /api/admin/publications/:id
  PUT  /api/admin/publications/:id        edit title/blurbs
  POST /api/admin/publications/:id/render { format: 'pdf'|'csv'|'png' }
       → { download_url } (R2 24h gated URL via Worker)
  POST /api/admin/publications/:id/publish
       optionally pushes to the public Insights page
       (frontend route /insights/public/:slug)

Template
  frontend/src/pages/admin/publications/AxalReportTemplate.jsx
  Cloudflare Browser Rendering renders this to PDF/PNG.
  Pages:
    Cover     — Axal wordmark, title, period, audience tag,
                confidentiality footer
    Summary   — 3-5 bullet "headline insights" generated by Claude
                (haiku-4-5 via fetch) from the underlying aggregates
    Charts    — one section per chosen MI section
    Methodology — sources, time windows, sample sizes, k-anonymity
                  notes
    Appendix — references / citations

Insights synthesis safeguard
  - The summary uses Anthropic only because the synthesis is
    high-stakes; cache the exact prompt + result for 24h to keep
    cost low.
  - Show the admin the synthesis before render with an "Edit"
    button. Persist the human edits in the publication row.

CSV export
  Streamed; columns match the aggregates table for the chosen
  section. Suppression: rows with n<5 elided.

Audit
  Every render and publish writes admin_audit_log with title,
  filters, audience, downloaded_url, published_at.

Acceptance
  - Admin can compose a publication in <2 minutes.
  - PDF renders Axal-branded with correct charts + methodology.
  - CSV export downloads with proper headers.
  - Publishing makes the publication available at
    /insights/public/:slug (read-only, no PII).
  - Audit log shows the action.
