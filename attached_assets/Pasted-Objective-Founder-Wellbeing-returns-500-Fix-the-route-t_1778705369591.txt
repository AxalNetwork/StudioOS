Objective
  Founder Wellbeing returns 500. Fix the route, then expand the
  feature into a real expert directory covering advisors, mentors,
  and wellness specialists. Match by category × rating × language ×
  availability, and let founders book directly.

Part 2 — Expert categories + directory
  Schema:
    CREATE TABLE IF NOT EXISTS experts (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      user_id INTEGER,                     -- platform user if applicable
      name TEXT NOT NULL,
      title TEXT,
      bio TEXT,
      categories_json TEXT NOT NULL,        -- e.g. ['executive_coach','sleep_specialist']
      sectors_json TEXT,
      languages_json TEXT,
      timezones_json TEXT,
      countries_json TEXT,
      modalities_json TEXT,                  -- ['video','voice','in_person']
      pricing_model TEXT,                   -- 'pro_bono','equity','cash','sliding','mixed'
      hourly_rate_usd REAL,
      first_session_free INTEGER DEFAULT 0,
      booking_calendly_url TEXT,
      booking_google_url TEXT,
      verified INTEGER DEFAULT 0,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );
    CREATE TABLE IF NOT EXISTS expert_ratings (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      expert_id INTEGER NOT NULL,
      rated_by_user_id INTEGER NOT NULL,
      score INTEGER NOT NULL,                -- 1..5
      review_text TEXT,
      category_match_pct INTEGER,            -- 0..100 self-reported
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      UNIQUE(expert_id, rated_by_user_id)
    );
    CREATE TABLE IF NOT EXISTS expert_bookings (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      expert_id INTEGER NOT NULL,
      booked_by_user_id INTEGER NOT NULL,
      scheduled_at DATETIME,
      duration_min INTEGER,
      status TEXT,                            -- 'requested','confirmed','completed','cancelled'
      notes TEXT,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
    );

Matching methodology
  cloudflare-worker/src/services/wellbeing/match.ts
    Scoring formula per (founder, expert):
      base_match    = categorical_overlap(founder_needs, expert_categories)
      rating_score  = bayes_avg(expert_ratings, prior_mean=4.2, prior_n=3)
      language_match = expert.languages ∩ founder.languages ? 1 : 0
      tz_match       = abs(expert_tz - founder_tz) <= 3h ? 1 : 0.5
      availability   = has_calendar_slots_in_next_14_days ? 1 : 0.3
      price_match    = founder_budget_compatible ? 1 : 0.5
    composite = 0.35*base_match + 0.25*rating_score + 0.10*language_match
              + 0.10*tz_match + 0.10*availability + 0.10*price_match

  Top-N (default 6) returned to the page as cards.

Wellbeing page UX
  Top: today's quick check-in (mood/stress/sleep/energy sliders),
  saved instantly.
  Below: "Experts matched to you" — 6 cards based on the most recent
  check-in tags + persona answers from Personal Advisor. Each card:
    - photo, name, title, top categories
    - "First session free" badge if applicable
    - rating + count
    - languages
    - "Book consultation" → opens Calendly / booked-by-platform flow
  Filters: category, language, modality, price.
  "Why these matches?" link expands the score breakdown.

Onboarding + Advisor integration
  - Onboarding chatbot asks the founder about wellness goals at the end
    of the persona flow (low-priority section, optional).
  - Personal Advisor asks weekly "How's your wellbeing?" check-in
    questions and tags answers for category routing.
  - Founder can self-declare expertise to become an expert themselves;
    admin verifies.

Privacy
  Wellbeing data is the most sensitive on the platform. Encrypted at
  column level (Prompt B). Never feeds Market Intelligence aggregates
  unless explicitly opted in. Free-text free_text fields paraphrased
  before any internal display.

Acceptance
  - Page loads without 500 on a fresh account.
  - Daily check-in saves; chart of last 30 days renders.
  - 6 expert cards rendered with sane matches.
  - Filter + search work.
  - Booking flow opens the expert's Calendly (or internal scheduling
    if Calendly not configured).
  - Free founder gets unlimited check-ins + 3 matched expert profile
    views/month; Growth/Studio unlock unlimited matches.
