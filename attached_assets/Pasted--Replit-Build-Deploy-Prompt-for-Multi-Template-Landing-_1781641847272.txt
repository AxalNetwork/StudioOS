## Architecture Notes

**Route Structure:**
All templates are lazy-loaded via React `lazy()` + `Suspense` in `App.jsx`. This ensures each template loads its own JS chunk on-demand.

**Data Pattern:**
Each template file exports content as structured JS arrays at the top:
- `METRICS`, `PROOF_BAR`, `PAIN_POINTS`, `SOLUTION_PILLARS`, `HOW_IT_WORKS`, etc.
- Data flows as props into shared components
- No hardcoded content in JSX

**Theming:**
All templates call `useForcedLightTheme()` hook to override app-wide dark mode.

**Brand Kit:**
All button classes and section backgrounds sourced from `frontend/src/templates/brandKit.js`.
