### Root cause to investigate

This is a JavaScript **temporal dead zone (TDZ)** error. It means somewhere in the Advisors page's route/component tree, a variable named `isAdmin` is being **read or referenced before its `const`/`let` declaration is evaluated** in the same scope. Common causes to check, in order:

1. `isAdmin` is used inside a function, `useMemo`, `useEffect`, `useCallback`, or JSX expression that is defined **above** the line where `const isAdmin = ...` is declared in the same component file.
2. `isAdmin` is derived from a hook (e.g. `useAuth()`, `useUser()`, `useSession()`, or a role-check hook) and that hook call was **moved below** other code that already depends on `isAdmin` during a refactor/paste.
3. `isAdmin` is destructured conditionally (inside an `if` block or after an early `return`) but referenced outside that block — this also throws a TDZ error in strict mode.
4. A prop or context value called `isAdmin` is passed to a child component, but the parent component's own local `const isAdmin` shadows it and is declared later in the file than a closure that captured it.
5. Two files both declare `isAdmin` (e.g. a shared permissions util and a local page-level override) and there's a circular import or evaluation-order issue between them.
