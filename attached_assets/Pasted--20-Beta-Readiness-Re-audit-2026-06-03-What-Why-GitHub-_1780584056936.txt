* Any production writes (read-only curl / code inspection / read-only D1 SELECT only, matching the original playbook).

The executor should instead: (a) produce the doc, and (b) include a ready-to-run closing section (issue refs + gh issue close / gh issue comment commands, and the doc-attach comment body) so a maintainer with GitHub access can finish the hand-off. Surface this limitation explicitly in the task summary.
