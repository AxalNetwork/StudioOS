#8 - AU — Admin Publication Exports
What & Why
Let admins export Axal-VC branded PDF reports and CSV extracts of any Market Intelligence section (advisor-derived or external) for publication, LP updates, founder distribution, or media. PDF rendered via Cloudflare Browser Rendering; headline summary synthesised by Anthropic (haiku-4-5) via AX's fallback path.

Done looks like
Admin can compose a publication in <2 minutes via /admin/publications/new.
Endpoints live: POST /draft, GET /:id, PUT /:id, POST /:id/render (pdf|csv|png), POST /:id/publish.
PDF renders with Axal wordmark, title, period, audience tag, confidentiality footer; pages = Cover / Summary / Charts / Methodology / Appendix.
Headline summary generated by aiRouter.run('publication', …) (Anthropic haiku-4-5 with prompt caching ≥1024 tokens, 24h cache); admin can edit before render; edits persisted on the publication row.
CSV streamed; columns match aggregates; rows with n<5 elided.
Publishing makes the publication available at /insights/public/:slug (read-only, no PII).
Every render and publish writes admin_audit_log with title, filters, audience, downloaded_url, published_at.
Download URL is R2-gated, 24h-signed, served via Worker.
Out of scope
The MI sections themselves (AT-1 / AT-2).
New chart-library work — reuse the same chart components AT-2 builds and render them inside the report template.
Steps
Bindings — Add Cloudflare Browser Rendering binding + R2 bucket binding (PUBLICATIONS) to wrangler config and Env type.
Migration — Create admin_publications (id, slug, title, subtitle, audience, section, filters_json, summary_text, summary_human_edited, status, created_by, created_at, published_at) + reuse admin_audit_log.
Endpoints — cloudflare-worker/src/routes/admin_publications.ts with the 5 endpoints listed in spec.
Report template — frontend/src/pages/admin/publications/AxalReportTemplate.jsx — printable layout with the 5 page sections; reads section-data props from query string for Browser Rendering.
Browser Rendering wiring — Worker endpoint navigates Browser Rendering to a signed internal URL of the template, captures PDF/PNG, streams to R2.
CSV export — Stream from aggregates table; suppress n<5 rows; correct content-disposition headers.
Headline synthesis — aiRouter.run('publication', {section_aggregates}) returns 3-5 bullets; admin reviews + edits in the draft UI.
Public insights page — frontend/src/pages/insights/PublicInsight.jsx at /insights/public/:slug, read-only, no auth required, no PII.
Audit — Every render and publish writes admin_audit_log.
