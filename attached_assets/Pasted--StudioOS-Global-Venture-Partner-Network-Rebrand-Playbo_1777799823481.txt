## Part 1 — What's actually shipped (feature audit)

The repo is far bigger than the landing page suggests. Here's the real surface area, grouped:

| Group | Modules in code |
|---|---|
| **Intelligence** | Market pulse, macro signals, private rounds, studio benchmarks, competitive intel, semantic search (Vectorize) |
| **Scoring & Diligence** | 100-pt scoring engine (Market 25 / Team 20 / Product 15 / Capital 15 / Strategic Fit 15 / Distribution 10), AI deal memos, automated diligence checker |
| **AI Advisory** | Strategy advisor (GTM / fundraising / product / team), financial planner, diligence automation |
| **Deal & Match** | Deal flow pipeline, partner matchmaking, referral system, **community voting (weighted: admin=3, LP=3, partner=2, founder=1)** |
| **Legal & Compliance** | 18 templates across GP governance, fund formation, portfolio execution, compliance. Signed-content storage with HMAC short-lived URLs. |
| **Capital & Fund Ops** | LP investor portal, capital calls, **VC Fund core (LPA generation via Llama 3.1 8B, distributions, TVPI/DPI charts)**, fund-scoped LP ledger |
| **Liquidity / Secondary** | Listings, AI valuation, anonymized buyer matching, atomic exit execution, marketplace |
| **Operations** | Tickets (auto-sync to GitHub issues), activity/audit log, monitoring (RPM, errors, anomalies via Workers AI) |
| **Integrations** | HubSpot, Salesforce, Sumsub, Stripe Atlas, Cooley GO, PitchBook, custom — Fernet-encrypted secrets, HMAC-validated webhooks |
| **Realtime** | Cloudflare Durable Objects: `PipelineRoom` (deal updates), `OnboardingChat` (AI chat transcripts) |
| **Refer & Earn** | CSV contact import, X/LinkedIn/WhatsApp/Email share, editable invite templates |
| **Auth & Perimeter** | TOTP + JWT (24h), email verification, Turnstile, **Cloudflare Zero Trust gating on admin/monitoring/infra routes** |
| **Roles** | Admin, founder, partner (LP), with admin impersonation + portal switcher |

The current landing page (`<title>Axal VC — StudioOS</title>`, meta: *"From Idea to Funded Company in 30 Days"*) sells **only the spin-out funnel** — which means ~80% of what's built is invisible to a visitor.

## Part 2 — The repositioning

### Old positioning (single funnel)
> **Axal Ventures — From Idea to Funded Company in 30 Days.**
> Linear, founder-facing, "we incubate you."

### New positioning (network)
> **Global Venture Partner Network (GVPN)** — the operating system where founders, partners, LPs, and capital connect across borders.

This shift does three things:
1. **Surfaces the partner side** of the platform (which you've already built — matchmaking, referrals, community voting, partner portal, integrations).
2. **Demotes the 30-day spin-out** from headline to *one product* inside a multi-product network. Call it **Spin-Out Lab™** (suggested — keeps the velocity story but signals it's a sub-brand).
3. **Lets you charge differently per audience** — partners pay for network access, LPs pay for capital ops, founders pay for spin-out. One landing, three doors.

### Naming map (suggested)
| Old | New |
|---|---|
| StudioOS | **GVPN OS** (internal) / **Global Venture Partner Network** (external) |
| Axal Ventures (brand) | **GVPN** |
| 30-Day Spin-Out Engine | **Spin-Out Lab** (niche product page) |
| 7 Engines | **5 Network Layers** (Partners, Capital, Deals, Intelligence, Legal) |
| Founder Portal | **Founder Lane** |
| Partner Portal | **Partner Lane** |
| LP Investor Portal | **Capital Lane** |

> If you want to keep "Axal" as the parent company and "GVPN" as the product, that also works — just swap product copy, leave corporate footer.

## Part 5 — What you should decide before kicking off Task 0

Three calls that change the prompts above:

1. **Is "GVPN" the brand, or is "Axal" the brand and "GVPN" the product?**
   - If GVPN = brand: replace "Axal Ventures" everywhere public-facing.
   - If Axal = parent brand, GVPN = product: keep "Axal Management, LLC" in the footer, swap only product copy. (The prompts above assume the second model — adjust Task 0 if you want the first.)

2. **Is "Spin-Out Lab" the right niche-product name?** Alternatives that test well:
   - *Velocity* (suggests speed, less literal)
   - *30-Day Cohort*
   - *Spin-Out Sprint*
   - *Founder Lab*
   Whatever you pick, change the `nicheProduct.name` value in Task 0's `gvpn.ts` once and everything propagates.

3. **Pricing surface — show or hide?** The current repo doesn't have public pricing. The nav in Task 6 includes a "Pricing" link that will 404. Either remove it or add `Task 6.5: build /pricing` before shipping.

Optional follow-on tasks I'd recommend after the rebrand lands:

- **Task 11** — partner directory teaser (pull a public subset from `/api/partners` and render as a logo wall on `/`)
- **Task 12** — case-study pages for completed spin-outs (one per liquidity event in the DB, admin-curated)
- **Task 13** — `/network` page that visualizes the 5 layers as a connected graph (use d3 force layout or react-flow — both are in the existing dependency tree-ish via the React 19 base)
