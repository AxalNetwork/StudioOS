# Personal Advisor: fullscreen mode + Worker-AI voice-to-text

## Context

The Personal Advisor today (`frontend/src/components/advisor/PersonalAdvisor.jsx`) lets users collapse the widget to a small floating pill ("Minimise to bubble"). The user wants to drop that pattern and replace it with the opposite gesture: a **fullscreen** option that takes the chat over the full viewport. The fullscreen view must offer two clear ways to return to the dashboard. In addition, the Composer (input bar) gains a **mic button** that records audio, ships it to a new Cloudflare Workers AI endpoint, and drops the transcript back into the textarea.

The deliverable is a set of self-contained Replit prompts the user can hand off one at a time.

User-confirmed decisions:
- Both exit buttons in fullscreen perform the same action — exit fullscreen back to the embedded card on the dashboard. Two visually distinct buttons, one underlying handler.
- Voice capture uses `MediaRecorder` in the browser → base64 → POST to a new worker route → Workers AI Whisper (`@cf/openai/whisper-large-v3-turbo`) → return text.
- Task prompts are decomposed into one prompt per task (4 prompts total).

### 4. Voice-to-text in Composer
Extend `Composer` (lines 864-921). Add a mic button between the textarea and the `SkipForward` button, mirroring its styling.

Implementation sketch:
```js
const [recState, setRecState] = useState('idle'); // 'idle' | 'recording' | 'transcribing' | 'unsupported'
const recRef = useRef(null);   // MediaRecorder
const chunksRef = useRef([]);

async function startRec() {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    const mr = new MediaRecorder(stream);
    chunksRef.current = [];
    mr.ondataavailable = (e) => e.data.size && chunksRef.current.push(e.data);
    mr.onstop = async () => {
      stream.getTracks().forEach(t => t.stop());
      const blob = new Blob(chunksRef.current, { type: mr.mimeType || 'audio/webm' });
      const b64 = await blobToBase64(blob);
      setRecState('transcribing');
      try {
        const { text } = await api.advisor.transcribe(b64, blob.type);
        if (text) setInput((cur) => (cur ? `${cur} ${text}` : text));
      } finally { setRecState('idle'); }
    };
    mr.start();
    recRef.current = mr;
    setRecState('recording');
  } catch {
    setRecState('unsupported');
  }
}
```
Button rendering: `Mic` icon (lucide) gray when idle, red + `animate-pulse` when recording, `Loader2 animate-spin` when transcribing, disabled when `unsupported`. Tooltip describes the state.

### 6. Worker endpoint
In `cloudflare-worker/src/routes/advisor.ts`, mirroring the existing route style:
```ts
advisor.post('/transcribe', async (c) => {
  const user = await requireAuth(c);
  const body = await c.req.json().catch(() => ({})) as { audio_base64?: string; mime?: string };
  if (!body.audio_base64) return c.json({ error: 'audio_base64 required' }, 400);

  // Decode base64 → Uint8Array (Whisper accepts a byte array)
  const bin = atob(body.audio_base64);
  const bytes = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);

  const out: any = await c.env.AI.run('@cf/openai/whisper-large-v3-turbo', {
    audio: [...bytes],
  });
  return c.json({ text: (out && (out.text ?? out.transcription)) || '' });
});
```
The route is mounted at `/api/advisor/transcribe` because `app.route('/api/advisor', advisorRoutes)` is already wired in `cloudflare-worker/src/index.ts:452`.
