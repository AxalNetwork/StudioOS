Eval (scripts/eval/advisor.mjs)
  Curated 50-prompt bank, runs through the live advisor against a
  staging account. Outputs scripts/eval/results/<date>.json with:
    turn count, repetition rate, write success rate, p95 latency,
    cost per conversation, MI signal coverage delta.

Production rollout
  Phase 1: enable for admin-impersonated test users only (env flag
    ADVISOR_V2_ALLOWLIST). Run for 3 days. Read eval results.
  Phase 2: enable for 10% of new signups via deterministic hash on
    user_id. Run for 1 week.
  Phase 3: enable for all users. Old advisor code removed in the
  follow-up PR.

Kill switch
  Env var ADVISOR_V2_DISABLED. Setting to '1' instantly routes back
  to the old advisor or returns a polite "advisor temporarily
  unavailable" message.
