#14 - Integrate legal-document work (PR #90)
What & Why
Claude Code built a complete refactor of the legal-document generation system plus new/cleaned drafts on the branch claude/cool-volta-0mc9i5 (draft PR #90). None of it is in the Replit workspace main yet — legalDocFormat.ts/legalDocFormat.js don't exist here, and pdf.ts/PaperPreview.jsx are still the old versions. This task brings that branch's changes into main by reusing the existing work (no rebuilding) and reconciling it against the 9 newer commits already on main.
The branch delivers the four-component legal layout (CONFIDENTIAL header + centered UPPERCASE title; standardized preamble; clause-only body; footer; execution block), fixes the Markdown-leakage bug (#, ##, **, >, ---, - [ ] showing in previews/PDFs), cleans 30 existing template bodies, drafts 15 previously-blank stubs, and adds a refresh migration that pushes all bodies to D1.
Done looks like
* The shared formatting layer (worker TS + frontend JS mirror) is present on main and both the exported PDF and the admin live preview use it, so they always match.
* Generated previews and exported PDFs contain no raw Markdown (#, ##, **, >, ---, - [ ] are gone; checkbox blanks render clean).
* Every document renders: "CONFIDENTIAL" top-right, centered/bold/UPPERCASE title, the standardized preamble with the registered Delaware address (16192 Coastal Highway, Lewes, DE 19958), a footer showing [Title] — v[N] / Page X of Y plus legal@axal.vc, and a proper execution block (By / Name / Title / Date).
* The execution block is document-kind aware: agreements carry the dual Axal/Counterparty block with Joseph Gabriel Guillaume Lauzier (Managing Partner) as the Axal signatory; portfolio/corporate docs sign as the Company; filings (83(b), accreditation) sign as the filer; policies (ToS/Privacy/AML) carry no signature block.
* The 15 previously-blank stub templates are populated and the 30 existing bodies are cleaned to the clause-only convention; the refresh migration applies on top of the current schema.
* npm run test:drift passes (including the worker tsc --noEmit step and the legal/PDF-dependent tests), and the new legal-format unit tests pass.
* Both changelogs are updated for this user-facing change: CHANGELOG.md (technical) and frontend/public/CHANGELOG-user.md (plain-English), with no duplicate entries.
Out of scope
* Reconnecting the GitHub provider / running Git Sync to push main to origin — that is an account-level action the user performs in Replit's Git pane (the task agent merges into the workspace main; the user syncs to GitHub afterward).
* Closing PR #90 and deleting its branch — handled by the dependent cleanup task.
* Any further legal redrafting or counsel review beyond what's on the branch (the drafted bodies stay marked as v1 drafts pending counsel review).
* Deploying to production (npm run deploy).
