## Replit prompt

Build a production-quality **Axal VC Spin-Out Lab Cohort Admin Dashboard** web app for internal operators to review founder applications, approve or reject submissions, track every company across the Spin-Out Lab stages, and let internal team members follow each company profile.

Use **Next.js + TypeScript + Tailwind CSS + shadcn/ui + Lucide icons + Supabase** for auth/database/storage. Make it feel like a premium modern venture platform: clean white surfaces, subtle purple accents, rounded cards, crisp tables, strong hierarchy, and dense-but-readable admin UX. Keep typography compact like a real admin panel. No generic AI gradient dashboard look.

### Product context

This dashboard is for the **Axal VC Spin-Out Lab** team. It manages startup applications and cohort progress.

The public/user-facing product already has:
- A cohort application page with fields like company/working name, project description, incorporation status, current stage, preferred jurisdiction.
- A 30-day cohort pipeline with 5 phases: **Validate, Structure, Build, Pitch, Fund**.
- Weekly modules and unlocked features/tools such as:
  - Startups
  - Customer Discovery
  - Market Intel
  - Profiling
  - Roadmap
  - Brand & Landing Pages
  - Pitch Deck Builder
  - Studio Ops
  - Scoring
  - Advisors
  - Office Hours
  - Co-founder Match
  - MI / Investor Signals
  - Revenue
  - Incorporate
  - Cap Table
  - 83(b)
  - Co-founder Agreement
  - Capital

The admin dashboard should help operators:
1. Review applications.
2. Approve, reject, waitlist, or request more info.
3. Assign accepted companies to cohorts.
4. Track where each company is in the 5-phase pipeline.
5. Track what features/tools each company has used or completed.
6. Let internal users “follow” companies/profiles and see a watchlist.
7. Add notes, tags, owners, and next actions.
8. See activity history and progress over time.
