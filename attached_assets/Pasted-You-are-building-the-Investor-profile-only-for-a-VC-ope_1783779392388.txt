Implementation tasks

Task 1: App shell
- Create the sidebar with these 5 top-level sections.
- Add routing for every feature page.
- Make the layout responsive.
- Add active state navigation.

Task 2: Network
- Build Introductions, Relationships, and Organizations pages.
- Use list/detail views where appropriate.
- Add filters and mock records.

Task 3: Pipeline
- Build Deal Flow, Screening, Commit, and Transactions as separate pages.
- Inside each page, merge the listed sub-features into tabs, filters, panels, or subviews instead of separate sidebar entries.
- Keep the pipeline flow linear.

Task 4: Portfolio
- Build Companies, Performance, Reporting, and Growth pages.
- Merge sub-features into each page as internal widgets or sections.

Task 5: Funds
- Build Fund Management, LP Management, Performance, and Accounting pages.
- Include the listed sub-features inside each page.

Task 6: Research
- Build Market, Companies, Documents, AI Research, and News pages.
- Merge document-related items into the Documents page and support search/filtering.

Task 7: Shared components
- Create reusable components for tables, cards, filters, breadcrumbs, empty states, detail panels, tabs, and side panels.
- Keep styling consistent across all sections.

Task 8: Mock data
- Seed the app with realistic mock data for every section.
- Ensure every page has meaningful content.
- Keep the models easy to replace with real backend data later.

Task 9: Polish
- Add simple tests for route rendering and sidebar navigation.
- Make sure the app feels cohesive, fast, and production-ready.

Before coding
- Inspect the repo structure.
- Identify reusable components and existing patterns.
- Summarize the smallest viable implementation plan.
- Then build section by section in the order above.
