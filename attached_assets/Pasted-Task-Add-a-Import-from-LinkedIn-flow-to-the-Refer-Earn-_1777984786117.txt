Task: Add a "Import from LinkedIn" flow to the Refer & Earn page that
complements the existing CSV import, then funnels imported contacts
into the same `api.emailSendReferralInvites()` path that's already in
production.

IMPORTANT — read first, then implement:
LinkedIn's public API does NOT expose a user's 1st-degree connections
(that endpoint was deprecated in 2015). The only way to programmatically
get a user's connections is via LinkedIn's self-service "Export your
data" flow, which produces a Connections.csv with name + email columns.
So this feature has TWO components:

  (A) "Sign in with LinkedIn" — OAuth 2.0 login via the standard
      r_liteprofile + r_emailaddress scopes. This authenticates the
      user with their LinkedIn identity, prefills their name/email,
      and gives us a verified LinkedIn profile to attach to their
      referral activity. It does NOT pull connections.

  (B) "Import LinkedIn Connections" — guided flow that:
      1. Opens a modal that walks the user through:
         linkedin.com/mypreferences/d/download-my-data → "Connections"
         → request export → wait ~10 minutes → download the zip.
      2. Lets the user upload the resulting Connections.csv (which
         has columns: First Name, Last Name, Email Address, Company,
         Position, Connected On).
      3. Parses the CSV (the existing CSV parser at the bottom of
         ReferEarnPage.jsx works — just map "Email Address" → email
         and "First Name" + "Last Name" → name).
      4. Hands the parsed list to the existing `imported` state and
         the existing send-invites pipeline. No backend changes
         needed for this part.
