---
1. Read the prototype's flows and goals recorded in Build (`build.read`).
2. Write the intro, one task per flow, neutral prompts for when a participant is stuck, and a wrap-up.
3. Keep every prompt neutral: it never names the button to press.
4. Write "Not recorded" for a flow with no stated goal.
5. Propose the script to the product lead.
