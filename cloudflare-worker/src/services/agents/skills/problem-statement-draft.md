roles: [cpo, ceo]

taxonomy: {product_discovery: working, product_user_research: aware}

1. Read the venture summary (`project.read`) and the validation records: interviews, problems heard and their counts (`validate.read`).
2. Write the problem in the customer's words, quoting the problems that came up most often, with how many interviews raised each.
3. Name who has the problem and when, from the recorded segments only.
4. Mark any count, segment or quote that was not read as "Not recorded".
5. Propose the draft to the product lead. It changes no record.
