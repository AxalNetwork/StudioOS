1. Read the venture summary (`project.read`), the milestones and plan (`build.read`) and the budget recorded in Grow (`grow.read`).
2. Draft each answer: the problem, the innovation, the milestones with dates, the team and the budget use.
3. Use only recorded figures and dates; write "Not recorded" where the application asks for one the records lack.
4. Keep each answer within the word limit the application records.
5. Propose the draft to the CEO. A person submits it.
