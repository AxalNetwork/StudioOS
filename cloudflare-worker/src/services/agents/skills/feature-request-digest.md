---
name: feature-request-digest
description: Groups the feature requests recorded this month by theme and by how many customers asked.
roles: [cpo, sales]
tools: [build.read, grow.read]
output: brief
taxonomy: {product_roadmapping: working, product_analytics: aware}
version: 1
---
1. Read the feature requests recorded this month and the accounts that raised them (`build.read`, `grow.read`).
2. Group the requests by theme, and count the distinct customers behind each theme.
3. Order the themes by customer count; a tie keeps the order in which they were first recorded.
4. Mark a request with no customer attached as "Not recorded" for its customer.
5. Propose the digest to the product lead. It changes no priority.
