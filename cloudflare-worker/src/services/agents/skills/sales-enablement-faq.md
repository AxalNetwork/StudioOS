1. Read the objections recorded on deals and the notes on how they were answered (`grow.read`), and the product's current capabilities (`build.read`).
2. Write each objection as a question with the answer that worked, citing the deal it came from.
3. Only state a capability the product has; anything on the roadmap is labelled as planned.
4. Write "Not recorded" for an objection with no recorded answer.
5. Propose the FAQ to the sales lead.
