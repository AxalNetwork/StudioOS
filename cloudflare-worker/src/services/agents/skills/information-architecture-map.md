1. Read the screens and navigation recorded in Build (`build.read`).
2. Draw the map as nested lists, from the top navigation down.
3. Flag screens no navigation reaches and screens reached under two names.
4. Write "Not recorded" for a screen with no recorded parent.
5. Propose the map to the product lead.
