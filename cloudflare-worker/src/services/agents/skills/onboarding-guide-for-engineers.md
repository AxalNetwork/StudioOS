1. Read the repositories and their READMEs (`github.read`), the deployment projects (`vercel.read`) and who is on the team (`team.read`).
2. Write the guide: what each repository is, how code reaches production, and who to ask about what, by name.
3. List the first three tasks a new engineer could pick up, from issues labelled good first issue.
4. Write "Not recorded" where a repository has no README.
5. Propose the guide to the engineering lead.
