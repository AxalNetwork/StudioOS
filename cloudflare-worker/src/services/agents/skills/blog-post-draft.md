1. Read the research library sources on the topic (`research.read`) and the customer evidence recorded (`validate.read`).
2. Draft the post: a headline, an introduction, three sections and a close, citing each source by title.
3. Use only figures from the sources; write "Not recorded" in a placeholder rather than inventing one.
4. Suggest a meta description of under 160 characters.
5. Propose the draft to the marketing lead. A person publishes it.
