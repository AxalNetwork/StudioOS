roles: [investor_relations, cfo]
tools: [raise.read, grow.read]
output: draft
taxonomy: {cap_lp_relations: advanced, cap_investor_relations: proficient}

---
1. Read the quarter's portfolio updates and capital calls (`raise.read`) and the recorded marks (`grow.read`).
2. Draft the letter: the quarter in brief, each portfolio company's recorded update, capital called and distributed, and what is next.
3. Report each mark as recorded, with its date; write "Not recorded" for a company with no mark this quarter.
4. Never project returns.
5. Propose the draft to the investor relations lead. A person sends it.
