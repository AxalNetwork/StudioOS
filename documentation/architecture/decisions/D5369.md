## D5369 — NULL storage owners are unattributed, not invisible (#5369)

HQ's storage total includes every stored file returned by an area's aggregate.
An owner id that is not an account and a NULL owner both belong to the
Unattributed population. A NULL owner does not invent an account or an
`accounts_with_files` entry; it contributes only files, measured bytes,
unknown-size files, and kind totals.

Each static owner query keeps its NULL group. `readStorageByOwner` validates
that group separately from positive account ids and returns one `unowned`
aggregate. `readPlatformStorage` adds it to Unattributed and to the platform
totals. An unreadable area remains unreadable; this decision does not turn a
failed aggregate into zero.
