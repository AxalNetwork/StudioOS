## Canvas departures and backend handoff

- The current Commit summary endpoint returns 100 newest-touched decisions. The list explicitly says this; counts and Mine to vote describe that bounded read, not all historical decisions. The 500-row generic list lacks votes/rosters and is not used to invent those counts.
- Partners/admins do not receive an investor's private deal-flow picker. They can choose a permitted venture and use the existing decision API; the disabled deal field explains the limit.
- Minutes for older/non-current decisions remain Not recorded with an explanation, because no decision-addressed meeting read exists. The code never assigns another record's meeting to the opened decision.
- Persisted quorum, closed-vote enforcement, reopen reason/audit and richer outcome-review fields remain D6153 backend work. See #7920 for the closed-vote service repair. The UI offers no fabricated quorum, Reopen, export, or unsaved AI-generated memo. Recording closes controls on this page; the current vote endpoint itself still permits votes after decided, and needs a separate service repair before claiming API-level closure.
- Existing owner-labelled conditions remain visible. This slice edits condition text/status through existing APIs; it does not invent a condition roster store.
