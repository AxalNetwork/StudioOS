## D5979 — Shared section-incident outbox (#5979)

Part of D5679. A producer submits a stable episode ID and a stable observation
ID using the request context's background task. Producers sharing an episode
also share its primary section and fingerprint. D1 serializes the ledger
write and counts distinct occurrence observations. Duplicate observations
carry the same ID even across producers.

The drain claims an episode before sending, persists the root Slack receipt,
and posts later occurrence totals, versions and recovery to that thread.
The latest pending version and occurrence total are coalesced. Verified
destinations, retry limits and uncertainty follow the capacity path.
Unconfigured or branch deployments make no Slack calls. Impacted sections
are included as labels in the opening message only.

The existing capacity delivery ledger and producer remain separate. Other
producers can adopt this outbox without changing request latency or results.
