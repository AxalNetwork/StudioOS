## D567 — Event organiser: audience, decisions and agenda (#1173, 2026-10-06)

Migration 392 adds nullable decision reason, deciding member ID and time to
registrations, and room/link to agenda items. Existing rows remain unrecorded;
no actor or timestamp is backfilled. Decline reasons are optional, trimmed and
capped at 1000 characters. The roster exposes a decision maker's name, never
their email; existing host-only registrant/invitation contact fields remain.
Host/admin decisions and agenda/rule writes use the activity audit. Decision
metadata is stored in the same UPDATE as the status, including capacity-guarded
promotion, so another concurrent decision cannot leave a mismatched actor. Paid rows
still receive no check-in code before payment settles; capacity compare-and-set
checks remain on waitlist promotion.

The audience JSON adds `mode` (everyone, selected, invite_only), `roles`, and
`personas`, alongside the existing complimentary-ticket flags. Selected matches
a role OR a canonical recorded persona; invitations must not be revoked. Missing
mode on legacy rules means everyone. Strict validation rejects unknown keys,
values and empty selected audiences. The shared registration entry point applies
this independently of complimentary pricing, including public and invite flows.
A failed persona lookup fails the request rather than granting eligibility.

Agenda links are HTTPS without embedded credentials, up to 2048 characters;
rooms are trimmed up to 300. Reorder accepts exactly the event's full unique
positive integer ID set and batches event-scoped updates. Scoped edits return
404 before reading another event's item. UI search never reorders a filtered
subset. Accessible move buttons replace the canvas's drag-only handles.

Ops E1/E2/E4 use WorkspaceShell without editing #1156's shared frame. E3 uses WorkspaceShell on signed-in numeric detail paths and shows
only the caller's registration, with status, cancellation, decline reason and
waitlist position. Every list has loading, empty and Unreadable states, and absent
record values explain Not recorded. Queue and agenda lists paginate at 25 rows.
