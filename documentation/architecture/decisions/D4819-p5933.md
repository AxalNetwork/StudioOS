## D4819 part 5933 — The Licences console in a browser at 390px and 1280px, on fixtures (#4819)

Built for #5933. #4707 asked that "phone/narrow viewport behavior is covered by browser tests" and closed on 2026-11-09 without one, because a test was thought to need a deployed preview and a signed-in Super Admin (`D4707.md`). The item moved to #4819. The part number is the issue's, so it cannot collide with a board-numbered sibling. It is a test only: no page, Worker or migration change.

### The decision

The test needs neither a preview nor an account. `frontend/tests/e2e/licences_console_5933.spec.js` serves the built SPA (`docs/`) from its own local server, with the Workers assets binding's single-page-application fallback. It answers every `/api/*` call with invented fixtures (`page.route`): two licences, one administrator, their contract, deployment, requests, invoices, terms and history reads, and a signed-in Super Admin. Country pricing (D5017) answers that it cannot be read, since it is not under test. Every other origin is aborted, WebSockets are closed, and the clock is pinned to 2026-11-09 12:00 UTC (`page.clock.setFixedTime`), so the renewal line reads "in 22d" on every run.

It proves the page in a browser, not the Worker's answers. The fixtures follow the Worker's shapes, and the Worker's own tests pin those (D4707, D4819).

### What it covers, at 390 × 900 and 1280 × 900

1. **The ledger.** The counts line; on a phone the stacked list and no table, on a desk the nine-column table; the row link is the deep link `/admin/licences/:uid`. Enter on the row opens the licence in place (`?licence=`), with the breadcrumb's current page and Overview selected. The page does not scroll sideways, before or after.
2. **A licence from its URL.** `/admin/licences/lic_fr/access` lands on `?licence=lic_fr&tab=admins`, with Access and Administrators selected and the administrator in the panel. It does the same after a reload.
3. **The tab strip.** Six tabs; the page does not scroll sideways and the strip sits inside the window. On a phone each tab is inside the window and at least 44px tall. From the breadcrumb, Tab reaches the selected tab, a single Tab stop. ArrowRight, End and Home move focus and selection, and the URL follows (`?tab=terms`). The next Tab leaves the strip.
4. **One reason dialog.** Remove… on an administrator, opened with Enter, opens "Remove this administrator" (`LicenceReasonDialog` on `ui/Lightbox`). The reason field has focus and confirm stays disabled until the rule is met. Eight Tabs and eight Shift+Tabs never leave the dialog. Escape closes it and returns focus to Remove…, and nothing was written.

Each test also checks that no `/api/admin/licences*` call went unanswered by a fixture, and that no write was sent.

### Where it runs

The `visual` job of `.github/workflows/ci.yml` runs it right after the editor's visual suite. That job already builds `docs/` and runs the lockfile's `@playwright/test` with its pinned Chromium (`PW_CHROMIUM_PATH`, which `frontend/playwright.config.js` reads). The job runs on ready pull requests and pushes, not on drafts. It uses `frontend/playwright.config.js` with the file named, so `pr-preview.yml`'s preview job, which names its own specs, does not run it. Locally: `npm run build` at the root, then `cd frontend && npx playwright test tests/e2e/licences_console_5933.spec.js`.

### Tests

Eight tests (four at each width) pass locally against a fresh `npm run build`, and pass 40 of 40 with `--repeat-each=5` on two workers.

The mutation check rebuilt the SPA for each mutation, ran the spec, and restored the file: 12 mutations, 12 caught, 0 equivalent. The mutations were:

- `ui/Lightbox.jsx`: focus not returned to the opener, the Tab trap removed, and Escape ignored;
- `LicenceReasonDialog.jsx`: no initial focus on the reason;
- `LicenceDetail.jsx`: the phone strip as one unwrapped row, the desk strip wider than the window, no tab as a Tab stop, every tab a Tab stop, and the arrow keys dropped;
- `LicenceDeepLink.jsx`: the section ignored;
- `LedgerTable.jsx`: the table drawn on a phone;
- `AdminLicences.jsx`: a row click that opens nothing.
