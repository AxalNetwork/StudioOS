### Rebuilding it: blocked

1. **Network.** On 2026-11-27 the session proxy refused (CONNECT 403) every source host:
   `data.brreg.no`, `avoindata.prh.fi`, `avaandmed.ariregister.rik.ee`, `www.sec.gov`,
   `adviserinfo.sec.gov`, `reports.adviserinfo.sec.gov`, `mops.twse.com.tw`, `mopsov.twse.com.tw`,
   `www.tpex.org.tw`, `eic.ec.europa.eu`. The work stopped there, as the brief requires.
2. **Even with the network, it would not be the same run.**
   - No importer exists for four of the eight publishers (SEC Form ADV, MOPS, EIC, official website).
   - `scripts/import-register-companies.mjs` is offline: it compiles captured source projections against a
     baseline snapshot and the hold ledger. The 19 November projections, the post-cohort baseline and the
     ledger version the later pass used are all part of the missing package. A fetch today returns the
     registers as they are today, so a rerun selects different companies.
   - The second register pass's parameters (its per-country targets) were never recorded.
   - The 22 November audit already rules it out: "Do not rerun an import to manufacture historical receipts."
