## D6923 — Icon-only Email link in the header (#6923)

The owner asked for Email to match the neighboring heart and bell. The existing header link keeps its route, role gate and responsive visibility, and now draws an 18px mail icon with the same eight-pixel padding as those controls. Its visible label and outlined button treatment are removed; an accessible Email name and tooltip remain.

This is a frontend presentation change. No email capability, permission, endpoint or stored data changes.
