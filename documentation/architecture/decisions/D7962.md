## D7962 — Preserve rendered text in program presentation tests (#7962)

The program presentation tests compare the words produced by React server
rendering. Their local text readers now decode ampersands after quote and
apostrophe entities, so literal entity spellings remain literal text after
one decoding pass.

Each affected suite adds a round-trip through real React rendering. The
fixture includes ordinary punctuation, literal entity names, nested
ampersands, and words separated by nested elements. It checks the resulting
text against the original words instead of duplicating the reader's logic.

Validation covers the complete affected suites, the new assertions against
incorrect reader variants and the restored readers, and the decision and
folder documentation checks.
