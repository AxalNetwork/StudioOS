## D6282 — The investor's Library files Diligence, and still has no Benchmark kind (#6282)

- **Status:** built 2026-11-14 by S25 for #6282 (tracker #5994).
- **Number:** D6282 is this issue's number (D4106). No migration:
  `research_documents.kind` is free text, and the Worker's set is the only check.
- **Code:** `cloudflare-worker/src/routes/research.ts` (`KINDS`),
  `frontend/src/pages/research/LibraryZone.jsx` (`kindOptionsFor`, `hasClients`),
  `frontend/src/workspaces/investorZoneFilters.js` (`research/library`).
- **Tests:** `cloudflare-worker/test/research_library_diligence_d6282.test.ts`,
  `frontend/test/research_library_investor_d6282.test.mjs`.

### 1. Diligence is a kind

The Worker's kind set gains `diligence`. Upload still coerces anything outside
the set to `document`, and the metadata edit still refuses it with
`invalid_kind`. The investor's `Diligence` chip is now live and filters on that
kind.

### 2. No Benchmark kind (the owner, 2026-11-14)

The issue's scope also named `benchmark`. The Benchmarks chip is disabled on
purpose with a recorded reason: a benchmark is a row in Benchmarking, carrying
its own source and sample size, not a document in this library. Adding the
kind would have reversed that. The owner chose to keep the position, so there
is no `benchmark` kind, and the chip stays off with its reason. `Stale` also
stays off with its reason.

### 3. Kinds by licence

An investor is offered Document, Report, Primary, Legal and Diligence. `My
playbook` and `About a client` are not offered, because an investor has no
clients. Founder, advisor and partner keep exactly the six kinds they had, and
are not offered Diligence. The edit list always includes a document's current
kind, so opening the editor never reclassifies a document on its own.

### 4. No client wording for an investor

No client can open a file to an investor, since `advisor_client_grants` opens
a project to an advisor. So the investor's empty state, the Library-and-Ask
pair note and the shared-document panel no longer mention clients. The stat
tiles were already the founder's set and had no client wording.
