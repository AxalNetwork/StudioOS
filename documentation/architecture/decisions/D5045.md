### 2. Focus, which did not exist before

HQ Team's actions are inline forms, not modal dialogs. Before this decision no form managed focus: opening one left
focus on a button the form had just replaced, and closing one dropped it on the page. `actionFocus.js` now gives
every form the same four behaviours:

- an action form takes focus on its first field when it opens;
- Escape closes it, except while it is submitting, because a request in flight still has to show its answer;
- Cancel or Escape returns focus to the button that opened it;
- a finished act (signed out, unbound, moved) moves focus to the line that now says what happened. That line takes
  `tabIndex={-1}` so it can hold focus.

Focus is asked for in the event handler and applied after the render that draws its target, because the opener is
not on screen while its form is open.

### 3. Which source guards stay

A source guard stays where it protects something a render cannot show:

- where a call lives (one supervision read; Support mounted only in the branch search);
- which route literal a client method names;
- that no file spells a branch host or the redeem path;
- the split into files that `_hqTeamSource.mjs` lists.

The regexes that only restated a behaviour are removed: the unbind and support reason floors and trimming, the
`window.open` of the route's URL, and the support toggle's source rule. Their rendered replacements are in
`hq_team_behaviour_5045`.

### 5. Considered and not built

- **A browser end-to-end suite for the eight operator journeys.** The repository's Playwright jobs need a deployed
  preview Worker with seeded HQ and branch accounts, and HQ Team's journeys span two Workers (HQ and a branch). The
  render-level tests above drive the same components against the same answers without production data. A
  multi-Worker browser fixture is a larger piece of infrastructure than this audit package.
- **Making the action forms modal dialogs.** The issue asks that the focus behaviour be tested, not that the forms
  change shape. Inline forms keep the table in view.
