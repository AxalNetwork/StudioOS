## D916 — Event write contracts and honest desk analytics

Issue #2699, part of #2368. No migration.

Create and edit validate event types with `isEventType` from the canonical
twelve-type registry. The compatibility `EVENT_TYPES` export aliases that
registry. Unknown types keep the existing create fallback/edit-ignore behavior.
Both writes accept `in_person`; `physical` remains valid for historical rows.
The public Format filter already classifies both values as In person.

Create validates `audience_rules_json ?? audience_rules` with the same
registration-rule validator as edit. Omitted rules default to everyone; invalid
rules return 400 before an event is inserted. Selected roles/personas,
invite-only mode and complimentary flags remain stored. Advisor eligibility is
unchanged and awaits O-ADV.

`GET /api/admin/events/analytics` retains its admin gate and 200 partial-read
contract. A failed summary block or event-row block is `null`, with its name in
`unreadable`; the independent successful block is retained. Successful empty
reads return zero counts and an empty list, with `unreadable: []`. A missing
aggregate row or an unsuccessful/missing D1 result is a read failure.

Each analytics event includes `ends_at`. Conversion remains attended divided
by active registrations, rounded to two decimal places, but is null until the
recorded end has passed. With no end, the boundary is 24 hours after start.
Offset-free timestamps are interpreted as UTC. Invalid or non-string dates cannot abort the portfolio read; their conversion
stays null. Events with
no registrations have no conversion; a finished event with registrations and
no attendance has a measured zero. Capacity utilization is unchanged.

Only the analytics handler changes in the admin router. Other registrations,
review/write handlers and frontend production files are outside this part.
Regression coverage exercises real SQLite writes, public serialization,
independent analytics failures, empty results and time boundaries. The type
parity guard also pins the create/edit validation wiring.
