## D546 — The Research rebuild's seven canvases land in design/incoming, and the raw Founder Research twin leaves

**The canvas the Research tasks cite is now a file in the repository, so a
slot on any account can build to it. The calls that settle how it is built
are recorded with it.** Slot S01, for the epic #1077 and its tasks #1079 to
#1082, on 2026-10-05. No migration, no route, no `frontend/src` change.

**Why now.** #1079 to #1082 carry `needs-design` and link
`https://claude.ai/artifact/NzuiaEyGymWqABC1kd8Nyj`, a canvas Session 1 drew
from what the platform records. On 2026-10-05 the owner asked to "build
anything in the backend that is missing and wire the wireframes". That is the
approval AGENTS.md's "Missing UI" step 4 waits for: Session 1 commits the
export under `design/incoming/` and the screens become buildable. A link
alone was not enough, because the slots that build these pages run on other
accounts and cannot open an artifact this account owns.

**What landed.** The canvas's seven page files, byte for byte, as
`design/incoming/Research · <page>.dc.html`: Main, Companies, Company,
Markets, Sector, Geography and Funds. They were already in the repository's
canvas format (the shared `design/canvases/shared/support.js` runtime, no
inlined fonts), so `scripts/read-canvas.mjs` had nothing to rewrite. The one asset no repo file
resolves is a 24px header logo, left as its artifact path, as that script
would have.

marked deleted.

the recommendation and not stop for questions. These are reversible, and
each is written into the README section the builders read:
