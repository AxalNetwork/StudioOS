## D8519 — The model inventory is generated, and a model with no price or no caller fails CI (#8519)

### Why

Model ids are spread across the Worker: Workers AI ids in `services/ai/` and
`services/aiRouter.ts`, the outside providers' tables in `services/ai/catalogue.ts`,
the agent accounts' models in `wrangler.toml`, and a direct Anthropic route with
its own price table. No list said which models production can call or which has a
price, so a new id without a price, or a price for a retired model, was found by a
user.

### Decision

`scripts/build-model-inventory.mjs` (rules in `scripts/lib/modelInventory.mjs`)
reads the repository as text and writes `documentation/architecture/MODEL_INVENTORY.json`:
id, provider, the files and `wrangler.toml` vars that name it, and the price entry
that holds it. It is generated and never committed (D5612): gitignored, written by
`scripts/build-generated.mjs`, and `--check` fails when the render is not
deterministic or git tracks the file. It makes no network call and no model call;
whether a model still exists at its provider is #8508's live layer.

`--check` (guard `check-model-inventory`) also fails on:

1. **unpriced** — an id the code can call that no price entry holds;
2. **stale** — a price entry for an id no code calls;
3. an allowlist entry that no longer matches a gap.

What counts as a call: a string literal equal to the id in Worker source (comments
stripped), a `*MODEL` var of `wrangler.toml`, or a read of a provider table through
its accessor. The catalogue and `aiCatalog.ts` list models without calling them,
and the job table's `notOffered` block names models the Worker refuses, so none of
the three counts. A price entry is a Workers AI catalogue row with a price, a
provider-table row with its rate, or a key of `assistant.ts`'s `PRICING`.

### The allowlist (reviewed gaps, with reasons in `lib/modelInventory.mjs`)

- Deprecated catalogue rows (seven today) still priced so recorded runs keep their cost: exempt from `stale` by status, not by id, because `check-model-coverage` forbids naming a deprecated id under `scripts/`.
- `@cf/cloudflare/clairic`: a priced beta the job table lists as not offered.
- `@cf/google/embeddinggemma-300m`, `@cf/openai/whisper-tiny-en`: named in `shapes.ts` and
  `sttFormats.ts`; unpriced, so the router refuses them.
- `openai/gpt-5.3-codex` (`OPENAI_MODEL`): priced only by the owner's `AGENT_OPENAI_RATES`,
  whose value is not in the repository. Owner: confirm the rates are set in production.

No price and no production behaviour changed.
