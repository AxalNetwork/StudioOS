## D581 — The Spin-Out pitch deck has eleven slides, and every count says so

**The Lab's pitch deck is eleven slides, the `SLIDE_META` array in
`lib/pitchDeckViewModel.js`, and every surface that states the deck's length
now reads `SLIDE_META.length`.** Slot S08, issue #1208, 2026-10-06, from the
owner's answer on #1009 (Session 8's line "Thirteen slides or eleven"). No
migration.

### The pick

- **Eleven.** D360 aligned the Lab's copy with the eleven-slide `SLIDE_META`,
  which is the order of the `axal_spinout_demoday` template. Problem carries
  the validation funnel, and the Ask carries the cap table.
- **The canvas's thirteen is a documented departure.** The Pitch Deck Builder
  canvas draws thirteen, with separate Validation and Cap Table slides. They
  are not built. Thirteen would mean splitting two slides back out in:
  - the template;
  - the Worker shaper (`services/decks/axalSpinoutDemoDay.ts`);
  - the PPTX builder (`decks/spinout/buildDeck.js`);
  - `SpinoutSlideEditor`.

  That needs the owner's word and its own issue.

### What still said otherwise, and what changed

| Surface | Said | Now |
| --- | --- | --- |
| `lib/spinoutBrief.js` `DELIVERABLES` | "12-slide pitch deck" | `numberWordCap(DECK_SLIDES)`-slide pitch deck |
| `lib/spinoutBrief.js` `TOOL_EXAMPLE_READS.deck` | "12 slides from recorded data" | the same, from `DECK_SLIDES` |
| `lib/spinoutLabArsenal.js`, the deck blurb | "Eleven slides from your own data." (typed) | from `SLIDE_META.length` |
| `components/PitchDeckModals.jsx`, the export sheet | "Rendering 11 slides" (typed) | `{SLIDE_META.length}` |
| `decks/templates/index.ts`, the `axal_spinout_demoday` row | `'11 slides · …'`, `slide_count: 11` (typed) | both from `SLIDE_META.length`. The description is the constant `SPINOUT_DECK_DESCRIPTION`, because `check-deck-templates` reads each row up to its first brace and a `${}` inside the row would end it early. |

- **`DECK_SLIDES`.** `spinoutBrief.js` exports `DECK_SLIDES =
  SLIDE_META.length`, so the brief names the deck's length once.
- **`numberWord` and `numberWordCap` moved to `lib/numberWords.js`.** The
  brief and the arsenal both spell the count out, and neither imports the
  other. The brief re-exports both, so `SpinoutLabBriefPage.jsx` is
  unchanged.
- **The order of evaluation.** `DELIVERABLES` is built when the module loads.
  If it had called a `numberWord` declared further down the same file, it
  would have read `NUMBER_WORDS` before its `const` was set.
