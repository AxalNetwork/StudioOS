## D6288 — Share the saved investor profile across Account cards (#6288)

Account › Security and privacy reads the investor profile once and shares
the result across Investor Signals, My thesis, and Investor Thesis & Matching.
A failed read offers a retry against the same shared state.

Each editor keeps its own unsaved fields. A save combines those fields with
the latest saved profile so the full-replace PUT preserves work from the
other cards. The cards allow one PUT at a time and use the returned profile
as the basis for the next save. Only the Investor Signals switch sends
consent, so a thesis save cannot reverse a separate opt-out. The Worker
already preserves consent when that field is omitted.
