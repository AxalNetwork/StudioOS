### 1. "Used up" is in the records (D894's "Part 1 puts used up in the records")

**One rule.** The engagement read's rule (D895) moved, unchanged, from `routes/decks.ts` into `services/deckShareUse.ts`, as `deckShareMetrics` and `LEGACY_SHARE_NO_VIEW_LIMIT`. `decks.ts` re-exports the same function, so its callers and D895's tests are untouched.

A link is used up when either holds:
- `used_at` is set;
- its views reached its cap.

A link has no cap when `view_limit` is NULL, or carries the old "unlimited" sentinel that links from before migration 549 still hold. An unknown count is not a measured zero.

**The list** (`services/raiseCycle.ts` `pitchRecords`) reads `used_at` and `view_limit` and orders a link's state as follows:
1. revoked;
2. expired;
3. used up;
4. active.

A used-up link's expiry cell is `{ text: 'Used up', tone: 'muted' }`. The State filter gains `used_up`, and Active no longer lists used-up links. The answer covers every version's links, not only the current version's newest 50 that the engagement read covers.

**The link's own record** (`services/records/raise.ts`) uses the same rule, and its pill reads "Used up". Revoke is still offered on a used-up link (withdrawing it marks it Revoked).

**The studio** (`pitchStudioModel.js` `linkRows`, `PitchStudio.jsx`):
- A link the records call live is live.
- The engagement read's `exhausted` can only make a current-version link more up to date: if the link was used up after the records were read, it reads Used up.
- The "views left unknown" state is retired. That state was D894 review R1's answer to records that could not say used up, and it covered three things that are now gone: the row's "Views left not read", "Reading views left…" and "Views left could not be read", and the second wording of the Withdraw dialog.
- Withdraw is drawn on every live link.

### 2. Time on deck is served in seconds

**Storage was already in seconds.** `deck_share_views.read_seconds` holds seconds (capped at 7,200, `decks.ts`). Only the serving rounded to whole minutes, so nothing about storage changes.

**Served as seconds.** `timeOnDeck(seconds)` (`raiseCycle.ts`) returns `{ text: 'm:ss', seconds }`. When no time was reported it returns `null`, never "0 min":
- the list's Time on deck cell;
- the record's Time on deck fact, whose reason reads "No read time recorded", or "Not opened yet" for an unopened link;
- each view's line in the record's Views section.

D894 drew "[0:66]" as 1:06, and 66 seconds is served as 1:06.

**The studio** draws the served seconds through `mmss`. A cell without seconds, including an old "N min" string, reads "Not recorded".

### 3. Sources in Present and the HTML file read the bindings

D896 stores a binding on each figure (`{ source_key, record_ref, as_of, grade, snapshot_hash }`). D897's New deck writes one on each metric block and on each read-only `auto` field, and the editor writes one on each block it binds.

**The HTML Sources appendix** (`services/decks/offlineHtml.ts`) is built by `sourceLines(slides)`:
- It walks `bindingsOf` (`services/decks/sources.ts`), so it covers slide, field, block and chart-series bindings.
- It lists each bound figure once per card, so the block and the field that hold the same slot appear once.
- Each line names the card, the slot's label and the slot's module from `DECK_SOURCES`, then the grade and "as of <day>".
- A figure bound to a slot that nothing filled reads "Not recorded on StudioOS".
- A key that no slot names is listed by the key itself, with "StudioOS" as its module.
- A version with no binding keeps the sentence "This version does not record where its figures come from".
- The "Written with AI help" line stays.

**Present** (`presentExportModel.js` `cardOf`, `PitchPresent.jsx`):
- A bound `auto` field is drawn as a figure, its label kept apart from its value, and no longer as a line of text.
- A bound metric block that the fields do not already show is a figure too. This covers a block the founder placed in the editor.
- "Show sources" draws each figure's own line through `sourceOf(binding)`: "Source: <area> · <grade> · <day>". A figure bound to an unfilled slot reads "Source: Not recorded on StudioOS". A figure with no binding still reads "Source: Not recorded".
