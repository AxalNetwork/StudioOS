## D936 — The admin page header: one header for every admin page, in place of the Admin Console's title and dropdown (#2375)

- **Status:** decided and built by S21, 2026-10-24 (#2375, under #2711), in draft PR #2742, which also carries D937.
- **Canvas:** the owner's "Admin page header", SHL1–SHL9 with SHL7 as two boards (artifact `KhVPwtFC4WkDiPYCFmSdjv`). It is one canvas, committed as `design/incoming/Admin page header.dc.html`.
- **Basis:** `origin/main` at `cc35435fd5`. The map is `documentation/audits/ADMIN_PAGE_HEADER_MAP_2026-10-24.md`.
- **Migration:** none.
- **Why:** many admin tools still sit inside `AdminPage.jsx` under an "Admin Console" title and a dropdown of fourteen unrelated tools (#2375 "The page today"). Every page issue (#2366 to #2390) builds on one header and one route map. #2375's route map is the source of truth for every address; this decision does not restate it. It records what the header is, what ships now, and the parts that move the rest.

### 1. What the header is

`frontend/src/ui/AdminPageHeader.jsx`, exported from `ui/index.js` with `HeaderTab` and `useMovedNotice`. Top to bottom, as SHL1 draws it:

| Piece | What it does |
|---|---|
| Breadcrumb | "Section › Page" in Roboto Mono 11 px, uppercase. The section is a link to its overview. A section's own overview has none. On a phone it is a back link, "‹ Section", at least 44 px tall (SHL8). |
| Title row | The h1 at 24 px (20 px on a phone), its pills, and on the right the page's actions. At most one primary button (SHL rules). |
| Line | One muted line, what the page is for. An optional facts strip under it, for program pages. |
| Scope chip | "HQ-held accounts · axal.vc", with SHL1's tooltip. Admin shell only. |
| Moved notice | Only after `?moved=<key>` from an old address. Lavender, an info icon, the sentence and Dismiss. It is a polite status message (`role="status"`, `aria-live="polite"`). Dismiss drops `moved` from the address, keeps the rest, and returns focus to the title (SHL3). |
| Tab bar | A `nav` named for the page, of `HeaderTab` links. Each is a literal `to`, so the reachability walk finds every door. It scrolls sideways and never wraps. The open tab is ink with a 2 px violet underline and `aria-current="page"`. |

- **A tab's count says one of four things,** never 0 for a missing value: a number that was read; a dash whose tooltip says why ("Not recorded: …" or "Could not be read: …"); an amber dot with "waiting" for screen readers; or a short grey bar while reading (SHL4, SHL6).
- **The header renders at once.** Its title, line and tabs come from the page, never from a read. A failed read never blanks it.
- **Nothing else sits above the content.** No "Admin Console" title, no section dropdown, no shield icon and no Trash link (SHL "DO NOT DRAW").
- **The "More" menu is not built.** SHL1 draws one with "Copy page link" and "Download (CSV)". No page has a CSV to offer through it yet, and a menu with one generic item is not worth its focus trap. It comes with the first page that needs it (part 1).

### 2. What ships now

- **Its first page is the Spin-Out Lab** (D937, #2374), which leaves the Admin Console in the same PR. The Lab draws the crumb, both pills, the line, the facts strip, the scope chip, the moved notice and seven tabs with their counts.

### 4. Who sees what

The header shows what the page gives it. The scope chip is the Admin shell's: a Super Admin's HQ pages do not pass it. An Admin on a Super Admin page sees SHL7a's notice, not the page; that card's redraw is part 3.
