## D6243 — Fund zones on a phone: registers and ledgers as stacked rows, actions within reach (#6243)

- **Status:** built by S23, 2026-11-15. Frontend only: no Worker route, no migration.
- **Boards:** Investor Fund v2, FV14 "Phone 390" (`design/incoming/Investor Fund v2 · Boards.dc.html`, D6229). IFD14D draws call lines as cards; IFD14F the ledger as cards; IFD14G the archive as cards; IFD14B Add LP as a sheet. All have 44px targets.
- **Code:** `frontend/src/pages/investor/InvestorFund{LPs,Calls,Accounting,Reporting}.jsx` and their four stylesheets.
- **Test:** `frontend/test/fund_zones_phone_6243.test.mjs`.

### What changed

- **A row is a card below 640px.** The LP register, the comms log, call lines, the wire trail, the call preview, capital accounts, LP capital and the report archive stop being wide tables. Each row stacks as a card:
  - the untitled first cell is the row's title;
  - each other cell is one line, with its column name on the left from `data-label`;
  - the header row stays in the document for screen readers but is not drawn.

  This is `FundLedgerPanel`'s `LedgerTable` pattern, done in each zone's own stylesheet, so the desktop tables are unchanged.
- **Nothing forces the page wider than 390px.** The 620, 650, 660 and 780px minimum widths are lifted at phone width, and long values wrap. The Accounting sideways scroller is switched off.
- **Call line actions are a full-width row of 44px buttons.** Record receipt comes first, filled, on its own line. Draft reminder and Log as sent share the line below.
- **The four forms are one column with 44px fields and full-width buttons:** Add LP, New call, Record receipt and Log as sent.
  - Inputs are 16px, so iOS does not zoom.
  - Add LP's note or error moves above its buttons.
  - Error text wraps in place.
- **Targets:** the refresh button and the fund picker are 44px on every zone. On an LP row the type shows as its select only; the text copy is kept for screen readers.

### Not done here

- **Menu or row.** The board draws a menu ("More…") for the two follow-up actions. Without a menu primitive in these pages, the acceptance's other option, a full-width row, is used.
- **The shared ZoneToolbar.** Its chips and actions already wrap without clipping, but they are under 44px. They are the toolbar's own sizing (`ZoneToolbar.jsx`, used by every workspace), outside this issue's files.
- **Pending the owner.** D6229 (a) to (d) are untouched: these are layout changes to the zones as they are.
