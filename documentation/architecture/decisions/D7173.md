- **Builds on:** D7038 (what the canvas decides), D670 (the two signals reads Research keeps), D1317 (the one detail `Sheet`), D5129 (the platform's state chips).

### What the Worker does now

- `services/signals/engine.ts`: only a missing table (an environment the signals migration has not reached) or a store no ingest run ever wrote a signal row to returns the example set, labelled `data_state: "illustrative"`. Any other D1 error on the signals, the company map or the company roster throws `SignalsUnreadableError`, before the KV write, so nothing is cached.
- `routes/signals.ts`: `GET /api/signals` answers that error with `503 { error: "signals_unreadable" }` through `refuse`, the D1 text logged and never sent.
- An ingested store with no active signal, or a live list a filter empties, is `200 { data_state: "live", signals: [], total: 0 }`.
- When the signal rows read but `signal_evidence` does not, every signal carries `evidence_state: "unavailable"`, `evidence_items: []` and `confidence_score: null` (ranking keeps it null instead of scoring the empty list 0), and the response is not cached. Otherwise each live signal carries `evidence_state: "recorded"`.
- The optional `sector_slug` is not added. The frontend matches a tracked sector by exact name, and would prefer a `sector_slug` if the Worker sends one later.

### What the page does now

- `LatestSignals` moved out of `MarketDirectoryZone.jsx` into `pages/research/RankedSignals.jsx`, with its pure readings in `rankedSignalsRead.js`. `MarketDirectoryZone.jsx` re-exports it and passes the sectors it already reads.
- Confidence prints `Math.round(score)` and "%": 82 reads 82%, a measured 0 reads "0% · no evidence recorded", null or a value outside 0–100 reads Not recorded (an out-of-range value is logged), and unread evidence reads Unavailable. The meter is neutral grey.
- Five card states, each with its own words: live (count "3 of N"), live but empty (None, no Retry, no examples), illustrative (a labelled example set, "View example evidence", example evidence never links out), loading (skeleton rows, no count) and "Could not load signals" with Retry.
- View evidence opens the shared `Sheet` at 560px, a bottom sheet below 640px: facts, what confidence measures, Why now, evidence newest first with an "Open source" link for an http(s) URL or the recorded citation as text, and Open sector profile only for an exact-name match. `?signal=` sits beside the directory's own keys; a sheet opened from the card closes by stepping back, so Back and ✕ agree, and focus returns to the same View evidence.
