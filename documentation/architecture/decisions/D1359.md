## D1359 — Record a Session: "Create the meeting for me" for Microsoft Teams

- **Status:** decided and built by S21 for S1, 2026-10-28, at the owner's request ("Create the meeting for me option is missing for Google Meet and Teams meeting"; "Yes, build it").
- **Migration:** none.
- **Builds on:**
  - the Microsoft calendar connection (`microsoft_oauth_tokens`, `Calendars.ReadWrite`; D1209 is its latest part);
  - D1346: Create the meeting for me on Zoom and Google Meet;
  - D1358: a meeting is captured by the platform, never by the browser.

### 1. The rule

`POST /founder/validate/meetings/instant` takes `provider: 'teams'`. It uses the member's own Microsoft calendar connection: no new Microsoft app, scope or table.

1. Microsoft calendar not configured on this deployment (`microsoftOAuthAvailable`): 503 `provider_unavailable`, "Create it in Microsoft Teams and paste the link."
2. The member's refresh token is exchanged for an access token.
3. Graph `POST /me/events`: an event starting now, in UTC, for the chosen duration, with `isOnlineMeeting: true` and `onlineMeetingProvider: 'teamsForBusiness'`.
4. The answer is `201 { provider: 'teams', join_url }`, where the link is `onlineMeeting.joinUrl` on `teams.microsoft.com`, `teams.live.com` or `teams.cloud.microsoft` over https. Nothing else from Microsoft is returned.

**A work or school Microsoft 365 account is needed.** A personal account's event comes back with no Teams link. Axal deletes that event again so it does not stay in their calendar, and answers 409 `teams_personal_account`: create the meeting in Teams and paste the link.

### 2. Refusals

Each is one of our own codes with our own words; no Microsoft text, token or event id reaches the client.

| Code | Status | When |
|---|---|---|
| `teams_not_connected` | 409 | No Microsoft connection for this member |
| `teams_reconnect` | 409 | Token refresh refused (400, 401), or Graph 401 or 403 |
| `teams_personal_account` | 409 | The event was made without a Teams link (deleted again) |
| `teams_create_failed` | 502 | Any other Graph refusal, or no event and no link |
| `teams_unreachable` | 503 | Network failure, timeout, 429 or 5xx |

### 3. Capabilities and the dialog

- `GET /meetings/capabilities`: Teams is `available` when the bot runs on Teams or Microsoft is configured; `connected` and `can_create_meeting` follow the member's Microsoft connection. Its notes say creation needs a work or school account, and that a Teams transcript import is not built.
- **Record a Session › Call › Teams:** "Create the meeting for me" is offered, with the note "Uses your Microsoft calendar connection, and needs a work or school Microsoft 365 account. A personal account: create it in Teams and paste the link." Not connected, it reads "Connect Microsoft to create the meeting here". A refusal keeps the member's own paste field and shows the Worker's message.
- **Capture is unchanged (D1358):** a Teams call is captured by Eadwyn AI or not at all. Creating the meeting does not import it.

### 4. What is not claimed

- No live Graph call was made from this change. Every Microsoft request in the tests is a mocked `fetch`.
- A Teams transcript import after the call is still not built.
