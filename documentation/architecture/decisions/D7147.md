### The estimate

The figures use Cloudflare's published Workers Paid prices, read on 2026-11-18. The sources are listed in `STAGING.md`. Included allowances are per account and shared with production. The range runs from **$0.00 a month**, when production leaves room in every allowance, to **about $3.70 a month**, when every staging unit is billed at the overage rate. That assumes 1,500 to 4,500 releases a month. No resource has a fixed monthly fee.

Two costs can jump:

- Durable Object duration is billed in whole millions of GB-s. A step is $12.50, so the worst month is about $16.
- Workers AI is billed to the account if the stub is off. `[env.preview.vars]` allows the advisor $100 a day.

The recommended ceiling is $20 a month, with a Cloudflare spend alert at that figure.

### Isolation rules

1. **Proof is the D4566 preflight, by identity.** A hosted step starts only after `check-preview-isolation.mjs --observed` answers `isolated`. Its JSON is attached to #7147.
2. **workers.dev only.** **Finding:** `[env.preview]` declares no `routes`, so Wrangler resolves the top-level custom domains for it. Wrangler 4.158 warns that `deploy --env preview` "will reassign these custom domains away from the top-level Worker". `npm run deploy:preview` would therefore move `axal.vc` and `app.axal.vc` off production. The D4566 preflight does not see this: `declaredBindings` reads `[env.preview.*]` tables only. This PR adds `routes = []` to `[env.preview]`. `preview_isolation_4566` now resolves the config as `wrangler deploy` does, and fails if preview carries any route or production loses its custom domains. The provisioning token has no zone permission, as a second guard.
3. **Internal secrets only.** The `INTERNAL_SECRETS` allowlist applies. `JWT_SECRET` and `SCORING_HMAC_SECRET` are required, and are fresh values. Every mail, payment, messaging, model, OAuth, provider, Cloudflare-API and cross-deployment secret stays unset. `STAGING.md` lists them.
4. **The off switches stay off.** These are `AGENT_ENGINE`, `MEETING_BOT`, `MCP_SERVER_ENABLED`, `API_KEYS_ENABLED`, `ROUND_CALLS_ENABLED`, the WhatsApp and Telegram switches, and the empty gateway slugs.
5. **The stub on every deploy.** Each deploy passes `--var AGENT_INFERENCE_STUB:deterministic`. That variable stays out of `wrangler.toml`, under D4594's test.
6. **The browser is unused.** Browser Run is account-wide, and the preflight refuses `browser: "used"`.
7. **Two tokens.** A one-run provisioning token (Workers Admin, D1, KV, Queues and R2 edit, no zone) is revoked after use. The standing staging token is Workers Editor on `studioos-preview` only, plus D1 Edit, with no zone permission. If D1 Edit cannot be scoped to one database, the staging token can write to `studioos-db`. That gap is the owner's to accept or refuse.
