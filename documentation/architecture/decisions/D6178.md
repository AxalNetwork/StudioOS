## D6178 — Share recorded ARR and net revenue retention (#6178)

Share an update now carries the existing `arr` and `nrr_pct` snapshot
columns as `arr` (USD) and `net_retention` (percent). `net_retention` is the
canonical Report Figures key, with the existing `nrr_pct` alias; no new
storage column or parallel `nrr` metric is introduced. `metrics_json` already
holds a list, so no migration is required.

`periodSnapshots` selects the two existing columns with date/ID ordering.
`buildMetrics` takes each latest recorded value inside the selected period,
with its stored source and as-of date. Missing values stay null with a
reason; a recorded zero stays zero. It never annualises MRR or infers
retention. It reads the recorded ARR column verbatim, preserving the existing
collector's policy; worked-out KPI policy belongs to #6104.

The existing founder snapshot endpoint and KPI fields already accept ARR and
NRR. The existing Share an update Metrics step draws the returned list, so
new duplicate founder inputs are unnecessary. The normal snapshot endpoint
records typed values as manual and refuses forged connector attribution.
Both the founder's Metrics step and the investor tiles label manual/typed
values as the founder's own figure. NRR is a percentage level, without the
growth-only plus sign/month-on-month qualifier.

Save validates source, value, unit and date against freshly read period
snapshots. An unproved browser claim becomes typed. ARR/retention with the
wrong unit, unknown keys, and source-less stored values are refused/withheld.
The existing send lifecycle stores the list; later snapshot changes do not
rewrite sent figures. Report Figures retains its existing column mapping,
and parity tests keep the two reporting paths aligned.

Deal Traction reads only the existing NDA/deal/sharing-authorized submitted
update history. No private project snapshot is read by the investor route.
Drafts, another venture, unshared rows and another recipient's explicit grant
remain excluded. An empty newest shared revision stays authoritative. A
failed history read is Unreadable, including the top-level ARR/retention
fields, rather than pretending that no figure was recorded.

The canonical two keys join TRACTION_TILES and its dated source-bearing
series. Missing ARR retains the “MRR is not annualised” explanation. The
route's old read-only `nrr` field remains a compatibility alias for its new
`net_retention` field; no saved metric accepts `nrr`.

The tests exercise actual founder snapshot entry, source refusal, context,
save, send and authorized investor reads on migrated SQLite; source proof,
zero/absence, unit rejection, period boundaries, Report Figures parity,
sent immutability, sharing/NDA isolation and unreadable reads are covered.
Client tests exercise canonical tiles, attribution, dates and the existing
Metrics step. Commands, mutation results and actual full-suite exit are in
the PR. No production data or deployment is used for acceptance.
