### 1. One read: `GET /api/decks/:id/usage`

The read is `routes/deck_usage.ts` and `services/decks/usage.ts`. It runs no model and writes no row. Anyone who may read the deck (`projectOwned`, read) may call it.

- **`estimated`.** It is `estimateDeck`, not a second pricing path.
  - The counts are the deck's cards, each area mapped to the grid element that fills it (`deckCounts`):
    - a title band, or the card's title, is `title`;
    - a text block, or an area left empty for the run to fill, is `body`;
    - a chart is `chart`, a table is `table`, a graphic is `flow` and an image is `photo`;
    - speaker notes are `speaker_notes`.
    - A metric, video, audio or link block runs no model and is not counted.
  - Each element is priced on the model `elementModelFor` resolves for this deck and member, at the member's multiplier. Each line is therefore the same quote line `GET …/element-models` gives, times its count.
  - A line that cannot be priced makes the total unknown: "Could not be read", never $0.00.
- **`spent`.** It is the ledger: the sum of `charged_microusd` over the runs recorded against this venture's deck, with their guard rows.
  - A deck run is a row whose `record_ref` is `deck:<id>` for any version of the venture's deck, or `project:<id>` on the Pitch deck rail page.
  - A row whose charge is not recorded makes the sum unknown, not smaller.
  - A deck with no runs has spent `$0.00`, which is a recorded zero.
- **`units`.** These are the per-run prices of a text area (`body`) and an image (`photo`) on the resolved models. The rail divides the top-up balance by them.

### 2. The rail

No new rail UI.
- The client is `frontend/src/lib/api/deckUsage.js` (`deckUsageApi.usage`), re-exported by one line in `api.js` (D527).
- `deckV2Adapter.deckUsage` is swapped (`SWAPPED`). It returns `{ estimated, spent, units }`, with `estimated` and `spent` formatted in dollars. A figure the Worker could not read is `null`, and its row reads "Could not be read".
- `deckRailGroups.deckRail` gains one row, "About [40] text areas or [12] images" (`plainUnits`). It takes the balance from `/api/ai-budget/me` (`balance_microusd`) and the deck's unit prices.
- The rows only read: no action, no prompt control. Dollars are shown, never credits.
