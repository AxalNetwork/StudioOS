## D7116 — Wellness in Admin Programs links to the personal Wellbeing workspace (#7116)

The global program catalogue lists Wellness in Access. Its overview links an eligible signed-in Administrator to their own existing `/wellbeing` workspace through the Wellbeing module. The existing header heart continues to open that same member experience. The new registry entry starts as proposed with member enrolment closed and a draft playbook. Founders and Administrators retain their existing personal workspace access.

The migration reuses an existing global Wellness or Wellbeing record when present. An occupied key stays with its owner. Studio-specific records, existing playbook content and versioned package composition keep their existing meaning. The catalogue module supplies navigation only. It reads no journal, provider booking or private health data.

The independent daily, weekly and monthly journal, opt-in recommendations, group sessions and public offline presentation have separate delivery criteria in #7117, #7118, #7119, #7120 and #7121.
