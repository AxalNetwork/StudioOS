## D6046 — Raise Overview V2 on desktop, boards RA-01 to RA-09 and RA-13 (#6046)

- **Status:** built 2026-11-22 (#6046, Raise V2 build 2/5, under #4863). Frontend only; the read is D6045's.
- **Canvas:** `design/incoming/Raise v2 Page.dc.html` and `Raise v2 · Boards.dc.html` (D4863), boards RA-01 to RA-09 and RA-13.
- **Read:** `GET /api/cycles/raise/overview` as it stands on main: the seven cards (D663), `next_steps` and `connectors` (D1610), `stage`, `primary_action`, `investor_activity` and the Pitch card's `pitch_state` (D6045). No new route, no client method, no migration.

### Choices this build makes

1. **Raise draws its own Overview, as Build and Grow do.** `pages/cycles/RaiseOverview.jsx` is `Overview` in `defs/raise.jsx` (a `lazyStep`), so `CycleRoute.jsx` gains no import. The shared `CycleOverview.jsx` is unchanged and still draws Validate; the page reuses its `CycleHeader` (with #5081's stage navigation, RA-12) and `CycleCard`. The shared branch of `CycleRoute.jsx` lost the Raise-only `lead` and `ask` props it could no longer reach, and the `RaiseLead` import with them (removing an import is allowed by the D5615 freeze).
2. **The primary action is the Worker's `primary_action`** (`raisePrimaryAction` in `cycleModel.js`), on the Overview only. None while the read loads, for a staff read, for an unreadable rule (the page then says why) or for an address that is not in-app. Module pages keep `defs/raise.jsx`'s `action` (Build your deck) and their own per-tool actions; that is #5081's.
3. **No headline figure row.** The V2 Overview has none; the four figures stay on the phone root and the module pages.
4. **The page data is the read as adapted** (`data`, which a card's Retry updates), so an unreadable card retries alone and the others stay drawn.
5. **Product-market fit is not a readiness area here** (D6049, RA-16): the readiness card's bar for it is left out of the coverage and the chart, by its label. The card's bars carry no item key; see "To file".
6. **A stage before the current one reads Earlier, never Done.** No store says a stage is complete, and the Worker's rule reads the most advanced fact first, so a venture can be running the raise with no narrative.
