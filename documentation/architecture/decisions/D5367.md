## D5367 — Run the dev company HTTP contract in CI (#5367)

The existing D4962 Python golden validator now runs in the `dev-backend` CI job. The same job also drives the Replit-dev FastAPI company router through `TestClient` and a temporary SQLite database, covering member and stranger reads, platform administrators with and without a company seat, a company editor, non-object and malformed field bodies, unknown fields and a direct `logo_url` PATCH.

FastAPI's request body is accepted as `Any` and checked by the route so valid JSON that is not an object receives D4962's stable `400 body_invalid` response instead of FastAPI's generated 422. This is dev parity only: the Cloudflare Worker remains the production API and its contract tests are authoritative.

The Company route's four persisted model types explicitly retain their existing naive-UTC timestamp contract. SQLModel 0.0.48 interprets a plain `datetime` annotation as timezone-aware and otherwise rejects the models' existing `datetime.utcnow` defaults before the route can run. The compatibility declaration changes Python annotations only; it does not change stored values, columns or migrations.
