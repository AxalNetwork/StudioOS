## D6290 — A checklist item's evidence and fields, from its row (#6290)

**Status:** Built, 2026-11-15 (S31). Canvas: Due Diligence Desk Page, board DDL4 (one row expanded).

The Worker has had `POST /api/dd/cases/:uid/items/:itemId/evidence` (a file or a link) and `PATCH /cases/:uid/items/:itemId` (status, owner, due date, severity, note) since D1248 and D1251. No screen called the evidence route, a note or a severity could be set nowhere, and an owner or due date only in bulk.

1. **A row expands.** On Checklist each row has Details. Expanded, it shows the item's note, its severity, owner and due date, and its evidence. Each file opens through the two-minute link issued to the caller (`dd.documentLink`, the same `OpenLink` Documents uses), and each link opens itself. An evidence list the case read could not carry reads "Not recorded", never none.
2. **Two dialogs, for who works the section.** Add evidence takes a link (http or https, with an optional label) or a file (up to 10 MB). Edit item sends only the fields that changed. A cleared note, owner or due date is sent as null, and a changed due date must be today or later. Severity is offered only on an item marked Flag or Fail, because the Worker keeps a severity on no other item. Both dialogs are drawn only when the read's `allowed.work` names the item's section. Anyone else reads one sentence (`WHO.work`), never a disabled button. A refusal stays in the dialog in the Worker's words.
3. **An observer is refused by the Worker too.** The item PATCH already refused an observer ("An observer reads this section and does not work its checklist."). The evidence route did not, so an observer could add evidence by calling it. It now refuses them with the same sentence and code `observer_reads_only`, unless they are an admin or the case lead or opener. `cloudflare-worker/test/dd_documents_d1248.test.ts` holds it, for a link and for a file.
4. **Evidence is not removed.** No Worker route removes evidence (D1248 §8), so the row offers no Remove. It says so in one line instead.
