## D5527 — Retry transient PR preview cleanup failures (#5527)

PR close cleanup stays on its existing same-repository event and
`studioos-pr-<number>` name. Wrangler gets three bounded attempts with
five- and ten-second delays for transient DELETE responses or a command
timeout. A confirmed absent Worker is a successful cleanup, including
when a previous request took effect before losing its response. Other
failures report the Worker, attempt count and next action.

A read-only settings lookup on 2026-11-12 found both
`studioos-pr-4540` and `studioos-pr-4541` in the StudioOS account.
Both still require the normal scoped cleanup. The workflow fixtures
simulate the DELETE results without accessing Cloudflare.
