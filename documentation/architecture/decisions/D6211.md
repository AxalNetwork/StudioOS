## D6211 — Portfolio zones, Overview address and tab names (#6211)

Portfolio's Investor shell derives its local navigation and zone listings
from the same declarations. Performance follows Reports and precedes
Value-add. Overview is still the Portfolio root and is first in the local
navigation. This formalizes an existing destination from D4817 part 1.

The Portfolio workspace replaces `/portfolio/health` with `/portfolio` in a
live Investor view, preserving the query and fragment. The Admin's Investor
preview still withholds records at both addresses. Founder and Partner keep
the legacy Health route and tab. The Admin tab bar uses Overview, Reports,
Positions, Performance and Value-add at its existing addresses.
