## D7515 — Help guides show their recorded verification, flag stale guides only against an agreed window, and carry Before you start (#7515)

- **Status:** built 2026-11-18. Split from #6861 (D6861 follow-ups 1 and 2, and the "Before you start" section D6861 left undrawn). Builds on D4641's review ledger and D6861's guide page and search.

### What #4641 recorded

`frontend/src/pages/docs/guideGovernance.js` (D4641) is the only source. It names an owner and a review scope for nine priority guides and holds one date field, `lastVerifiedAt`, which is `null` for every guide: no verification pass has run. It records no first verified date and no review window, and the PR template's Help impact section is the only release check. Nothing here changes that.

### Decided

1. **The ledger carries two dates.** `firstVerifiedAt` (the day the first source and journey check passed; it never moves) joins `lastVerifiedAt` (the latest check that passed), both `YYYY-MM-DD` or `null`. Every record and the unassigned default declare both, and both are `null`. A malformed or impossible date (`recordedDate`) is not a verification.
2. **What a guide says** (`guideVerification`): "First verified 12 Nov 2026", with "· last verified <date>" when a later check is recorded; "Last verified <date> · first verified date not recorded" when only the last is; "Verification pending" when nothing is (the word D4641, D6861 and the canvas use). The guide page shows it under Owner and Review; a search result shows it only where something is recorded, so today no result row changes; the admin Review column reads the same line.
3. **Stale needs an agreed window, and none is agreed.** `REVIEW_WINDOW_DAYS` is `null`. A guide is stale when its latest recorded check is more than that many days old, and current within it; while the window is `null`, or nothing is recorded, staleness is not recorded, and no guide is called stale or current. Stale draws Honesty's Stale chip (`StateChip kind="stale"`, with its age) on the guide page and the search result; the admin column says "stale not recorded", "current" or "stale · N days since verified". No number is invented here: #4641's owners set it. "The page changed since it was verified" (D6861 follow-up 1's other half) is not built: nothing records when a guide's page changed.
4. **Before you start** is an optional guide field, `beforeYouStart: string[]`, beside `howto`, `tips` and `pitfalls`. The guide page draws it as its own section between Overview and Steps, as HC5 draws it, and On this page lists it; a guide without it draws nothing and lists nothing. Search and reading time read it. The five workflow guides (D4639) whose first step began "Prerequisite:" have that step moved into the field with the label dropped and the first letter capitalised; no other guide text was written or changed.
5. **The format check is a test.** The guide manifest has no validator script; `frontend/test/help_verified_7515.test.mjs` fails a `beforeYouStart` that is not a non-empty list of non-empty strings, an item that still starts "Prerequisite:", or a step that does.

### Waiting on #4641's owners

- A verification pass that records `firstVerifiedAt` and `lastVerifiedAt` per guide, with evidence.
- An agreed review window for `REVIEW_WINDOW_DAYS`.

Until both are recorded every guide reads "Verification pending" and no guide is flagged stale.
