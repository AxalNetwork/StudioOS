## D6094 — Print the frozen sent report on light paper (#6094)

The sent report has a **Print or save as PDF** control beside its existing
actions. It opens the browser's native print dialog with an isolated iframe
document. No new report read, metric refresh, write or Worker route occurs.
The control is absent for a draft or a report without its sent timestamp.

The document uses the report already admitted by the Worker: title, period
and recorded dates, revision (including 1), sent timestamp, corrections,
frozen figures and their sources/as-of dates, highlights/lowlights and their
sources, narrative and attached document names. Attached files are downloaded
separately. Missing values retain their reason; a recorded zero stays zero.
There is no receipt/recipient projection into the print model.

Reader mode additionally excludes unshared team-only fields. This preserves
the Worker's redaction boundary and defends against a raw team figure being
passed accidentally to a read-only print control. Explicit Mercury sharing
retains its founder-sharing attribution. Figures left out retain their
reason and never print a stored excluded value.

The print document is built with native DOM elements and textContent.
Narrative text is never interpreted as HTML. It contains no shell, rail,
navigation or recipient list, independently of whether the on-screen reader
lives in a sheet or on a page. Its standalone stylesheet specifies light
paper in both app themes, A4 margins, wrapping, repeated table headers and
page-break rules. The iframe stays available until afterprint, including
nonblocking print dialogs, then restores focus and removes itself. A failed
preparation or unavailable print dialog reports a retryable error and leaves
the sent report unchanged.

The existing RPT6 action row and RPT11 reader supply the control placement;
the print copy is a document, not a new product screen. The Grow Help guide
adds the native print/PDF instruction after the sent-report read.

provenance, recipient/private-figure exclusion, literal narrative, no new API

exit, mutation checks and Chromium results. No production data or deploy is
