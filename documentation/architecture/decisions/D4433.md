## D4433 — Bound review time and record each attempt before spending (#4433)

The advisory runner owns retries, streams Anthropic and Kimi responses, and uses one job deadline with a 60-second upload reserve. No paid retry or fallback starts with less than 60 seconds left. Configuration refuses a timeout/retry product above that budget; recommended defaults are 600 seconds and no retries.

Each account has a durable record written before every paid attempt. A timeout retains its worst-case charge, including when a later account succeeds. Successful usage replaces only its own reservation. Always-run upload steps preserve account records after cancellation. No credentials or workflow permissions change.

Verification: fake-clock deadline/budget tests, durable reservation checks, fake-SDK streaming/error tests and workflow upload checks.

Fallback Claude keys may each specify ANTHROPIC_WORKSPACE_ID_2 or _3. Configuration validates the workspace ID; each key client receives only its own anthropic-workspace-id header, never the main federation workspace or another fallback workspace. Unset IDs explicitly suppress an ambient workspace header.

Claude review regressions: detect SDK APIUserAbortError by class (its name is Error in 0.135.0); preserve worst-case cost for unknown or connected-stream failures; keep aggregate cost_known false when earlier attempts are uncertain. Artifact names include run ID and attempt before the account suffix, while the ledger keeps reading legacy names. Failing-first tests reproduce each finding.
