## D8773 part 3 — Build in Lovable: Review numbers the exact text by line and marks what changed since the draft (#8773)

- **Status:** built 2026-11-27 on `main` after #8805 (D8773-p2). The owner accepted option A for Q1 to Q4 on 2026-11-27, and the autosubmit answer is in D8773-p2. The browser verification of this flow belongs to S21 (#8795, #8777), not this part.

### Built

BLP05 and BLP06 draw the outgoing prompt with a line gutter and a mark on each changed line. The canvas's accessibility note says: "The line gutter is aria-hidden; the finding gives its line in words. Tags, glyphs and line marks always carry a word".

- **Review's "exact text" region** (`BuildInLovable.jsx`) is now one row per line of the text. Each row has:
  - its line number, in an `aria-hidden` gutter that cannot be selected;
  - the line itself (`white-space: pre-wrap`);
  - for a line that differs from the draft, its mark: "~ Edited" or "+ Added".
  The glyph is `aria-hidden`; the word is read. A marked row is tinted, in dark mode too. The lines joined by newlines are the text, byte for byte, and that same text is what Copy copies and Open sends.
- **`lovableModel.js` `reviewLines(draft, text)`** gives each line its number and mark. It uses the same whole-line diff as "Edited · n lines" and Compare (`lineDiff`). Within one run of changes, as many added lines as were removed count as edited, and the rest count as added. A removed line marks nothing; Compare with the draft still lists it. The unedited draft and an aliased draft (the Worker's own text) carry no marks.

### Departures

- **The editable Prepare box keeps its plain textarea, with no gutter.** A gutter cannot stay aligned with a textarea that wraps its lines. The canvas draws an editable box with a gutter, which would need a content-editable editor, and that is out of proportion here. On Prepare, a finding still gives its line in words ("…, in line 13"), as part 2 built.
- **No "!" mark on a found line in Review.** Review is reachable only when no finding stands, so a found line never reaches it.
- **Phone (BLP09A–F).** The dialog is still the full-height sheet (LV8a). The gutter is 2rem, and each line wraps inside its row at 390 px.
