## D8250 — Pitch analytics: distinct investors and a per-reader average in the daily read (#8250)

Follow-up of D6062 (#6062, PR #8151), which left two lines of PS07 undrawn because the daily read (`GET /api/decks/:id/analytics/daily`, D4272) counted views and first views only: "N investors" under Visits, and the most-read card's average per reader. No migration and no new store: both come from rows the read already joins (`deck_share_views`, `deck_view_slides`, `pitch_deck_share_tokens`).

### The counts are per link

A share link is the only identity a reader has. The share reader collects no name, email or device mark, and this change collects none either. So **a reader is a link**: one investor who holds two links counts as two readers, and two people who open one forwarded link count as one. The words on the screen say "link" for this reason ("2 investor links opened", "1 m 52 s per link on average · 2 links read it"), and the read names its unit (`readers.by = 'link'`). Counting people would need an identity the link does not carry; that is not built.

### What the read adds (`services/decks/shareDaily.ts`)

- `readers: { by: 'link', count }`: the distinct investor links with a view in the range, on the same views as `days` (the venture, the version filter, investor links only, the date range) and under the same NDA filter. `count` is null when no view was counted: there is no reader to count.
- On each drop-off card, `readers` (the distinct links whose views counted seconds on the card) and `seconds_per_reader` (its seconds over those links, rounded). Both are null when nobody counted the card, and `readers` is null if a counted row arrives without its link, never a guess. A revisit adds seconds, not a reader.
- Counts only leave the read: no link id, hash or reader identity.
- A failed read keeps D4272's `500 { state: 'unreadable' }`, which D6062 draws as Unavailable.

The per-link route (`/investor-links/:shareId/analytics`) and the route file are unchanged.

### What is drawn (`ShareBoard.jsx`, `shareBoardModel.readerFigures`)

- Under Visits, "N investor links opened". Under the most-read card, its seconds per link on average and how many links read it. The canvas's "2 investors" and "1 m 52 s avg" become these words, since the unit is a link.
- With no data each reads **Not recorded**, never 0: no view in the period, no reader count in the read, no timed card, or a top card the read sent no reader count for. The tile's own figure keeps D6062's states (a period with no views is still Visits 0, measured).
- A failed read is D6062's Unavailable: the board's failed-read card, and `overviewFigures(null)` answers both figures `unreadable`; the reader line draws nothing beside an Unavailable tile.
