## D6175 — Deal room link and company profile actions (#6175)

The authorized deal header offers Copy link for the current tab's URL.
Opening a copied URL uses the same deal access checks as opening any deal
tab. Free-plan and refused deal views have no More menu.

The full deal read can supply a relative link to the public startup profile.
It uses that profile's existing eligibility rules. Deals without an
addressable profile still offer Copy link.

The NDA-gated, audited investor PDF is tracked separately in #6629.
