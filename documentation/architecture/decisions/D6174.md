## D6174 — Deal Evidence actions on the existing layout (#6174)

Before the NDA, investors can open Documents from Evidence. Afterward, area, source and claim-state chips filter only the returned items. The shared-claim tally counts distinct claims linked to those items and appears only when both reads succeeded. The existing Evidence layout remains in the round call and shared diligence room.

The item drawer opens Diligence or pre-fills the editable Notes form with the item's displayed name and area. The user still saves the note. The evidence projection does not carry an authorized file identifier or link, so it cannot offer a direct data-room link. This work ships on the current layout ahead of the v2 restyle.
