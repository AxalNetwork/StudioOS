## D5942 — Recorded pipeline lifecycle activity (#5942)

The activity read serves recent events for the caller's pipeline or one
need. It uses the same partner and active-company checks as the zone reads.
Passes are partner-level, as on Leads, because their store has no company
column. An unknown opportunity returns an empty feed.

| Event | Recorded timestamp |
| --- | --- |
| Lead passed | `partner_lead_passes.passed_at` |
| Proposal version | `quote_versions.created_at` |
| Proposal won or lost | `quotes.decided_at` |
| Latest negotiation move | `quote_negotiations.last_moved_at` |
| Retainer created or ended | `partner_retainers.created_at` / `ended_at` |

Older negotiation moves, separate stage and ball changes, retainer term
edits and outcomes without a decision timestamp are omitted. A planned
renewal date is not a completed renewal. No migration or page change.
