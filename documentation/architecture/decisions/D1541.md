## D1541 — The elements library: icons, shapes, dividers and textures (#3779, deck v2 B3)

- **Status:** built by Claude Code for slot S18, 2026-11-01. Not deployed and not checked live.
- **Numbering:** #3779 assigned D1541 at filing. Migration: none.
- **Builds on:** D1500's decor (at most 16 items a card), D1499's Grid and D1604's `GridStage.jsx`, `deckV2Adapter.js` and the D1511 contracts.

### 1. The icon set

- **Lucide**, ISC, 1,877 distinct line icons (2,141 files with aliases), from the `lucide-react` the app already depends on. No package was added.
- `scripts/gen-deck-icon-set.mjs` writes `services/decks/iconSet.json`: each icon's SVG nodes and the set's licence record (name, version, SPDX, URL, copyright, the Feather notice for the icons derived from Feather, MIT) and the full licence text. The output is sorted, so a second run with the same package writes the same bytes. The Worker bundles it as a JSON module, as `railMatrix.json` is.
- `GET /api/decks/elements/licence` serves the full text. The panel says "Open licence · recorded · Lucide ISC".
- **The licence travels with the block.** An icon decor item stores `licence: { set, version, spdx }`, set by `cleanDecorItem` from the library and never taken from the client.

### 2. Shapes, dividers and textures

They are drawn in code from parameters: no file and no third-party art.
- 10 shapes, 7 dividers, and 6 textures: dots, grid, diagonal, cross, waves, and grain from a seed.
- A texture draws the same SVG from the same seed.
- Every item names a theme tone (`ink`, `accent`, `muted`, `surface`) as `var(--deck-<tone>)`, never a colour. The editor fills it with the card's own colours.

### 3. The sanitiser

`sanitizeSvg` is the one gate for any SVG a card holds.
- **Allowed elements:** `svg`, `g`, `path`, `circle`, `rect`, `line`, `ellipse`, `polyline`, `polygon`, `defs`, `pattern`, `title`, with a listed set of drawing attributes.
- **Refused, each with its own reason:**
  - `script`, `href` (and `xlink:`) and `foreignObject`;
  - event handlers, `javascript:` and entities;
  - `<style>`;
  - a `url()` that is not a local `#id`.
- Everything the library draws passes it; a drawn SVG that failed would throw.
- Phase 2's generated icons (`grid_icon`, the `BROWSER` render and the vision check) will pass the same gate.

### 4. Decor on a card

- **Kept:** a decor item of a library kind (`icon`, `shape`, `divider`, `texture`) that names a `ref` keeps the ref, its tone, a texture's seed and an icon's licence.
- **Dropped:** a ref the library cannot draw drops the item, and the save names it ("… is not in the elements library").
- **Unchanged:** an item with no ref (D1500's placeholder) and any other kind are kept as before.
- **The cap:** 16 items a card is now `elements.MAX_DECOR`, and `slideModel` takes it from there, so the model and the panel agree.

### 5. The routes

`routes/deck_elements.ts` serves these, for anyone signed in, mounted before `decks`:
- `GET /api/decks/elements`;
- `GET /api/decks/elements/icons?q=&offset=&limit=`, or `?refs=` for the icons a card holds;
- `GET /api/decks/elements/licence`.

They run no model. Placing decor is the deck's own save.

### 6. The panel (pd28)

The panel is built into S1's `GridStage.jsx`, not new chrome.
- **Where it opens.** "Graphics" sits in the one-area selection tools beside Ask, never in a toolbar or a right panel.
- **What it holds.** Icons · Shapes · Dividers · Textures, "Search icons", the licence line, and "[n] of 16 decor items on this card".
- **Placing.** A pick is placed on the selected area's cells, which lie on the 8 px baseline, and the chip says "Snapped to the baseline".
- **The cap.** At 16 the tiles are off and the card says it holds the most it can.
- **Generate.** "Generate an icon" is drawn greyed "Coming later", with its hold line. Its model is picked only in the AIRail's Graphics group (#3754).
- **The write path.** `PitchEditor` passes `onDecor` (it appends to the card's decor through `setCard`), held until a version is saved like every edit.
- **Drawing.** Decor is drawn under the areas as an image (`data:image/svg+xml`) of the Worker's sanitised SVG, so nothing in it can run.
- **The client** is `lib/api/deckElements.js`, re-exported by one line in `api.js`. `deckV2Adapter.elementsLibrary` is swapped, and `contracts/deckElements.schema.json` is its D1511 contract.
- **The area picker** (`deckV2Model.js`) keeps its Graphics items greyed: an area's element is what Eadwyn fills, and decor is placed from the selection tools.
