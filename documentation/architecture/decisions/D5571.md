## D5571 — Azure Container Apps Jobs as the first external executor, disabled and unmounted (#5571)

**Status:** part 1 of #5571, the Azure adapter. Disabled by default and unmounted; no Azure account, credential, binding, route or deployment exists or is changed. The owner chose Azure Container Apps Jobs as the first provider on #5571 (2026-11-13). Google Cloud Run Jobs and AWS Fargate follow later on the same contract. It builds on the merged D5565 `ExecutorAdapter` and is placed by D5570.

### The adapter (`services/agents/azureJobsExecutor.ts`)

`createAzureJobsExecutor({ config, transport })` implements D5565's `ExecutorAdapter` for one pre-provisioned manual-trigger job. The request shapes come from the Microsoft.App REST reference, api-version `2026-07-01`:

| Contract call | Azure call |
|---|---|
| `create` | `POST …/jobs/{job}/start`. The body is a `JobExecutionTemplate`: one container, image `<registry repository>@<spec digest>`, and `cpu`, `memory` and `ephemeralStorage` from the spec. |
| `get` | `GET …/jobs/{job}/executions/{name}` |
| `terminate` | `POST …/jobs/{job}/executions/{name}/stop` |
| `collect`, `cleanup` | Read the execution. Azure holds no artifacts (they reach the broker through D5565/D5567), and execution history stays under the job's retention, so nothing per execution is deleted. |

**Status mapping.** `Processing`→`provisioning`, `Running`→`running`, `Succeeded`→`finished`, `Failed` and `Degraded`→`failed`, `Stopped`→`cancelled`, `Unknown`→`unknown`. Any other value is `unknown`, never a guess.

**Ambiguous outcomes, verified against the API's documented answers:**
- **Start is not idempotent.** It answers 200 with the execution name, or 202 with only a `Location` header. Every execution therefore carries a plain env var, `AXAL_EXECUTION_KEY` = `tenant.run.attempt.generation`.
- **Unknown, then located.** A 202, a 5xx or a dropped connection returns `unknown`. `get` finds the execution by listing the job's executions for that key. Before a start, `create` looks for the key, so a retry returns the running execution instead of starting a second. Two executions with one key are refused as `duplicate_execution`.
- **Stop.** A dropped stop is `unknown`, not `cancelled`. A finished execution is never sent a stop.
- **Ownership.** An execution whose key differs from the ref's (another tenant or another generation) is refused, whatever name the ref gives.

**Fails closed.** Each capability comes from operator config, and an unset one refuses the spec with D5565's typed `capability_denied`:
- network mode: none unless declared enforced;
- hostile-code isolation: only on operator attestation;
- checkpoint restore: off;
- duration: capped by the job's `replicaTimeout`, which Azure sets per job, not per execution;
- regions, CPU, memory, disk, and concurrency.

An allowlist network policy is refused unless the environment enforces it.

**Credentials.** The adapter takes an injected ARM transport. The broker attaches a short-lived Entra token from workload identity federation. No key is in this module, the template or the container. The template carries three references only: the key, the run id and the generation.

**Errors.** 401/403 → `provider_auth_refused` (revoked identity). 409/429 → `provider_quota`. Other 4xx → `provider_rejected`. 404 → `execution_not_found`. Provider error text is never copied into a refusal.

**Cost.** Without priced rates, `estimate` refuses with `estimate_unavailable`, never 0. With rates, it bills vCPU-seconds and GiB-seconds over `max_duration_s` and marks the figure unmeasured.

### Not verified yet, and how it will be

These need the owner-authorized test account:
- the CPU/memory pairs a consumption environment accepts;
- startup time;
- whether the 202 `Location` poll ever names the execution sooner than the list does;
- real billing figures;
- the maximum `replicaTimeout`.

Until then, the job's configured values bound every spec, and estimates stay unavailable. No live-migration claim is made: a run resumes only from an acknowledged checkpoint, and `checkpoint_restore` stays off here.

### Azure runbook (staged; enabling is the owner's)

1. **Account.** A dedicated subscription or resource group for workspace runs. One Container Apps environment per Axal region, and one manual-trigger job in it with `replicaTimeout` set to the longest permitted run.
2. **Least privilege.** A user-assigned managed identity for the broker, federated with the Worker's OIDC issuer. Give it a custom role limited to `Microsoft.App/jobs/start/action`, `Microsoft.App/jobs/executions/read` and `Microsoft.App/jobs/executions/stop/action` on that one job. The job's own identity gets `AcrPull` on the registry and nothing else.
3. **Image registry.** A private Azure Container Registry. Images are referenced by digest only; the adapter refuses a tag.
4. **Networking.** A VNet-integrated environment whose outbound traffic is denied, or forced through a firewall that implements the allowlist. Set `enforced_network_modes` only after that is in place and tested.
5. **Metrics.** Execution start and end times and status, plus Container Apps metrics, feed D5570's queue-wait, start p50/p95, error and cost-per-success figures.
6. **Cost.** Set `rates` from the subscription's actual price sheet. Until then, D5570 reserves the spec ceiling.
7. **Teardown.** Stop running executions, then delete the job, the environment and the identity's role assignment.
8. **Emergency disable.** Set `enabled: false` (every call refuses before a request leaves), or remove the identity's role assignment (every call returns `provider_auth_refused`).
9. **Rollback.** Delete the module and the test. Nothing imports them.

### Tests

`cloudflare-worker/test/azure_jobs_executor_5571.test.ts` has nine tests on a synthetic ARM endpoint built from the reference's response shapes. They cover:
- disabled refusals and config validation;
- the digest-pinned, secret-free template;
- each fail-closed capability;
- ambiguous 202 and dropped starts, with no second start;
- every status mapping;
- cancel and terminal calls;
- quota, revoked identity and cross-region refusals without provider text;
- another tenant's or generation's ref refused;
- unpriced estimates refused.

Twelve source mutations each fail a test.
