## D6155 — IC decision pages: offer only what the Worker allows, add Recuse, show conditions (#6155)

- **Status:** Built for #6155, 2026-11-15. Frontend only.
- **Interim.** The IC Decision Record canvas (D6153) moves one decision to `/deals/commit/:uid`, and its first proposal replaces `ICDecisionPage.jsx` and `ICDecisionsPage.jsx`. This fix stays small and adds no Worker read.
- **No migration, no Worker change.** Every rule below is the Worker's own, in `cloudflare-worker/src/routes/ic.ts`.

### What was decided

1. **Save memo, Record decision and Outcome are the author's, or an Admin's.** `PUT /api/ic/:uid` refuses anyone else with 403. The page used to offer them to every admin, partner and investor, so other members only ever got "Forbidden". The page now applies the Worker's rule to the read's `created_by`. Everyone else reads the memo and one line: only the person who opened the record, or an Admin, can change it. Voting stays open to every IC member, as it is in the Worker.
2. **Recuse.** Recuse… opens a form asking for the declared conflict. It says that a recusal is final, and sends `{ vote: 'recused', rationale: <declaration> }`. A member who has recused is told so and offered no vote. A later vote the Worker refuses (`recusal_is_final`, 409) shows the Worker's own sentence.
3. **The tally is words and numbers, with Recused beside it.** Both pages show "Yes n · No n · Abstain n · Recused n". A count the read does not carry is "Not recorded", never 0. Recused is never added to the yes/no/abstain counts (`tally()` in `ic.ts`).
4. **Conditions are shown read-only.** The detail page lists each condition from `GET /api/ic/:uid` with Open, Met or Waived. The page changes no condition. The link to `/deals/commit` is offered to an Admin or an investor only, because that route's guard admits nobody else (`App.jsx`). A partner would otherwise land on a refused page.
5. **A failed read is Unreadable, with Try again.** On the list, a failed read is no longer drawn as "No IC decisions yet". Loading says what it is reading.
6. **`/ic` and `/ic/:uid` light the Deals row.** That row is in the investor sidebar. The admin and partner sidebars have no Deals row, so no row is invented for them here.

The rules live in `frontend/src/pages/icDecisionModel.js`. Guard: `frontend/test/ic_decision_pages_6155.test.mjs`.
