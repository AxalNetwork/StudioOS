## D5064 — Mount completed Build connector parts (#5064)

### Decision

The Build module registry mounts the completed Vercel and Lovable components
against the connector parts already returned by the canonical module read:

- Prototype / MVP: GitHub, Vercel, Lovable, Notion, PostHog.
- Product roadmap: Vercel, GitHub, Google, Notion, PostHog.
- Company creation: GitHub, Vercel.

Each existing component remains inside the registry's `PartBoundary`, so one
connector failure cannot remove its siblings. No new connector read, store or
layout is introduced.

Company creation maps failed proposal writes to fixed product copy. Provider
and server error text is not rendered to the member.

### Consequences

The Worker no longer pays to return these completed parts without a reachable
Build UI. Existing connector permission and privacy rules remain unchanged.
