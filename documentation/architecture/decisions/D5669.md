## D5669 — Fence company membership writes at commit (#5669)

Leave, member removal and member edits decide against the company's current
unarchived state in their DELETE or UPDATE. Preflight alone cannot fence an
archive that commits between the read and the batch. Reuse D4805's existing
`decision_guard` immediately after that deciding statement and `runDecision`
to roll back a lost write before dependent compliance or membership events.
An archive winner receives the existing shared archived 409 refusal; a seat
that disappeared receives the existing not-found response.

Removal and demotion also check last-primary-admin safety in the deciding
statement, preserving a primary admin if another admin leaves after preflight.
Successful seat endings retain the existing compliance reassignment flags and
events, without automatic reassignment. Restore permits the previously refused
write. Existing role, member, support-session and primary-admin admission gates
remain in force. There is no new route, schema, migration or client method.

This follow-up covers the three membership mutation paths named in #5669.
General/settings/logo fencing remains in #5686; invitations and the separate
primary-admin transfer route are not changed here.

Verification uses the existing migrated-schema company-settings fixture with
synthetic accounts and supported archive/restore/leave requests interleaved
immediately before the target batch. The archive races preserve membership,
compliance tasks and dependent events; restore permits the write and retains
the successful-write audit/compliance behavior. Separate concurrent-primary
regressions keep the last admin. Each regression fails on the starting code;
production fence mutants are checked against the restored passing tests.

The final focused run has 15 passing tests; 40 existing membership/compliance
compatibility tests also pass. The partial-schema lifecycle, leave, carry-permission and direct-add-retirement
fixtures load only the guard table DDL from its existing production migration;
the lifecycle/leave additions match the same setup in #5686. Eight targeted production mutants (archive predicate,
decision guard, demotion and deletion admin fences, refusal, cleanup, compliance
and audit kind) fail their assertions; restoring the implementation passes.
