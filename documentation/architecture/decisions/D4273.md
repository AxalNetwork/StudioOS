## D4273 — The Decks tile: variant cards, the Versions timeline, Compare and Share this version (#4273)

**D4254 P5, slot S24 · 2026-11-03.** Part of #4254. Frontend only: every read already exists. No migration, no new route.

### What the tile draws (ps3)

`DecksTile.jsx` sits on the Pitch page's home (`StudioHome.jsx`), below the tile row, whenever the venture has a current deck version.

- **Cards:**
  - **Main** is the deck at its current version: title, `vN`, its card count from the deck read, "Edited … by …", and its links.
  - **Each variant** comes from `GET /api/decks/:id/variants` (`deckInvestorLinksApi.deckVariants`) of the current version. Its card count is the length of its `slide_order`.
  - **Links** come from the current version's investor links (`deckInvestorLinksApi.investorLinks`). A link row names its variant at `version.variant`: a link with no variant counts for Main, and one with a variant counts for that variant.
  - **Unread values:** an unread links read leaves every figure "Not recorded". A counted 0 reads "No links". A failed variants read says "Your variants could not be read." once, and the tile draws the deck alone.
- **Versions timeline:**
  - It lists the versions the page already reads (`GET /api/decks/by-project/:id`), newest first.
  - Each version shows who saved it and when, and its `shared_links` count. Nobody named reads "Not recorded", not a blank.
- **Compare:**
  - Compare sits on every version but the current one.
  - It opens PD15's `VersionCompare` against the current version, which carries Restore and its dialog, unchanged.
  - The compare now also draws the summary line "v6 → v7 · Added: … · Removed: … · Changed: …" (`compareLine` in `compareModel.js`).
  - The line matches cards by uid, falling back to place, so a card that only moved is not counted as changed. It names cards by title. When nothing differs it reads "No card changed".
- **Share this version:**
  - Only a writer gets it. It opens the existing `ShareDialog` on that version, so a link can point at an older version without making it current.

### What stays

The deck card's ⋯ keeps its "Versions…" entry, PD15's full table with checks. The timeline is the tile's short form, not a replacement, and the editor's ⋯ › Versions (D1604) also uses that table.
