### What the canvas decides

- The console is a private operator store for community-shared sources. Its first board says it plainly: "A source record is not a fund." A record is decided (link, create, retain privately, reject, leave unresolved) before anything reaches the directory.
- Runs and sources (FND-I01) list each source with its period, terms verdict, list name and last run, and every run with the five outcomes (created, linked, retained privately, unresolved, rejected) and their sum. The entry is one Super Admin link beside the unchanged FND-G01 Sheets card.
- Choose a file (FND-I02) works out the SHA-256, size and manifest count in the browser, classes each column (fact, prose, contact) with withheld cells counted, and previews new, unchanged, changed and removed per source under "Nothing has been written." Contact columns are Held by default.
- Apply (FND-I03) sends bounded batches with a paced wait, asks for step-up again when it expires, and resumes a stopped run only with the same file. The result (FND-I04) is Complete only when what is stored is read back against the manifest; Outcome uncertain blocks a new run until Reconcile, which ends Complete or still short.
- One run (FND-I05) shows digests, the deployed commit, per-source counts, cells stored, withheld and blank, refused records by id and reason code, and the status history, never record content. Remove (FND-I06) takes a record's private fields, one record or one source, each behind a typed confirmation that says applying the file again will not restore it.
- Records and decisions (FND-I07 to FND-I09): the list has no private field, no search and no export; one record is shown as captured with its private part masked and a round marked as history. A shared website is a warning, never a ground to merge alone or in bulk, and bulk mapping that fails any row is refused whole. Company, round and individual records can only be retained privately, rejected or left unresolved.
- Columns (FND-I10) set role, destination and serve beside the source's terms verdict; cheque, stated fund capital, AUM and revenue threshold are four separate destinations. Promote (FND-I11) previews, applies, undoes one record and withdraws a source; a source with no reviewed terms promotes nothing. The report (FND-I12) gives the five outcomes by source and by kind, each summing to the staged total.
- No Eadwyn rail and no AI action: nothing in the private store is read by Eadwyn or sent to a model (#7739). The NSI canvas (#7679) had not landed when this was drawn, so the shared run steps, review row and result receipt are drawn here and FND-I17 says so; NSI cites these boards.
