## D6161 — Round call read states and the investor Deals shell (#6161)

Round call pages use the Worker's refusal codes. Investors who need
verification can open the identity verification flow at `/kyc`.
The index sends founders to Raise if no valid venture was supplied.
Missing calls and missing ventures have their own messages. Network and
server failures retain retry.

Both investor routes use the existing Deals workspace. Counsel keeps
the existing detail view and founders still redirect to Raise. The
index displays Open for sent calls and Paused while counsel approval
is pending, alongside Closed and Draft.
