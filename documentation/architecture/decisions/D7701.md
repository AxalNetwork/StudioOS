### Scheduled fund integration

The owner confirmed that #7668 carried the selected-fund reader onto main. Sessions now accept a checked fund target and apply the reader's same institutional GP/company scope, including its null-company fund exception. The caller's held licences are hydrated before the investor-tier check, matching the reader; a raw users row can incorrectly bypass a paid-tier check for a founder who also holds Investor. The new lower-tier regression caught this during implementation.

The saved target binds vc_fund:<id> into both context reads and the pre-charge readiness gate. Those reads enforce current fund ownership and access again, so deletion, company/GP changes or lost tier access after scheduling refuse before agentRun and charge. The input matrix now declares the scheduled path supported. Existing targets and migration preservation remain covered. No live model or production database is used.
