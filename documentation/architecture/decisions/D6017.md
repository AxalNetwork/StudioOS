## D6017 — Experiments across hypotheses (#6017)

V9 lists all experiments on open venture hypotheses, independent of the claims table’s page and filters. Planned, Running, Result needed (Done without an observation), Completed with result, and Stopped stay distinct. Planned and Running rows never count toward a decision’s evidence bar, even if a legacy row holds result text.

Stopped uses additive stopped_at, preserving the original status CHECK and existing foreign keys and IDs. Result direction and recording time are nullable; migration does not infer historical values. Updating results preserves them when omitted, and changing the result refreshes its recording time. Existing hypothesis actions and per-experiment Lovable flows remain available.

S1’s November 21 clarification drops the unsupported experiment owner and start/end dates. The list follows VA09; its action opens the hypothesis’s existing experiment forms rather than introducing a separate experiment route. Reads fail independently with Unavailable.
