## D7318 — Research Markets global sourced observations (#7318)

- **Status:** implementation branch for #7318.
- Adds an append-only observation model with source, edition/vintage, period, unit, status, retrieval time, methodology/licence metadata and revision links.
- World Bank WDI is the first enabled adapter. Missing values are skipped (never converted to zero), ISO-3 is validated, and World Bank's empty/ambiguous status is exposed as `unspecified` rather than falsely labelled Actual.
- IMF WEO, WIPO GII, OECD, Eurostat and UNCTAD are registered but disabled until the exact redistribution/API path is verified. This deliberately prevents unlicensed or guessed data from entering production.
- API: `GET /api/research/market-data/sources`, `GET /api/research/market-data/countries/:iso3`, `GET /api/research/market-data/export.csv`, `POST /api/research/market-data/refresh/world-bank`.
- Existing Research v2 Markets UI ownership (#7036–#7039/#7171–#7174) is not duplicated. The new API is the provenance backend those surfaces can consume.
- Refresh failures are recorded without deleting the last known good observations.
