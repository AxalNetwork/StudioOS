## D5315 part 3 — Service publication states (#5315)

Services have a stored Draft, Published or Hidden state. The public profile includes only Published services. Draft and Hidden remain visible to the owner, and the owner can publish a Hidden service again. The service publication action uses the existing revision check.

Existing active services stay usable in the owner's practice and start as Draft for publication. Only an explicit publish action adds a service to the public profile. Older clients can still hide a published service by deactivating it. Booking availability remains owned by Practice Sessions and is read from the existing public booking settings.
