### Backend required: what was built and what was not

- **A store of searches that found nothing: built.** Migration `202611161142_6861_help_search_misses.sql` (`help_search_misses`: query, UTC day, count, no member; `help_search_miss_marks`: one count per member per query per day, kept two days). `routes/help_center.ts`: `POST /api/help/search-misses` (signed in; 20 counted a day per member; a query that looks like an email address or carries six or more digits is withheld and never stored; days older than 90 are deleted) and `GET /api/admin/help/search-misses?days=` (admin; most searched first, at most 50, no member). Client `helpCenterApi.recordSearchMiss` / `adminSearchMisses`. The page records a member's search that found nothing once per query after 1.5 seconds without typing. Tests: `cloudflare-worker/test/help_search_misses_6861.test.ts`.
- **Broken-link flags: built, without a store.** The guides are code, so `guideLinkFlags` checks each guide's Related links and its page against the manifest the Help Center is built from; the admin column shows it. **Stale-guide flags: not built.** Stale is measured from a first verified date, which no guide has (#4641); the column says "stale not recorded". Follow-up below.
