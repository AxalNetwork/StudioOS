## D6674 — Keep timing artifact selection machine-readable (#6674)

The timing selector writes the eligible main artifact ID to stdout, or no
bytes when the inventory is valid and nothing qualifies. A malformed
inventory exits with an error. Read-only planner commands do not run the
generators. Executing a planned shard still generates the required modules.

CI, the nightly future-clock suite, and the runner benchmark use the same
download step. It reports an unavailable query or download separately from
an inventory with no eligible artifact. Both cases fall back to equal weights.
An invalid selector result fails the step. A successful download logs the
artifact ID and hands the timing file to the exact-once planner.

Hosted timing coverage and shard wall times depend on the producer in #5608.
