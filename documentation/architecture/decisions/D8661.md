## D8661 — Reconcile task states from reviewable GitHub evidence (#8661)

The D6312 coordinator keeps its snapshot, independent verification, plan, dry run and explicit apply sequence. The evidence step records each issue’s comments, related PRs, dependencies and claim at the main revision under review. Plans carry those observations. A held ref stays held after expiry. Ambiguous label ownership and unreadable refs hold the item for triage. A verified handback can explain a legacy label claim after the exact ref read confirms absence.

PR links separate closing intent from partial and reference intent. Topic-branch merges require evidence of their implementation on the recorded main revision. Ancestry locates ordinary merges and rebases when the reported landed commit reaches main. A squash into a different branch can be confirmed with an exact PR-file blob on main. The independent verifier checks all acceptance criteria, remaining parent and child scope, and file witnesses. A marker, closing keyword, merged flag or closed child alone cannot close an issue.

Before posting a note or changing state, apply rereads the evidence. A stale item is listed for another pass. A retry can recognize the exact note from the applying identity and the planned final issue state without the local ledger. GitHub accepts the note and state update as separate requests. An edit between them can stop the state change after the note was posted. Each write uses the newest evidence available before that request.

The lifecycle report reads a bounded set of recent issues, PR and dependency events, and inconsistent task states. Generated alerts and landing reports are observations. A changed blocker prompts verification of the remaining gates. The workflow checks out main, uses read-only permissions, and publishes a report artifact and summary. Trusted authors and merged PR events can start event reports. Scheduled runs cover other activity. Its concurrency group coalesces pending events. Reports name the observed main, evidence links, unknowns, counts and deferred candidates, including incomplete recent PR pages. Only the independently verified, explicitly applied plan can change issues.
