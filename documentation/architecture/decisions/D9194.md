## D9194 — Public pages say a failed read could not be read, with Try again (#9194)

- **Status:** S15, 2026-11-28 (#9194, from the 2026-11-27 coordinator audit, UXP-12 and UXP-07). No migration, no Worker change.
- **Basis:** `/articles`, `/events`, `/programs` and `/trust` already say a list "could not be read, which is not a claim that there are none". Eight public pages did not: seven printed the server's `e.message` for any failure, and `/circles` drew a failed read as "No circles are published yet".

### 1. One helper

`frontend/src/lib/pageReadFailure.js` exports `pageReadFailure(err, { unreadable, notFound })` → `{ kind, message, retry }`:

| What the read threw | `kind` | Words | Try again |
|---|---|---|---|
| 404, and the page has a `notFound` sentence | `not_found` | that sentence, unchanged | no |
| any other 4xx but 429, with a sentence for a person | `refused` | the server's sentence | yes |
| 5xx, 429, a timeout, a network failure, no status, or a 4xx whose text is a bare machine code | `unreadable` | the page's own `unreadable` sentence | yes |

It holds no page's words, so `/verify/:token` (#9178) can use it; that page is not changed here.

### 2. The pages

`PublicProfilePage`, `PublicStartupProfilePage`, `PublicPartnerProfilePage` (404: "Profile/Startup/Partner not found", as before), `PublicDirectoryPage` (Try again repeats the last read, filters included), `StatusPage`, `ChangelogPage`, `ESignPage` (the full-page `ErrorCard` from `setLoadError`; Try again repeats the envelope and paper reads) and `CirclesPage`, which gets its own failed state. An empty successful read on `/circles` still says "No circles are published yet." The buttons sit inside each page's existing error box: the light-only boxes (red-50, and the public site, which is light only) keep light classes; the eSign card's button carries `dark:` variants as the card does.

### 3. Tests

`frontend/test/public_read_failures_9194.test.mjs`: the helper's table, then each page mounted on a stubbed `fetch` answering 503 with a distinctive `detail` (absent from the page, the page's words present, Try again re-calls the API and draws the read), a network failure, the profile pages' 404 wording with no retry, and `/circles` failed against empty. Mutation check: 18 mutations, 18 caught, 0 equivalent.
