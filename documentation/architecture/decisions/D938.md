### 2. One redirect map

`frontend/src/pages/admin/LegacyContractsRedirect.jsx` keeps its name and holds `ADMIN_TAB_MOVES`, the one map in place of `MOVED_TABS`.

- **`/admin` mounts nothing.** Its route is `<LegacyContractsRedirect />`, which forwards with `<Navigate replace>`, so no old read fires. The route is not guarded; the page it lands on is (D937's rule).
- **Query and hash travel.** The forward drops `tab` and any old `moved`, keeps every other parameter and the hash, and adds `?moved=<tab>`. GitHub's own `#github` wins over an incoming hash. Integration keys and GitHub add no `moved`, since their page shows no notice.
- **A bare or unknown tab opens All accounts,** as the console opened Users (#2375's last row). It carries `?moved=users`.
- **The notices,** in #2375's three forms, are in the map beside each target:
  - "The Admin Console has moved: Partner profiles now lives under Approvals." The same form is used for Directory and Wellbeing (Community), for Payments, Bank accounts, Product testing and Promo codes (Platform), and for Billing (Revenue);
  - "Users is now All accounts, under Accounts.", "KYC Queue is now KYC & KYB, under Approvals." and "Personas is now Persona segments, under Accounts." for the renamed three.

  Each page reads only its own (`movedNoticesFor(path)`) through D936's `useMovedNotice`.
- **The redirect beacon** still counts paths only; counting each old `?tab=` is part 2 (#2744).

### 3. The pages

`frontend/src/pages/admin/ConsolePages.jsx` holds one exported page per address. Each is `AdminPageHeader`, then one console from `pages/admin/consoles/`, unchanged.

- **The header** draws:
  - the crumb, "Section › Page", whose section links its landing;
  - the title and one muted line;
  - the HQ-held scope chip on the Admin shell only;
  - the moved notice.

  It renders at once, from the page, never from a read (D936).
- **The crumb follows the viewer's shell.** All accounts reads "Accounts ›" on the Admin shell and "Team ›" on HQ's. Persona segments reads "Accounts ›" and "Content ›". Every other page has one crumb.
- **The rail.** Each page sits in `AdminBoardFrame`, named for the board D768's page map gives its address in the viewer's own profile (`consoleBoard`). This is how the console's one frame was named for its tab (D775). A page that is no board of the viewer draws the page alone: Identity checks for a Super Admin, Personas for an Admin, and Bank accounts, Product testing and Billing for both.
- **The rail keys keep their canvas names** (#2375): "Admin · Accounts · Users" and "Super Admin · Team · Users" now own `/admin/accounts/all`. Only the routes in `railPages.js` and the `railOptions` board rows changed. Their `host` is `ConsolePages.jsx`.
- **The More menu (SHL1)** is built in `AdminPageHeader` as `more`, of `HeaderMenuItem`s: a literal link (`to`) or an action (`onSelect`). Its first page is All accounts, with "Copy page link" and "Trash (soft-deleted projects)". Trash's door lived in the console's header line, so it moved here with it.
  - "⋯" carries `aria-haspopup="menu"`, and the menu is `role="menu"`.
  - Opening it focuses the first item. The arrow keys, Home and End move between items. Escape closes it and returns focus to "⋯", and an outside click closes it.
- **The dropdown's "N pending" badges are gone** with the dropdown. `KycConsole` and `PartnerProfilesConsole` lose their `onPendingCount` prop. The Approvals landing's lanes already show those counts from the glance read.
- **`AdminPage.jsx` is deleted,** with `ADMIN_SECTIONS`, `AdminSectionNav` and `tabBoard`. Its pins moved to the new pages: the rail frame, the Trash door, the one-read-per-console rule and the placement map's tab list. The tests now read the tab list from `ADMIN_TAB_MOVES`.
- **`LegalConsole.jsx` is mounted by no page.** Its tab has forwarded to Contracts since D647. It stays for its tests until the Contracts work retires it.

### 4. The maps

- **`adminPlacement.js`.** Each tab entry keeps its key, `tab:<value>`, which H35's question pins. Its `route` is now the page's address, and its `hqOnly` restates the route. Directory is placed on Community, with Approvals' "Not a queue" as its `also` (#2375). `UNPLACED` keeps `/admin` as a redirect.
- **`hqStrips.js`.**
  - The Platform strip's four items and the Content strip's "Persona segments" are paths.
  - `stripFor` matches an item's sub-paths and reads the path alone.
  - The selected item is the longest address that owns the location (`stripItemFor`), so Overview is not lit beside Payments.
  - `hereFrom`, `adminRowFor`, `ADMIN_ROW_ROUTE` and `NO_ROW` are gone: no page lives on a query.
- **`SidebarNav.jsx`.** The HQ shell still lets a strip's pages light its row. The Admin shell lights by path and `match` alone.
- **`sidebarConfig.js` `match` lists** follow #2375's "The sidebars after the move":
  - **Accounts:** `/admin/accounts/all` and `/admin/persona-segments`.
  - **Approvals:** `/admin/kyc` and `/admin/partner-profiles`. `/admin/refer-earn` stays until #2371 forwards it.
  - **Community:** `/admin/directory` and `/admin/wellbeing`.
  - **HQ › Team:** `/admin/accounts`, which covers All accounts and a member's credits.
  - **Revenue:** `/admin/revenue`.
  - **Content:** its six strip subtrees, so #2383's `/admin/articles/*` will light it.
- **In-app links** to `/admin?tab=` now name the new addresses, so no door inside the app shows a moved notice. These include the held landings, the Studio glance, the branch boards' links to HQ's consoles, the HQ Platform, Content, Revenue and Dispute pages, HQ Team's KYC card, Fund admin's two Bank accounts links, Mercury's HQ line and the demo admin's landing.
