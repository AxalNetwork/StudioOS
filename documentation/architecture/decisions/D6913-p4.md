### What is built

- **Eadwyn's proposal** (`RoomLibraryProposal` in `pages/research/RoomLibrary.jsx`, its words in `roomLibraryModel.js`).
  - It lists the room's files that are open to every invited investor (`visibility = 'open'`) and are not in the caller's Library. A file behind an NDA is never named or proposed, even to an investor whose NDA lets them open it.
  - Nothing is proposed while the room's Library read has not answered, or when the founder has not allowed Library copies.
  - It reads "Proposal · nothing is added until you accept", then "N files open to every invited investor in this room are not in your Library: [names]. Add them?", with Add, Edit selection (a checkbox per file) and Discard.
  - Eadwyn adds nothing itself. Add sends the selection through `POST /api/room-library/items`, one file at a time (`addSelection`). A second add (409 `already_added`) counts as added.
  - It names where it read from: "Read from: this room · [room] · [time of the read]".
- **RS-19, the proposal's own states.** Saving reads "Adding… [names]". A failed add reads "The N files weren't added. Nothing changed. Your selection is kept." with Try again, which sends only the files that were not added (`proposalOutcome`).
- **RS-19, the room.**
  - Loading is a skeleton in the room's shape: header, four tiles, the file list.
  - A room Library read that fails says Unreadable with Try again. It never reads as Off.
  - A room whose founder has not allowed copies reads "Not allowed in your own Ask", the reason, "You can still read and download them here." and "Add to my Library is not offered on this room."
- **RS-18, empty states** (`roomsEmpty`, `RoomsEmpty`).
  - From data rooms with no room file in the Library reads "No data-room files in your Library yet", "Open a room you hold and choose Add to my Library on a file. Filter: From data rooms · 0 of N documents.", and Open your rooms.
  - With no live grant (the investor's room list answered and is empty) it reads "No rooms are open to you" and offers only Show all sources, which clears the filter. A room list that has not answered never claims there are no rooms.
- **RS-20, phone.**
  - A: the room's files were already stacked rows at 390 (#6270). Each row now ends in a 44px ⋯ button.
  - B: ⋯ opens a bottom sheet (`RoomFileActions`, `PhoneSheet`): Open file page, Add to my Library (or Open in your Library once it is there), Download, Cancel.
  - C: the confirm sheet was already full-height below 640px (`Sheet`); its primary is now 48px.
  - D: a Library room row is a card (`RoomCardFacts`) with both pills, the room chip and Read-only, Added [day], Open in room and Remove from Library. A lapsed one reads "No longer available." with its reason in its own words and offers only Remove from Library. A lapsed NDA file is nameless on the card too.
  - E: the citation sheet was built in part 3 (`phone="sheet"`), unchanged.
- **RS-21 and RS-16, dark and the lapsed row.** Everything above carries its dark tokens. A lapsed reference's index state (`source_lost`) reads "Entries deleted" rather than Not recorded, with no passage count.
