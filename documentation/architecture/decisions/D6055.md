## D6055 — Pitch Studio home and navigation (#6055)

The first build slice of D4839 (PS-01 and PS-02) adds the Overview tab alongside
the existing five studio tabs. Editor and Present remove the regular app
navigation and keep their own controls. Legacy links, venture selection and
the existing editor menu continue to work.

Studio home shows the current saved version and the server's working draft as
separate states. The draft read only describes changes that reached autosave.
The next step prioritizes review of an unchecked version or flagged figures,
then a recorded draft, then an investor link when the checked version has no
active link and the draft read confirms no changes. Missing data never produces
a recommendation. Review and link creation carry the chosen saved version in
the URL and require that it belongs to the selected venture.

Readiness reflects the existing figure check. The consolidated review checklist
is a later slice. Evidence coverage counts cards with at least one figure and
all figures linked. Investor activity uses the current and previous versions;
it shows the version on each row. First use reuses the existing New deck flow
and the import from #4599. The manual entry opens New deck at its manual form.
The Raise header action stays under #5081.
