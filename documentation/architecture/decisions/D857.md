## D857 — Record a Session translates: chat text and voice transcripts, the original kept

- **Status:** filed by S1 as #2502, W2 of #2500 (WhatsApp for Record a Session). Built by S11.
- **Basis:** `origin/main` at `3704a16a62`. Worker paths are relative to `cloudflare-worker/src/`.
- **Stacks on:** D684, D754 and D756 (the channels and their consent), D658 and D757 (structuring and its suggestions), D761 (the router's translation shape), D763 (the guard), D844 (one AI token ledger).
- **Migration:** 527.

### 1. The decision

Every final transcript segment of a session is translated into the founder's working language by Workers AI, and the original is always kept beside the translation:

- a chat message;
- a voice note's transcript;
- a call's passage.

Structuring reads the translation. A quote shown as evidence keeps the customer's own words, with the translation beside them.

The owner's question (Q1) was built as **A**. The working language is the member's own setting, `user_settings.validate_working_lang`, when they have one. Otherwise it is the account's language (`user_settings.locale`). Otherwise it is English. B (always English) would be a one-line change in `workingLanguage`.

### 2. How it works (`services/sessionTranslation.ts`)

**Where it runs.** At the start of `structureSession`, after the consent gate (`sessionDigestConsentBlocks`). So every trigger that structures a session translates it first:

- a chat's new text;
- the quiet-chat sweep;
- a consented voice note;
- the recorder's job;
- the Structure button.

A segment exists only after its chat's consent (D754), so nothing unconsented is ever translated.

**Detection, cheaply.**

1. **The script.** It settles most passages for free: Cyrillic (Ukrainian by its letters), Arabic (Urdu and Persian by theirs), Hebrew, Greek, Devanagari and the other Indic scripts, kana, Han, Hangul, Thai, Georgian and Armenian.
2. **Latin text.** It is scored on short common words and diacritics for English, Spanish, French, Portuguese, German, Italian and Dutch.
3. **No clear winner.** Latin text that no language claims more strongly than the working language is read as the working language, so a short "ok, Friday" costs nothing.
4. **A real contest.** Only then does one small-model call decide (`detect_language`, the 8B).
5. **Nothing placed.** A passage that still cannot be placed is `undetected`. Its original stands and nothing is charged.

**Translation.** One `translate_segment` run per segment, through `aiRouter.run`. That run:

- holds the member's AI tokens before the model (`reserveAiBudget`);
- settles after it (`settleAiReservation`);
- writes its `ai_usage_logs` row, with the page `/validate/customer-research`.

The segment records that row's `reservation_uid` as `translation_reservation_uid`.

The models:

- `@cf/meta/m2m100-1.2b` translates every pair.
- `@cf/ai4bharat/indictrans2-en-indic-1B` translates only from English into an Indic language. It is used for that direction, with its FLORES code (`hin_Deva` …), and its `{ translations: [] }` answer is read (`ai/shapes.ts`).
- Both are priced from the catalogue, at $0.342 per million tokens in and out.

There is one pass per session, with at most 200 segments in it.

**The working language costs nothing.** A segment already in it is marked `same`. No model runs and nothing is charged.

**Failure leaves the original.** A refused or failed run marks the segment `pending`, and the session keeps working on the original. A refusal that would refuse every other segment ends the pass at once:

- no AI tokens left;
- a spend limit;
- AI paused or assistance off;
- the guard unavailable.

A pending segment is tried again on the next pass, at most three times (`translation_attempts`).

### 3. What reads the translation

- **`structureSession`** reads each segment's translation when it has one (`readSessionSegments`). Each placement cited from translated segments keeps, beside its `quote` (the translation the model read):
  - the cited segments' original words (`quote_original`);
  - their language (`source_lang`).

  Both are in `validate_proposals.citation_json`, so no new column is needed (`withOriginals`, `storePlacements`).
- **`moduleSuggestions`** returns `quote_original` and `source_lang`. The original has the same consent gate as the quote: without the interview's consent to be quoted, both are withheld.
- **The session page** (`GET /api/founder/validate/sessions/:id`) returns each segment's own words in `text` and, beside them:
  - `translation` (decrypted for this writer);
  - `source_lang`;
  - `translation_status`.

  The ciphertext never leaves the Worker.

### 4. Privacy

**The translation is encrypted at rest.** It uses `columnCipher` (AAD `interview_transcript_segments:translated_text:<id>`). It is never logged, and it is deleted with its segment and its session (`deleteSession` already deletes the segments).

**The original segment text was already plaintext.** It has been plaintext in `interview_transcript_segments.text` since D657, and is copied to `discovery_interviews.transcript`. The issue says "encrypted like the text", but only the pending chat store (`channel_thread_messages.text_enc`) is encrypted today. This change does not alter the original's storage. Encrypting it is a separate change that every reader of `text` would follow.

### 5. Whisper's translate mode or transcribe-then-translate: not measured

The issue asks for a measured choice between Whisper's own translate mode (`whisper-large-v3-turbo`, `task: translate`) and transcribe-then-translate.

**Nothing was measured.** This environment cannot call Workers AI: every model in the tests is stubbed. So the choice rests on the requirements, not on a measurement. It is **transcribe-then-translate**, because:

- **Whisper's translate mode outputs English only.** It cannot serve a working language other than English, which Q1 A allows.
- **It returns no transcript in the spoken language.** The issue requires the original to be kept beside the translation.
- **The extra cost is small.** Speech-to-text is billed per audio minute either way. The translation adds m2m100's tokens: about $0.342 per million, or well under a millionth of a dollar for a typical voice-note segment.

The quality comparison is left to a run on the owner's account. Run the same French and Spanish notes both ways and compare the English. If Whisper's English proves better for English-working founders, the voice-note path can use it for that pair alone and keep the original from a second transcribe.

### 6. What is not built here

- **A way to set the working language.** The column exists and is read; the screens are W7's (#2507).
- **The session summary.** The engine's summary stage still reads the original text. Only the structure stage reads the translation.
- **The Telegram coverage.** That is #2511, which stacks on this.
