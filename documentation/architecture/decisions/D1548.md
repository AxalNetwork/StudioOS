### 2. The Terms re-acceptance (decision Y)

- **The switch.** `TERMS_REACCEPT_FROM` in `services/trust.ts`, a `LEGAL_DOCUMENT_VERSIONS` date or null. It ships null.
- **The gate is the existing one.** `GET /auth/me`'s `terms_acceptance_pending` (task #178) already gates the app with `AcceptTermsPage`. It keeps its first query unchanged. When the switch is set, a second query runs: an account whose `tos_v1` obligation is required and `satisfied`, but which has no `legal_acceptances` row for `tos_v1` with `document_version` at or after the version, owes the acceptance again.
  - An acceptance recorded before migration 583 has no version, so it does not count as v4.
  - Waived, not-required and unseeded accounts are not asked, as before.
  - A database error still gates nobody.
- **The reason.** `/me` also returns `terms_acceptance_reason`: `'missing'`, `'updated'` or null. `App.jsx` passes `updated` to `AcceptTermsPage`. Its default copy says "Nothing about the documents has changed", which would be false here. So the updated screen says the Terms changed since the member last agreed, and links to them. It does not summarise counsel's text or name a version.
- **Accepting clears it.** The screen calls the same `POST /auth/accept-terms`. `recordTermsAcceptance` records `LEGAL_DOCUMENT_VERSIONS.tos_v1`. So the switch must never be later than that date, or the screen would never clear. A test enforces this.
- **The obligation key stays `tos_v1`.** Versions live in `document_version` (D1074). A new `tos_v4` obligation key would have meant reseeding every account and changing the Trust Center matrix, for no gain.

**To go live, once counsel's Terms text exists:**
1. Put the text on `/terms` (`frontend/src/pages/TermsPage.jsx`) and in the v4 template.
2. Move the template module's `tos` import to it.
3. Move `TERMS_UPDATED` and `LEGAL_DOCUMENT_VERSIONS.tos_v1` to the new date (D1074's test holds the two together).
4. Set `TERMS_REACCEPT_FROM` to that date.

`test/legal_publish_d1548.test.ts` fails if the switch is set while the v4 template still carries A19's DRAFT banner.
