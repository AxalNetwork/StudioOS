## D4587 — Keep Validate review work bound to its venture and session (#4587)

Status: accepted, 2026-11-07.

Validate's review focus and Customer research record continue to use the
existing overview, session and record routes. This decision does not add a
queue store or change access rights.

The overview chooses review work from every `transcribed` session and every
`structured` session that still has a pending, run-backed proposal. Candidates
are ordered by their recorded activity time descending and then session id
descending. Completed, draft and already-cleared sessions therefore cannot
hide older actionable work. The CTA names both `project_id` and `session`, so
normal navigation, a new tab, a bookmark and reload retain the same venture and
session. The existing project-scoped record read remains the authorization
boundary.

The record treats each interview/session selection as a request generation.
Session lists, details, receipts and audio may update the page only while their
originating generation is current. A detail response must also name the
selected session before summary, speaker, placement or summarise actions are
enabled. Switching selection stops and clears the old player; an object URL
created after a switch is revoked instead of being installed. Failures from an
obsolete generation are ignored just like obsolete successes.

The shared cycle-card retry callback remains owned by #4601. This decision
does not duplicate that callback or alter Worker permissions.
