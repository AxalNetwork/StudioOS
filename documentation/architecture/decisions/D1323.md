### 4. The rules every part keeps

- Eadwyn proposes and a person accepts.
- In a form nothing is written until Save.
- A typed value is never overwritten by Accept all.
- A decision, score, Verdict, identity field, signature or payment amount has no
  trigger.
- No model name and no option key appear in product copy.
- A failed read is "Unreadable", never "typed".
