## D4838 part 9 — Recent movement and the sheet's Activity from the lifecycle feed (#4838)

Built 2026-11-16 for #5943 (slot S33). Part of D4838 (Pipeline v2). Follows D5942, the recorded lifecycle feed (`GET /partner/pipeline/activity`, `routes/partner_pipeline.ts`), and part 8, the shared opportunity sheet (#5934).

### What was there

Recent movement on the populated command centre (PP02, PP02m) was a fixed Not recorded card: "Nothing joins lead, proposal, negotiation and retainer events into one timeline yet." D5942 has since recorded one feed. The opportunity sheet's Activity tab (part 8) already read the feed for one opportunity, with its own list of event words.

### The decision

1. **Recent movement is the feed.** The root reads `partnerPipelineActivityApi.list({ limit: MOVEMENT_SHOWN })` beside its other reads, settled on its own (`readPipeline`). `movementView` keeps the feed's rows in the order the Worker returns them, newest first. Each row is the event's date, its words and its opportunity's title. A kind this page does not know is left out, not guessed at.
2. **No event is derived on the page.** Nothing is sorted, merged or inferred from a stage, a date or a count on another read. The rows are the feed's, and the page shows at most `MOVEMENT_SHOWN` (8) of them.
3. **Three states, never conflated.**
   - A feed that answered with no events: "Nothing has moved yet", followed by the kinds that would count.
   - A failed read: Unreadable, "this is not evidence that nothing moved".
   - A failed feed read does not fail the page; the zones still draw.
4. **First run is unchanged.** First run is decided by the zones alone, and its setup path draws no movement. A feed event does not turn first run into the command centre.
5. **One list of event words.** `EVENT_WORDS` and `activityRows` move from `OpportunitySheet.jsx` to `commandCentre.js`, and the sheet imports them. Recent movement and the sheet's Activity tab therefore say the same thing for the same kind. The sheet's Activity tab (one opportunity's events in one timeline, `need_id`) is otherwise unchanged from part 8.

### Not built

- **A link from a movement row to its opportunity sheet.** No zone opens the sheet yet (part 8's departure). The row names the opportunity but does not link.
- **A "See all" for the feed.** No page lists the whole feed. The root shows the latest eight.
