### 1. The fake AI binding

`cloudflare-worker/test/_fake_ai.mjs`, `fakeAi({ answer, fail, failOn })`. It answers from recorded outputs and never calls a model. It counts the guard's calls apart from the model's.

It can inject each failure a real binding gives, on the `failOn`th model call or on every one:

| Failure | What the binding does |
|---|---|
| `rate_limited` | throws a 429 |
| `capacity` | throws error 3040, "Capacity temporarily exceeded" |
| `timeout` | throws a `TimeoutError` |
| `guard_block` | Llama Guard answers `unsafe` |
| `bad_json` | answers with something that is not the JSON asked for |
| `over_capacity_text` | returns the recorded JSON with every string far past any area's room, with no figure in it |
| `non_image` | an image model answers with words |

An image is answered base64 in `image`, as FLUX answers on Workers AI.

### 2. The one-click run on it

`cloudflare-worker/test/deck_fake_ai_d1511.test.ts` runs `POST /api/decks/generate` on the fake binding, with recorded words for every card. The venture's unrecorded records are unticked (`exclude`), as a founder does.

**The one-click bar:**
- no Not recorded placeholder;
- no fit or overflow problem;
- a quote (`POST /api/decks/new/quote`) at least as large as the settled charge. On the fixture it is 21,680 micro-USD against 108.

**Each failure through the same run:**
- **429, 3040 or a timeout on every try:** the deck comes back from records, with nothing charged.
- **A guard block:** 422 `guard_blocked`, before any model runs, and no proposal is written.
- **Bad JSON:** the cards keep their titles.
- **Over-capacity words:** they never overflow a card.
- **A non-image answer:** the router reads no image from it.

### 3. Contract schemas, and `test:drift` from "the route exists" to "the reply matches"

`cloudflare-worker/src/contracts/` holds:
- `deckGrid.schema.json`, the reply of `GET /api/decks/:id/grid` (#3749);
- `CONTRACTS`, each adapter method that has a route;
- `contractErrors`, the subset of JSON Schema those contracts use. A keyword it does not check is an error, never skipped.

**The Worker never loads a schema.** The tests read them.

**What `deck_contracts_d1511.test.ts` checks** (it runs in `test:drift`):
- the grid reply, for a deck saved before v2 and for a v2 deck at 4:3, matches its schema;
- an extra field, a missing one or an unknown aspect fails;
- every top-level field is required, so a new field enters the contract on purpose;
- every `deckV2Adapter.js` method swapped to `through()` has a contract, and every contract names a swapped method.

**The rule for later swaps** (`saveCard`, `batch`, `areasQuote` and the rest): the PR that swaps a method adds its schema and its `CONTRACTS` entry, or this test fails.

### 4. Property tests

They run over seeded random inputs, so a failure names its seed and replays. There are two files.

**`cloudflare-worker/test/deck_grid_properties_d1511.test.ts`:**
- **Every structure** (all 17), at both aspects:
  - whole cells, with no cell in two areas;
  - every box inside the safe frame;
  - no two boxes sharing a pixel.
- **`deriveAreas`:**
  - for any blocks, it gives sound areas (whole cells, no overlap, at most 12) in reading order;
  - each area is one of the blocks' own ranges;
  - deriving again changes nothing.
- **`sanitizeAreas`:**
  - it is idempotent;
  - it keeps a saved reading order;
  - it refuses exactly what `areasProblem` names.

**`frontend/test/deck_grid_properties_d1511.test.mjs`:**
- **Op and inverse:**
  - any point inside a cell's box is that cell, and a point in a gutter is none;
  - a box's centre falls back in its cell, through `cellAtPoint` and `nearestCell`.
- **A move and its inverse:**
  - a block moved and moved back is where it was;
  - a nudge and the opposite nudge cancel;
  - a move never leaves the grid or lands on another block.

**Not on `main` yet,** so not tested here:
- reflow maps between structures;
- the editor's history ops with their inverses (#3767).

Each gets its properties in the PR that adds it.
