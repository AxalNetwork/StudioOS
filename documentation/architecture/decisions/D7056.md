### What the canvas decides

- The investor book keeps NW12.2 and its Tie Sheet: On Axal (38) and Contacts you keep (142), each with its own count and pager.
- Every form names its tie ("Draft for [Jonas Berg] · [Elm Studio] · tie 4127"), and Save names the person.
- Drafts, reads and save results are keyed by tie. Switching A → B → A keeps A's draft, opens B empty, and a late reply for A never changes B.
- A save is bound to the tie it was pressed on. A failed save keeps the text and puts focus on Retry; discard is explicit and names the tie.
- Each section shows its own state when its own read answers. A slow or failed introductions read leaves the book usable, with its own Retry.
- The operating partner logs an interaction from a named row or from the toolbar. The toolbar opens a keyboard picker scoped to the current view with nobody chosen; Continue stays off until a pick.
- A filter that matches nobody offers Clear search, Search all contacts or Cancel. A failed firm-book read shows Unavailable with Retry, never "Your book is empty".
- Each dialog names the person and firm, ends with a dated confirmation, and returns focus to the control that opened it.

### Backend required

- An idempotency key on both interaction writes, so a Retry after a lost reply cannot record a touch twice (#7056).
- Optional: `POST /book/:uid/interactions` returns the row it wrote (#7056).
- Refusing support-session writes on `/api/partnernet/*` (#6256).
