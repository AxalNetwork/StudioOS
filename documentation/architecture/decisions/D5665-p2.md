## D5665 part 2 — Preserve simultaneous SHA roles (#5665)

A source record may carry the PR head, tested commit, merge candidate, landed
commit and deployment target together. Itemized Slack rows retain every
validated role instead of selecting only the first available SHA. Check links
use the tested commit when it is recorded. Existing queued rows with one
stored SHA keep their original presentation. Source records and routing
remain unchanged; no live delivery is enabled by this correction.

Validation covers simultaneous distinct SHAs, exact check links, bounded
pages and existing delivery/restart behavior using fixture transports only.
