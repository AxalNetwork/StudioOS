## D5512 — Readable homepage counts and Network dismissal focus (#5512)

The homepage’s 11 px module-count label uses the existing `--ax-muted`
design token. Its only current use is the Platform section on the public
site’s opaque white background. The public site forces its light palette;
browser checks measure every rendered instance at desktop and phone widths
under both light and dark system preferences. No shared palette token changes.

Computed browser measurements: `rgb(107, 101, 119)` (`#6b6577`) against
`rgb(255, 255, 255)` gives **5.596:1** in all four width/preference
combinations (1440/390 px × light/dark). The original `#9a96a8` measured
2.876:1 on that background. The label remains 11 px.

The public Network disclosure keeps a ref to its button. Escape closes the
menu and returns focus to that button when focus was inside the disclosure.
Escape from an outside control closes the menu without moving that control’s
focus. Pointer dismissal and route changes retain their existing behavior;
links retain native activation, and mobile navigation retains its burger.

The browser regression opens Network with Enter, tabs to Overview, dismisses
with Escape, checks the actual focused element and visible outline, and tabs
onward to LP login. It also exercises pointer dismissal, outside focus, native
link activation and mobile navigation. Computed colors, backgrounds and WCAG
contrast ratios are attached to the browser report, with label and restored
focus screenshots. Pricing-specific accessibility remains with #4655.
