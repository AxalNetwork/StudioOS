### 1. Story's "Ask Eadwyn ▾" (NAR2) and its route

**The route.** `POST /api/cycles/raise/narrative/:version/sections/:section/draft` (`routes/cycle_raise.ts`, `services/narrative/sectionDraft.ts`):
- Body `{ mode: 'draft' | 'shorten' | 'plain', words? }`. `words` are the unsaved words on the page; without them, the stored words.
- One `rail_write` run, metered like every rail option, under page "Founder · Raise · Investor narrative" and option **`draft:narrative-section`**. The issue named `draft:narrative/section`; a slash in a founder draft key is a research ZoneDraft surface (`railOptions_founder_d771`), so it takes a hyphen, as D911 did.
- **It writes nothing:** no section, binding, or `ai_rail_proposals` row. It answers `{ version, section, mode, text, removed }`.
- **A write, by the narrative's gate:** an admin is refused 403 `admin_read_only` (D914) before any read or run.

**No figure enters; no figure leaves:**
- Every figure in the founder's words is masked as `[figure]` before the model reads them. The positioning is read as words only.
- Each sentence of the answer that holds a digit (or the mask) is dropped and counted in `removed`. If all of them are dropped, the answer is 422 `nothing_kept`.
- The store still refuses a digit in Eadwyn's wording on save (D908). So a figure enters a section only as a bound figure.

**Refusals:**

### 3. A bound figure sits inside the sentence (NAR2, NAR20)

- **Why not a token:** D908 keeps a section's bindings as an ordered list beside the words, and most sections' words are the deck's own rows. A token in them would print in the deck, and a character offset would need a migration.
- **How it works:**
  - Insert a figure writes the figure's own value where the cursor is, and binds it.
  - "Reads as" draws that value as the bound chip, in its place (`inlineSegments`). Each binding takes one place, and it matches its own value, never the first number.
  - Any other typed number stays a claim, "Founder's figure".
  - A bound figure whose value is not in the words yet is listed once under them, "Not in the words yet", until it is placed.
  - The deck prints the same value.

### 4. Home's From Mercury: "Insert in Story" (NAR1)

- **Where:** on the Investor narrative's From Mercury card only, beside each figure Story can bind.
- **Why it can bind them:** each of Mercury's citable figures is the same record as a Story source (`services/decks/sources.ts` `MERCURY_SLOTS`):

  | Mercury figure | Story source |
  |---|---|
  | `revenue_last_month` | `grow.mercury_revenue` |
  | `revenue_growth` | `grow.mercury_growth` |
  | `net_burn` | `grow.net_burn` |
  | `runway` | `grow.runway` |

- **What it does:** the door is `/raise/investor-narrative/story?…&insert=<source_key>`. Story opens Insert a figure on that one record, for the section that is open.
- The card adds the canvas's line: "Investors see one of these only after you insert it in the Story."
