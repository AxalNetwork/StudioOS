## D7917 — Bound row-count batches and preserve drill cleanup (#7917)

D1 refused the 40-term UNION ALL query despite accepting the restore. Count up to 40 tables with one SELECT of scalar COUNT subqueries, alias columns c0 through c39, then map those columns back to manifest names before comparison. Validate the whole response before appending; a missing/malformed batch falls back to per-table queries. SQL identifiers remain quoted and no backup values or raw provider errors are logged. Both operator restore and monthly drill use this shared implementation.

The workflow gives its drill step 50 minutes and reserves a five-minute always cleanup step within the 60-minute job. Before creating a database, the drill writes its name to a private ownership file outside its temporary restore directory. Actions names include the UTC stamp, run ID and attempt, preventing concurrent-run collisions. Successful EXIT-trap deletion removes the file; failed/interrupted cleanup leaves it for the workflow fallback. Fallback validates a regular non-symlink file and the exact run/attempt name before deleting, never enumerates resources, and retains the record on failure.

No always step can guarantee execution after runner loss or platform termination; an absent cleanup confirmation still needs operator reconciliation. The historical orphan identified in #7917 is an owner dashboard action, not targeted by this new cleanup. After T2 merge, the authorized main DR drill and its row-count, cleanup and RPO/RTO evidence belong on #1008 under #7127. No live drill, production read/write, orphan deletion or workflow dispatch is performed by this implementation.

Tests use real SQLite behind a fake Wrangler that rejects every compound SELECT. A 115-table restore compares in three count queries, and per-table refusal fallback remains tested. Cleanup tests cover cancellation-like leftover ownership, successful retry, malformed/foreign/production records, symlinks, absent record, and create-before-cancel ownership. Actionlint, shell syntax and local checks are recorded on the PR. Rollback reverts query construction/cleanup wiring; it does not certify an orphan removed or a restore successful.
