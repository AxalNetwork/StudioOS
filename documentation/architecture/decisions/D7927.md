## D7927 — U.S. Census County Business Patterns: national establishments, employees and payroll by NAICS industry (#7927)

**Decision date:** 2026-11-26. **Scope:** one importer (`services/marketObservations/censusCbp.ts`) and its registry
entry, a bounded ZIP reader (`util/zipRead.ts`), `naics_2017` added to the industry schemes, one data-only migration
(`202611260844_7927_census_cbp_source.sql`: source `census-cbp`, **disabled**, and three catalogue rows), and tests
with invented provider files. No screen, schedule, credential, seeded observation or production write.

### Where the data comes from (read 2026-11-26)

- The Census Data API (`api.census.gov/data/<year>/cbp`) needs a key: "A valid key must be included with each data API
  request", and a keyless query redirects to `missing_key.html`. The owner chose the flat file instead, which needs no
  key: `https://www2.census.gov/programs-surveys/cbp/datasets/<year>/cbp<yy>us.zip`.
- `cbp23us.zip` (750,265 bytes, `Last-Modified: Thu, 26 Jun 2025`) holds one deflated entry, `cbp23us.txt` (3.8 MB,
  CRLF, quoted CSV). Header: `uscode, naics, lfo, emp_nf, emp, qp1_nf, qp1, ap_nf, ap, est`, then size-class columns.
  `lfo = "-"` is all legal forms of organization. NAICS is padded: `------` all industries, `54----`, `5415//`,
  `541511`. 2023 is the latest year (the 2024 path is a 404) and is still NAICS 2017.
- The national file covers the 50 states and DC. Coverage excludes the self-employed, private households, railroad,
  agricultural production and most government employees. An establishment is a single physical location. Employment
  is the pay period including March 12; payroll is in $1,000.
- Noise flags in the record layout: `G` under 2 %, `H` 2 to under 5 %, `J` 5 % or more, `N` not available (the field
  is set to zero). From 2017 the old `D` flag was replaced by `S`. The methodology page now says its "information on
  this page is no longer current", because the Department of Commerce ordered noise infusion stopped; a release after
  2023 may therefore change its flags.

### Terms relied on

The dataset metadata (`https://api.census.gov/data/2023/cbp.json`) gives the licence CC0 1.0 (release modified
2025-03-06). The Census Data API terms of service (revised 2026-04-14) ask for the notice that the product is not
endorsed or certified by the Census Bureau, that content not be modified while still presented as the Bureau's, and
reserve a right to limit use. The flat file is not the API, but the source note carries the same notice anyway. Values
are stored as published; only the NAICS padding is removed.

Hence the source lands **disabled**: #7927 authorises no live activation, so the owner enables it with an operator
migration when they choose. `export_allowed` stays unset (D7716).

### What a row says

| Field | Value |
| --- | --- |
| metrics | `cbp_establishments` (EST, establishments, units); `cbp_employees` (EMP, persons, units); `cbp_annual_payroll` (AP, USD, thousands, current prices) |
| `statistical_unit` | `establishment`: never summed with enterprise counts (D7716, D7717) |
| `industry_scheme`, `industry_code` | `naics_2017` and the unpadded code; the all-industries total has neither |
| `size_band` | `all_sizes`. CBP size classes count establishments, not enterprises, so they match no D7716 band and are not imported |
| `geography` | country `USA` |
| `observation_status` | `unspecified` |
| `vintage`, `published_at` | the archive's `Last-Modified`; without one, a content hash and no date |
| `limitations` | the coverage text above, plus the cell's noise-flag note |
| key, series | `cbp:us:<year>:<code>:<column>`, `CBP.US.<code>.<COLUMN>` |

A cell flagged `N`, or with a flag the layout does not define, stores **no row**, never a zero; the report counts
them (`not_available`, `unknown_flag`) beside the industries the file does not publish (`not_published`). A published
zero establishment count is a value and is stored. A duplicated industry row, a missing column, a short line or a
non-integer value fails the whole batch with `provider_payload`.

### Bounds

One request per batch: one year from 2018 to 2023, one to ten industries, up to three metrics (at most 30 cells,
inside the writer's 40). The archive is capped at 4 MB, the entry at 16 MB inflated; the ZIP reader refuses ZIP64,
multi-disk, encrypted, missing or ambiguous entries and checks size and CRC. A year after 2023 is refused until
someone reads its layout and raises `LAST_VERIFIED_YEAR`.

### Rollback

Revert the PR. The source row stays disabled; nothing is imported until the owner enables it.
