## D5292 — Facebook Pages connection and deletion callback (#5292)

Facebook uses the shared Meta app with a separate Login for Business
configuration and a long-lived user token. The Worker checks granted
permissions before accepting a connection and before reading or saving Pages.
Selections belong to the enabled company and are revalidated against the
current Pages directory before saving. Disconnect revokes the named Facebook
permissions. The signed Meta callback deletes the matching Facebook connection
and its directory configuration and returns a signed completion receipt.
