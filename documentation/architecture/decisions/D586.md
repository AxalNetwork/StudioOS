## D586 — Wyoming C-Corps are formable, priced from the catalog, chartered by counsel

**A Lab founder whose application chose Wyoming can order a Wyoming C-Corp
(`us_wy_ccorp`).** Two conditions apply:
- It is priced only from the Stripe catalog.
- Its Articles of Incorporation are generated only from a counsel-approved
  body.

Slot S08, issue #1213, 2026-10-06, from the owner's answer A on #1213. No
migration.

### What the owner chose

**A: form Wyoming companies.** The owner adds the catalog price, and counsel
approves the Wyoming documents. Both are actions outside the code, so this
change makes Wyoming orderable the moment each one lands, and says what is
missing until then.

### The Worker (`routes/legal.ts`)

- **`JURISDICTIONS` has `us_wy_ccorp`, "Wyoming C-Corp".** It is a C
  Corporation, not supported by Stripe Atlas (Atlas forms Delaware companies).
  Its tax summary says only that the 21% federal rate applies and that Wyoming
  levies no state corporate income tax.
- **Its templates** are `articles_of_incorporation_wy`, `bylaws`,
  `stock_purchase_agreement` and `section_83b`.
- **The price.** `GET /incorporation/quote` and `POST /incorporation/order`
  price it through `resolveIncorporationPrice`. That means an active catalog
  product tagged `jurisdiction_id = us_wy_ccorp` with a one-time price.
  - Wyoming has no `JURISDICTION_COSTS` entry and no legacy
    `STRIPE_PRICE_INCORP_*` env price, so no estimate can be charged.
  - Until the owner adds the price, the quote says `catalog_price_missing`.
    An order is then refused (502) before any order row is written or Stripe
    is called.
- **The charter needs counsel.** `COUNSEL_REQUIRED_TEMPLATES` holds
  `articles_of_incorporation_wy`. The wizard writes that document only from
  an active body in the D1 template store. Until there is one, it writes no
  stub row and lists the document under `pending_counsel`.
  `templates/legal/LEGAL_REVIEW.md` records the request. It also asks counsel
  to confirm the shared bylaws, stock purchase and 83(b) bodies for a
  Wyoming corporation.
- **The handoff** lists the Wyoming Secretary of State filing, a Wyoming
  registered agent and the EIN application.
- **The name check** (`services/nameCheck.ts`) asks the Wyoming register
  through OpenCorporates (`jurisdiction_code us_wy`). Without the API key it
  answers "verify manually" (`wy_register_requires_manual_check`).

### The page (`SpinoutLabIncorporatePage.jsx`, `lib/incorporationPricing.js`)

- **`formationJurisdiction`** maps a Wyoming application to `us_wy_ccorp`
  for a C-Corp. A Wyoming PBC or LLC has no Worker jurisdiction, so it gets
  no id and the page says why.
- **The formed entity and its charter take the state's names**, through
  `entityLabel` and `charterName`. For example, "Wyoming C-Corp · State of
  Wyoming" and "Articles of Incorporation". Before this the page would have
  printed "Delaware C-Corp · State of Wyoming".

### Done when

No surface calls a jurisdiction live unless a founder can order it. Delaware
and Wyoming stay live in `LAB_JURISDICTIONS` and the brief's `JURISDICTIONS`,
and a test maps every live entry to a Worker jurisdiction. Whether a founder
can pay today is the catalog quote's to say, and the page shows its reason
when it cannot.

### Still with the owner and counsel

- **The owner:** add the Stripe product and one-time price tagged
  `jurisdiction_id = us_wy_ccorp`.
- **Counsel:** supply the Wyoming Articles of Incorporation, and confirm the
  shared documents.
