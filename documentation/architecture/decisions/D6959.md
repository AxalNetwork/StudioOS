### What is verified, and how

- **Where.** In the `visual` suite (`frontend/tests/visual/`, CI's `visual` job): the built SPA and the real Worker from `server.ts`, in Chromium. Five layouts:
  - the desktop card at 1440×900;
  - the phone sheet under Playwright's `iPhone 13` (390) and `iPhone SE` (320) descriptors, and `Pixel 7` resized to 390 and 320.
  - The descriptors give viewport, user agent, touch and `isMobile`. Their WebKit default is dropped, so the iPhone rows are iOS-shaped Chromium, not Safari.
- **Mocked, not live.** Every sign-in request is answered by `page.route`: Apple's and Google's config, start and callback redirect, Google's window (a stand-in `gsi/client`), magic-link send, `/auth/login`, both passkey calls. Turnstile and `navigator.credentials.get` are stand-ins, and no request leaves 127.0.0.1. This proves what the page sends and how it reads every answer the Worker's callbacks can return (success, cancel, denial, transient failure). It does not prove what Apple or Google answer.
- **Approximations, named in the spec.**
  - An open keyboard is a shorter layout viewport.
  - 200% text is `text-size-adjust: 200%` on a phone (as Android's font scale) and half the CSS viewport on the desktop (browser zoom).
  - `env(safe-area-inset-bottom)` is 0 in Chromium, so the check reads the sheet's padding at a zero inset.
- **The protected Grow return** stays with #4580's `frontend/tests/e2e/grow_return_4580.spec.js`, not edited here (ownership not agreed). This spec covers `?next=` with a query through the code, Apple and Google paths and the contextual Create an account link.

### Found and fixed (one line)

- **Resend on "Check your email" never sent where Turnstile is configured** (production).
  - `sendMagicLink` refused without a Turnstile token, but the sent step mounts no widget, and the step change cleared the token. So Resend said "Please complete the verification challenge first." with no challenge on screen.
  - The token check now applies only to the link step. `/api/auth/magic/start` never received the token (`magicStart` sends only the address), so no server check changes.
  - Guarded by `login_offers_what_it_names.test.mjs` and the spec's resend step.

### Noted, not changed

- Under reduced motion the sheet appears at once: `index.css`'s global rule (`animation-duration: 0.001ms !important`) shortens the sheet's own 120 ms fade. That is calmer than D6958 describes, so it is left as it is.
