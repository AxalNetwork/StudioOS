## D4420 — Project Work and company Compliance entry points (#4420)

Work has no sidebar link. The Portfolio project page reads one project-only
summary aggregate behind the same flags and membership checks as the board,
and a two-week burn-up through the Work adapter. Empty history is Not
recorded; failed reads are explicit and retryable. A history failure keeps
the successfully read counts. The card links to that project's Work page.

The Portfolio company page reuses the existing Compliance card with its next
five tasks, full overdue count and links to the company's compliance list
and the Calendar compliance layer. The Calendar link uses the supported
compliance layer; no company filter is invented. A standalone project never
mounts a Compliance card, and a company mounts no Work card.

No optional per-project row counts, new store or migration is introduced.
