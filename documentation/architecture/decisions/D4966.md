### What the canvas decides

- **General** regroups into Company identity, Public presence, Matching profile and Business snapshot, with a sticky preview, a save-status rail and a sticky Save / Discard bar.
- **The preview shows public fields only.** It draws what the Worker's `PUBLIC_FIELDS` exposes; revenue, employees, products and goals are private and never appear in it.
- **Save states:** clean, dirty, saving, saved, invalid (a summary plus inline errors), failed, partial ("Logo saved; 2 profile changes still need attention"), outcome unknown, and conflict; a 12-state matrix (CS-12).
- **No atomic-save claim:** fields go over `PATCH` and the logo over its own routes, and the boards say so.
- **Currency** is a combobox over the existing ISO list; "Not recorded" is explicit and nothing is guessed. **Regions** are a multi-select tagged pending, because today they are one comma-separated column (`international_presence`).
- **Read-only:** a support session gets a compact mode bar and genuinely read-only fields; an archived company shows Restore.
- Components: logo uploader (6 states), URL fields with normalisation hints, narrative, number and revenue fields, and a leave-with-unsaved-changes dialog. Four phone boards at 390, dark mode, and an accessibility spec.

**Departures, and why.**

- **Revenue is a band, not free text.** The canvas tags revenue "Free text today · revenue bands need
  the data contract · #4964". #4964 has since merged and `REVENUE_RANGES` exists, so the field is the
  band picker it already was. Keeping free text would be building backwards.
- **Regions are the canonical codes, built as drawn.** The canvas tags the multi-select pending #4964
  for the same reason; the codes exist, so it is built over them, with a legacy entry no code covers
  shown to the editor rather than dropped.
- **The group picker below 1024px is a `select`, not the canvas's segmented control.** One control, one
  label, 44px, and nothing new to maintain; the canvas's own phone board shows a selector.
- **"Recent currencies" is not built.** The canvas says "recent would need stored history"; nothing
  stores one, so the list is the fixed common set and the stored code.

**Checked in a browser.** The built SPA was served from `docs/`, the Worker stubbed (the session, the
company read, and `/api/settings/appearance` for the theme), and
`/account/portfolio/<uid>/settings` opened in Chromium at 1440 × 1100 and 390 × 844, in light and in
dark. Each of the four runs: the four groups drew, the preview drew, the currency combobox opened and
found GBP for the query "pound", the rail read "Unsaved changes · 1 field" after an edit, the preview
was marked "Includes unsaved changes", no private value (`100k_1m`, a product, a goal, the employee
count) appeared in the preview, there was no horizontal page scroll, the page was in the theme asked
for, the preview's toggle was drawn at 390 and not at 1440, and the console was clean. Two layout
defects were found this way and fixed: the changed-field ring boxed a textarea's character count
along with the textarea (the ring is on the control now), and the preview offered a Hide/Show toggle
on a desktop, where it is the sticky rail.
