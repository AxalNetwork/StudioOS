## D5157 part 4 — Research Project briefs (#5157)

A member can write and review the eight RS-09 sections, with one saved brief
per project. The project owner can read it and can edit it while the project
is active. A version check rejects stale writes. The Research Overview lists
the latest saved briefs from that member's projects.

Brief sections are written by the member. The Findings tab remains the
source of structured findings and citations. This slice does not generate
brief text, send it to another module, or change the Ask session store.
