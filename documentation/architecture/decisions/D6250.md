## D6250 — Issued fund report reading view (#6250)

Issued periods render a document using the approved Investor Fund Detail Pages
canvas: attributed issue masthead, prose sections, reciprocal correction links
and a frozen-figures side column that stacks on phone widths. Managers retain
the separate correcting-period action and LP delivery receipt. Draft editing
and Worker authorization stay unchanged.

The fund rows reuse the PDF model's frozen report-pack sections. Legacy issue
snapshots render only their recorded cents and reasons; neither current fund
totals nor the operator model fill missing history. The issuer is the stored
name, with an explicit absence reason for old periods.

Print uses the document's print stylesheet. The existing LP archive PDF export
remains the single PDF renderer; its issued rows now link to the reading route.
