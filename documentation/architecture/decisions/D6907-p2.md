### What is proposed

- **Only the askable types.** The card asks the clause read only for the
  types that `askableTypes(rightsRows(...))` gives: rights not recorded, with no
  open request. So it never proposes a recorded right, or a right already
  requested.
  - It reads nothing when no type is askable.
  - It is not drawn for a viewer who cannot ask (`canAsk`).
- **One proposal per right type.** It comes from the first readable document in
  the read's order, and from that document's first matching clause.
- **The wording** follows PRM18. The sentence is "This *document* §*n* grants
  you *right*; it is not recorded here. Add it?" The citation is "Source:
  signed *document* · *date* · §*n*, page *p*". Where the paper does not mark a
  page, the page is left out, never guessed. A clause with no number is named
  by its heading, else by its line.

### Accept, Edit wording, Discard

- **Accept** sends one `POST /api/portfolio-rights/requests` with
  `{ project_uid, type, description }` and nothing else.
  - The description is the document, the clause, the page, the signing date
    and the quoted clause text, cut to fit the request's 2,000-character limit.
  - The rights read then refreshes: the right shows Requested, its proposal is
    gone, and the page says "Sent to HQ: …, from Eadwyn's proposal".
- **Edit wording** opens the description in a box. Send to HQ makes the same
  single request with the investor's words. A blank description is caught
  before sending.
- **Discard** forgets the proposal on this page. Nothing is sent or stored.
- **A refusal** shows the same wording the request form uses (for example
  `request_open`), and the proposal stays on the page.
- **Eadwyn never records a right.** The card has no path to the admin record
  route.

### States, kept apart

| State | What the card says |
|---|---|
| Reading | "Reading your signed documents…" |
| The clause read failed | Eadwyn could not read the documents, and that is not a finding that none grants a right. Retry is offered. |
| No signed document | Says the investor holds none for this company. |
| Every readable document read, nothing found | Says how many documents were read and that none grants an unrecorded right. |
| Every document unreadable | Says Eadwyn cannot say whether one grants a right. |

In every state the documents Eadwyn could not read are listed with their reason.
So "none found" is never said about a document that was not read.

### Departure from the canvas

- **Where the card sits.** PRM18 draws the proposal in Eadwyn's rail. The
  company page's rail is the shared `WorkerRail`, which has no slot for a card
  owned by the page. So the card is an Eadwyn section, headed "Proposals only ·
  you decide", directly under Rights under your documents. #6888 placed its
  covering-note card in the statement sheet the same way.
- **No model run.** The proposal comes from the clause read, not from a model
  run, so nothing is metered.
