## D4637 — Public Help and safe support channels (#4637)

### Decision

Expose only an explicit, reviewed subset of account-independent Help guides to anonymous visitors. Public Help is not a blanket exemption for tickets or admin content: the catalogue and its search use the same role-filtered manifest. The public-route predicate exempts the home and article-shaped URLs from incidental API-401 redirects, but excludes ticket and admin paths.

Keep ticket lists, article feedback and popularity reads authenticated. Security reports use the existing private reporting path from D1075 (#2967), with GitHub's private security advisory available to signed-out visitors. Ordinary ticket submissions disclose public GitHub mirroring and the absence of attachments before submission.

### Boundaries and verification

No new private store or API route is created. No unsupported response-time guarantee is asserted. The blocked Help Center redesign (#4957 / #4640) owns visual restructuring, not this security and routing fix. Guide eligibility uses an explicit whitelist in the existing manifest; admin and ticket URLs remain guarded.

Tests cover anonymous route handling, catalogue/search parity, excluded admin/account guides and authenticated-only widgets, plus the pre-submit confidentiality notice. Production browser verification for anonymous and authenticated roles remains necessary after deployment.
