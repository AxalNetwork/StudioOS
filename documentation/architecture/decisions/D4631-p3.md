## D4631 part 3 — Apply deal audience rules to investor workspace reads (#4631)

The investor licence and verified firm still determine access to the investor workspace. A deal-backed response also follows the caller's current relationship to that deal. This extends [D4631](./D4631.md) and the cross-vendor review tracked in #5307.

| Surface | Access and response |
| --- | --- |
| Deal Flow and New for you | Personal and verified firm rows retain their existing workflow fields. The shared deal audience determines whether each row opens a room. Flow membership and inbox source carry no independent room access. |
| Deal Flow stage, pass and history | Existing personal or firm scope applies. Closing still requires a current commitment. The flow records the firm's work and the round keeps its own status. |
| Saved views | Author, firm membership, seat status and selected company govern the saved settings. The settings carry no deal permission. |
| Thesis fit | Uses the current deal audience and a live venture before reading fit inputs. Unavailable rows keep the existing neutral projection. |
| Comparison notes | Drafting, saving and reading deal-backed notes respect the current deal audience. Notes stay scoped to their author. The existing investor score-sharing gate still applies when preparing the draft. |
| Send an NDA | The venture's active NDA prevents a duplicate send. The sender's pending envelope is checked separately to preserve the in-flight signing record. |

The creation and withdrawal transition rules from #4632 and the firm attribution from #4633 retain their existing scope. The primary-role investor paywall remains the owner's billing decision recorded in #4631.

Verification uses the existing synthetic Deal Flow, comparison note, saved-view, and data-room route suites. The PR stays in draft for cross-vendor review.
