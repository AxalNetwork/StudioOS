## D583 — The Brand page stores voice tags, a dark logo and an Archived page status

**A founder's brand now carries up to three voice tags and a dark-background
logo, and a landing page can be archived and restored.** Slot S08, issue
#1210, 2026-10-06. S1 decided 1A, 2A and 3A for the owner, as the issue's "Do"
section and the canvas describe them. Migration 399.

### The decisions

1. **Voice (A).** Up to three free-text tags, trimmed and deduplicated.
2. **Archived (A).** Archiving unpublishes the page and hides it from the
   list. The page is kept and can be restored.
3. **Dark logo (A).** A second logo, uploaded through
   `/api/brand/logo/upload`'s type, size and storage checks.

### The store (migration 399, on `landing_pages`)

Migration 399 adds these columns to `landing_pages`:
- `voice_json`, a JSON array;
- `logo_dark_url`, `logo_dark_svg` and `logo_dark_asset_id`;
- `archived_at`.

All are nullable, with no backfill. `services/landingPageSchema.ts` carries the
same columns as the D235 safety net. Every public brand route calls it before
reading.

### The routes (`routes/brand.ts`)

**Voice and the dark logo**
- Both are validated by `parseBrandExtras` **before** the page is written, so a
  refused value never leaves a half-saved page.
- Both are stored only when the body names them. A write that doesn't carry
  them, such as Eadwyn's or an older client's, leaves them as they are.
- Voice tags are trimmed, inner spaces are collapsed, and duplicates are
  dropped regardless of case.
- These voice values are refused:
  - more than three tags;
  - a tag longer than 32 characters;
  - anything other than a list of text.
- `null` or an empty list clears the voice tags.
- The dark logo's URL and SVG go through the light logo's own sanitizers
  (`sanitizeLogoUrl`, `sanitizeSvg`).
- This applies to `PUT /landing/by-project/:pid` and `PUT /landing/pages/:id`.

**Archiving**
- **`POST /landing/pages/:id/archive { archived }`** has the same ownership
  scope as publish.
- **Archiving** sets `archived_at` and `published = 0`.
- **Restoring** clears `archived_at` and leaves the page as a draft.
- **The page list** hides archived pages. `?archived=1` includes them, for
  Restore.
- **Both publish routes** refuse an archived page with 409 `page_archived`.
- **Every public route** (the JSON, the site page, the waitlist, the view
  ping and the two HTML renderers) also requires `archived_at IS NULL`. An
  archived page is never served, even on a row that is somehow still marked
  published.

### Dark templates

`DARK_TEMPLATES` lists the four templates drawn on a dark ground:
`capital-ready-kit`, `capital-storyteller`, `seed-stage-spark` and
`builders-launchpad`. On these, a page's dark logo replaces the light one
wherever the template places it. A test renders every template and checks
the set against the `color-scheme: dark` each one emits.

### The page (`SpinoutLabBrandPage.jsx`)

The brand rail gains two pieces:
- **"Logo on dark"**, a second upload shown on a dark tile;
- **"Brand voice · 3 max"** chips.

Both save with the brand.

Each page card shows Archived, Published or Draft and has an Archive button.
"Show archived pages" lists the archived ones with Restore, and says so when
that list cannot be read. The header no longer lists the three as omitted.
