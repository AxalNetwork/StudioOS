## D6481 — First-time queue admission for eligible pull requests (#6481)

A scheduled Actions workflow on the default branch can request native queue entry for a green T0/T1 pull request, including after its creating session has ended. The owner keeps T2, model-repaired and already-ejected pull requests. The implementation uses #6469's suggested order and the same admission rules as the interactive landing procedure.

Each run has one serialized reservation against the UTC daily cap. A scoped installation token submits the verified head to the native queue. A changed head invalidates the request. The run summary and the PR's queue timeline record admission. The combined candidate still goes through the default branch's required checks.
