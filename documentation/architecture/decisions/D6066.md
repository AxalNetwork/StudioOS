## D6066 — Pitch Review: the "intentionally qualitative" card mark (#6066)

**Decided by the owner, 2026-11-15: yes**, a founder may mark a card as
carrying no figure on purpose. The forward-looking-statements rule is **not**
decided here: its wording stays with counsel under owner decision T on #3716.
Until counsel's wording lands, the built footnote (D1546,
`services/decks/compliance.ts`, `complianceModel.js` `FLS_FOOTNOTE`) keeps its
interim text.

**The rule.**
- A card the founder marks is reported by Review's evidence check as
  **Qualitative by choice**, not as a gap ("no figure", "no evidence").
- The mark never counts as evidence, and never raises a card's evidence
  coverage. It only stops Review asking for a figure the founder decided the
  card should not carry.
- Any figure the card does show is still checked as before (source,
  freshness, forward-looking). The mark cannot hide an unsourced number.
- The mark belongs to a saved version, so each version's Review reads that
  version's marks.
- Only the venture's founders, who write the deck, set or clear it. A shared
  investor view never shows it.

**Where it is stored.** On the card itself, in the deck's saved slides
(`pitch_decks.slides`, the version's card JSON), as `qualitative: true`,
absent when unmarked. No migration is needed: the slides are JSON. The
Editor sets it from the card's menu ("Mark as intentionally qualitative" /
"Clear the mark"). Review reads it from the exact saved version it checks.

**The build.** Building the mark belongs to Pitch Studio v2 build 6/9
(#6060, Review of one saved version, PS-06), which names this decision as a
dependency. No separate issue is filed, so two slots never edit the same
Review files.
