## D6735 — Scope reference checks to the investor’s verified firm (#6735)

The deal reader rule still applies. Admins can read every check on an accessible
deal. An investor can read checks they authored and checks stamped with their
verified active firm, using the same company resolver as deal flow in D6148.
The Worker records that firm at creation. A later company switch or membership
change cannot move an existing check to another firm.

The additive migration leaves historical rows unstamped. A check without a firm
is visible only to its author and admins. No company is inferred for historical
data. A list with no visible checks returns the same 404 whether it has zero
checks or only hidden ones. The deal page displays this response as an empty
state and still offers scheduling. A missing or unreadable individual check
returns the same 404. PATCH and DELETE still require the author or an admin.
Consent capture inherits the same reference visibility rule.

This supersedes D609’s deal-wide read for investors. D6182’s reference card
restores the firm-visibility line and explains the administrator access.
