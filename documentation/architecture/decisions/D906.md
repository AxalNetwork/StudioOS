### 1. Where the tool lives

The tool is the Investor narrative module, not a page beside it.

| Address | What it is |
|---|---|
| `/raise/investor-narrative` | Home: CycleRoute's module page as today (the versions card, the versions table, From Mercury, Eadwyn's "Phrase the fix"), with the tool's tab bar under its header |
| `/raise/investor-narrative/story` | Story: one version's words, section by section |
| `/raise/investor-narrative/positioning` | Positioning: a door to today's generator, until part 5 stores positioning here |
| `/raise/investor-narrative/check` | Check: one version's consistency check against the metrics |
| `/raise/investor-narrative/versions` | Versions: every saved version, and two compared section by section |
| `/raise/investor-narrative/4` | a version's own page (its record), unchanged |
| `/raise/investor-narrative/new` | New version (the module's Add), unchanged |

- **No route is added.** Every `/raise/investor-narrative/<word>` already reaches the module's record route (`/raise/:slug/:id`, `App.jsx`), and every one is a cycle path (`cyclePaths.js` RECORD_ID).
  - A version's id is its number, so CycleRoute reads the four tab words as tabs (`isNarrativeTab`, `frontend/src/pages/raise/narrative/narrativeModel.js`) and never as records.
  - The record read is not made for a tab word.
  - The cycle-route rules (`cycle_spacing_d694`, `record_mode_d696`, the `/new` tie) all hold as they were.
- **A static route was weighed and refused.** It would have to mount `<CycleRoute` to satisfy `cycle_spacing_d694`, and would have duplicated the gutter, the rail and the header CycleRoute already draws.
- **The canvas's Claims tab is not drawn.** It waits for #2430's claim check (part 6). The tab bar draws Home, Story, Positioning, Check and Versions.
- **The guard is today's,** `labRoles(['admin', 'founder'])`, through the module routes.
- **The Raise header is CycleRoute's own.** CycleHeader gives the eyebrow, the title, Call for Capital, the "Raise modules" rail and the phone Module select, and the canvas's header matches it.
  - The canvas's Calls pill address (`/raise/capital-relationships/calls`) would be a record id. The rail keeps `#calls`.
  - The venture chooser is not drawn: an in-page project picker is refused (#181). The venture comes from the address, as on every founder tool.
- **The tab bar** is the canvas's second level: underlined text tabs, `nav aria-label="Investor narrative"`. Story and Check add a Version picker, which writes `?version=` and keeps `?project_id=`.

### 2. What is read, and from where

Every figure comes from a read on `main`. Each read answers alone, and a failed one says so where its figure would be.

| Tab | Read |
|---|---|
| Home | `GET /api/cycles/raise/modules/investor-narrative`, as CycleRoute draws it today |
| Version picker, Versions list | `GET …/modules/investor-narrative/form-options` (`versions`) |
| Story | `GET …/modules/investor-narrative/records/:version`, "The narrative" section |
| Check | the same record, "Consistency check" section |
| Compare | two record reads, the newest version and the one before by default |

- **The check is drawn in the Worker's own words.** Each figure's detail and result come as the consistency section sends them, and nothing is re-derived.
  - With no figure compared, the line reads "Nothing compared yet.", never "no mismatch".
  - The deck side waits for the Pitch deck studio's bindings (#2434 part 2 and part 1 here); the page says so.
- **Compare lines up the five sections** a version stores today and marks what changed. Bound figures and claim states on each side wait for parts 2, 4 and 6.
- **A missing value is "Not recorded",** never a blank or 0. No canvas sample reaches a page.
