## D6111 — Grow's row Edits open with the saved values (#6111)

- **Status:** built by S13, 2026-11-14. Frontend only: no route, no migration.
- **Code:** `frontend/src/pages/cycles/forms.js` (`editRole`, `editPartner`, `editMarket`, `editObligation`, `sentChanged`), `frontend/src/pages/cycles/recordModel.js` (`recordFormFor` hands `valuesOf` the read), `frontend/src/pages/cycles/CycleRoute.jsx` (a record-reading Edit's `submit` gets the values it opened with).
- **Test:** `frontend/test/grow_edit_record_values_6111.test.mjs`.

### Why

A Grow module row carries only some of a record's values (`adapters/grow.js`). Edit role opened blank, because `valuesOf` returned `{}`. Edit partner had only type, stage and the old free-text terms. Edit obligation had no kind, repeats or reminders. The record page's Edit already drew the record's own values. Build's and Validate's row Edits read the record (`FROM_RECORD`); Grow's did not.

### What changed

- **The four Edits read their record.** Roles, Partners, Markets and Obligations carry `readsRecord`. A row's Edit asks for the record (`useRowRecordEdit`) and opens from its Edit action, as Build's and Validate's do. A refused or unreadable read draws the existing refused form, with the Worker's sentence and nothing to save.
- **`valuesOf` maps the record's Edit to each form's fields:**
  - **Role:** title, team, type and target start. The pay band comes from `comp_min_cents` and `comp_max_cents`, shown as dollars ("90,000–120,000"). Equity is `equity_pct`, and the jobs-board switch is `comp_public` (`['1']` → Show).
  - **Partner:** name and type, and stage. The typed terms go in the one Amount box (`terms_pct` as "20%", `terms_amount_cents` as dollars). Then renewal, and the contact's name and email. The Edit now draws the name and the renewal, as the record's own Edit does.
  - **Market:** state, the scored parts with their sources, and the attached country. The decision is not on the record's Edit; it is the record's own Change decision form, so `recordFormFor` now passes the read to `valuesOf` (`row.record`). A read without that form draws no decision field, rather than a blank one.
  - **Obligation:** title, kind, due date, owner and repeats. The reminders map from `remind_days` to this form's Remind. Remind now offers every preset the record can hold (30, 14, 7, 1 and 0 days, labelled as `growDaily.ts` labels them). State adds Overdue and Snoozed, which the record reads.
- **Saving without changes sends no field.** `sentChanged` compares each body key's field with the value the Edit opened with. It sends only what changed, so a list compares in any order and an empty value equals nothing. CycleRoute passes those values (`spec.current`) as `submit`'s fifth argument, on a row and on the record page. Without them, as on Distribution's Channels tab, `sentChanged` is `sentOnly`, unchanged. The jobs-board switch still goes with a changed band, so a typed band with the switch off turns it off. From a record it also goes on its own once it changes. Before, turning it on alone sent nothing.
- **Chips keep a stored value.** A role's team and a market's country are kept as a chip (`keep`) when the chip set does not list them. Edit role and Edit market now load their chips (`loadOptions`) as their Adds do.
- **Target start is typed.** The record stores "2027-01" or a day, and a date box refused "2027-01", which blocked Save. The Edit draws it as text with the record's own placeholder.

### Left as it is

- **Partner's old free-text terms.** The record's Edit does not carry `terms`, so Notes on terms is no longer drawn when an Edit opens from the record. The text stays stored, and the record's Terms fact still shows it.
- **Currency.** A band or a terms amount is typed and sent in US dollars, as the Adds do. A record stored in another currency is shown as its number and changes to US dollars only when that field is changed.
- **Feedback and Channel** still open from the row (forms.js `editFeedback`, `editChannel`). Their rows carry what their Edits draw, and the issue left them as a scope choice.
