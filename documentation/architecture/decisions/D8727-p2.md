### What is built

- **Two reads, each with its own state.** The escalation card reads `GET /api/admin/escalations?status=open` (`api.escalations`, already on `main`) beside the overview. Pending is Reading (`aria-busy`, skeleton rows); a successful empty read is All clear with "0 open"; rows only after a successful read; Unavailable only when the read failed, answered `available: false`, or gave no answer in 20 s. Still reading at 8 s adds the slow line. Its Try again reads this card alone; the overview's Try again (in Platform) reads the overview alone. A late answer after the 20 s deadline is ignored (`api.escalations` takes no abort signal, so the request is not cancelled).
- **Order and headings (SHQ00, SHQ20).** Scope bar, h1 **HQ home** under the breadcrumb "HQ › Home", h2 **What needs my attention?** (h3 Escalations awaiting HQ, h3 Other signals), h2 Platform (four tiles: Licences, Seats licensed, Accounts · HQ, MTD revenue), Subsidiary health, Licensing events, My tasks last.
- **Other signals** (renewals within the window, suspended licences, HQ ticket queue) come from the overview with its state: Reading, the figures, or Unavailable with "see Platform below to try it again". The Queue backlog and Suspended tiles moved here.
- **Rows go to Support's Queue (SHQ03 → SHQ07).** Each row is one link to `/admin/hq-support` (Queue is its default tab): SLA word and glyph, subject, subsidiary and code, kind, raised by, raised and due with the distance to due. Names are joined from the overview by branch code; with the overview failed, a row shows its code and the card says why (SHQ06D). "Answer on Support" is the first viewport's one primary action.
- **Controls only when they change the result.** The tenant switcher is drawn once the ledger has loaded, never disabled; the kind filter only when both kinds hold a licence; My tasks draws Show and Due only after a read has answered (`hideControlsWhenOff`), so while Work is off HQ sees one sentence, "Work is not switched on for HQ yet. Tasks assigned to you on a Team will be listed here once it is." (`offReason`), and no issue number. Other workspaces pass neither prop and are unchanged.
- **Announcements (SHQ20).** One polite region for the page: "Loading HQ home.", the slow line, "Escalations could not be read." once per page view, "Reading escalations again.", "Escalations read. 2 waiting on HQ, 1 past SLA." (or "Nothing is waiting on HQ."), and "The HQ overview could not be read. Escalations are unaffected." once. A failed retry is an alert in the card. After a retry succeeds, focus moves to the card's heading, since the Try again button is gone.
- **Copy.** No server reason string about escalations is printed; the overview's `escalations_reason` is no longer read by Home.
- **Seats used, summed as numbers.** The Seats licensed tile's "utilised" figure added the display strings `num()` returns, so 268 and 251 read as "268,251"; it now adds the numbers. Found while checking the Platform tiles in a browser.
