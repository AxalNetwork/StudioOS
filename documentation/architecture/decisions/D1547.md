- **Migration:** none.

### What was decided

- **The task is docs, ops and research only** (S1's revision): no screen, no frontend file. The first-run tour is dropped (the final canvas removed it) and the empty states are S1's (plan §8).
- **The runbook is `documentation/operations/DECK_GRID.md`**, with four procedures: switch off a model; refund a batch; unstick a batch; purge an image, including a DMCA takedown.
  - Each procedure states what exists today, the steps, how to check, and what is not built.
  - **It says plainly where no route exists:**
    - there is no "refund a batch" route, so the refund is a member adjustment keyed by the batch uid;
    - there is no repair route for a stuck run, only the owner's Stop, the DLQ retry, and one bookkeeping SQL for a run whose hold has already expired;
    - there is no admin image takedown, so it is a set of SQL statements, an R2 delete and an edge cache purge.
  - **It never settles a hold by hand.** Settling is `settleAiReservation`'s compare-and-set over two tables plus the ledger trigger.
- **"Test every step on staging" cannot be met yet.**
  - `[env.preview]` has placeholder ids and no CI deploys it, and `branch-provision.yml` has never run.
  - The runbook therefore marks every procedure "Not on staging".
  - The guard test fails if any line claims a staging run while the placeholders remain.
- **The acceptance fixture is the guard:** `cloudflare-worker/test/deck_grid_runbook_3792.test.ts`.
  - It pairs each route, refusal code, name and limit the runbook prints with the source line that makes it true. A route renamed, a state added, a TTL or a slice cap changed, or the runbook edited alone fails the build.
  - It reads the batch states, the one-active-run index and the tombstone reasons from the migrations.
  - It reads the hold TTL, the queue slice and cap, and the model that cannot be switched off from the code's own constants.
  - It reads the queue's retry count from `wrangler.toml`.
- **The maps:**
  - The route map gains `0999-deck-critique-and-proof-d1552-d1586.md` for the two v2 routes it did not list: Fix with critique (D1552) and a figure's proof (D1586).
  - The usage meter and the templates were already listed (section 0880), and S1's D1604 owns the `/raise/pitch/templates` row. This adds nothing there.
  - `CODEBASE_MAP.md` gains one paragraph saying where the Grid's routes, engine and runbook live.
- **Out of scope (owner):** the 10% rollout decision.
