## D5496 — Use of Funds uses the shared money layer (#5496)

Scenario editors and money labels use each recorded currency's exponent.
Legacy round targets convert from major units in the round's currency.
Migration 607's two-decimal mirror is used only for two-decimal currencies.
Forecast, Base and legacy project projections use their existing USD
contracts. The Base chooser offers only sources recorded in the Base
currency, so copying a round amount cannot relabel its minor units. Cash
paths with mixed or unknown currencies use the comparison table.

Stored values and API field names retain their existing units. The seven
paths leave D5373's pending list and are checked by its conversion guard.
