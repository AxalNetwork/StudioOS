## D5889 — Refer & Earn joins the Programs shell (#5889)

The six core sections surround the Referral queue module in the shared
Programs order. Existing addresses and test IDs are retained. The registry
supplies capability modules, availability, status and member access. Settings
keeps Who can refer and shows referral rewards alongside the shared member
access editor. Super Admins edit access and Admins read it.

Participation reads Not recorded with the shared reason because referral
counts do not measure distinct participating members. A failed registry read
marks the sections that use that read. Referral reads retain their own states.
