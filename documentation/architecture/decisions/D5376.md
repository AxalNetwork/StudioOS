## D5376 — Pitch Studio uses the shared safe Raise error path (#5376)

Pitch Studio now turns failed calls into founder-facing copy through
`userFacingRaiseError`, like the other Raise surfaces in D5070. Each call site
keeps its own fallback sentence. Internal browser, provider, database and 5xx
text is never rendered.

The deliberate exceptions remain code-driven, not raw-message-driven:

- a 402 deck-method refusal maps to the existing plan/top-up experience;
- a 503 code ending in `_off` maps to the existing "not switched on" state;
- an authored 4xx Worker refusal with a code keeps its sentence under D5070.

`raise_no_raw_error_5070.test.mjs` scans all of `pages/raise/pitch/`. No Pitch
file is allowlisted: code may inspect status and machine codes, but not render
raw `message` or `detail` fields.
