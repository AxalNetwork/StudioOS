## D6133 — Retire historical match scores from Investor Studio (#6133)

The owner chose to remove the historical scores and their average from Investor Studio. The catalogue and default omit the tile, and the existing saved layout read quietly drops the retired key without rewriting the member's layout. The frontend also omits it if an older Worker returns it. Deals in flow, Watching, and Active deal rooms use their existing reads. The dashboard response keeps its historical fields for compatibility.
