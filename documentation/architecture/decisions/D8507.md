## D8507 — Hosted Stage A keeps a receipt and is swept by a second job (#8507)

- **Status:** built by S09, 2026-11-25 (#8507, tracker #8509 row A3; lifecycle #4594). Workflow changes are a protected path: T2, the owner lands them.
- **Migration:** none. No resource is provisioned, and Stage A is not dispatched by this change.

### Why

`agent-stage-a.yml` cleaned up only from the harness's own `finally`. A cancelled or timed-out job is killed from outside, and that block may not run. Nothing else looked for what it left behind. The job also runs with the `production-ops` token, whose scope could not be read.

### What

1. **A receipt per resource.** `scripts/agent-stage-a.mjs --receipt <file>` appends one JSON line (`run`, `kind`, `name`, `id`, `at`) as each resource is created. The Worker's line is written before its first deploy, and the Workflow names are written before the deploy that creates them. The workflow uploads the receipt `if: always()`.
2. **A sweep job.** `sweep` needs `stage-a` and runs `if: always()` in the same environment. `scripts/agent-stage-a-sweep.mjs` lists every kind, selects with `selectForSweep`, deletes (the Worker first, the database last), lists again and reports `left`. A dispatch with `sweep_run_id` runs the sweep alone for an earlier run, reading that run's receipt.
3. **The selection rule.** A name is swept only if it is exactly one the run would have created (`runPatterns`, built from `stageANames`). The receipt supplies ids (a KV namespace is deleted by id) and the "already gone" list, but it never adds a name: a receipt line for anything else is refused. A widened pattern fails `stageASweep.test.mjs`.
4. **Zero left, or red.** `leftCount` counts what is still listed plus one per kind whose list could not be read. The sweep step exits 1 on anything but zero.
5. **The harness is pinned.** Both jobs check out `github.sha`; both summaries name it, and the Stage A JSON summary carries `harness`.

### Not done here

- **The environment.** Both jobs still name `production-ops`. The preview environment and its scoped token are console work under #8063 and #8064. The switch is then the two `environment:` lines and the two inventory rows.
- **The three recorded runs** (success, cancellation, timeout, each ending with zero left) are owner-dispatched.
