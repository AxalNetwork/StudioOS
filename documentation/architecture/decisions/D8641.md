### Production admission is not changed

The ruleset requirement applies to pull requests and the merge queue.
Production's push-event admission (`scripts/verify-production-candidate.mjs`)
waits for the six checks that run on a push to main. Dependency Review never
runs on a push, so adding it there would make every release wait forever. That
verifier and its tests are untouched; #5501 keeps that scope.
