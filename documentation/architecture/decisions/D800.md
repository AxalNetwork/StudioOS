### What was there

`/admin/my-licence` (`pages/subsidiary/MyLicencePage.jsx`) was one read-only column: Territories held, Commercial terms, Dates, Entity, Seats licensed, Custom host, Notices from HQ and History.

### 1. The frame: one page, six sub-paths

- **The tabs are routes.** `/admin/my-licence` is Summary. `/terms`, `/contract`, `/statements`, `/requests` and `/history` are each registered in `App.jsx` with the same `guard(['admin'])`, and each mounts `MyLicencePage`, which reads its tab from the path (`tabFor`). Its default export takes no props, so the Admin frame stays its outermost element (`rail_options_admin_d774`).
  - One page means one read of `/api/licence/mine` and one notices read, whichever tab opens first. The frozen banner (D136) stays above every tab.
- **The tab row writes its six paths out** (`LicenceFrame.jsx`). The reachability walk (`admin_route_reachability.test.mjs`) counts a literal `to="…"` as a door, so a mapped list would have left five routes with no door. The test holds the literals equal to `LICENCE_TABS` in `lib/licencePage.js`.
- **The Licences row stays lit on every tab.** The HQ-held Admin row gained `match: ['/admin/my-licence']`; the branch row already matched its subtree. D768's page map keys every sub-path to `Admin · Licences` (a non-`exact` entry answers the paths below it), so each tab draws the Admin rail. The test renders all six in the real App with D781's harness.
- **Contract, Statements and Requests** draw "Built by D804" until #2241 lands.

### 2. Summary (board L1)

- **Term, Renewal, Fee and Share come from `/mine`.**
  - *Term:* "Year n of m", the start and end dates, and a progress bar. Any part the ledger lacks reads "Not recorded".
  - *Fee:* the next invoice is the next anniversary of `starts_on`, which S1 set as the invoice date (#2230).
  - *Share:* the revenue share and the AI token split. The royalty on licences sold appears once D797's `royalty_platform_licence_bps` rides `/mine`.
- **The Renewal card puts what HQ is deciding first.**
  - A notice of non-renewal with HQ (a `non_renewal` request that was delivered) reads "Notice of non-renewal given".
  - Otherwise, an open `renewal` request reads "Renewal requested" with D799's response hours.
  - Otherwise, D797's `renewal_mode` gives "Auto-renews" or "On request", with the notice deadline from `non_renewal_notice_days`.
  - With no mode recorded, the card says "Renewal: Not recorded" rather than guessing one.
- **Needs you** is D798's list, in its order, with one button each: Sign, Answer, View, Request seats.
  - A notice's Answer opens History, where D136's answer form is, whatever link D798 gave it.
  - An unreadable list says so, and never "Nothing needs you".
- **What you owe HQ** is the latest statement that is not void, with period, gross, share, owed and paid. On a branch it shows D798's reason instead.
- **Your contract** shows the one sent and waiting, and the one in force. **"Sign" is drawn only with `sign_url`.** Without one, D798's `sign_reason` is the line.
- **Deal terms at a glance** reads D797's five deal terms. Until #2242 is on `main`, `/mine` carries no `terms`, so each reads "Not recorded" with the read's own sentence.
- **Seats** draws licensed against used per type.
  - Used comes from `seats_used_by_type`, which only a branch counts (D127, D129). It is never summed or derived here.
  - On HQ the map is absent: no bar is filled, and the card says "Seats used is not counted on HQ yet".
  - `licence_admins.test.mjs` now pins that sentence. It also pins that neither the page nor its model reads the summed `seats_used`.
- **Administrators lists the caller only.** The licence's other administrators are `licence_admins` rows, which only a Super Admin reads, and no Administrator read returns them. The card says so rather than drawing a list of one as the whole list. "Request a delegate" opens Requests with `?kind=delegate`.
- **The AI allowance** is the caller's own (`/api/ai-budget/me`): daily, monthly and this month's use. A missing figure reads "Not recorded", never `$0`.
- **Each read fails alone.** Every card states its own failure, and the terms beside it still render, as D136's notices read already did.
- **Kept on Summary though the canvas does not draw them:**
  - Branch settings, on a branch only (D796).
  - The custom host (D197), the one place a holder binds a host. The canvas shows the host as a Terms row, which the Terms tab also draws.

### 3. Terms (board L2), from the ledger

- **The canvas's eight sections**, each row a label, a value, a source chip and at most one action.
- **Today every row is the licence row's own**, chipped "Ledger":
  - Parties: licensee and signatory;
  - Territory: countries;
  - Term: start, length and renewal date;
  - Fees: annual fee, revenue share and token split;
  - the four seat types;
  - Brand: name, kind and custom host.
- **`MyLicencePage.jsx` builds these rows** (`ledgerSections`) with its own formatters, so a term the ledger lacks reads "Not recorded" exactly as it always has there. `bps_single_definition` pins that formatter on this file.
- **D797's sections say why they are empty.** Parties, Territory, Term, Fees, Deal terms and Compliance carry the rest of D797's schedule. Each shows the read's sentence until #2242 is on `main`. A follow-up adds D797's rows through D801's `lib/licenceTermsForm.js`, with "Contract §x" chips from `sections`.
  - #2242's branch had diverged from `main` in twenty files, so stacking on it would have pulled in another PR's conflicts. Part 1 targets `main`.
- **"Request a change" appears only on terms D799 takes** (`REQUESTABLE_TERMS`: territory, seats, fee, term), and opens `/admin/my-licence/requests?change=<term>`. That query is the prefill D804's `terms_change` sheet reads.
- **A frozen licence keeps this lane open.** D142 freezes the queues, not the way to HQ. Only Terminated closes it.
- **Compliance draws the ladder:** Notice → Your answer → Freeze → Suspension.

### 4. History (board L6)

- Notices from HQ is D136's panel, unchanged: its three states, its answer form and its exact sentences.
  - An answer also re-reads the needs (`refreshLicenceNeeds`), so the row's count follows.
- **Licence history** is the event trail. Each event is named ("Terms changed") with its date and note. A branch still shows D107's sentence that the trail is HQ's.
- When suspended, the Suspended banner repeats above the notices, as the canvas draws it.

### 5. The states (board L7)

- **Pending activation:** "Sign your contract to activate". The banner's button is "Sign" with `sign_url`, else "Open contract".
- **Suspended:**
  - D142's two lists (`lib/branchFreeze.js`) and the appeal now sit inside the banner, under its title and HQ's `status_note`.
  - "Answer the notice" opens History.
- **Terminated:** read-only. **"Export your data" is not drawn:** no account data export exists to link. The ROUTE_MAP row records the gap, and S1 files it.
- **No licence on record:** "Your account is not linked to a licence. Ask HQ.", with "Contact HQ" opening the Help Center.
- **Not pushed** (a branch HQ has not sent its licence to yet): D107 and D244's state, unchanged.

### 6. Phone (board L8)

- The tabs are one scrolling row of pills below 640px.
- The four cards stack from two columns to one, and the two-column body becomes one column.

### 7. The Licences row's count

- **The pill.** `sidebarConfig.js` gives both Admin shells' Licences row `count: 'licence_needs'`. `SidebarNav.jsx` draws the number of "Needs you" items beside the label.
- **One read.** `hooks/useLicenceNeeds.js` reads `/mine/needs` once and shares it with the Summary's card, so the two cannot disagree.
- **No zero pill.** An unread count and a count of zero both draw nothing, never "0".
