## D7906 — Translate the trusted runner catalog (#7906)

The bootstrap registry remains the source for native labels, runtime pins and eligibleShards. The adapter loads the real file relative to trusted control code, converts its fields for executionTarget and exposes the same numeric approvedGroupId for coordinator integration. Standard hosted supplies pinned runtimes and all six Worker parts; Mac remains restricted to worker-1-of-6. Unknown IDs, malformed shard sets, altered targets and unverified numeric self-hosted group IDs refuse.

The owner must choose the common self-hosted group and an administrator must verify its ID and workflow restrictions before recording it. No group is guessed; ID remains null. This adapter is not a live transport, isolation proof or authority configuration. #7909 owns coordinator integration and legacy Mac caller replacement; the old group selector remains until that replacement. No enrollment, dispatch or routing is enabled.
