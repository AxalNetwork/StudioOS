## D4210 — "Ask Eadwyn to suggest a fix" for one preflight finding (#4210)

- **Status:** built by S09, 2026-11-02 (#4210, part P2 of #3661, under D1370).
- **Code:** `cloudflare-worker/src/routes/deck_assist.ts` and `cloudflare-worker/src/services/decks/assist.ts`, which are D899's card tools. There is no second AI path.
- **Test:** `cloudflare-worker/test/deck_preflight_fix_4210.test.ts`.

### 1. One more card tool

`POST /api/decks/:id/cards/:card/assist/quote` and `POST …/assist` now also take:

```
{ tool: 'preflight_fix', finding: { check, block, title? }, block, text }
```

It is a text press like the others:

- **The quote** returns the hold (`hold_microusd`). The panel's line reads "Holds up to $… · you pay what it uses".
- **The run** goes through `run()` on the rail option `deck:shorten`, because the fix is a shorter text. So no new option or price is needed.
- **The charge** goes to the founder who pressed, and it is no more than the hold.
- **The result** is one `ai_rail_proposals` row, which Ask lists. Its payload names the finding by check and block, never by its words.
- **Nothing is applied by itself.** Accept places the proposal in the editor, and Save writes the version (D777 §3).
- **Out of tokens** is a 402, as for every card tool. The panel reads "Not enough AI tokens · Add tokens", and the checks still run.

### 2. Which findings

- **Allowed checks:** text only, `overflow`, `density`, `font` and `placeholder` (`PREFLIGHT_FIX_CHECKS`). Every other check is refused 422 `fix_not_offered` before anything runs, so the refusal costs nothing. That includes `sources`, `contrast` and `image`.
- **The finding's block** must be the block the press sends.
- **A bound figure or a metric tile** is refused `never_fill`, as for every text press. A figure is never rewritten (D1370 §1).

### 3. What may be proposed

The prompt names the problem in fixed words for each check. The finding's own title is the deck's words, so it is read as an untrusted `deck_import` block (D1506). Then `wordingProblem` keeps D899's rules and adds two for a fix:

- **Shorter:** the reply must be shorter than the text, or it fixes nothing.
- **Same figures:** it may add no figure, as for every press, and it may drop none the text had.

Either refusal is 422, and the answer says the run was charged.

### 4. The panel (wired 2026-11-03)

The Worker half merged first (#4216); the wiring followed once the preflight panel was on main (#4229). No new client method: `deckAssistApi.quote` and `run` take the body as it is.

- **On:** `BUILD.P2.live = true` in `preflightUiModel.js`.
- **Which rows:** `canAskFix` mirrors the Worker: one of the four text checks, on one text block with words, not a figure bound to a record. A reader, a result that is out of date, and AI paused draw no Ask.
- **The hold line:** each such row quotes its fix (`fixBody`), and the line under the action reads "Holds up to $… · you pay what it uses" (pf2).
- **The run:** charged as `deck:shorten` (`railPressHeaders`). On success the row reads "A suggestion is waiting in Ask…" with "Charged $x of $y held" (pf2b). The editor re-reads what waits and opens the header Ask (`DeckAsk`'s new `openKey`), where Accept places it like any text edit. Ask names it "Suggested fix".
- **Out of tokens:** a 402 on the quote or the run turns the editor's out-of-tokens state on, and every askable row reads "Not enough AI tokens · Add tokens" (pf5e). The checks still run.
