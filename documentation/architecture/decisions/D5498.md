## D5498 — Use the shared money layer for the remaining form and import paths (#5498)

Advisor ledger exports use the currency returned with each ledger or tax-summary response. Advisor booking and session prices, engagement corrections, partner budget floors, retainers, and proposal versions use the existing USD contracts. Their inputs share the exact minor-unit parser and keep D4674's accepted decimal and grouping forms. Pitch sources with the `cents` unit are USD cents under the existing source contract and display the recorded precision.

Stripe provides the price amount in the [price currency's minor units](https://docs.stripe.com/api/prices/object). The existing MRR destination is in USD. The import rounds the monthly aggregate once in USD minor units and preserves that count in its sync result. A nonzero recurring price in another currency, or a subscription currency that disagrees with USD, fails the import before writing a snapshot. The source has no exchange-rate data or currency column in the destination to record the amount correctly.

The ten paths are removed from D5373's pending guard. Storage units and public API shapes stay as documented by their existing contracts.
