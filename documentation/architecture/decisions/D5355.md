## D5355 — Retire the unused pre-firm commitment branch (#5355)

Status: accepted, 2026-11-10. Supersedes D4633 decision 2's selected-firm compatibility branch.

The required read-only production D1 aggregate on 2026-11-10 returned zero commitments whose `company_id` is NULL. The query read one aggregate row and wrote none. Because there is no legacy row to repair, this takes #5355's zero-row alternative: no privileged assignment route, audit write, new route-map row, authorization-inventory entry or staff control is added.

An investor's commitment read now returns only rows whose `company_id` is the resolved firm context. When that context is NULL, a no-firm commitment remains the investor's own and can be changed or withdrawn. When a firm is selected, a NULL row is not borrowed into that firm. The page removes the compatibility section and its “Ask the studio to assign it” promise. Staff still read every commitment and the firm recorded on each through the existing read.

This preserves the one-context rule used by commit and withdraw, removes an unfulfillable promise, and avoids creating a staff write with no production subject. There is no migration, new endpoint, binding or deployment configuration change.
