## D5652 — Roll back pricing apply after a concurrent review closure (#5652)

The pricing decision INSERT now requires the named review to remain open for that licence. Its decision guard rolls back the entire batch if the INSERT loses. A supported keep request interleaved immediately before the apply batch wins, returns the apply as 409, and preserves the old core terms.

Uses the existing decision_guard table and runDecision helper. Deterministic supported-route interleavings use synthetic fixtures only. No migration or production-data access.
