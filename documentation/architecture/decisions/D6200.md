## D6200 — Deal syndicate discovery and pledges (#6200)

The existing syndicate list accepts a deal ID for a separate, count-only
view. An investor with an active invitation to that deal can see only
open syndicates on its venture. The response names the lead, never a
member, and carries the recorded target, minimum and member count.
The existing details read returns the roster only to the lead.

The existing join requires approved KYC. For deal-linked syndicates it
also requires an active invitation to a deal on the same venture.
Passing a deal ID binds the join to that exact invitation. The insert
checks the live invitation, open state and minimum again. A pledge does
not move money or mark the syndicate funded.

The existing project list stays separate. The DL13 view and confirmation
dialog need coordination with #5906's ownership of the shared frontend.
