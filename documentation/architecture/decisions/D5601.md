## D5601 — Stop stale merge queue CI early (#5601)

Amends D4130 for merge groups. A failing matrix leg cancels its queue siblings. PR and push runs keep all legs. The required summary gate keeps its existing dependency and result checks.

### Hosted verification

1. **The expression works.** In [merge-queue run 43207043224](https://github.com/AxalNetwork/StudioOS/actions/runs/43207043224), worker 6/6 failed and all eight siblings were cancelled. In [PR run 43101197992, attempt 1](https://github.com/AxalNetwork/StudioOS/actions/runs/43101197992/attempts/1), frontend 2/2 failed and all eight siblings finished successfully. The workflow enables matrix fail-fast only for `merge_group`.
2. **Queued legs are cancelled too.** Three cancelled siblings in run 43207043224 recorded no job steps. In [run 43196816186](https://github.com/AxalNetwork/StudioOS/actions/runs/43196816186), all eight cancelled siblings recorded no job steps. #5502 tracks reporting cancelled legs as “not run.”
3. **The aggregate stays failed.** The [full-suite gate](https://github.com/AxalNetwork/StudioOS/actions/runs/43207043224/job/131145214995) logged `SUITE: failure` and finished with failure 16 seconds after the failed leg completed. The same gate failed 23 seconds after the first failed leg in run 43196816186.
4. **An absent queue ref stops work before installation.** In [worker 6/6](https://github.com/AxalNetwork/StudioOS/actions/runs/43207043224/job/131144950900), checkout succeeded, the ref probe reported that the branch no longer existed, and dependency installation and tests were skipped. This establishes that the ref was gone by the probe. The Actions record does not timestamp the deletion itself. A [live-ref queue run](https://github.com/AxalNetwork/StudioOS/actions/runs/43213163737) passed all nine legs.

The liveness check runs after checkout in frontend, worker, drift and suite, and again before the suite tests. Git exit 2 proves the ref is absent. Any other lookup failure leaves CI running. The local shell test covers existing, deleted and unreachable refs. Before/after runner-time evidence is tracked in #5506.
