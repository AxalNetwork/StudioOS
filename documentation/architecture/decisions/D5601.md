## D5601 — Stop stale merge queue CI early (#5601)

Amends D4130 for merge groups. A failing matrix leg cancels its queue siblings. PR and push runs keep all legs. The required summary gate keeps its existing dependency and result checks.

GitHub's [workflow syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#jobsjob_idstrategyfail-fast) documents expression support and cancellation of both queued and running matrix jobs. The existing gate accepts only a successful suite. The aggregate `needs.suite.result` for a failed merge-group matrix still needs a hosted rehearsal. GitHub documents [removal after failed required checks](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/managing-a-merge-queue#failing-ci). The local test reproduces a deleted queue ref using a bare Git repository. Exact production branch-deletion timing remains to be measured.

The liveness check runs after checkout in frontend, worker, drift and suite, and again before the suite tests. Git exit 2 proves the ref is absent. Any other lookup failure leaves CI running. A hosted failing queue run and the before/after timings are tracked in #5506. Cancelled legs should be reported as not run in #5502.
