## D6276 — Benchmarking controls and visible-row export (#6276)

New benchmark opens the Add a metric form and focuses its first field. The summary tiles
use the four counts from the Worker response. A missing value or failed
read shows Not recorded. Zero remains a recorded count.

No read yet uses the same rule as the Worker’s unread count. CSV uses
the visible rows in their current sort order, with each peer figure,
source, sample size and as-of period together. This keeps the published
limits on changing a peer set and exporting a chart.
