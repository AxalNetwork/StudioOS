### What is tested

Two invented companies, Kestrel (project 7) and Harbor (project 8), each with a ledger, a cap table and two contracts. Every figure and clause of Harbor carries a marker that exists nowhere in Kestrel's world, so a leak is a string match. Each company has its own approved MCP ledger server, owned by its own founder, answering budget lines and spend from fixtures.

The agent under test is Kestrel's: a `cfo` (persona `orrin`) or a `general_counsel` (persona `vesta`), sponsored by Kestrel's founder, running a real library skill (`budget-vs-actual`, `cash-runway-snapshot`, `contract-clause-extraction`) through the real `agentRun`.

### Decisions

1. **The refusal is in the tool layer, and the test proves it by the absence of a model call.** A case that crosses companies asserts `modelCalls == 0` and an empty prompt list, so nothing the prompt said could have produced the refusal.
2. **The disclaimer text is read from the constant.** Counsel's wording is pending (#3727); the case holds that the text is non-empty and is an instruction of the run, so counsel's wording lands with no test edit.
3. **No seam was added to `src/services/agents/`.** `agentRun` already takes `toolDeps` for the MCP call, and the inference stub is `env.AI`, as in the existing skill-evidence tests. "The real planner" is read as the run path and the evidence preflight (`skillEvidenceForRun`, `preflight`); the goal planner (`planner.ts`) is a different thing and is not exercised.
4. **The go-live document lists the cases as a precondition** to step 2 and as a gate (`documentation/operations/AGENT_ENGINE_GO_LIVE.md`).
