- **Keyboard:** a pill is a `button` with `aria-pressed`; selecting Fintech with Enter kept focus on it with `aria-pressed="true"`. Getting back to All took six Shift+Tab presses. There was no one-action return that also cleared the author and search filters, no live region and no result count.
- **Phone:** the selected pill stays on screen (the pills wrap), but at 320 px the result note starts 38 px below the fold, under 395 px of pills.

### 2. What changed (no layout)

- `frontend/src/lib/articleListState.js` (new, pure): one read becomes `loading`, `unreadable`, `no-match`, `empty` or `list`, with the applied filters (sector, author, search, with labels from the live taxonomy and the author options) and the count. Only an unfiltered, successful, empty read is `empty`.
- `ArticlesPage.jsx`:
  - a failed read sets `failed` and draws **Unreadable**, never the empty publication;
  - a filtered zero result names every applied filter ("No articles match Fintech · Investors · “ledger”.") and offers **Show all articles**, which clears sector, author and search, returns to page one and moves focus to the All pill;
  - a visually hidden `role="status"` `aria-live="polite"` region announces the sentence and the count ("2 articles.").
- The note and the button reuse the page's existing `ax-empty` and `ax-btn ax-btn-sm ax-btn-quiet` styles. The wording is interim; the canvas supplies the final copy.
- Rechecked on the rebuilt SPA at 1440, 390 and 320: each state drew its own sentence, Show all restored the list with the search box and author select cleared, focus landed on All (`aria-pressed="true"`), and the document width stayed at the viewport.
- Tests: `frontend/test/articles_filtered_empty_8791.test.mjs` (9); `network_hub_d679.test.mjs` now reads the empty-publication sentence from the module.

### 4. questions:

- **Route:** `/articles`, public, signed out or signed in alike. The Network sub-nav sits above it.
- **Who sees it:** every visitor; nobody needs an account to read.
- **The parts and their stores:**
  - sector pills: `GET /api/articles/sectors` (`cloudflare-worker/src/data/sectors.ts`, 17 entries today);
  - author select: the page's fixed `ROLE_FILTERS` (All authors, Founders, Investors, Partners, Advisors, Coaches, Axal VC team), filtering on the author's `users.role`;
  - search: `q`, matched against title and subtitle;
  - list and count: `GET /api/articles` (D1 `articles`, `status = 'published'`), 12 per page, with `total`;
  - featured strip: `GET /api/articles?featured=1`, page one with no filter only;
  - Briefs: `GET /api/market-intel-public/publications`, drawn only when there is one.
- **States to draw:**
  - populated All list, with the count;
  - a filtered result with matches, with the applied filters and the count;
  - **empty (no match):** a sector with no article, then sector + author + search, each naming the filters, with one action back to the full list;
  - **empty (publication):** a successful read with no filter and no article: the only state that may say there is nothing published;
  - **Unreadable:** the list read failed, with and without a filter: no claim either way;
  - **Not recorded:** an article whose sector is not in the taxonomy shows its key; an author with no name shows no author line.
