### 1. Object classes and admission

There are four object classes, kept apart in policy and in storage:

| Class | Purpose | Largest object |
|---|---|---|
| `master` | the editable original | 2 GiB (#5581's revision cap) |
| `snapshot` | an immutable import | 2 GiB |
| `rendition` | a derived web or 3D export | 256 MiB |
| `thumbnail` | a preview | 2 MiB |

A rendition or thumbnail is never a source, and nothing replaces a master.

`admitMedia` takes the bytes, the asset kind (`image`, `brand`, `model_3d`), the object class and the declared type.
The format comes from the bytes, never from a name or a declared type. It refuses with a fixed code:

| Code | When |
|---|---|
| `empty` / `oversized` | no bytes, or over the class cap. SVG and glTF are parsed whole, so they are capped at 8 MiB |
| `unsupported_format` | an unrecognised signature |
| `mime_mismatch` | the declared type is not what the bytes are (parameters such as `; charset` are ignored) |
| `wrong_kind` / `wrong_class` | the format is not admitted for this kind or class. For example, a GIF or SVG is admitted only as a master or snapshot, and AVIF is never a thumbnail |
| `corrupt` | the structure fails end to end: PNG without IHDR first or IEND last; JPEG without end-of-image; WebP whose RIFF size is not the file; GIF without its trailer; GLB whose header length is not the file or that is not glTF 2; AVIF whose ftyp does not fit; glTF that is not glTF 2.0 JSON; SVG that is not UTF-8 or never closes |
| `unsafe_metadata` | SVG: a script (self-closing included), an event handler, a `javascript:` URL, `foreignObject`, an entity declaration, an external or active `href`, an external `url()`, `@import`. glTF: a buffer or image URI that is absolute, scheme-bearing or escaping (`..`), unless it is `data:`. JPEG: EXIF carrying the GPS pointer. PNG: an `eXIf` chunk |

The admitted formats are PNG, JPEG, WebP, AVIF, GIF, SVG, PSD, GLB, glTF, USDZ and Blend. PSD, USDZ and Blend are
**opaque**: WorkGraph cannot parse them, so concurrent edits to them are variant branches, never merged.

### 2. Provenance and rights

A version's `MediaProvenance` carries:

- its origin: upload, generated, import, or derived (with the source revision);
- for a generated version: provider, model, recipe, seed, and reproducibility;
- its rights: basis, licensor, licence reference, usage scope, attribution, expiry and revocation;
- consent, where a person is shown;
- any watermark or content credentials.

`checkProvenance` refuses with these codes:

| Code | When |
|---|---|
| `rights_missing` | no rights basis |
| `license_ref_missing` | `licensed` with no reference |
| `license_revoked` | the licence was revoked |
| `license_expired` | the licence has expired |
| `usage_out_of_scope` | the use is not in the licence's scope |
| `generation_missing` | a generated version has no model or provider |
| `source_missing` | a derived version has no source revision |
| `reproducibility_unverified` | the version claims reproducibility without a verification date. Generated media may be nondeterministic, so the claim is never assumed |
| `consent_missing` | a person is shown without recorded consent. **At publication only**: a draft may show a person |

`provenanceFromDeckImage` reads `deck_images`' own columns: `source`, `model`, `prompt`, `shows_person`,
`person_consent_at` and `person_consent_by`. Their rights are scoped to `deck`, because that is all the table states;
a wider use needs a recorded licence.

A revision's `recipe` keeps the provider, model, seed, rights, consent flag, watermark and font manifest. It does
**not** copy the prompt: the prompt stays in its domain row, and the recipe records only that one exists. The
`recipe` column holds 2,000 characters (#5581's CHECK), so an oversized provenance is refused as `malformed` before
the insert.

### 3. Dependencies

`pinDependencies` handles two kinds of dependency:

- **Fonts** are pinned **by family and licence only**. The licence must be OFL-1.1, Apache-2.0, UFL-1.0 or
  `platform`. A font given as an asset or bytes is refused (`font_binary`), so WorkGraph never redistributes a
  binary. Any other licence is `font_license_unknown`, a person's question.
- **Textures, materials, linked images and brand tokens** become `read` edges pinned to an exact revision. #5581
  refuses a revision whose pin is no longer that asset's head (`stale_dependency`), when it is recorded.

### 4. Renditions

`renditionPlan` says what a master gets:

- **Web formats** get WebP and AVIF at 2,048 px, and a 320 px WebP thumbnail.
- **GLB and glTF** get a GLB rendition and a thumbnail.
- **PSD, Blend and USDZ** get a thumbnail only.

GLB, glTF, PSD, Blend and USDZ set `externalCompute`: the Worker has no renderer for them, so the rendition job
waits for #5571's executor. The rendition worker itself is a later part.

### 5. Variants, selection and the brand pack (`workGraphVariants.ts`)

Every asset is registered under `human_publication`. Only `image`, `brand`, `model_3d` and `composite` are
registered here; any other kind is `kind_mismatch`.

- **`recordMaster`:** a **person** records the master, and their act is the approval. Its provenance must hold for
  publication. Its dependencies are pinned.
- **`recordVariant`:** one variant is one revision whose parent is the asset's current head (the master). Its
  provenance must hold for a draft. The head does not move.
  - Twenty visuals from two agents are twenty sibling revisions, each naming its agent run. Nothing is merged byte
    by byte.
  - A variant whose parent is not the head is refused (`not_a_head`). A late retry after the master has been
    superseded is therefore refused too, and writes nothing.
- **`selectVariant`:** a **person** picks one variant, and it becomes the head. Its provenance must hold for
  publication: rights in scope, licence neither revoked nor expired, and consent where a person is shown. An agent
  gets `person_required`.
- **`composeBrandPack`:** builds a `composite` revision.
  - It pins each member's **current** head and its digest. A member with no head is `not_a_head`, and a head that
    moves before the swap is #5581's `composite_incompatible`.
  - Its digest is the SHA-256 of the canonical list of pins. Its `SourceRef` names its own `work_graph_edges` rows,
    because a composite is nothing but its pins (#5581).
  - A person approves it. A pack only points: masters and unchosen variants are never overwritten.
  - An empty pack, a repeated member or a non-composite target is refused.

Masters and packs take the head the caller built on (`expectedRevisionUid`) and never read it back. A retry
therefore replays exactly, through #5581's idempotency, instead of becoming a conflict.

Brand tokens are `brandKitUnits` over `deck_brand_kits`: fonts, each palette colour, image style, references and
logo, one unit each. Through D5582's `planMerge('brand', …)`, two writers changing different tokens merge, and the
same token changed twice is a conflict for a person. No token is text-merged.

### 6. What part 1 does not do

- **No bytes.** Writing masters, snapshots, renditions and thumbnails to R2 and verifying them on read-back is #5581
  part 3. Part 2 here calls it, with the four classes kept apart. The test shows each recorded digest verifies
  against its bytes with D5579's `verifyVersionBytes`.
- **No quota.** Part 2 calls `assertStorageRoom` before every write. Usage is attributed as D1170 does: the
  uploader for personal files, the venture's owner for company files. Deduplication stays within one tenant: the
  same digest in two tenants is two objects, never shared.
- **No rendition worker.** It comes later, with queue throttles, and uses #5571 for external compute.
- **No route.** A route follows D5581's conditions: Super Admin only, behind a flag that defaults off.
- **No change to existing domain tables.** `deck_images`, `deck_brand_kits` and the R2 prefixes they use are read,
  never altered.
- **Third-party sources of truth.** A Figma, Drive or other editor file is canonical in that editor, under
  D5579's external editing mode. WorkGraph records its revision as `external_editor` and refuses a version cut from
  a revision that is no longer current (`external_source_changed`).
