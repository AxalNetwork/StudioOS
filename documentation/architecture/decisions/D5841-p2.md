### 1. Where the path is

There is no canvas for this step. It is drawn with Raise › Evidence's own parts (the shared Sheet, `ChangeDialog`, the
sharing and Stale pills, the card and button tokens), so nothing new is invented:

- **Raise › Evidence › Organic search** is a Sheet over the Evidence view at 640, opened by the address
  `?organic=<week|open>` (and `&organic_claim=<uid>`). A founder opens it from the view's header ("Organic search"),
  from an organic-search claim's drawer ("Back with Search Console", the claim pre-chosen), or from Grow.
- **Grow › Distribution › Results** (and the Account connector, which mounts the same report) ends with "Use a week in
  Raise": what the report does not do, and a link to the sheet with the newest whole week pre-chosen. It is a link,
  never a write; with no whole week stored it says so and offers no link.

**Departure.** The sheet is an address on `/raise/evidence` (a query, not a new path such as `/raise/evidence/organic`),
so no route, route-map row or App route is added; closing it removes the query.

### 2. What a pin takes

1. The founder picks a **whole week** (only weeks the results read stored in full: `complete`; a partial week is never
   offered) and **one figure**: clicks, impressions or weighted CTR.
2. **Preview figure** calls #8927's preview. It shows the value (CTR as clicks ÷ impressions too), the window in
   Pacific Time and the coverage, with days Google returned no row for named and never counted as zero. A preview the
   Worker refuses shows its reason and no figure.
3. **The claim it backs** lists only the venture's claims that figure may back (`organic_search_clicks`,
   `_impressions`, `_ctr`, mirroring `searchConsoleMayBack`); none is pre-chosen unless the founder came from that
   claim. Paying customers, revenue, conversions and traction proof are never listed. With no such claim the sheet says
   how to state one in the Investor narrative ("4,200 organic search clicks") and the pin stays disabled.
4. **Pin to this claim** opens `ChangeDialog`, which says the figure becomes evidence for that claim, pinned and
   Private. Only **Pin, Private** calls `pin` with the property, week, metric, the preview's `snapshot_hash` and the
   chosen claim's uid. The Worker rebuilds the value; a figure changed since the preview is refused (`changed`).

Sharing beyond Private stays on the evidence item: each current selection links to its item ("Sharing"), where the
existing sharing dialog is. Nothing in this path shares anything.

### 3. Withdraw and re-review

The sheet lists every selection, current first, with the state #8927's read gives:

| State | Shown | Actions |
| --- | --- | --- |
| `current` | Current | Sharing, Withdraw |
| `corrected` | Corrected by Google: re-review; pinned beside revised and the corrected days | Re-review, Sharing, Withdraw |
| `missing` | No longer stored in full | Withdraw |
| `revoked` | Access lost; it left every shared view | Withdraw |
| `withdrawn` | Withdrawn; Private, unpinned, removed from its claim | none |
| `replaced` | Replaced after re-review | none |

Stale (older than 90 days) adds the Stale pill. **Re-review** first reads the revised week's preview, so the dialog
shows pinned beside revised and the founder confirms the hash of the figure they were shown; the new item is Private.
**Withdraw** says it unpins, makes Private and removes the claim link, and that a withdrawn figure cannot be shared
again.

### 4. What nothing does

Opening the Grow report, the Account connector, the claim drawer or the sheet calls only reads (the stored results and
the founder's selections); the preview is a click. Only the three confirmed dialogs write. A refusal shows the Worker's
own sentence or `organicError`'s (unavailable until approved, changed since the preview); a raw error never reaches
the page. The sheet is keyed by venture, so a changed venture drops every read, draft and pending preview. It is drawn
for founders only (`permissions.can_decide`); the routes refuse anyone else as well.
