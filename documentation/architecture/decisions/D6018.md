## D6018 — Evidence before the founder’s verdict (#6018)

V10’s module has one evidence snapshot before its current recorded decision and decision history, shared by desktop and phone. The snapshot counts all offered evidence with the existing decisionEvidenceV2 bar; interview relationships and distinct sources are labelled separately. Missing results, unknown customer fit and unsupported hypotheses lead with Review evidence, while recording a decision remains possible. A failed snapshot stays Unavailable.

The existing decision form starts without a decision, requires a rationale, and keeps the founder’s evidence selection. An empty choice is never serialized as Proceed. The decision writer’s legacy optional-rationale API remains compatible; the new product form requires it. The history retains filters, paging and record links. Partners are refused by the existing route gate before the new read.

V11’s Stop state offers Review the record and Reopen (a new recorded decision), with no Build link. Proceed offers the existing Plan the build; Pivot links back to the objective. No computed state is presented as a founder decision.
