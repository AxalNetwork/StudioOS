## D5505 — Complete guard reports and shared local preflight (#5505)

`guard-commands.json` is the ordered source for full guard commands, flags and
prerequisites. `npm run test:guards` runs the catalog with no filtering. Its
former npm pre-hook is now the first catalog entry, so a generator failure is
recorded and blocks only declared consumers instead of hiding independent
results. Required TypeScript loaders, static-only flags and exclusions stay on
the original commands. The full drift gate remains authoritative.

The runner uses argv-based child processes without a shell. It records each
exit code or signal and continues independent checks after failures. Blocked
checks name their failed prerequisites. SIGINT/SIGTERM terminate the active
child, mark the remaining checks not run and return a failing interrupt code.
Missing executables are failures. The CI rest part also continues its independent
commands after ordinary failure, retaining a nonzero overall result.

`guard-results.json` (version 1, scope `guards`, mode `full`) exposes stable guard
IDs, repository-relative script paths, commands, status, exit code, signal,
blockedBy and durationMs to #5502. It contains no captured child output or
request data. Preflight writes the same schema to `preflight-results.json`.
Both are ignored local artifacts. Diagnostic writing failure fails the command.

`npm run test:preflight` selects generation, decision headings, migration
identity, runtime DDL, auth inventory and undefined symbols from that same
catalog. It needs installed Node 22 dependencies, but no SPA build. It is
advisory and never substitutes for root build plus the complete drift gate.

Tests run real synthetic child commands for independent failures, success,
missing executables and interruption, and check blocked prerequisite behavior,
full catalog membership and required flags. Existing wiring assertions read the
catalog rather than a now-retired package command chain.
