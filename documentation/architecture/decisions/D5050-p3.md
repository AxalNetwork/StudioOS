### Rules

- The stored ISO-2 code is still what the address, the filter input and `GET /api/admin/contracts?territory=` carry.
  Only the printed label changes, so filtering and links behave as before.
- A code the runtime cannot name, or a value that is not two letters, prints as the code (upper-cased). The name is
  never guessed, and the label is never blank. An empty value prints nothing (`null`), as before.
- `fallback: 'none'` is set so that an unnamed code is detected rather than echoed back. A runtime without `Intl.DisplayNames`
  prints codes.
- `frontend/src/lib/phoneNumber.js` is not reused: its country list and default-country rule are phone-specific.
