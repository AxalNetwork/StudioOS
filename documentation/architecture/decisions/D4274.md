### What was decided

1. **The deck bar replaces the crumb while a deck is open.** `PitchPage` takes a `bar` and draws it in the crumb's place, and the editor passes one (`DeckBar.jsx`). In order, the bar holds:
   - **‹ Pitch:** to `/raise/pitch`, with the venture kept. On a phone it is "‹" alone, named "Back to Pitch".
   - **The deck's h1:** "[Venture] · vN".
   - **The section menu:** a pill reading "Decks", opening the five tiles in a menu with the keyboard `useMenuFocus` gives.
   - **Edit / Comment.**
   - **D1604's tools group and Ask, unchanged:** `DeckToolbar`, held in the same `pitch-header-tools` group, so "nothing else in the header" still holds for that group.
2. **Comment is the editor's own comments sheet.** Comment opens the selected card's comments (the ⋯ › Comments item, D1570). Edit closes them (a new editor action, `close_comments`). The editor reports `commenting` up with the rest of its chrome. A reader (read-only HQ) has Comment and no Edit, and no Ask, as before.
3. **What is not drawn, and why:**
   - **The deck and version switcher (▾ on the deck name):** ⋯ › Versions already switches versions, and one venture has one deck.
   - **Compacting the bar when the Ask is open:** the Ask's open state lives inside `DeckAsk`. The bar is compact on a phone only.
4. **Recent investor activity is the current version's investor links.** It reads `GET /decks/:id/investor-links` (D1568's signals ride on each link).
   - **Each row's event:** the newest signal in D1568's words ("Opened", "Revisited after 48 h", "Reached the ask"), else an accepted NDA, else the last view.
   - **What is left out:** a link nobody opened is not activity.
   - **Order:** newest first, at most five.
   - **When the read fails:** the section says so; it never shows "no activity".
   - **Draft follow-up:** Capital relationships' own `DraftDialog` (purpose `follow_up`). It is one metered run, and nothing is sent. It is offered only for a link with a prospect behind it, and never to a reader.
   - **Open in Capital relationships:** goes to the venture's pipeline.
5. **Baselines.** The editor's four whole-page screenshots (light, tablet, phone, dark) change with the bar. They were redrawn in the pinned image (`mcr.microsoft.com/playwright:v1.56.1-noble`, Chromium 141.0.7390.37), after the unchanged suite first passed all 28 comparisons there.

### Not in this decision

- Review's own Comment mode entry under the bar (P3, #4271), which builds on this bar.
