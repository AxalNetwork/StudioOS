## D6224 — Download the reported figures as CSV; print a received report (#6224)

The company Overview's "Company-reported performance" block (the old
Figures, kept on Overview by D4817 part 6, #5846) gains **Download figures
(CSV)**. It is drawn only once at least one report has been received, so a
company with none, or a read that failed, shows no control.

The file is built in the browser from the reports the block already holds,
through the same `seriesOf` rows the tables draw
(`figuresCsvRows` / `figuresCsv` in `portfolioReportsModel.js`). There is no
new read and no Worker route. Columns: Period, Figure, Value, Unit, Source,
Corrected, Why not recorded. One row per figure per report received, oldest
first, in the canvas's figure order. A gap is "Not recorded" with its reason
(the founders' left-out reason, or "Not in this report"), never 0 and never
blank. A recorded zero stays 0.

Fields follow RFC 4180 (quoted when they hold a quote, comma or line break;
quotes doubled; CRLF line ends). Text that a spreadsheet would run as a
formula (a leading `=`, `+`, `-`, `@`, tab or carriage return) is prefixed
with a single quote. Numbers the model writes itself, including a negative
burn, stay numbers. The file starts with a UTF-8 byte-order mark so
spreadsheets read "·" and "’" correctly. If the browser refuses the file, the
block says so beside the control and nothing else on the page changes.

**Print** on the reader was already delivered by D6094 (#6094): the
reader's footer prints, in reader mode, the company, period, sent date,
revision, figures with sources, left-out reasons and the document list into
an isolated print document with its own stylesheet
(`cycles/reporting/printing/reportPrint.css`). This issue adds no second
print path; its test pins that content for the investor reader.
