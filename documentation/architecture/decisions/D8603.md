## D8603 — Preserve literal characters in evaluation summaries (#8603)

The deterministic evaluation summary now preserves the literal text of every
finding within its table cells. Existing whitespace normalization and the
four-column summary format continue through the same formatter.

The tracker remains open through the confirming default-branch scan. Evidence is
in the protected [Code Scanning alert](https://github.com/AxalNetwork/StudioOS/security/code-scanning/7491).

The existing Worker suite checks empty and plain text, literal separators,
backslashes adjacent to separators, repeated and trailing backslashes, and
multiline whitespace in all four columns. All 11 tests pass. Reverting the
formatter change, processing only the first special character, or dropping
whitespace normalization each fails the focused regression.
