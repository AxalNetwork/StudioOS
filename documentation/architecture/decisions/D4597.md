## D4597 — A missing price is never "free", and both creation paths submit the accepted quote (#4597)

- **Status:** built by S27, 2026-11-07 (#4597, Pitch audit 3/5, follow-up to D1540/#3791 and D897/#3768).
- **Number:** D4597 is this issue's number. Migration: none.
- **Shared mechanism kept:** the pinned quote (`deck_run_quotes`, `takeQuote`, `pinMicrousd`) is still the one pricing source; the quoted cap, the explicit no-cost path and the usage limits are unchanged.

### The defect
The pricing copy read `quote?.ai ? price : "AI is off … at no cost"`, so a missing quote, a failed quote read or a `pricing_unavailable` answer drew the no-cost sentence. One-click creation sent `quote_uid` only when a quote happened to be present; guided creation displayed prices but sent no `quote_uid` for the outline or the build, and its quotes omitted the round the runs carry. The Worker ran a metered outline or build with no quote at all.

### The fix
- **The states** (`newDeckModel.js` `priceState`): `loading`, `unavailable`, `free`, `metered`, `stale`. `free` is drawn only for an explicit `ai: false` with `assist_off` or `not_switched_on`. A failed read, any other refusal (`pricing_unavailable`, `misconfigured`, none), and a metered answer without a pinned `quote_uid` are `unavailable`: the sentences say the price could not be read, Confirm is off, and "Read the price again" retries. `asPrice`/`canConfirm`/`quoteUidOf` are the one reading of a quote; the old sentence helpers accept a raw quote through it.
- **Both paths submit the exact accepted quote.** One-click Build and the guided Regenerate outline and Build deck each send the `quote_uid` of their own quote, and the press is guarded by `canConfirm`. The guided quotes now carry `round_ref`, so quote and run carry matching venture, step, audience, length, round, outline and exclusions.
- **Inputs invalidate.** Both pages set the price to `loading` the moment an input that prices the run changes, and the guided build quote is dropped when there is no outline. The guided dialogs read the price as it is now.
- **Stale or missing.** A `quote_stale` or `quote_required` answer closes the dialog, reads the price again and waits for a fresh confirmation; nothing is re-sent on its own.
- **Worker** (`deck_new.ts` `priceGate`): an outline or build with no `quote_uid` is refused 409 `quote_required` ("Nothing was charged") when it would be metered, decided the way the quote decides it. A run the quote would refuse (AI off for the page, build model off, an unpriceable run) is not metered and needs no quote. The daily-ceiling refusal still comes first. A `quote_uid` is taken as before: used, lapsed, another member's, another venture's or another run's is 409 `quote_stale`.
- **A card's regeneration** (`step: card`) is still shown, not pinned (D1540); its dialog applies the same states and disables Confirm unless the price is read.

### Contract change
`POST /api/decks/outline` and `/api/decks/generate` need `quote_uid` for a metered run. Callers other than the two pages must quote first (`POST /api/decks/new/quote`). A venture whose quote cannot be pinned (the table or write fails) cannot start a metered run until it can; that is the intended fail-closed behaviour.
