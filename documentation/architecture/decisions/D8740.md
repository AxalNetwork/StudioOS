## D8740 — Match inventory identifiers literally (#8740)

This change addresses grouped trackers #8740, #8741 and #8746. Authorized
reviewers can read the finding evidence through those trackers' protected
Code Scanning links.

The source inventory reads declarations with fixed expressions and compares
their identifier text directly. Identifiers containing a dollar sign retain
their literal meaning. Tests exercise declaration selection, supported
property forms, and the distinction between stable and random values.

The trackers stay open through review, merge and a confirming scan on `main`.
