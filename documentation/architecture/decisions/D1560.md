### 1. The route

`POST /api/decks/:id/transform/quote` and `POST /api/decks/:id/transform` take `{ action, cards?, language? }`.

| Action | Rail option | What it proposes |
|---|---|---|
| `speaker_notes` | `deck:notes` | each card's notes, from its own words |
| `proofread` | `deck:proofread` | spelling, grammar and punctuation only, for the blocks it changed |
| `fix_slide` | `deck:fix-slide` | one card (`cards` names exactly one) tightened |
| `translate` | `deck:translate` | each block in `language` (the assist list) |

- `cards` names card uids or places; none means every card.
- The run reads the saved version's words: each card's title, sent as block `__title`, and its text blocks. A block bound to a record and a metric tile are never sent.
- Each call is one `run()`, quoted and held like any other, and charged to the founder.
- Each call leaves one `ai_rail_proposals` row. **Nothing is saved:** Accept places the proposal in the editor and Save writes the version.
- Only the deck's founders may call it (`projectOwned` with `write`).
- `deck:notes` is registered in `railOptions/founder.js`, and `railMatrix.json` is regenerated.
- `deck:proofread` and `deck:fix-slide` have no page that calls them yet, so they run on the Pitch deck page's own models until a surface registers them. The parity test admits only options with a call site.

**Refused before anything runs, so it costs nothing:**
- an unknown action;
- a fix with no card, or with more than one;
- a language off the list;
- a deck with no words: 422 `nothing_to_change`.

**An answer with nothing that may be placed** is 422 `nothing_proposed`, charged for the run.

### 2. What may be proposed

`services/decks/transform.ts`'s `proposalsFrom` checks each block. A block that fails is left out, and listed in `dropped` with its reason:
- `figures_changed`: a translation must keep **the same digits per block** (`sameDigits`):
  - the same digit runs in any order, separators aside, in Western digits;
  - a figure dropped, added, changed, or written in another script fails.
- `figure_added`: a proofread, a fix or notes may name only figures the block (for notes, the card) already had (`noNewDigits`).
- `link_added`: a link or email address the founder's words did not hold.
- `guarantee_language`: every sentence promised a return (D1546). Within a block that keeps any other sentence, only those sentences are dropped.
- An answer for a block that was not sent is ignored, and an unchanged block is no change.

### 3. A language outside Guard's set warns

`run()` checks input and output with Llama Guard 3. Meta's model card trains it on eight languages: English, French, German, Hindi, Italian, Portuguese, Spanish and Thai (`GUARD_LANGUAGES`).

A translation into another language from the assist list (Dutch, Japanese, Chinese, Korean, Arabic) still runs. Its quote and its answer both carry `warning: { code: 'guard_language', message }`, so it is read before it is used.

### 4. The frontend: Speaker notes only

Per S1's spec, there is no Translate button, no proofread item and no new menu. The per-area "in French" stays in `InstructionBox.jsx`.

- The area lightbox's **Speaker notes** element (`deckV2Model.js`) moves from adapter `media` (#3788) to `R('POST /api/decks/:id/transform', 'deck:notes')`.
- Its plan (`areaLightboxModel.rowPlan`) is one charged `notes` run for the card. It never replaces the area.
- `AreaLightbox.jsx` quotes and runs it through `deckTransformApi`, `frontend/src/lib/api/deckTransform.js`, which is re-exported in `api.js`.
- `AreaResults.jsx` draws the proposal as a before and after.
- Accept (`placeResult`) sets the card's `notes` only while they are still the proposal's `before`.

### 5. The one-click run is present-ready

The build run (`deck:build`, `deck_new.ts` `POST /generate` and the card regeneration) now asks for each card's speaker notes in the same run.
- `wordingFromModel` reads `notes` under the same rule as the words: a number or an unrecorded link drops it, and `blockGuarantees` covers it.
- `buildCards` puts the notes on the card. A card the run wrote none for has none, never a placeholder.
- The build run's `maxTokens` grows to hold the notes. The quote reads the same options, so the price shown covers them.

Proofread's output reaches Check claims › Wording or Fix with critique (#3799) when those wire it. That is not built here.
