## D6688 — Incorporation doors on the current engine (#6688)

Build INC8–INC12 from D6719 and the landed Incorporate Entry Points canvas.
The owner settled its choices on #6681/#6682. This is the current six-step
flow; the four-step case-based replacement stays with #6708, which depends
on this issue and owns that later change.

### Source and admission

| Surface / value | Existing Worker read | Source |
| --- | --- | --- |
| Company eligibility and order link | `/api/account/companies` | `formation_state`, `formation_order_id`, caller's membership role |
| Project eligibility and order link | `/api/account/projects` | Same formation fields, `my_seat`; never every-project reads |
| Switcher company words | `/api/account/switcher` | `formation_state` on company rows |
| Switcher standalone-project words | `/api/account/projects` | `formation_state`; switcher project rows do not supply it |
| Legal facts sheet | `/api/company/:uid/legal` | Existing facts, `can_edit`, archived state; existing save routes |
| Company-subject order | `/api/legal/incorporation/order` | Existing D6687 `company_uid`, mutually exclusive with `project_id` |

The client never derives formation state from empty legal fields, dates or
old active/in-formation status pills. Incorporated hides the door. In
formation replaces it with the recorded order link, only for a caller who
can act on that subject. A missing/failed state is Unavailable, with no
action. Only the project owner or a company editor (primary admin, Owner,
Admin, Founder, matching `companyAccess`) sees an incorporation action.
Archived companies have none. The Worker remains the write authority.

The subject-less route shows INC8. Its lists are read independently: a
failed company read cannot remove eligible projects. It offers standalone
owned projects, companies administered by the member, and a new company.
The latter opens the existing fresh-project flow; the project is created
first at order time. The Portfolio empty action prefills the new-company
choice on the board (`?start=new`); Continue uses `?new=1` for the legacy
fresh-project flow. These are query parameters on the existing route.

For `?company=`, membership and formation state are read before the form
opens. No project is read or created, and the order body carries only
`company_uid`. The company name prefills the editable legal-name field.
The remaining steps, quotes, review and payment stay on today's engine.
Company drafts do not use the old unscoped device draft; server case drafts
belong to #6708. No production order or payment is executed by this work.
