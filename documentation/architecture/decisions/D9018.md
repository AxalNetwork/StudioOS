### What is built

The detail read adds `my_line: { commitment_cents, status, joined_at } | null`. It comes from one query keyed on the caller's own user ID, the same query that answers the member check, so no other member's row can reach it and it carries no `user_id`. The rest of the response is unchanged: a member still gets an empty `members`, `show_member_names: false` and the counts.

The read now runs for every caller, the lead and admins included (it used to be skipped for them), so an admin who is also a member gets their own line. The lead cannot join their own syndicate, so the lead's `my_line` is null, and so is a non-member admin's. A signed-in user who is neither lead, member nor admin is refused with 403, as before.

In the drawer, a member's view draws Your line under the member count: the amount, a status pill and "Joined <date> UTC. Only you and the lead see this line." Without `my_line` (an older Worker, or the lead) it draws what it drew before. The lead's named roster is unchanged and never shows Your line.

### Choices

- **The pill reads "Pledged", not "Signed".** DL13l draws "✎ Signed", but no syndicate signing is recorded: the join route writes `status = 'committed'` and nothing else ever changes it. A join records a pledge and moves no money (the D6200 join step says so), so `committed` is drawn "Pledged" in violet, the canvas's tone. A status this build does not know is drawn as stored, in grey.
- **The join time is shown.** DL13l draws only the amount and the pill. The issue's objective names the date, and `joined_at` is stored, so it is one line under the row.
- **A missing amount says Not recorded.** The column is `NOT NULL`, so this should not happen; if it does, the row says so rather than drawing $0.

### Phone and dark

DL13l has no 390 or dark frame. The row sits inside the existing drawer (the shared Sheet, full width on a phone), wraps at 390 with a 44px row height, and every light class carries its `dark:` pair. Checked in Chromium against stubbed data at 390 and 1440, light and dark.
