## D6040 — Show the Build module read’s recorded facts (#6040)

Desktop and phone module pages draw one shared facts strip directly below the chart. Build’s existing module response already passes through adaptModule unchanged, so CycleRoute needs no duplicate read or new API. Founding team shows option pool and its record/model source, the existing co-founder decision model’s outcome/note/date, and the agreement limitation returned by the Worker. Company creation shows the stored IP answers, incorporation snapshot, filing count and next due date. Roadmap shows items and recorded shipments this month.

Null, missing and unusable values are Not recorded; a numeric zero remains a recorded zero. Failed module reads use the existing Unavailable recovery and expose no stale facts. IP flags are words, never raw JSON or React objects. The legacy incorporation snapshot is labelled as such, and is not presented as the new formation case’s current status (#6703/#6704). Unallocated is omitted because the read does not return it. Shared tokens and layout components remain the canonical visual contract.
