## D6149 — Compare: Remove a venture, keep picks when adding one, and export every row (#6149)

- **Status:** built 2026-11-15, on top of #5913's DX11 redraw (D4815, "DX11 Compare").
- **Builds on:** D1241 (Compare, DLS8 and DLS9), D4815 DX11 (the six sections), D1236 (`?ids=` and the picks rule).

### What changed

- **Remove.** Each venture card on `/deals/compare` has a Remove link to the
  same address without that id (`compareHref`). It is a link, so it is reached
  and followed by keyboard, and it is at least 44 by 44 px. With one venture
  left, Compare shows its existing "Pick at least two ventures to compare"
  state, whose "the table" link keeps that pick.
- **Add a venture keeps the picks.** "Add a venture" (the toolbar button and
  the empty card) goes to `/deals?view=table&scope=all&pick=<ids>`
  (`addVentureHref`). `DealFlow` seeds its picks from `&pick=` once, when it
  mounts (`picksOf`, the same rule as `?ids=`: digits only, no repeats, at most
  four, in order), so the earlier picks are ticked and Compare's link keeps
  their order. `pick` is not a view setting: a saved default view still
  applies, and the first settings change drops it from the address while the
  picks stay ticked.
- **The CSV is the table.** `compareSections` in `compareModel.js` lists the
  table's sections and rows, each cell in the table's words. `CompareTable`
  draws its rows from it and `compareCsv` writes it, so the file and the
  screen cannot drift: Investment case (6 rows), Scorecard (11), Fit to thesis
  (1), Traction (the reporting period and each tile) and Risk (1). The file's
  columns are Section, Comparison, then one per venture. Absence is a word,
  never blank or 0: Not recorded, Not reported, Not on your deals, Not shared,
  Locked, Unreadable, Reading…. Where the screen draws a dash (no days in
  stage, fit not shared), the file writes the word the dash's title gives. A
  cell a spreadsheet would run as a formula (`=`, `+`, `@`) is written as text.
- **A scorecard cell whose batch failed now reads Unreadable** on screen as in
  the file; before, it was a bare dash.
- **Print.** `comparePrint.js` is the page's print stylesheet, and a Print
  button sits beside Export CSV. Only the comparison prints: the venture cards
  four across with their colours, the summary, the whole table with its
  venture header repeated on each page, and the saved notes. The chart is left
  out because the table holds the same bands ("chart as table"); the
  breadcrumb, buttons, Remove and Add do not print.

### Choice made (owner question)

Add a venture opens the table under **All deals** (option A), not Mine.
Compare reads every listed round (`flowRows('all')`), so a picked venture may
not be in the investor's own flow; under Mine its tick would be held but not
shown. Options: **A** All deals (built), **B** Mine, as the link was before.
