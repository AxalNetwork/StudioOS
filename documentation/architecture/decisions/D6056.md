## D6056 — New deck stepper and one price confirmation (#6056)

through Audience and round, Sources, Outline, Price, Generate and Review.

and outline edits when moving back. Step changes move focus to their heading.

The price card uses `newDeckModel.priceState`. Reading, unavailable, confirmed
no charge, confirmed metered and expired remain distinct. Unknown prices
cannot run. Metered confirmation sends the quote UID displayed for the
current inputs. Superseded quote responses are ignored. A stale refusal
returns to Price and requires an explicit new quote and confirmation.

The existing template preview and apply-method confirmation are retained.
The existing proposal review keeps its per-card choices and acceptance.
The Overview import entry from #5727 is unchanged.

Desktop uses the existing Pitch shell and a two-column price layout. Shared
Axal theme tokens remain the source for colour and typography.

the Worker refuses an expired quote because its quote read has no expiry
field. Generation uses the existing BuildProgress, without invented live
charges or a Stop action the synchronous generation route cannot honour.
Templates keep their existing apply-method flow. The standalone Decks-tab
one-click component retains its existing confirmation and shared review.
