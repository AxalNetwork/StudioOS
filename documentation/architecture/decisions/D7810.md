## D7810 — Stored company publishers and licence references (#7810)

A record's stored publisher, raw licence, source URL and snapshot date are provenance; no consumer should infer Wikidata from a column default. companySource provides shared words without switching record pages: empty publisher means Source not recorded, an exact reviewed reference supplies normalized licence words/link and quoted attribution, and an absent reference displays raw terms marked licence terms not reviewed. Links accept HTTPS only. #7812 switches the record surfaces; this change does not claim those surfaces are already corrected.

The new table is keyed by exact source_name. Only Wikidata and Companies House are seeded: migrations 228/403 establish CC0 Wikidata data; migration 405 quotes “Contains public sector information licensed under the Open Government Licence v3.0.” Companies House attribution is copied verbatim. CC0 has no mandatory attribution, so that field is null. Evidence links: https://www.wikidata.org/wiki/Wikidata:Licensing and https://download.companieshouse.gov.uk/en_output.html; canonical licence links are stored separately. No other publisher's terms were opened/reviewed in this session, and no other reference is invented.

The authorized read-only production aggregate was posted on #7810 on 2026-11-20: 53,018 records, 46 stored source names and 48 publisher/licence groups, with zero writes. It supersedes the audit's earlier row count, not its findings. The grouped endpoint returns every stored publisher, its count/latest snapshot/distinct raw terms, reference fields or licence terms not reviewed, and the count of Wikidata-named records without a canonical HTTPS Wikidata page URL. scope explicitly says all stored company records; these are provenance inventory counts, not served-directory totals. The shared exported label says company records from N publishers and names the nonempty stored publishers; unnamed rows remain separately visible in the inventory.

GET `/api/research/company-publishers` uses precisely D7178's Companies gate (Founder/Advisor held licence, active Spin-Out Lab or admin), with no public bypass. It performs one grouped query and propagates storage errors to the Worker's unavailable handler. #7819 is not on the starting main; this service must be added to its pending-reader list if it lands later. If #7819 lands first, integrate this read through its module before landing. Existing overview files remain with #7823 after #7708.

GeographyProfile's single closing provenance sentence is publisher-neutral; no figures or layout change. #7718's country-figure work is absent from the starting main and remains untouched. The founder Companies toolbar's obsolete unbuilt Compare row is withheld per D7177. No CSV/export helper is changed (#7811 owns formula safety).
