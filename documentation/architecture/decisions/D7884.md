Use canonical hosted/linux-x64/macos-arm64 profiles and one reviewed organization
group. Profiles use actual OS/native architecture AND shared capability labels;
no hostname or per-machine YAML. A repository-only registration is not membership
of that group. Standard ubuntu-latest remains a separate active pool, never a
paid larger-runner substitution. Keep all six Worker shards, frontend/rest hosted,
initially at most two compatible external Worker shards, and at least one hosted
Worker shard even in later stages. Actual hosted quota is not inferred from the
self-hosted inventory; more registered processes are not more hardware capacity.

Publish the trusted direct executor on main before callers. Independent admission
checks exact authenticated source/original attempt/plan, complete queue ancestry
and queueBaseSha, owned child run and lease generation. Only owned real test step,
job and run truth satisfies the exact-candidate aggregate; dispatch/trace success
is not a test pass. Real failures remain failures. A durable authority outside
Actions owns reservations, cancellation uncertainty, deadlines and bounded hosted
fallback. No hosted waiter is the completed capacity solution. Reuse Merge Control
only after deployment/availability/recovery are verified; no authority URL is
invented. Additional App/webhook/lifecycle/provider permissions and all gate
consumers require review before activation.

The local bootstrap contract prepares separate listener/job identities and private
registration material. The actual executor must prove the privilege boundary,
owned temporary/cache paths and complete cleanup before enrollment. Same-UID host
jobs can read runner OAuth files. A partial bootstrap or unverified runtime cannot
be counted as safe capacity. The old Mac workflow/group remains recoverable until
a drained migration is explicitly coordinated.
