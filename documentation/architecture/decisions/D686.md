### 3. Decisions

#### 3.1 Decided by S1 on the owner's standing instruction

The owner, 2026-10-13: **"No time for questions: decide using the recommendations."** Each item below was an owner decision in the gap analysis. S1 took the verifier's recommendation, or, where there was none, the option that matches the canvas while staying safe and honest. Each is **Decided by S1 on the owner's standing instruction.**

**Build**
1. **The fifth core system is Workspace, replacing product analytics.** The tiles read Bank, Accounting, Payroll, CRM, Workspace. *Why:* the canvas draws those five; the registry has no analytics provider, and no client has ever written a mapping (`PUT /systems/:kind` has no caller), so nothing real is lost.
2. **A connected row's action is "Disconnect", with an inline confirm; the row's name opens the tool's detail.** *Why:* the canvas says Disconnect; the confirm (reusing `disconnectNote`, `ConnectorSheet.jsx:489-498`) prevents an accidental click, and Manage stays one click away.
3. **Free keeps every tool already connected.** A manual sync of an existing connection is no longer tier-gated. Connect, OAuth start, push and named actions stay gated. The locked banner adds the canvas's sentence, "Free keeps every tool you have already connected." *Why:* the cron and webhooks already keep flowing after a downgrade, so only the manual sync contradicted the sentence; push writes to the provider, so it stays paid. The sentence promises no sync for a tool that has none (Slack and Affinity answer `sync_not_supported`).
4. **The canvas's placeholder providers ("[Accounting tool]", "[Bank]", "[Payroll tool]") are not registered.** Figma ships as `coming_soon`. The "Accounting and banking" and "Payroll" groups render nothing until a provider exists. **The owner picks the real providers, and the tier for accounting, later.** *Why:* the verifier's correction says literal placeholders must not ship, and the registry must name no invented provider.
5. **A locked row shows the real tier**: a "Growth" or "Studio" pill and "Upgrade to Growth" / "Upgrade to Studio". *Why:* the Worker's tiers are `free`, `growth` and `studio`; the canvas's "Pro" is a placeholder.

### 4. The pattern every cycle follows

1. **Route.** `/<cycle>/<path>` is a static route beside `/<cycle>/:slug`, with the same guard. It renders `<CycleRoute cycle="<cycle>" lightbox />`: the cycle page with its lightbox open once the project resolves.
2. **Opening.** The CTA is a `Link` to `/<cycle>/<path>${q}`. A plain left click (`isPlainClick`) calls `onOpen`, which pushes `/<cycle>/<path>${q}` with `state.under` set to the current path and search. `aria-haspopup="dialog"` is set only when `onOpen` exists. With no project yet, `onOpen` is undefined and the link navigates.
3. **The page underneath** is `state.under` when it is one of the cycle's modules, otherwise the overview (`underModule`, generalised to `/${cycle}/` and to the action path).
4. **Closing** makes no server call: `navigate(-1)` when `state.under` is set, otherwise `navigate('/<cycle>' + q, { replace: true })`. Back closes the lightbox.
5. **Completion** is per cycle and uses `{ replace: true }`, so Back never reopens a finished lightbox. Validate: `/validate/session/:id` (until D685 S02-B's `/validate/record/live`). Build: none; Done closes and re-reads the page. Raise: none; the lightbox shows the outcome and links the call. Grow: `/updates/:uid`.
6. **The frame.** `ui/Lightbox` with `size="tall"`: a fixed `h-[min(820px,calc(100dvh-40px))]`, headless, with the body container not scrolling. The cycle body draws Cycle Action's `page=false` layout through `ui/ActionSheet` (§5.1, item 5): header (eyebrow, title, sub, ×), a steps band, an optional banner, a scrolling body and a pinned footer.
7. **Escape** closes one layer: the top of one stack shared by `Lightbox` and `useEscapeClose`.
8. **A field the Worker does not store yet** is drawn disabled with `'Not saved yet: the Worker does not store this field.'` (`NOT_STORED`, `recordSetup.js`) and never sent. An action whose route is not merged is drawn disabled with "Not available yet: the Worker has no route for this." Each part keeps a frozen flags object, as `SETUP_FIELDS` does, and flips a flag in the PR that follows the route's merge. A read field that is absent is not drawn, or reads "Not recorded".
9. **Every new `/api/*` client method waits for its Worker route** (`npm run test:drift`).

### 7. Honesty rules

- **A canvas is a proposal.** Every bracketed value is a placeholder, never data: "[Bank]", "Pro", "[38%]", "Sent to [Counsel name]".

The sync banner prints only a sync result's numbers. A percentage is drawn only when the Worker gives one.
- **Prices, tiers and providers come from the Worker.** No invented provider, tier or price.
- **Refusals are printed in the Worker's own words.**
- **A field the Worker does not store is drawn disabled and never sent** (§4, item 8).
- **Privacy.** A matched investor stays anonymous until they respond, and a single match's cheque range is withheld. Network recipients are counted, not named. A teammate's connection names its owner only to a member of the same company.
