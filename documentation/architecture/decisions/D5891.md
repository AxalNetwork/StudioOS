## D5891 — Mentor cohort access uses the Programs shell (#5891)

Mentor cohort access follows PG03a and the pattern established in D5313.
Overview keeps its operational tiles and adds Capability modules. Cohorts
uses the existing /people screen and its assignment and removal actions.
Playbook and History retain /how-it-runs and /activity.

Availability and Settings use the shared registry sections. A missing registry
response is shown in those sections and in Capability modules. The program's
own operational reads still work. Settings uses the existing member-access
permission checks.

Participation reports sessions booked with a mentor from the existing sessions
read, across the newest cohorts covered by that read. Distinct participants
are not recorded because the read contains session counts by cohort.
