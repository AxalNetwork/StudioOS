## D5315 — Expertise V2 Worker contracts (#5315)

### Part 1 · Cancel a proof request

An advisor can cancel an unanswered request for their own proof. The request remains in the advisor's proof history as `cancelled` and no longer counts as awaiting. Repeating cancellation returns the original timestamp.

An append-only cancellation row records the actor and timestamp. In the same database statement a trigger revokes the invitation and spends any outstanding codes. Code issuance and attester responses recheck the invitation on their writes so that work already in flight cannot restore a cancelled request. A completed answer takes precedence if its update commits first. Attester authorization and consent rules remain as in D4670.

The Worker exposes `POST /api/advisors/me/proof/:id/consents/:consentId/cancel` and the client exposes `advisorProofApi.cancelConsent`. The cancellation does not send mail.
