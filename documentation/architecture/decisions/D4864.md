### What the Worker now says

`GET /api/cycles/grow/overview` → `figures[]` gains two fields (`services/growCycle.ts`), as GR-19 asks,
so the page never parses the prose `reason`:

- `reason_code`: `null` for a recorded value (a measured 0 included); `no_record` when the store was read
  and holds nothing; `not_connected` for MRR and Customers when nothing was typed AND the founder has no
  active Stripe integration (`integrations.provider_key = 'stripe'`, the same read Enter a KPI's source
  chips use); `unavailable` when the read failed. Stripe's connection is read only when a Stripe figure
  is missing; when it cannot be read the figure is `no_record`, never `not_connected`.
- `freshness`: `stale` when the figure's as-of month is before the last closed calendar month (in
  November, a figure as of 30 September), else `current`; `null` with no value. The calendar sets the
  rule; no sample threshold is copied.
- No Grow figure is team-only, so none is `restricted`: a viewer who may not read the venture is
  refused the whole read (403), which the page draws as Refused.

### What the page draws (`GrowSnapshot.jsx`, `growKpiModel.js`)

| Figure state | Drawn as | Action |
| --- | --- | --- |
| A value, including 0 | the figure in ink, its change (only when current), "Measured zero, not missing." for a 0 | none |
| `freshness: stale` | the figure, Stale with its age, "No change shown: the figure is from an earlier period." | none |
| `no_record` | Not recorded with the Worker's reason | MRR, Customers: Enter manually (the KPI form, `/grow/revenue-and-traction/new?kpi=…`); Headcount: Set up team (`/build/team`); NRR: none (it needs two months of revenue) |
| `not_connected` | Not recorded, reason "Stripe is not connected…" | Connect Stripe (`/account/connectors/stripe`), then Enter manually |
| `unavailable` | Unavailable, "<figure> could not be read. This is not a claim that nothing is recorded.", Retry; "Last read: …" when an earlier read of the same venture by the same viewer had a value | Retry (the overview read) |
| loading | four skeleton tiles in the card shape | none |

Every card ends in its source line ("Source: Stripe · as of 2026-11-14", "Source: none connected",
"Source: none recorded"), and reads to a screen reader as one sentence (value, change, source, date,
staleness). A polite status line announces the snapshot's counts when they change.

- **Failed refresh (GR-15).** When an overview read fails after a ready one, the page shows the last
  good read's figures again only when it is the same venture and the same viewer (`viewerKey`:
  project and user id), each marked Stale by the read's age, with an alert "Grow could not refresh…"
  and Try again. It hides ranked attention, setup, What changed and every domain action of that old
  read, so nothing sends the founder to work already done. Another venture or viewer starts empty and
  gets the whole-read Unavailable.
- **Domain tiles (GR-01, GR-02).** Each "What is happening" tile is a link to its area plus, where the
  area is empty and an action exists, one setup link: Add customer, Add channel, Set focus metric, or
  the card's own `next` (Add partner, Add market, Add obligation, Log feedback) when it is a same-site
  `/grow/…` link. A zero count is None; a failed read is Unavailable with no setup action; the reason
  is cut to its first sentence. Readers get no actions.
- **Refused** whole reads use `DataState state="refused"`; the whole-read failure keeps `Unreadable`
  (screen word Unavailable) with Retry.
- **Phone (GR-16a).** A sparse venture's snapshot folds into a "Growth snapshot · N figures · …"
  disclosure below 1024px; an active venture's cards stack one per row.

### Departures from the canvas

- **Not connected** is drawn as Not recorded with its reason, not its own chip: the owner answered
  Platform States Question 2 with A, which settles a source not set up as Not recorded with its reason.
- **Restricted** is Refused (D5129's word) and applies to the whole read only; no figure is team-only.
- **Error** on a figure is Unavailable with Retry (Q2 = A), not "Couldn't read".
- **Measured zero** has no chip: D5129 draws a measured 0 as a Value in ink; the card adds the words
  "Measured zero, not missing." instead.
- **"Synced 14:05"** is not drawn: the store records a snapshot date, not a sync time, so the line says
  "as of <date>". "November to date" periods are not drawn for the same reason.
- **PostHog retention and Mercury spend** cards (GR-12's Retention and Spend examples) are not on
  today's overview: its four figures are MRR, Net revenue retention, Customers and Headcount.
- **Sync now** (GR-15 refresh failed) is Try again on the overview read: there is no per-source sync
  from the overview; a source's own sync stays on its connector page.
- **Source disconnected on a date** (GR-15) is not drawn: no store records when an integration was
  disconnected; a disconnected Stripe reads as `not_connected`.
- **Dark (GR-17)** is the shared components' `dark:` pairs; GR-17 draws only the active overview.
