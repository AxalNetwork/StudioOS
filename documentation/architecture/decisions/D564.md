## D564 — The founder's /studio is the Founder Studio canvas, and there is no separate home

D701: below 1024px the founder's `/studio` is the Studio Mobile Page canvas (Eadwyn, with no zone); this page holds at 1024px and up.

**`/studio` is each profile's one front door. For a founder, its body is
`Founder Studio.dc.html`.** The owner answered on #974 (2026-10-05): "Home was
a mistake, keep everything in /studio. That was the initial intention. So no
home." Slot S07, issue #1168, 2026-10-06.

### What changed

- **The founder body is the canvas.** The body that followed canvas
  `69dc42f3` is retired: its venture, deck, raise, metrics, office-hours,
  introductions, subsidiaries and Lab cards, and `founderStudioCards.jsx`.
- **Two things stay:**
  - Eadwyn's chat and its collapse (`StudioInterview`, D324);
  - the archetype card (`ProfileFitSection compact`, with D594's lock).
- **No "Home" in the sidebar.** The group holding Studio was labelled "Home"
  for founder, investor and advisor. It now has no label, as partner's
  already had. HQ's "Home" (`/hq`) is a different page and is unchanged.
- **The canvas moved** from `design/canvases/backlog/` to `integrated/`, and
  both canvas READMEs' counts moved with it.

### Each zone and what feeds it

The page makes each read once, and each settles on its own.
`founderStudioModel.js` turns every read into a zone that is one of: loading,
unreadable (with Retry), not recorded (with its reason), empty, or ready.

| Zone | Store and route |
|---|---|
| Header: phase, company, founder line | `GET /projects`, `GET /spinout-lab/state` |
| Eadwyn | `StudioInterview`; ticket creation stays inside Eadwyn’s header/form |
| Summary strip | Lab deliverables against `WEEK_DEFS`, or the lifecycle checklist outside a cohort; `/advisor/progress`; `unlocked_features`; Lab milestones; the latest `score_snapshots.total_score` |
| Do these next | the lifecycle checklist's open items, in checklist order |
| Company progress | the Lab's week ladder, deliverables shipped and still open, and the gate |
| Eadwyn's questions | `/advisor/queue` and `/advisor/progress` |
| Activity across the platform | `GET /activity/recent`, last 7 days |
| Module map | `unlocked_features`, shown Active or Locked |
| Your founder profile | `/advisor/progress` `profiling` (completion, and each section's confidence), plus the archetype card |

**What has no store is said, not drawn:**
- "Holding progress" and "What this adds up to" read Not recorded, with the
  reason. Their stores are asked about on #1168.
- Nothing is drawn for each action's "unlocks", each activity's "feeds", or
  each module's percent.
- A figure the read did not send stays absent. It is never 0.

**Name.** The canvas's "Advisor questions" zone is named "Eadwyn's
questions": D322 has the model named Eadwyn, never "the advisor", and the
regulated-wording scan now reads the new files.
