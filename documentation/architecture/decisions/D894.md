### 2. What is read, and from where

Every figure comes from a read on `main`. Each read answers alone, and a failed one says so where its figure would be.

| Board block | Read |
|---|---|
| Current deck, versions | `GET /api/decks/by-project/:pid`, then `GET /api/decks/:id` for the cover |
| Views by week, most read slide, seconds per slide, the investor links | `GET /api/cycles/raise/modules/pitch-deck` (the module's card and records, every version), its records a page of 25 at a time through the read's own `page`, under a pager with the read's own total |
| One version's views, unique viewers, median time, NDA signed, the funnel, whether its links are used up | `GET /api/decks/:id/engagement` |
| Withdraw | the link record's `revoke` action (D696), after a dialog, on a live link only |
| New link | the module's own form (`/raise/pitch-deck/new`), until part 8's share dialog |

- **Two scopes, each labelled.** The module's figures cover every version and say so. Engagement covers the current version and says so.
- **"No one has opened a link yet." is the Worker's own empty card,** no view ever. A card that could not be read is a failed read, with Try again. Views older than eight weeks draw eight zero bars, "0 views in the last 8 weeks", and the other figures still show.
- **A unique viewer** is one browser: `ip_hash` with `ua_fingerprint`.
- **The engagement read sends at most 200 views,** so at that cap the views read "200+" and the viewers and median say they cover the latest 200.
- **NDA signed is a count of signatures,** never divided by browsers. The funnel's one denominator is the version's views, from the same read, and the funnel says so.
- **A link is live only when it has not expired and is not used up.** The records give expiry and withdrawal; the engagement read's `shares` give `exhausted` for the current version's links, and a link never opened has every view left. An opened link of another version says "Views left not read" and offers no Withdraw, until part 1 puts used up in the records.
- **A missing value is "Not recorded" or a dash, never 0.** The canvas's "[0:66]" is drawn as 1:06.
