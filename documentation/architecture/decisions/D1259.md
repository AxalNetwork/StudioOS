### 1. Model versions

- **A version is code.** `model.ts` holds `VENTURE_MODELS`: v1.0 (D1255) and v1.1.
- **v1.1 is v1 with three inputs given a store,** the ones v1 held with `source: null`:
  - Geographic › Country environment;
  - Political and regulatory › High-risk jurisdiction lists;
  - Political and regulatory › Political stability and regulatory quality.

  No weight moves. The two WGI inputs read a yearly edition, so their freshness window is a year (`records`); the lists keep 120 days.
- **v1 is never edited.** The engine README's rule holds, and a test pins that v1's index inputs still have no source.
- **Every venture's country is a market's country:** `markets.geography_ref`, for markets served, entering or considering. A founder's country is never an input.

### 2. Publish

- **The route:** `POST /api/venture-scores/models/:version/publish` takes `requireSuperAdminWriteBar`, so a Super Admin, a TOTP session and a fresh step-up. The global step-up prompt asks for the authenticator code, as SC13's dialog draws it.
- **Once, and only forward.** A version not newer than the live one is refused, `model_not_newer`: a published version is never published again, and the live model never moves back. An unknown version is a 404.
- **The live model** is the latest row of `venture_model_publications`. With none, v1.0 scores, as D1255 shipped it. `liveModel` throws if the table cannot be read: scoring on a guessed version would write rows the live model never computed.
- **Every venture recomputes.** The every-minute job (HQ only) rescores 25 ventures a run, by id, with trigger `publish`.
  - A run claims its batch by moving `cursor_project_id` first, so two runs never score one batch twice.
  - A venture that fails is counted (`ventures_failed`), never named in a log.
  - When no venture is left, `finished_at` is set.
- **Old rows stay.** Each scope's hash names its model version, so v1.1 writes new rows, and v1.0's rows are never touched. A venture's history keeps both.
- **The audit:** `venture_model.published` carries the version and the venture count only.

### 3. The licence check

`countryIndex.ts` `INDEX_SOURCES` records each source's licence. A source whose licence is null is refused at import (`licence_not_recorded`), before anything is fetched or written. Each value carries the licence its edition was imported under, and the reader counts it only while that licence is still the one recorded here. So a source never recorded, or a licence later withdrawn, is not read. Changing a licence is a decision: it is edited in the registry and here, together.

| Source | Recorded licence | Basis |
|---|---|---|
| World Bank, Worldwide Governance Indicators | CC BY 4.0 | The World Bank Data Catalog lists the WGI under Creative Commons Attribution 4.0. Attribution: World Bank, Worldwide Governance Indicators. |
| European Commission, high-risk third countries (Delegated Regulation (EU) 2016/1675 and amendments) | EU reuse of Commission documents, with acknowledgement (Decision 2011/833/EU) | Commission documents are reusable with acknowledgement of the source. |
| FATF, high-risk and other monitored jurisdictions | Not recorded | The FATF's terms allow reuse of its data with attribution, but they do not say whether its public statements on jurisdictions are data. Until the owner decides, the FATF lists are neither imported nor read, and the scorecard says "FATF not counted: no licence recorded". |

### 4. The import (migration 627)

- **Tables:**
  - `country_index_editions`: source, edition, licence, the decision that recorded it, published date, citation, count, importer.
  - `country_index_values`: source, edition, licence, country, indicator, value 0–100, as of.

  An edition is imported once and never edited; a second import of one is refused, `edition_imported`. One batch writes an edition whole or not at all.
- **WGI:** the Worker fetches the four percentile ranks for the edition's data year from the World Bank API (keyless): `GE.PER.RNK`, `RL.PER.RNK`, `PV.PER.RNK` and `RQ.PER.RNK`.
  - **What is stored:** only a country in Research › Geographies (`research_countries`). An aggregate, an economy outside the directory, and a missing figure are not stored; a missing figure is never a 0.
  - **When an indicator fails:** one unreadable indicator refuses the whole edition.
- **Lists:** a Super Admin enters the countries each list names, with its edition and published date.
  - A list is stored as 100 for each country it names. A country it does not name is stored as nothing.
  - An unknown code, or a list the source does not have, is refused.
- **Who:** both imports take the Super Admin write bar, and the audit row (`country_index.imported`) carries the source, edition and count.
- **What v1.1 reads:**
  - **Country environment:** the mean of government effectiveness and rule of law, per market country, averaged across markets.
  - **Stability:** political stability and regulatory quality, the same way.
  - **High-risk lists:** the share of market countries on no list, over the lists whose licence is recorded.

  All three are graded Sourced. Each reads "Not recorded" with its reason when no market has a country, or when no edition is imported.

### 5. Routes, and part 3

- **Routes:** `routes/venture_score_models.ts`, mounted at `/api/venture-scores`:
  - `GET /hq/models`;
  - `POST /models/:version/publish`;
  - `GET /hq/indices`;
  - `POST /hq/indices/:source/import`.
- **Who reads:** reads are HQ admin (`requireHqAdmin`), writes Super Admin. A branch is refused by both.
- **Why not `venture_scores.ts`:** the issue names that file, but part 3 (#3279) is creating it in parallel, with its mount and its client. Two new files with one name would conflict whole. So this part has its own module and client (`frontend/src/lib/api/ventureScoreModels.js`).
- **No path collision:** its paths cannot meet part 3's `/:projectId`, `/deal/:dealId` or `/models` routes.

### 6. SC13, HQ › Scoring

`HqScoringPage.jsx` reads both routes, each failing alone with Unreadable and Try again.

| Block | What it draws |
|---|---|
| Model versions | Version, state (Live, Draft, Retired), date, who published it, and the ventures each version scored. v1.0 says "No publication recorded" rather than inventing a publisher. A running recompute shows its progress. |
| What v1.1 changes | Each changed input, with its weight, store and window in both versions. |

The Publish dialog says how many ventures recompute, and in about how many minutes. It also says that earlier values stay in each venture's history, and that the authenticator code is asked next.
