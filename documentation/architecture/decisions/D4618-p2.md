### Loading with the section

`lazySection(load, what, name)` (`pages/account/lazySection.jsx`) returns a card that fetches its module the first time it draws. While the module loads, the card's place shows a loading line. If the module fails to load, or the card throws, that card alone says Unreadable, with Try again. Try again makes a fresh `React.lazy`, because a failed lazy stays failed. Once the card draws, it looks again for the address's `#anchor`. The page's own scroll ran before the card existed. Each card has its own boundary, as each already had its own read, so the folder rule "a card fails alone" holds for loading too.

The pane layouts stay in `SettingsPage.jsx`, card by card. Newsletters, push devices and the investor cards keep their own static modules.
