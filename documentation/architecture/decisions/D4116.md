### 2. What wins over the canvases

1. **Values:** the canvases draw the older eight values (Courage, Craft, Empathy, …). Every build uses the **six Axal values** of D4117 §1: Integrity, Stewardship, Curiosity, Resilience, Collaboration and Ambition (`FIT_V2_VALUES`).
2. **The persona:** it carries no philosophy, no Schwartz bars and no trade-offs (D4117 §1). #4119's body still lists "philosophy" and "Schwartz bars"; D4117 wins.
3. **No roles:**
   - an agent is a persona with skills;
   - skills are grouped into the **eight areas** of the `/studio` radar (D4117 §3): Product, Marketing, Engineering, Design, GTM, Capital, Finance and Legal;
   - any skill can go to any agent, and natural fit only sorts.
4. **SkillEnergy is style B** (D4120). EN1's choice is made.
5. **Agents propose, and a named person accepts.** No board adds an action that sends, posts or pays.

### 4. Rules for every build

- Client methods only for mounted routes. A surface whose route is not on main goes behind `pages/team/agentsAdapter.js`, greyed, with its reason.
- "Not recorded" is never 0: a radar with no skills, a cost with no figure, a used-by count that was not read.
- A failed read is never an empty list.
- Agent avatars are pixel-art portraits with the agent mark beside the name; people keep photos or initials (#4118).
- No job title (CTO, CFO, …) renders anywhere an agent appears (D4117).
