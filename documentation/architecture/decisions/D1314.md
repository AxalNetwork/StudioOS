### 1. The two canvases are one design

Google's and Notion's pages draw the same eight boards with each provider's words. Google "files you choose" and Notion "pages you share" read the same way; so do Map columns and Map properties, and "From Google" and "From Notion".

So each provider gets **one** shared From section, and every module that reads it mounts that section; no module draws its own.
