### HQ: Record a mark… on a queue row (PRM22 B, C)

Before this part, "Record a mark…" opened the company's sheet and HQ then opened the mark form and, after saving, answered the request by hand with Resolve….

- The button opens the company's sheet **with the mark's write flow already open**, and a line above its steps says which request it answers: "Answers the request from <investor> · <kind> · requested <day>".
- The flow is the ordinary Prepare → Review → Confirm → Receipt; nothing in it is prefilled. The request records no as-of date, basis or source (its row holds kind, reason and state), so there is nothing true to prefill from it. The canvas's prefill comes from Eadwyn's proposal, which is a later part.
- **When the Worker has stored the mark**, the page answers the request: `PATCH /api/mark-requests/<uid>` with `{ state: 'resolved', mark_uid: <the new mark's uid>, note: null }`. The investor's list then reads "Answered · mark recorded".
- The mark is written first; the answer is a second call. If it fails, the mark stays saved and the receipt says so: "The mark is saved, but the request from <investor> was not answered. Resolve it below with this mark." Resolve… on the sheet's request list is unchanged and does it by hand.
- A mark recorded from the sheet itself ("Record a mark" under Marks) answers no request and shows neither line. Closing the flow, or opening one from the sheet, forgets the queue row.

### Investor: the mark-history header (PRM18)

The mark-history Sheet's header, beside the mark's age, carries the company's latest request as a chip:

| State | Chip |
| --- | --- |
| open | ◷ Requested · <day> |
| resolved | ✓ Answered · mark recorded · <day> (or Answered, with no mark) |
| declined | ✕ Declined · <day>, with HQ's reason as the chip's title |

Each state has a glyph and a word, so it never rests on colour alone. The words are `requestStatusOf`'s, the same as the requests list under the panel. A request list that could not be read, or a company with no request, draws no chip; the panel below says which.
