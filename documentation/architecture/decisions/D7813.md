## D7813 — Research › Companies: the page's scoped export, an honest Evidence badge, the Funds rule and keyboard tabs (#7813)

- **Status:** built (the slice the coordinator released on 2026-11-25). Part of #3701, from the owner's Research › Companies audit of 2026-11-19.
- **Builds on:** D7172 (`zoneActionBuilder`'s `view.scoped`, the Markets scoped export), D7811 (the shared `csvSafe` rule and the export convention), D7812 (the stored publisher, licence, link and date on each directory row), D7179 (the directory's URL state), D7180 (the profile's evidence collections).
- **Migration:** none. **Worker change:** none.

### The Companies export is the page's own scoped export

`frontend/src/pages/research/companyDirectoryExport.js` builds it and `CompanyDirectoryZone.jsx` runs it, because the search, filters, sort and page live there. `ResearchWorkspace.jsx` only passes it to `zoneActionsFor(role, 'research/companies', { view: { scoped } })`, so the Founder and Advisor shells draw the same control and write the same file. The export ops in `founderZoneActions.js` and `advisorZoneActions.js` are unchanged.

- **The control** reads "Export this page · N rows" before the click. Its hover (`title`) names the page and rows ("Page 2 of 8, rows 26–50 of 186"), the search ("no search" when none), the filters ("no filters" when none) and the sort. A read in flight reads "Export this page · loading", a true zero "Export this page · 0 rows", and a failed or refused read "Export · not available"; none of them writes a file. After the click, a status line names the file that was handed over, or says it could not be written.
- **The file** is `companies-page-<p>-<n>-rows-<day>.csv` (`exportFileName`). The header row is the first line. Ten columns: Record uid, Company, Country, Founded, Website, Sector label, Publisher, Source link, Licence, As of. Every value comes from the list response: `uid`, `name`, `country`, `founded_year`, `website`, `sector`, then D7812's stored `source_name`, `source_url`, `source_license` and `as_of`. The source link is admitted only as `companySource` admits one (https); an unknown value is "Not recorded".
- **Formula-safe cells.** Each cell is checked with the shared `csvSafe` and, where that rule would prefix it, written with the apostrophe through `exportView`, whose `csvCell` does the quoting. The bytes equal `toSafeCsv` over the same cells (the test pins it), and no second copy of the rule exists. `csvExport.js` and `zoneActionBuilder.js` are not edited.

### The Evidence badge

The profile's section nav badge for Evidence is never a bare number and never 0 when a collection failed: every collection read gives "N records"; some failed gives the count that was read, "N read · partial"; all four failed gives "Unavailable" and no number. Its hover says how many collections could not be read. A partial or Unavailable badge takes the amber tone. The Sector peers badge is unchanged.

### The Funds section

The section states its matching rule under the existing lede: headquarters is where the fund's manager is based, not where it invests, and each list shows the first three funds by name (the fund directory's default `name` order), not a ranking. The Market context card and the market index line are not edited (#7710).

### The Directory and Saved analyses tabs

The RS-17 E keyboard departure PR #7206 listed is closed: Left and Right arrows (wrapping), Home and End move to and select a tab, only the selected tab is a tab stop, each tab has `aria-controls` naming its tab panel, and each panel is a `role="tabpanel"` labelled by its tab. The panel not shown is rendered empty and hidden so both names resolve; its contents still mount only when selected. This is the Markets tabs' pattern (D7172).

### Departures from the issue text

- The complete-read Evidence badge reads "N records" rather than a bare number, because the Done-when says the badge is never a bare number. Sector peers keeps its number; it is not this issue's.
- No in-page export control beside the count: the issue names the header row's control, and the Companies canvas (D7045) draws none there. The status line after the click is this page's only addition.
- Selection and all-matches scopes are #7831 and #7848 and are not built here.
