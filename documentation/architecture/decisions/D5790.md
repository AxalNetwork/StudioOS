## D5790 — Compare HQ skill drafts with their deployed library source (#5790)

The Super Admin skill diff accepts `from=source` for version-zero drafts as
well as its existing published-version comparisons. It reads the deployed
library asset and validates the matching entry before comparing frontmatter
and steps. A missing, ambiguous or invalid source refuses the comparison;
no source is invented and no catalogue row is written by this read.

The HQ refusal map names `source_missing`, `source_ambiguous` and
`source_invalid` in the page's words, and `version_unknown` includes the
library source among the available comparison inputs. The existing frontend
contract derives the Worker's refusal codes and rejects a missing message.

The original reconciliation test covers Super Admin scope, a drifted
version-zero draft, missing source and unchanged persisted row counts. The
failed frontend check was reproduced before adding the messages. Each new
mapping is removed temporarily to confirm that the contract rejects it, then
restored for the passing run. Build and other validation results are recorded
on PR #5802. No production catalogue operations or permissions change.
