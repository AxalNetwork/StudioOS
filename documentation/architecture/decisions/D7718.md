## D7718 — Country figures and their observation provenance (#7718)

The Geography profile uses the existing observation catalogue and the metric-and-geography query, which accepts the page’s two-letter code and returns coverage. It displays the newest measured period of each series in Worker order, grouped by source. Source health and retrieval age come from the Worker. A failed read offers Retry. Downloads use the existing authenticated CSV export and its source terms.

The shared Sheet receives a single observation. The calling page supplies the catalogue definition for its source and the direct successor from the revision read. Each CSV provenance field has a labelled reading. A missing publication date stays empty of any date, and a reported zero remains zero.
