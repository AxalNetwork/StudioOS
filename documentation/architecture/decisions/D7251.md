## D7251 — Route automatic Code Scanning issues to S21 (#7251)

The owner assigned automatic Code Scanning tracking issues to S21. New trackers
receive the existing `slot:S21` label when created. The workflow adds
`state:ready` when a tracker is ready for a session to claim, using the existing
task protocol.

For a trusted bot-created tracker with the exact automatic title and alert
marker, `slot:S21` represents the default route. Reconciliation can still link
a prepared branch or PR, close a scanner-confirmed fix, and reopen a recurrence.
Atomic claims, assignees, locked issues, other slots and human work states
continue to protect active work. An S21 label on a legacy or owner-created
tracker continues to represent human ownership.

The existing unclaimed automatic issues are assigned `slot:S21` through GitHub's
additive label API. Their readiness and other labels are preserved.

Validation covers the full tracker lifecycle with the default slot and checks
that active claims and manual assignments stop reconciliation.
