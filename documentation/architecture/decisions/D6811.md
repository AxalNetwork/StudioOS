The failed #6773 attempt 43774352397 had one substantive failure: the Build
record role-table test expected Manage connection and received Reconnect.
Both summary jobs then refused the failed suite. The R2 inventory was not the
failing assertion. The affected file passes in isolation.

D5065's embedded mutation runner rewrote `systemsState.ts`, `records/build.ts`,
`cycle_build.ts` and `CycleCharts.jsx` in the shared checkout while Node ran
other test files concurrently. Its healthy-system mutant changes exactly
`manage` to `reconnect`. A parallel process can import those bytes before the
finally block restores them; its module cache then retains the mutant.

The runner now creates one private source copy for its baseline and mutation
children. It copies the Worker source, SQL, tests and required frontend/scripts
source and shared protocol/contract imports; only installed dependencies are linked. Every child imports and runs
from that private root. The mutation and restoration targets are private files,
and every check also verifies the shared source remained unchanged. Cleanup
runs after the test file and on copy failure. TAP is explicit for the child
summary assertions. No test or mutation is disabled, no production behavior or
workflow concurrency is changed, and no hosted rerun is requested.

A focused synthetic fixture verifies private versus shared imports while the
mutant is held, dependency linking, cleanup after a failed child and partial-copy
cleanup. The actual D5065 mutation checks and the previously failing Build record
file are also exercised together. These are local synthetic records; no live
logs beyond the failed GitHub job or member data are accessed.

Validation: all 57 focused tests pass together, including all 13 existing
mutation checks. A controlled replay holds the healthy-system mutant while
running the real Build record file: the original runner reproduces the hosted
Manage/Reconnect failure (24 passed, 1 failed); the isolated runner passes all
25 tests. The replay runs entirely in disposable source copies. Four negative
helper variants (source symlinks, missing cleanup, leaked partial copy and
