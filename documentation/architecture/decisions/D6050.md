## D6050 — Show the Cap table plan lock on Raise Overview (#6050)

RO13 of the Raise Overview board uses the Cap table card's existing `plan`
response. An explicit `locked: true` takes precedence over chart data. When
the plan is unlocked or omitted, the overview uses its existing card states.

The desktop card displays the named plan and a See plans button. Its title
continues to open the Cap table. On the phone overview, the Cap table list row
shows the same lock and upgrade action. Both actions pass the Worker's
`plan_key` to the existing checkout sheet. Entitlements are enforced by the
existing Worker rules.
