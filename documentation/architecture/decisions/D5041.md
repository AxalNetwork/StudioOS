## D5041 — HQ Team: a branch is never "not deployed" because nobody asked, and an unreadable registry is never "no branches" (#5041)

- **Status:** Built for #5041, 2026-11-08. Package 2 of the HQ Team audit (P1).
- **Builds on:** D108 (the fan-out and its per-branch states), D138 (the Team read), D150 (the licence stamp), D717 (the branch deadline), D153 (the view-as overlay).
- **No migration. No new route.** Fields are added to `GET /api/admin/hq/admins`, `/overview` and `/funds`; none is removed.

### The state model

| State | Meaning | Where it appears |
| --- | --- | --- |
| `not_asked` | A service binding exists and HQ ran no search. Ready; nothing is known about the branch from this read. | Team with no `q` |
| `ok` | Asked, answered. | any fan-out |
| `unreadable` | Asked, did not answer. The only state with a retry. | any fan-out |
| `not_deployed` | HQ holds a deployment row; this Worker has no binding to it. | any merge against the registry |
| registry unreadable | HQ cannot establish the deployment set. `registry_available: false` with a reason. | Team, overview, funds |

### What was decided

1. **`deployedBranches()` preserves availability** (`routes/admin_hq.ts`): `{ available: true, rows }` or `{ available: false, reason }`. It returned `[]` on every error. A missing `licence_deployments` table (migration 258 not applied) is still an empty registry, because nothing can be recorded in it; any other failure is `available: false` and is logged.
2. **Team without a search makes no RPC.** The idle rows are derived from the bindings this Worker holds plus the registry: a bound branch is `not_asked`, a registry row with no binding is `not_deployed`, a binding with no registry row is listed as `not_asked` with no licence. `withRegistry([], registry)` used to read every registry row absent from the results as `not_deployed`, including branches that were bound and merely not asked.
3. **Coverage counts what was asked** (`teamCoverage`, `services/branches.ts`). `{ total, asked, answered, complete, unreadable, not_deployed, not_asked }`. Idle rows are not failures. `complete` is true only when the registry is established, nothing failed or lacks a binding, and either a search ran or there is no branch to ask. With the registry unreadable it is false whatever the bindings say. The old `coverage()` is unchanged for fan-outs that ask every branch.
4. **The whole-team claim needs positive establishment.** The payload carries `registry_available` and `no_branches` (the registry read, no row in it, and no binding). The page says "this is the whole team" only for `no_branches === true`; an unreadable registry draws Unreadable with Retry, and an older payload with neither field makes no claim.
5. **The other callers of `deployedBranches()`** (`/overview`, `/funds`) carry `registry_available` (and a reason) and are never `complete` over a registry that could not be read. `stampLicence` only needs the rows and takes them when there are any.
6. **The page** (`HqTeamTable.jsx`, `hqTeamBranchModel.js`, `AccountsPage.jsx`): "Ready to search" in the neutral colour with no retry; "Not deployed" reserved for a missing binding; "Could not be read" with Retry for a branch that was asked; the rail and the footer say what was asked (`2 branches ready to search; none asked yet`, `Of 2 branches asked, 1 answered; 1 could not be read`).
