## D8005 — Exercise grid layout boundaries with generated inputs (#8005)

Extend the existing Worker grid property suite while retaining its seeded
structure, geometry, derivation and sanitization checks. The additional cases
compare real layout behavior with an independent enumeration of the grid's
cells, covering accepted and rejected inputs without filtering away failures.
They also check preservation of input, canonical sanitization and derived
reading order.

Use the exact development dependency fast-check 4.10.2 with its locked
pure-rand 8.4.2 dependency. Both versions satisfy the existing release-age
policy. No production dependency or implementation changes are needed.

Each new property runs 400 bounded cases with a fixed seed. Failures shrink
and report the seed and path needed for replay. A two-second interruption
budget fails the property if exhausted, and the test has its own timeout.
Local validation also uses an outer process timeout for synchronous failures.

Validate the complete affected suite and correct, mutated and restored
production-source copies, including replay of minimized counterexamples.
Keep mutation fixtures outside the checkout and preserve the original source.
