## D4824 — Expertise Services: cards with the stored publication state, Undo, Preview and explicit prices (#4824)

- **Status:** built 2026-11-18 to EX-06 (Services list) and EX-07 (Service editor) of `design/incoming/Expertise v2 · Boards.dc.html` (D4823), on the Worker routes in `cloudflare-worker/src/routes/advisors_services.ts`. No route, client method or migration is added.
- **The state on a card is `publication_state`** (D5315 part 3): Draft, Published or Hidden, read as stored and never derived from Active / Inactive. A row without the column reads Draft, the column's default. Each card offers one move: Publish (Draft), Hide (Published), Publish again (Hidden), sent as `PATCH /me/services/:id { publication_state }`. The toast after a move has an Undo that sends the previous state back; an Undo offers no Undo of its own.
- **Active / Inactive is no longer a control.** The Worker moves `is_active` with the publication state (published sets it, draft and hidden clear it), so a second dial on the card would say the same thing twice. The editor keeps every other field and sends only what changed with the revision it opened on (D4674).
- **Nothing says Bookable.** By the owner's answer of 2026-11-09, booking is Practice › Sessions' (#4832): each card links there read-only and edits no duration, price or booking setting of a session type. No column links a service to a session type, so the link is to Sessions, not to one type.
- **Preview** opens the public profile (`/advisors/:uid`) and is offered only for a Published service once a saved profile gives the page an address. The public profile (`AdvisorProfilePage.jsx`) now lists the `services` that `GET /api/advisors/:uid` already returned and nothing drew, so Published means what the card says.
- **A price is written with its code** at the currency's own decimals ("CHF 12,000.00", "USD 450.50", "JPY 5,000"); no price reads "No price set", never a zero.

### Where the build departs from the canvas

- EX-06 draws Active / Inactive with the Undo toast and marks Published and Bookable as a backend proposal. The backend for Draft, Published and Hidden landed (#5705), so the card shows those and S1's note on #4824 drops Bookable; the Undo toast is kept for publication moves.
- EX-06's chips (All, Active, Inactive, No price) stay the zone's existing kind filter from the shared toolbar; the whole-list publication counts are a line above the cards.
- The delete action reads "Remove…" and keeps the in-place question of D4711 rather than a separate dialog.
