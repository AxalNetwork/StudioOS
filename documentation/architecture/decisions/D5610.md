## D5610 — Affected-test selection in shadow (#5610)

CI continues to run every test and required check. A PR-only job named
`selection (shadow)` waits for suite, computes an advisory decision, and uploads
one JSON record. It is outside gate's needs, continues after diagnostic errors,
and exits zero. Setup errors still emit a full, unscored record.

The pure selector considers traced file reads (including resolved imports and
existence probes), additions/deletions under listed directories, changed/new
tests, static transitive imports for untraced tests, and generator inputs for
#5612's three outputs. Mandatory commands are `test:guards`, `test:types`,
`test:types:frontend`, and `build`. Opaque tests and traces above **FAN_IN_MAX =
500 files** always run. A trace above that bound changes too often to prune
usefully, and an opaque child may read anything.

Full fallbacks: any package or lock file, loader or adjacent underscore helper,
`.github/`, missing/malformed trace, trace over 24 hours old, more than
**STALE_COMMITS = 20 commits**, unavailable ancestry, or selection over 40%.
Exactly 40% is selected. The CLI also rejects a trace SHA not ancestral to the
tested base. Neither threshold authorizes skipping anything.

### Artifact contract and scoring

#5608 producer contract verified in #5630: `test-deps.json` has `{sha,node,tests}`, `tests` is a map
of repository-relative test paths to
`{reads,modules,sqlite,probes:{hits,misses},directories,children,opaque}`.
The selector unions reads, imports, sqlite files and both hit/miss probes. The
artifact's creation time supplies freshness unless `generatedAt` is present.
The producer implementation in #5630 was inspected before integration. Unknown schema falls back to full.

Proposed #5502 contract: `ci-failures-*` holds JSON with
`{verdict:'pr_failure',failures:[{file:<repository-relative test path>}]}`.
The contract was requested on #5502. Missing, empty, non-PR or malformed evidence
is **unscored**, with `misses:null`, never a zero-miss scored run. Only a failing
file in a proven `pr_failure` run can count as a miss. Stable file identity is
independent of the assigned part. `--report <directory>` prints scored failing
runs, unscored runs, miss count and full-fallback fraction f.

The gate for #5621 is **zero misses across at least 300 scored pr_failure runs,
and zero misses in the complete backtest**. An unscored backtest does not meet
that gate. The owner decides after reading the report; this change grants no
permission to switch execution policy.

### Historic replay evidence

The fixture is grounded in 566 completed main push CI runs from 2026-11-04
15:47 UTC through 2026-11-11 15:47 UTC. First failure after a successful interval
yields 29 intervals. Excluding one audit-only and one aggregate-only failure
yields the issue's **27 suite episodes**. Each has a first-red commit and run/job
links. TAP failure locations recover failing files for 25; two guard/setup-only
failures have no test-file identity. Raw logs and excerpts are not committed.

Historic dependency traces were not recorded (#5608 is still being built).
`--backtest` therefore prints an explicit unscored verdict for every episode.
Supply `--evidence <directory>` with `<firstRedCommit>.json` containing replay
inputs (`changed`, `deps`, `tests`, `graph`, `meta`) to score a reconstructed
snapshot. The fixture never fabricates traces or passing results.

#5608 and #5502 remain integration dependencies. The draft is part of #5610
until the actual field contracts and historic replay evidence are verified.
