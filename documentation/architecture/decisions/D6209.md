## D6209 — Private Portfolio saved views (#6209)

The Worker stores bounded table settings against the authenticated member and
page. Views never grant company, fund or colleague access. List, create, rename
and delete bind the member ID on every query; another member's UID is
indistinguishable from an unavailable or concurrently changed record.
Optimistic versions prevent stale rename and delete. The maximum is 100 views
per member and page; impersonation does not manage personal settings.

Overview stores query, sector, stage, health, reporting and sort. Positions
stores query, the existing All/Needs attention/Below cost/Stage selection,
stage and as-of date. It has no sector filter or independent sort. Retired
stage and sector strings stay in the specification so applying them can show
no matches rather than silently widening the view.

The approved Portfolio canvas marks Saved views as backend required but draws
no save/apply/rename/delete menu or its states. This part supplies the Worker
and API seam. The interactive menu awaits its canvas; existing tables are
unchanged and usable independently of the saved-view read.
