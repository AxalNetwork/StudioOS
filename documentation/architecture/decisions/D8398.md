## D8398 — Perk console uses the Offers interaction system (#8398)

The embedded partner console retains its approved OF-07 layout. It uses the canonical Offers input, amber primary, outlined secondary actions and headings. The primary is 48px on phones and secondary actions are 44px through the shared kit. Console fields have visible labels, including separate labels for each cost input; the console text floor is 12px.

Read failures use zoneReadError and SectionState rather than displaying response messages. Failed performance refreshes hide the stale performance controls; failed listing reads do not draw an empty-list claim. Form values remain independent of the reads.

This depends on #4845 / #8305 for the canonical read-error helper and phone primary height. It is developed on main with that prerequisite merged into S19's branch; the draft PR targets the prerequisite branch until it lands. No shared kit or helper is copied. No API, permission or database changes. ClaimModal and ExtendModal remain byte-identical to the prerequisite merge.

Verification uses the reference Offers markup regressions, the existing Perks contracts and the new console render test. Class assertions establish the phone sizing contract; they are not screenshot or browser evidence.
