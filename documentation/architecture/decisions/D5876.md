## D5876 — Page approval boards and read their counts separately (#5876)

Part of #4716. The Product testers, Wellbeing experts and Co-marketing boards
read one aggregate summary and the active queue page. Changing the page or
tester filters reads only the queue. A decision refreshes both reads.

The existing Admin gates also protect the summaries. Expert counts use the
same hidden, declined, verified and profile-completion rules as the page.
Testers apply search, role, verification, consent and sort in the Worker
before paging. The tester profile chart, programme total and published
pitch attribution use aggregates over their full recorded sources.

If the summary cannot be read, tab counts are unreadable and the queue page
can still render. Overdue and unassigned retain their existing completeness
rule. They use the waiting rows only if the current page contains all of them.
The Inbox and the decision endpoints keep their existing contracts.
