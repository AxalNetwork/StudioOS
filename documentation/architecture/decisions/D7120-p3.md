## D7120 part 3 — The member downloads their own calendar entry for a group seat (#7120)

- **Status:** built by S10, 2026-11-25.
- **What it closes:** the "Download calendar entry (.ics)" row that D7120-p2 left out, because the client's `request` reads JSON only.
- **Worker:** no change. The route `GET /api/wellbeing/group-reservations/:uid/calendar.ics` and its content are part 1's (D7120).
- **Migration:** none.

### What is built

- **A text-reading client helper (`lib/api/wellbeingGroupSessions.js`, `calendarFile(uid)`).**
  - It reads the entry with exactly what `request()` sends: `rawRequestHeaders('GET')` plus `credentials: 'include'`, and `Accept: text/calendar`.
  - A refusal goes through the shared `refusalError`, so it carries its `status` and `code`.
  - The body must start with `BEGIN:VCALENDAR`. Anything else, such as the app shell answering instead of the Worker, is refused as `calendar_unreadable`, so HTML is never saved as an `.ics`.
  - It returns `{ text, filename }`. The file name is the Worker's (`appointment.ics`).
  - `api.js` is a frozen hub (D5615), so the helper lives in the domain's own module, as `adminGovernance.js`'s file read does.
- **The download (`pages/wellbeing/GroupSessions.jsx`, `CalendarDownload`, on My group seats).**
  - A reserved seat offers "Download calendar entry (.ics)" when its session is not cancelled and the member did not choose "No calendar entry" (`calendarEntry`).
  - The file is saved on this device from the text, under the Worker's name.
  - The line beneath says what the entry shows:
    - discreet: "“Private appointment”, with no description";
    - named: "the session’s title";
    - both end with "It lists no one else."
  - A failed download says so, and that the seat is unchanged (`calendarRefusal`):
    - "There is no calendar entry for this seat any more" for 404 `calendar_entry_not_found`;
    - a retry sentence for anything else.

### Confidentiality

- **The request names only the seat.** The reservation uid is encoded, and there is no body or query.
- **It carries the member's own credentials**, and the Worker serves the entry to its owner alone (D7120, tested).
- **The file name never names the session.**
- **The page never shows the session's title** beside a discreet seat's download.
- **What the entry contains is unchanged and tested Worker-side:** no attendee, no organiser, and "Private appointment" unless the member chose "Session title".
