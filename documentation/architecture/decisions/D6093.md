## D6093 — Reminder settings from Reporting on a phone (#6093)

Reporting already offers Share an update in History and on an empty desk.
The missing phone door is Reminder settings. A writer now gets the existing
More menu in CycleBar, beside the existing Eadwyn control; its two actions
remain Share an update and Reminder settings. No new reporting write or route.

This deliberately departs from D1062/RPT20's no-More phone header, as #6093
requests. The pinned Prepare bar and desktop header retain their behavior.
Phone menu controls have 44px targets. Escape and browser back dismiss the
menu. The Worker's can_write gates the phone menu and an empty desk's Share
action, so advisors, Operating Partners and admins cannot see writer actions.

Mounted tests exercise the two-tap paths, actual Share callback, Reminder
dialog, Escape/back, target classes, readers and an unchanged Prepare bar.
Existing desktop regressions run beside them; mutation checks and final
build/drift results are kept with the batch review package. Roll back by
reverting this issue's commit. No migration, API or configuration change.
