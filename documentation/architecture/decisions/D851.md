## D851 — Model and coding providers (Anthropic, OpenAI, xAI): what each really offers, and one adapter shape on the AI token ledger

- **Status:** groundwork, S22, 2026-10-21 (#2474; part of #2463). Off by default.
- **Basis:** `origin/main` at `56c24989`. Worker paths are relative to `cloudflare-worker/src/`.
- **Plan:** `documentation/architecture/MCP_API_PLATFORM.md` (it lands with #2464's PR, #2484). A model API is **pattern C**, a native adapter. It is never described as an MCP connection.
- **Depends on:** #2469 (D848, the connector contract) and #2466 (D844, metering with idempotent holds). Neither is on `main` yet. This part needs neither: it holds and settles through `reserveAiBudget` and `settleAiReservation` directly, as `run()` does (see §3, "When the dependencies land").

Three things are often confused, so this record keeps them apart:
- a provider's **inference API**, which the platform calls with its own key;
- a provider's **coding agent**, a product a person runs;
- a provider's **MCP features**: a remote MCP server it hosts, an MCP client inside its product (which could call `https://axal.vc/mcp`), or a tool in its API that calls a remote MCP server.

A provider is never "connected" because its API exists.

#### 1.1 Anthropic

1. **Inference API.**
   - `POST https://api.anthropic.com/v1/messages`, the Messages API. The body needs `model`, `max_tokens` and `messages`; `system`, `stream`, `tools` and `thinking` are optional. ([overview](https://platform.claude.com/docs/en/api/overview), [create](https://platform.claude.com/docs/en/api/messages/create))
   - Also: Message Batches (`/v1/messages/batches`, 50% off), `/v1/messages/count_tokens`, `GET /v1/models`. ([overview](https://platform.claude.com/docs/en/api/overview))
   - Headers: `x-api-key` (or `Authorization: Bearer`), `anthropic-version` (the examples use `2023-06-01`), `content-type`, and `anthropic-workspace-id` when the key is not scoped to a workspace. ([authentication](https://platform.claude.com/docs/en/manage-claude/authentication))
2. **Auth.**
   - API keys (personal, service-account, legacy workspace; optional expiry), Workload Identity Federation (`POST /v1/oauth/token`), and App Attest (Apple apps, Messages only). Admin API keys exist. ([authentication](https://platform.claude.com/docs/en/manage-claude/authentication))
   - There is **no OAuth flow for a third party to call the API on a member's behalf**. Third-party products may not offer claude.ai login unless Anthropic approved it. ([Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview))
3. **Usage reported.**
   - `usage.input_tokens` (uncached input only), `output_tokens`, `cache_creation_input_tokens`, `cache_read_input_tokens`, `cache_creation.{ephemeral_5m_input_tokens, ephemeral_1h_input_tokens}`, `output_tokens_details.thinking_tokens`, `server_tool_use.{web_search_requests, web_fetch_requests}`, `service_tier`. Total input is the sum of the three input fields. ([create](https://platform.claude.com/docs/en/api/messages/create))
   - Streaming: `message_start` carries the initial usage; each `message_delta` carries cumulative usage. ([streaming](https://platform.claude.com/docs/en/build-with-claude/streaming))
4. **Rate limits.**
   - RPM, input TPM and output TPM per model class, by usage tier, with a monthly spend cap per tier. Cache reads mostly do not count toward input TPM.
   - Headers: `retry-after`, and `anthropic-ratelimit-{requests,tokens,input-tokens,output-tokens}-{limit,remaining,reset}`.
   - Over a limit: 429 `rate_limit_error`. The tier's spend cap is also a 429, with `error.details.error_code: enforced_spend_limit_reached` and no `retry-after`. Overload: 529 `overloaded_error`. ([rate limits](https://platform.claude.com/docs/en/api/rate-limits), [errors](https://platform.claude.com/docs/en/api/errors))
5. **Errors.** 400 `invalid_request_error`, 401 `authentication_error`, 402 `billing_error`, 403 `permission_error`, 404 `not_found_error`, 409, 413 `request_too_large`, 429 `rate_limit_error`, 500 `api_error`, 504 `timeout_error`, 529 `overloaded_error`. The body is `{"type":"error","error":{"type","message"},"request_id"}`, and a `request-id` header comes with every response. A stream's errors arrive as SSE `error` events after the 200. ([errors](https://platform.claude.com/docs/en/api/errors))
6. **MCP.**
   - (a) **A remote MCP server of its own:** none for the platform. Only a documentation server, `https://code.claude.com/docs/mcp`. ([Agent SDK MCP](https://code.claude.com/docs/en/agent-sdk/mcp)) Whether a general one exists is UNVERIFIED.
   - (b) **The API calling a remote MCP server: yes, the "MCP connector"** (beta, header `mcp-client-2025-11-20`).
     - `mcp_servers: [{ type: 'url', url, name, authorization_token }]` with a `tools` entry `{ type: 'mcp_toolset', mcp_server_name }`.
     - It calls tools only, on a public Streamable HTTP or SSE server.
     - The caller runs the OAuth flow and passes the token.
     - It is not eligible for zero data retention.
     - ([MCP connector](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector))
   - (c) **An MCP client in its products: yes.**
     - Claude.ai and Claude Desktop add a "custom connector" by HTTPS URL. Sign-in is OAuth (a client ID metadata document, dynamic client registration, or the server's own client) or none. Static request headers are a limited beta. The server must be publicly reachable. ([custom connectors](https://claude.com/docs/connectors/custom/remote-mcp), [help](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp))
     - Claude Code: `claude mcp add --transport http <name> <url>`, with OAuth or `--header "Authorization: Bearer …"`. ([Claude Code MCP](https://code.claude.com/docs/en/mcp))
     - So `https://axal.vc/mcp` can be added to Claude, Claude Code and the Agent SDK today, with D665's OAuth or, once #2470 lands, a member key as a bearer header.
7. **Coding agent.**
   - **Claude Code** signs in with a claude.ai subscription, a Console account or API key, or a cloud provider. It runs headless (`claude -p --output-format json`; `total_cost_usd` is a client-side estimate). ([authentication](https://code.claude.com/docs/en/authentication), [headless](https://code.claude.com/docs/en/headless))
   - The **Agent SDK** (Python, TypeScript) runs the same loop as a library, on API keys. It calls remote MCP servers over HTTP or SSE with headers; the app supplies any OAuth token. ([Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview))
8. **Pricing.**
   - Per token per model: input, 5-minute cache write, 1-hour cache write, cache hit, output. Batch is 50% off, and server tools are priced per use.
   - **Claude Sonnet 5.5: $2 input, $2.50 5-minute cache write, $4 1-hour cache write, $0.10 cache hit, $10 output, per 1M tokens.** ([pricing](https://platform.claude.com/docs/en/about-claude/pricing))
9. **Retention.** By default not retained and not used for training without permission. The "Covered Models" (Fable 5.x, Mythos 5.x) need 30-day retention. Zero data retention is arranged per organisation and excludes Batch, Files, the MCP connector and others. ([retention](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention))

**UNVERIFIED (Anthropic):** a general Anthropic-hosted MCP server; how long the MCP connector retains data; which `anthropic-version` values are current beyond `2023-06-01`; the per-search price of web search.

### 2. The decision

1. **Pattern C, one shape.** Every model provider is an adapter in `services/ai/providers/` with two pure functions:
   - `build(apiModel, request, apiKey)` returns the HTTP request;
   - `read(status, body, header)` returns `{ ok, output, usage | null, requestId }` or `{ ok: false, error, status, retryAfterSec }`.

   An adapter reads no `env`, holds nothing, settles nothing and logs nothing, the rule `services/ai/` already has.
2. **One caller, `services/aiProviders.ts` (`runProviderModel`).** It does everything around the adapter, the same way for every provider:
   1. the provider's switch;
   2. the page's AI switch (`assistOff`);
   3. the platform key, a Worker secret;
   4. the hold, the call, the settlement and the usage row.
3. **Platform keys (option A).** The key is the Worker secret `AI_PROVIDER_ANTHROPIC_KEY`: never in D1, never a member's key, never logged. It is not `ANTHROPIC_API_KEY`, which stays dev-only (Task #31). Members pay in **AI tokens**.
   - **Option B** (a member's own key, with only the platform's fee charged) is not built. It needs a per-member secret store, and §1 shows no provider offers a delegated sign-in.
4. **Off by default.** A provider's rows are offered only while its switch is exactly `'on'` (`AI_PROVIDER_ANTHROPIC`). Unset, `'true'` or `'ON'` is off: no hold, no call, no row. No task in `aiRouter`'s `ROUTE` names a provider, so nothing reaches an adapter except a caller of `runProviderModel`, and there is none yet.
5. **Prices.** A provider prices in USD, not Cloudflare neurons.
   - Its models are a separate list, `PROVIDER_MODELS` in `ai/catalogue.ts`, each with its rates as printed, the page and the date. `CATALOGUE` and its fixture are unchanged.
   - `PROVIDER_PRICING_VERSION` (`p1-2026-10-21`) names the price list a settlement used.

### 3. What was built

- **`ai/catalogue.ts`:** `PROVIDER_MODELS`, with one row, `anthropic/claude-sonnet-5-5` at $2 / $2.50 / $0.10 / $10 per 1M (input, 5-minute cache write, cache hit, output). Also `PROVIDER_SWITCH`, `PROVIDER_PRICING_VERSION`, `providerModelById` and `providerOffered`.
- **`ai/providers/`:**
  - `types.ts`, the adapter shape;
  - `anthropic.ts`, the Messages API: `x-api-key`, `anthropic-version: 2023-06-01`, the text blocks as the answer, usage read from §1.1.3, errors from §1.1.4 and §1.1.5;
  - `index.ts`, `ADAPTERS`.
- **`ai/pricing.ts`:** `usdRatesBilledMicro(rates, counts, multiplier)`, the same exact decimals as `costMicro` and rounded up once per run. A counted unit with no rate is refused, never free.
- **`aiProviders.ts`:** `runProviderModel(env, opts, { fetch })`.
  - **Hold.** `reserveAiBudget` for the quote (`providerQuoteMicro`): the input at the dearest input rate, at 3 characters a token, and every output token `maxTokens` allows, at the member's multiplier.
  - **Reported usage.** It settles at `usdRatesBilledMicro(rates, usage, memberChargeMultiplier)`.
    - Anthropic's `input_tokens` excludes cached input, so cache writes and cache reads are each billed at their own rate, never subtracted.
    - Usage above the hold goes to a Super Admin's review, as `run()` does (D640). Until then the row's `charged_microusd` is NULL.
  - **No readable usage** (no `input_tokens` or `output_tokens`, or not whole non-negative numbers). It settles at the quote, the policy, and `units_json` says `{ usage_reported: false, pricing_version }`. The token columns read 0 only because they cannot be NULL; `units_json` is the record.
  - **A failure** releases the hold (`refunded`) and charges nothing. The row's `units_json.error` is one of `auth`, `invalid`, `billing`, `rate_limited`, `spend_limit`, `overloaded` or `server`. A 429 carrying `enforced_spend_limit_reached` is the platform account's spend cap, not a rate limit. A missing `retry-after` is unknown, never 0.
  - **The row** is written through `aiRouter`'s own `recordUsage` (now exported), with `units_json = { provider, pricing_version, usage_reported, …counts }`. Readers already skip non-numeric and `tokens*` keys (`aiCost.otherUnits`).

### 4. Verification

`test/ai_provider_adapter_d851.test.ts`: real SQLite with the AI budget migrations, and a stubbed `fetch` (no live call, no real key). 14 cases:
- **Inventory.** The row's rates, page and date; not in `CATALOGUE`; no `ROUTE` entry names a provider.
- **Off.** Unset, `''`, `'true'`, `'ON'`, `'off'` and `'1'` make no call, no hold and no row. An unknown model is `model_not_offered`.
- **No key.** `misconfigured`, with no call and no hold.
- **The page's switch.** Off refuses before the hold.
- **The request.** URL, headers and body. The key appears only in `x-api-key`: not in the body, a log line or the row. The prompt is not in the row.
- **Settlement from usage.**
  - 1,000 in, 200 cache write, 300 cache read and 500 out settle at 7,530 micro-USD, and the hold is `settled` at that amount.
  - The row has the units, the reservation and 1,500 prompt tokens.
  - With `AI_BILLING = "charged"` a member pays 9,413 (× 1.25, rounded up once); the admin licence pays 7,530.
- **Missing usage.** Six shapes of unreadable usage settle at the quote, with `usage_reported: false` and the version.
- **Rounding.** One token of each kind is 14.6 micro-USD, so 15, never 16. An unpriced unit throws.
- **The quote.** 20,035 micro-USD for the test request, at the cache-write rate.
- **Over the hold.** `review`, with `recorded_cost_microusd` 68,000 and the row's charge NULL.
- **Failures.** 429 (with `retry-after: 7`), the 429 spend cap, 529, 401, 402, 400, 500, a 200 with no content, and a network error: each `refunded`, charged 0, with its kind.
- **No allowance.** Refused before any call.
- **Reading.** Text blocks only, in order; an unreadable `retry-after` is null.

**Mutation checks: 19, all caught.**
- **Switches:** a truthy switch; the switch ignored; the page switch ignored; a call with no key.
- **Rates:** the cache write at the input rate; cache reads at the input rate; cached tokens subtracted from the input; the multiplier ignored.
- **Missing usage:** read as zero; settled at 0.
- **Settlement:** a failure settled at the quote; an over-hold recorded at the quote; the quote at the input rate only.
- **Errors:** the spend cap read as a rate limit; an absent `retry-after` read as 0.
- **Secrets:** the key written to the row; the key logged.
- **Reading:** non-text blocks kept as text.
- **Rounding:** per unit instead of once.

Rounding per unit survived at first, because 7,530 is a whole number; the one-token case now catches it.

Providers stay stubbed; production data is never read.
