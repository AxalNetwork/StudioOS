## D890 — Missing data is unscored

Issue #2448; allocated by S1. A recorded zero remains a value; an absent input or failed read does not become zero, perfect compliance, or an invented allocation.

Incomplete intake uses the official scoring rubric's required-input validation before any insert. Partial sandbox scoring returns no total, tier or snapshot and lists the missing inputs. Complete inputs retain explicit zeros rather than replacing them with defaults. The practice form omits cleared or invalid controls, and optional intake numbers normalize blank text to null while refusing nonnumeric values.

Venture-risk layers with no recorded signals return null scores and reasons. The overall averages numeric scored layers only and reports its coverage. A band-only analyst override remains visible but does not invent a numeric score. Empty due-diligence sections contribute no weight; an entirely unscored case has no score or band, including reports and the case view. Unseeded trust-batch members return null with a reason; seeded pending obligations still score zero and satisfied obligations score 100. A failed desktop Trust Center read is Unreadable. A decision gate without traction metrics supplies no recommendation.

Narrative readiness uses D906's actual comparison count. With nothing compared it keeps “Not enough recorded”, carries no score or evidence classification and uses the grey unscored tone. Scored rows still require evidence. Null readiness values are omitted from averages and stay unscored in records/history. S21 assigned migration 558 for nullable score and evidence storage after D891's migration 536 merged. It preserves every row, index, constraint and the AUTOINCREMENT high-water mark; applied migration 536 remains immutable.

Five deck templates render “Use of funds not recorded” instead of a sample allocation unless an allocation was supplied. D895 (#2689) already removed the invented reviewer score and fallback runway line; those changes are retained.

No historical rubric scores are retroactively recomputed. No production data write is part of this task. The owner reviews and merges the PR, then verifies deployment.
