### What the audit found

- The four cards read alike (Course, Draft, a title, Intro, 75–85 min): `CatalogList` draws only the kind and draft pills, a title clamped to two lines and "level · minutes", with the whole card as one link.
- The audience, practical output and prior learning were only on the outline: `GET /catalog` does not select course meta, which only `GET /courses/:slug` sends (`learningCourseMeta.ts`), where `courseAbout()` already words it.
- No card showed art: the route sends `cover_url` but `catalogRow()` drops it, and courses have no `cover_alt`.
- Nothing said who could see a draft or a program course: `/catalog` selects `visibility` and `enrolled` but does not return them. Super Admins see drafts, others see program courses only when enrolled, and main has no course seeds; all four founder courses were drafts.

### What the canvas decides

- Every card leads with the task and what the learner produces (the pitch card: a decision memo and claim register), then effort and level, then audience; rows line up across cards through CSS subgrid, titles are not clamped and each card has one link (LCC00, LCC03, LCC04).
- Variants: preview, available, in progress (Resume names the next lesson), completed, program for an enrolled member, program-only for a Super Admin, and progress Unavailable. Each states who sees it, what the action does and where its value comes from (LCC05).
- Drafts tell a Super Admin that only Super Admins see them; Preview draft opens the course page and Edit in Studio stays secondary (LCC02, LCC12B).
- Courses get Level and Length filters next to search. A suggested order, when shown, is labelled Recommendation (LCC03).
- Cover art (LE8) where there is one; otherwise a typographic fallback of initials on a tint chosen from a hash of the slug, which also replaces a cover that fails to load (LCC06).
- Missing metadata: the summary stands in for a missing output, and missing fields are named once as Not recorded (LCC07). A long title, 200% zoom (one column) and a 31-course catalogue are drawn (LCC08, LCC08B, LCC09).
- States: loading, the empty catalogue members see today, no match with Clear search, Unavailable with Retry, progress unavailable and offline (Stale) (LCC10); focus order and names on LCC11; the phone route LCC12A to LCC12F; dark on LCC13; handoff on LCC14.
