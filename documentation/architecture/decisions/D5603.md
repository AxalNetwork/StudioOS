Queue stalled minutes are the union of observed queue-entry intervals inside the window minus the time when any observed queue CI job is running. Overlapping entries count once. If a listed queue CI run has no job sample, stalled time is unavailable. Peak jobs and runner minutes are observed from the sample and may understate totals. Queue runs are attributed to the PR named in the temporary ref, and queue-to-merge uses the last entry before merge. PR feedback measures completed CI run creation to last update. Failure inheritance uses the last observed comparable completed main run, following the existing job-name classifier. The prior attempt is sampled only when GitHub reports a rerun.
