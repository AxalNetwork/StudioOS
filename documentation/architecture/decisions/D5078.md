### 1. The problem

The 8 November audit of `/build/operating-systems?project_id=12` found three product concepts on one undifferentiated page (core systems, AI operating rituals, connector history), a no-company state that read as five failures (a prerequisite notice plus five Not connected rows of Not recorded facts), Reconnect offered on every tool row whatever its state (every tool's action was Open), sync history from GitHub only, and no list of the Build-feeding tools a venture had not connected.

The record page's own actions (D5065) are unchanged.
- **The overview read gains no statement.** `parts.systems`, the not-connected list, the failure words (one statement, only when something is failing) and the sync lines are read on the module page only (`opts.parts`); the overview's budget (`build_read_amplification_4603`) holds and its card is unchanged.

### 3. Departures from the canvas

- **"Tools ↗"** is a section of this page, not a link out: Build › Tools' address already is `/build/operating-systems#tools` (D6029), so the section is that page and there is one list of tools.
- **"Link company"** (BD20 A, BD24 B) is not drawn: moving a venture into an existing company is the venture lifecycle's move (D1415, `routes/project_lifecycle.ts`), not a Build action, and a second door to it is not this issue's. The one action is Go to Company Creation, the issue's own words; BD20 A's "Form the company first" link is that action.
- **Cadence's "This week" list** (Monday plan due today, weekly review Thursday, …) draws each active ritual with its schedule and its last filed run, because the cadence store records rituals and runs, not a due state per week. "Metric annotations · 2 this week" is not drawn: annotations are drafts with no store (`build/kpi`'s footnote).
- **The separate cadence screen is not redirected.** `/build/cadence` is the workflow where rituals and reviews are filed; Cadence is its one entry and summary, so nothing duplicates it and nothing it does is lost.
- **Eadwyn's asks** for Systems and Cadence stay in the module's one rail, both sets (D5077); a section does not change the rail.
- **Coming soon tools** (Google Workspace, Figma today) are listed as Coming soon with "Not available to connect yet." and no action, because the connect route refuses them; the issue's list names Google among the tools to show.
- **The records table** (System, Provider, State, Last sync, Used by) and its per-row Choose connector are no longer drawn on the module page; Choose connector, Used by, Feeds and Sync stay on each system's record page, where every Systems row leads. Export (D6043) has no button here now.
- **Dates** read "9 Oct" on system lines; tool rows keep the stored timestamps they showed before.
