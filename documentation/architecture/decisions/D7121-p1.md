- **Status:** built 2026-11-19 on `main` at `602e6e1b0`. Part of #7121: the page, its two panel states, its og entry and its tests. The five-slide PDF, its edition date, the `/programs` index card and the admin detail's View presentation wait (below).
- **Canvas:** `design/incoming/Program Wellness Presentation Page.dc.html`, boards PGW01 (1440), PGW02A and PGW02B (the panel's two states) and PGW03 (390), landed under D7121.

### What this part builds

- `/programs/wellness`, signed out, in a new route module `frontend/src/routes/programsWellness.jsx`. The path is literal, so the kit's `/programs/:key` (#6966) cannot shadow it. `isPublicPath` lists it, so a background 401 never bounces a visitor to `/login`.
- `frontend/src/pages/wellbeing/WellnessPresentationPage.jsx` renders the page in the public site's frame (`SitePage`). `wellnessPresentation.js` holds the map entry (key, page, PDF path, availability, edition, `pdfPublished`) and every word on the page, taken from the canvas. `wellnessPresentation.css` holds the kit's `pgs-*` and the Wellness `pgw-*` styles, scoped under `.pgw-page`.
- The page reads nothing live and imports no API module. It names no expert, member, session or journal entry. It links the private workspace only as `/login?next=/wellbeing`.
- `ogRegistry.js` gains `/programs/wellness` (title "Wellness · Programs", the purpose sentence as description, section card `content`). `/wellbeing` has no entry.
- `frontend/test/wellness_presentation_d7121.test.mjs` pins the deck href, the content type, the absence of private content, the public literal route and both panel states.

### Owner-pending items, held at their most conservative value

Each item is one field in `wellnessPresentation.js`.

- **Availability:** `proposed`, which draws PGW02B ("Proposed · not open"). This is the registry's own wording: migration `202611171541_7116_wellness_program.sql` writes status proposed and member access not_open. PGW02A ("Eligible members · signed in") is built and tested, and the answer selects it with `availability: 'elig'`.
- **Edition date and the PDF:** `edition: null`, `pdfPublished: false`. No PDF is committed and the page links none. Both Download PDF controls render as disabled, with the line "Not published yet". A link to a file absent from `frontend/public/` would get the SPA fallback (200, HTML) instead of a PDF (D6966 § Backend required). The test fails if `pdfPublished` disagrees with the file on disk, or if a committed file does not start `%PDF-`.
- **Roster:** no expert is named, as drawn.
- **Other roles:** the copy names founders and Administrators only, as drawn.
