## D5883 — Separate the Admin Approvals view models (#5883)

The Inbox, Lanes, Decided, assignment and weekly analytics now have individual pure JavaScript modules in `frontend/src/pages/admin/approvals/`. The item drawer and the three native boards have their own model modules. Shared formatting lives in `approvalsFormat.js`.

The existing pages, boards and tests import through `inboxModel.js` and `approvalsModel.js`. Those modules retain the public names. The folder README maps each implementation to its file.
