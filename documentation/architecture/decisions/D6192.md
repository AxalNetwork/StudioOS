## D6192 — Deal notes: every note reachable, who wrote it and when it was edited, filtered by tag (#6192)

DL14's Notes list in `frontend/src/pages/deal/DealNotes.jsx` read the first 25 notes and stopped. Its header showed the total, but nothing reached the older notes. Each note also said only "You" or "Your firm".

### The Worker

`GET /api/deals/:id/notes` in `routes/deal_context.ts` (D1150) gains two things. Its scope, guard and page limits are unchanged.

- **`?tag=`** narrows both the rows and `total` to one tag, matched exactly as saved. The response echoes the tag (`tag`, or null). A tag longer than 80 characters, the write limit, answers `400 invalid_tag`. So a filtered count is the Worker's, never a count of the rows a page happens to hold.
- **`author_name`** on each item: the author's account name (`users.name`), or null when the account has none.

**Privacy (D1150).** A firm note is read only by members of the same firm, and a note with no firm only by its author. Naming the author shows a member of the same firm a colleague's name. It adds no reader and no row. A foreign firm's note is still outside the scope, so its author is never named.

### The page

- **Show more** reads the next 25 from the loaded count (`offset`) until the loaded rows reach the total. It shows "Show more (25 of 60)".
- **A failed page** says "The older notes could not be read", with Retry, beside the notes already shown, and keeps them. The first page failing is still the card's Unreadable state.
- **Tag chips** (All, Thesis, Risk, Question, Decision, the tags a note is saved with) re-read the first page with `?tag=`. The count reads "30 tagged Risk". An empty filter says "No note is tagged Decision.", not the first-note prompt. A stale answer from an earlier chip or load is dropped.
- **The byline** reads date · author · tag · edited:
  - the author is You, the colleague's name, or "Your firm" when the account has no name;
  - "edited <date>" appears only when `updated_at` is later than `created_at`.

  `dealNotesModel.js` holds the byline and the paging test (`noteAuthor`, `noteEdited`, `noteByline`, `notesHaveMore`).
