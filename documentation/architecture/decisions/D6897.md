## D6897 — Raise: the readiness snapshot shared outside Axal as a dated link (#6897)

- **Status:** part 1 built 2026-11-16 (`Part of #6897`): the readiness snapshot link (RA-30). The A4 PDFs are part 2 (`D6897-p2.md`); Eadwyn's draft covering line and the Raise status page (RA-31, which waits on #6045's stage) follow.
- **Builds on:** D6054 (the canvas, RA-30), D6864 (the evidence pack link store and its public page), D6049 (Fundraising readiness owns its page), D1610 (the four evidence values).

### What is built

**The snapshot.** `readinessBody(env, projectId)` in `services/raiseEvidenceShare.ts` reads the readiness items and their newest scores (`loadReadiness`, `latestScores` in `raiseCycle.ts`, so the filters the readiness page applies apply here) and returns seven areas, in the page's order:

- Investor narrative, Pitch deck, Data room, Cap table, Use of funds, Traction proof: the score out of 10, the evidence (Measured, Stated, Pattern, Anecdote), what is missing and the day scored.
- An area with no score reads **Not scored yet**, never 0. A recorded 0 reads 0 of 10.
- **Team** reads "Team is assessed by a person": its score and note are never shared.
- There is **no overall score** and **no Product-market fit row**.

**The link.** `POST /api/cycles/raise/readiness/share-links` (founders only, `createReadinessLink`) takes `label`, `expires_in_days` (1–90, default 14), `view_limit` (1–100, default 10) and an optional `covering_line`: one sentence on one line, at most 200 characters, spaces collapsed. It stores the frozen snapshot in `raise_evidence_share_links` with `output = 'readiness'` and `reader = 'before_nda'`, the token's SHA-256 only, and logs `readiness_snapshot_shared`. Nothing is sent: the founder copies the address.

**The reader's page.** `GET /api/share/readiness/:token` (`routes/readiness_share_public.ts`) and `/share/readiness/:token` (`pages/share/ReadinessSnapshotPage.jsx`): no sign-in, dated, says it does not update, the covering line above the table. Each open consumes one view (`openPackLink(env, token, 'readiness')`). Expired, used-up, revoked and unknown links refuse with the evidence pack's pages, which name no venture. It shares the evidence pack's per-IP bucket (`EVIDENCE_SHARE_READ`).

**Founder's screens.** "Share outside Axal" on Fundraising readiness (`pages/cycles/evidence/ShareReadiness.jsx`, shown to founders) opens the composer, which says what the reader sees. The link is listed and revoked on Raise › Evidence › Shared links with the packs: the row reads "Readiness snapshot", and "Changed since sent" (the snapshot's hash against the live one) offers "Make a new snapshot" on the readiness page.

### Choices made here

- **One link store, not two.** `raise_evidence_share_links` already allows `output = 'readiness'` (D6864's migration), so no migration is needed. `openPackLink` filters on `output` in both its UPDATE and its SELECT, so a pack token never opens the snapshot page and a snapshot token never opens the pack page.
- **A snapshot is always "before an NDA".** It carries scores and short notes, not figures, files or quotes; the store's reader CHECK is met without an NDA.
- **The covering line is the founder's.** Eadwyn's draft of it follows with the pack proposal.
