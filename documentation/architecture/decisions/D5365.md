## D5365 — Portfolio audit defects (#5365)

Date: 2026-11-10  
Issue: #5365

## Decision

Portfolio reads keep failure, empty, and zero as separate states. A failed
primary positions read replaces the book with a retryable generic error. A
failed optional source labels only its dependent figures `Unavailable`.
Worker error details are never rendered to the investor.

KPI values use the stored KPI unit when one is available, with conservative
key-based fallbacks for legacy rules. Alert dates use a UTC member-facing date,
a middle-dot separator, and the recorded age. Internal issue, decision, canvas,
and roadmap language is not investor-facing; the UI explains the product
boundary in member language instead.

## Verification boundary

Mounted regressions cover primary and optional read failures and the KPI
display. Pure contracts cover KPI units, alert-date formatting, and the
absence of internal identifiers from investor-visible source.
