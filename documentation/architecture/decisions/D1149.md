## D1149 — One deal-access rule, missing values, currency and the Free-plan header

Issue #3054, part of #2421. Slot S19. Migration 599.

- `services/dealAccess.ts` owns the investor predicate: an invitation or a
  commitment on the deal, never a joined room. Both the deal reader and DD case
  opener call it. Staff/founder role gates retain their existing scope. DD stays
  Professional for investors through the index's investor gate.
- The legacy join endpoint and its existing room row now record an invitation
  request only. Its reply, actor audit and button name say so. Existing quota,
  company scope and leave behavior are retained; no request grants deal or DD
  access. Pending requests appear in the staff Invitations read, replaced by
  the actual invitation when issued. No new invitation is issued by requesting,
  and no new request store is invented.
- Missing target/committed input or timestamps produce null progress/age, while
  recorded zero remains zero. The deal page and pipeline age cell say Not
  recorded. No percent is printed as zero when it is unknown.
- Migration `599_deal_currency.sql` adds a non-null three-letter currency with
  default USD, preserving historical denomination. New deal/draft inputs accept
  a validated currency code. Existing deals refuse denomination changes so
  historical commitments and transfers cannot be silently relabelled. Deal amounts, commitment dialogs/totals, transfer
  and syndicate displays, and activity amounts use the deal denomination.
  This is a denomination, never an FX conversion; bank figures keep their own
  recorded currencies. Cross-deal currency aggregation is outside this page task.
- A founder's back link goes to `/raise/capital-relationships`.
- Only numeric `GET /api/deals/:id` joins the existing leave exemption from the
  Professional gate. Authorization still runs. Free replies use a fixed field
  allowlist for the header/key strip, excluding private deal details and notes.
  A failed own-commitment read is Unreadable with retry, leaving the header.
  The Free component returns before tabs, quota, invitations or other detail
  readers mount; all those endpoints remain gated.

The approved DL22b source is the owner's D1148 integration commit `564285bf23`
(`#2421`), whose two canvases were read from its published branch. That integration
was not on main when this task began. This PR keeps the existing main page and
adds a reusable `DealFreePlan` header/key-strip and plan card; it does not import
unrelated, unmerged S21 work. D1148 and the later shell task can reuse it.

Verification uses real routers with node:sqlite, mounted React tests, and
counterfactual mutations. No production content or provider was accessed.
