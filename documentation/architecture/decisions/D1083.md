### 1. The link

`lovable_app_links` holds one row per record. A record has at most one link (`UNIQUE(record_table, record_id)`).

| Cycle | `module` | `record_table` | `record_id` |
|---|---|---|---|
| `validate` | `experiments` | `hypothesis_experiments` | the experiment's id |
| `build` | `prototype-mvp` | `projects` | the project's id |

- **`app_url`:** https only, a public host (`isSafePublicUrl`), no user name or password, no fragment, at most 2,048 characters.
- **`lovable_project_id`:** NULL. Part 6 reads it from the founder's key.
- **`last_status`:** `live` or `not_reachable`. NULL until the first Check now, which reads "Not checked".
- **`last_title`:** the page's `<title>` as plain text. Tags and angle brackets are removed and it is capped at 120 characters.
- **`checked_at`:** when Check now last ran.
- **Grep first:** no `lovable_app_links` table and no `lovable_project_id` column existed before. It is a new table, so nothing is backfilled.

### 2. Routes (`routes/lovable_app_links.ts`, mounted at `/api/cycles` before Build's router)

| Route | What |
|---|---|
| `PUT /api/cycles/:cycle/lovable/app-link?project=` `{ record_id?, app_url }` | Links or replaces the address. Validate's `record_id` must be an experiment of this venture (404 otherwise). A new address forgets the old address's check; the same address keeps it. |
| `DELETE /api/cycles/:cycle/lovable/app-link?project=&record_id=` | Removes it (404 when none). |
| `POST /api/cycles/:cycle/lovable/app-link/:uid/check?project=` | Check now: one `fetchPage`. A 2xx or 3xx answer is `live`, with its title. Anything else, including an error or a timeout, is `not_reachable` with no title. Both write `checked_at`. Our own per-user limit (429) records nothing. |

- **`:cycle`:** `validate` or `build` only; any other answers 404 "No such cycle".
- **Who may write:** every route is a write, gated by `canWrite` (the venture's own, or an admin's). Another member gets 403. A support session (`impersonated_by`) gets 403 `support_session_refused`.
- **Never a fetch outside Check now:** linking never fetches, and there is no cron.
- **`fetchPage(…, { noCache: true })`** is a new option. It neither reads nor writes Competitors' `competitor_cached_fetches`, and it asks the edge for a fresh copy. A live check must answer for now, and the founder's own page text belongs to no competitor.
- **Logged without the address:** activity rows are `lovable_app_linked`, `lovable_app_unlinked` and `lovable_app_checked`, on `build.prototype-mvp` or on the experiment's claim (`validate.experiments`). Their summaries hold no address, title or page text.
- **Refusals** carry fixed sentences and never echo the address.

### 3. The part (`services/lovableAppLinks.ts`)

- **Shape:** `parts.lovable` is `{ state: 'ok', slots: [{ record_id, label, link }] }` or `{ state: 'unreadable' }`, never an empty list on a failed read.
- **`link`:** `{ uid, app_url, host, status: 'live' | 'not_reachable' | 'not_checked', title, checked_at, hosted_on }`.
- **Where it rides:**
  - on the experiment record (`services/records/validate.ts`), one slot per experiment of the claim (`RecordContent.parts`);
  - on Prototype / MVP's module read (`routes/cycle_build.ts`), one slot.
- **One Live line per host (`services/liveHost.ts`):** `liveLineOwner(appHost, vercelProductionDomains)` matches exact hosts only.
  - Hosts are lower-cased, with no port, path or trailing dot. `app.example` and `www.app.example` differ, and a name is never matched.
  - On a match the link's `hosted_on` is `vercel`: From Lovable reads "Hosted on Vercel" and draws no Live pill or Check now of its own.
  - `vercelProductionDomains()` returns `[]` until Vercel part 3 (D1098, #2963) fills it. Whichever of #2948 and #2963 lands second adds the shared test (D1311 §2).

### 4. The page (`FromLovable.jsx`, `lovableAppLink.js`)

- **The part:** "From Lovable", with "Connector · Lovable". Each slot shows the address in mono, a pill (Live, Not reachable, Not checked or Hosted on Vercel), "checked 2026-10-23 14:05" in mono (UTC), and Check now.
- **LV6's states:**
  - **Empty:** "No app linked yet. Paste the address Lovable gave you.", with the "https://….lovable.app" input and "Link the app".
  - **Loading:** "Reading…" while Check now runs.
  - **Not reachable (amber):** "Not reachable, checked 2026-10-23 14:05.", then "The app may be Invite only in Lovable.", and Check now.
  - **Unreadable:** "Lovable's figures could not be read. The address and its last check are kept.", with Try again.
- **No claim without its time:** a status with no time reads "Not checked", never Live or Not reachable.
- **Asking first:** linking and removing ask in place and say what changes, for example "Nothing is read until you press Check now." or "Nothing changes in Lovable." A refusal stays in place with its words. Check now is a direct press.
- **Mounts:**
  - **Validate › Hypotheses › a claim:** `CycleRoute.jsx`'s Validate `recordPage.experiments` draws the record, then From Lovable, one slot per experiment, each labelled.
