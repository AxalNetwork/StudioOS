## D6319 — Keep PostHog cohort intervals and recent rows (#6319)

Grow stores the retention insight's interval with its cohorts. When the
query response omits the period, the sync reads the saved insight definition.
The newest twelve valid dates are kept and shown chronologically. Older
records with only a cohort date use numbered periods with the interval marked
missing. The venture-scoped PostHog module read includes cohort facts alongside
the existing tracked-metric summaries.

[PostHog documents the period labels and cohort intervals](https://posthog.com/docs/product-analytics/retention).
