## D5677 — Attach a section hint to client error diagnostics (#5677)

The existing anonymous browser error beacon now includes the rendered shell, a bounded list of held licence types and whether a sidebar link opened the two ambiguous destinations. The Worker maps that context and the current path to a fixed profile and section in the existing structured log. A shared account or Trust link has a shared destination unless the corresponding sidebar supplied its origin. Company and project identifiers never enter the section hint. Unknown paths and missing role context may yield null.

The browser supplies this evidence. It cannot authorize a Slack delivery, open a public issue or start a repair. Those decisions require trusted incident evidence and visibility rules in #5678. The existing log payload, rate limits and anonymous 204 response continue to work with old clients. This change adds no schema, external calls or Slack credentials.
