## D8639 — Pin the mounted HQ pricing catalogue to its fixture date (#8639)

The catalogue renders source freshness using the current date. The fixture expects the 2 September 2025 source to be 14 completed months old on 15 November 2026. On 2 December it reaches 15 months, which reproduced the scheduled failure with libfaketime at +7 days.

The mounted catalogue test now uses its existing `TODAY` for the Node test context’s `Date` mock. The context restores the clock after the test, and the renderer’s asynchronous timers continue to run normally. The other mounted cases check stored dates, queue-provided values, or a stale source from 2020 without asserting its exact age. Only the catalogue case needs a clock pin.
