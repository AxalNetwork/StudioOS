## D4467 — Retry transient artifact listing failures (#4467)

Artifact page reads get up to three retries with 1, 2 and 4 second backoff
for HTTP 5xx, 429, rate-limited 403, network errors and timeouts. Other
statuses, including 401 and 404, fail immediately. Only the failed page is
retried; previous records and the existing completeness checks are retained.
Other GitHub reads receive no retry policy from this change.

An exhausted read remains an unreadable ledger. With a monthly budget set,
no account may spend against it. Warnings name the page and a safe HTTP status,
timeout or network cause; response bodies and raw exception text are excluded.
Main's skip reason reports the actual budget refusal rather than calling an
unreadable ledger exhausted credit.

Tests cover recovery on page two, bounded retry classes and backoff, immediate
401/404 refusal, safe causes, and refusal across the fallback chain. No owner
settings or budget values change.
