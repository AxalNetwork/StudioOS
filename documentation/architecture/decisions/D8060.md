### What was applied

The ruleset `main: required checks` (active, branch target, the default
branch) was kept and changed in three settings, with the owner's go
("A — apply the prepared main-ruleset change first", 2026-11-21):

| Setting | Before | After |
| --- | --- | --- |
| Bypass actors | Repository admin, always | none (the API returns `[]`) |
| Maximum merge group | 30 | 5 |
| Wait to meet the minimum group | 0 minutes | 5 minutes |

Kept as they were: pull request and merge queue required, force pushes and
deletion blocked, squash merges through the queue, build concurrency 5,
minimum group 1, `ALLGREEN`, a 90-minute status-check timeout, strict status
checks off, check-free branch creation allowed, approval count 0 with code
owner review and stale-review dismissal off, auto-merge and "always suggest
updating branches" on. A single non-forced, same-tree update of `main` by an
administrator was refused by GitHub ("Changes must be made through a pull
request … through the merge queue"), and `main` did not move.

The disabled `Code Quality Copilot review for default branch` ruleset stays
disabled. No `platform paths` ruleset exists.

### How the baseline mirrors it

- The keys use the live name, `ruleset[main: required checks]`, because the
  check keys a ruleset by its live name and the STATUS asks that the live rule
  is not renamed to fit the placeholder `main`.
- `rulesets.names` lists both rulesets, the disabled one included, and the
  disabled one's `enforcement` is a row, so its being turned on shows as drift.
- The required checks row is left to #8641. The STATUS recorded six contexts;
  `Dependency Review` became the seventh on 2026-11-23 (#7899), so the six are
  out of date. #8641 fills the row, under the live name.
- Build concurrency, minimum group, the wait and the timeout are not rows: the
  check does not read them yet, and a row it cannot read fails the whole run.
  The same holds for each required check's source binding (GitHub Actions).
  Adding them to the reader is a later change to
  `scripts/ops/check-github-admin.mjs`, with its rows.
