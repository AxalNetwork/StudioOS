### Worker

- **Step times, in `output_json`, with no migration (RS-13 B3).** `runCompetitorAnalysis` writes `output.run_steps`: `search` (stamped as the run starts), `discovery` (with the `companies` it returned), `read` (the reads `tried`, failed ones included, and `fetched`) and `synthesis`; `POST /analyze` adds `saved` as it stores the result. Each `at` is ISO. A save of the person's text keeps them (the page's save lays its fields over the stored output); a rerun's proposal carries the new run's steps but does not apply them, because `run_steps` is not a field a rerun may rewrite, like `findings` (PR #7202's merge comment): the steps on record are those of the run that wrote the findings. A run before this change has none, and the page says so.
- **The run's start (RS-13 A5) needs nothing new.** `competitor_analyses` is inserted with status `running` as the run starts, and only a new run is ever `running` (a rerun is a proposal and never sets it), so `created_at` is the start of a running analysis. The setup panel prints the time this browser pressed Run, since its row is not read until the run returns.

### Frontend

- **A2, tokens.** Known competitors is a token field: Enter or a comma ends a name, each name once (case ignored), each token has Remove (`Remove <name>`), and Backspace on an empty field takes the last. The subject's name, uid or site is never added: entered with Enter it stays in the field with "…: the subject cannot be its own competitor. Remove it to run." and Run waits; split off by a comma it is dropped and the field says "… not added". A subject that arrives in the list (a `known` link, Fill empty fields) is drawn as a refused token, "· the subject", and Run waits for its Remove. A name still being typed runs with the tokens. The payload is unchanged: `known_competitors` is the names joined by ", ".
- **A4, the switch.** On setup, "Run for" is a radiogroup, A directory company / A custom market (arrow keys move it). A custom market, from a subject, drops `company`, `name` and `website` from the link, keeps every typed field and moves focus to Market; from Saved analyses it says "Started from Saved analyses · no company is the subject". A directory company with none chosen says so, links to the Directory, and holds Run; the subject arrives through a profile's Run competitor analysis, as part 1 built.
- **A5, start time.** The subject bar while running reads "Running · started HH:MM · nothing is listed until the run returns" on setup and on a running analysis's page, whose running card also gives the date.
- **B1, the table.** The competitor table has the canvas's columns: Company (name, site or "Website: Not recorded", origin in #7176's words), Classification (the select, "unconfirmed · no source read"), Why · support (the run's reason and "Read from N of M sources", or Not attempted · no website), Sources (chips, "none attempted"), Relevance (right-aligned; a blank is Not recorded). Remove stays as the row's last cell, with a screen-reader header. The inputs row adds Region (`region_focus`), Not recorded when not given.
- **B3, step times.** "What the run did" (Insufficient evidence) prints each line's time from `run_steps`, and the counts discovery and the reads recorded; a run with none reads "Not recorded · step times: this run is older than the record of them".
- **B4, loading.** The page draws the title-card shape and the four tiles with their labels and skeleton values, never 0, under "Loading this analysis." (`aria-busy`).
- **B5, the preview.** `ExportPreview.jsx` is a dialog headed "Export preview" with Markdown and JSON tabs. Each tab reads the saved version's export (`loadExport` in `CompetitorAnalysis.jsx`, checked as a download is: a status that is not 2xx, or another content type, is drawn in the tab with Retry, and Download stays off). On the page it is "Preview the file" in the Export menu and the phone Actions sheet (it replaces part 1's Markdown-only preview card); #7176's direct downloads stay. In the in-place panel (`/build/competitors` and the startup page), JSON and Markdown now open the preview on their tab and download through it, so the panel's JSON is the Worker's export of the saved version, no longer its own copy; with unsaved edits the preview says they are not in the file.
- **C2, the phone bar.** Not built again: #7176's bottom bar (Save, Actions ⋯) and its Actions sheet (Refresh sources, Rerun discovery, Export Markdown, Export JSON, Preview the file) already put Export and Re-run at the bottom of the phone. A second sticky bar would stack two.
- **C4, focus.** A run started on setup in the Research zone navigates with `focusResults`, and the page focuses the shell's h1 (D593: one per page) once it has read the analysis; a run in the in-place panel focuses its new "Results" heading. Escape, Close and Cancel on the preview return focus to the control that opened it (Export ▾, Actions ⋯, or the panel's button), and its heading takes focus as it opens.
- **Dark.** Every new surface has its `dark:` pair.
