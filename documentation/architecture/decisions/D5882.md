### Moves only: how it was checked

The new files were cut from the old one by line range with a script. The check:
- take the old file without its import block;
- take the seven new files without their new header comments, their import lines, the six re-export lines and the `export` keyword added to a declaration that moved;
- compare the two as multisets of lines.

They are equal. Each new file starts with a header comment. The only other changes:
- the `export` keyword on what another file now imports;
- the import lines each file needs. `eslint` and `check-unused-imports` hold those to exactly what is used.
