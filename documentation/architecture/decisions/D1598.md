## D1598 — Failed advisor count reads return an error instead of an empty shelf

Issue #3871. S1 approved the two existing-handler edits alongside #3870 and
assigned D1598 in comment 6546630486. No migration or new API shape.

Remove the catch-to-empty fallbacks from two reads in `routes/advisors.ts`:

- `/me/thinking`: the `articles` read supplies published/draft counts and
  published reach. A failed read cannot establish that the shelf is empty.
- `/me/cohort/:cycleId/calendar`: the `week_windows` read feeds
  `next_14_days`, `cohort_obligations` and `collisions`. Dropping its rows
  after a failure understates the advisor's obligations and possible clashes.

Both failures reach the existing `mapError` path, matching the other advisor
own-record reads. A D1 failure returns HTTP 500 `storage_error` and the
existing authored sentence; raw database diagnostics stay out of the body.
Successful empty and populated reads retain their payloads and real counts.
An actually unrecorded calendar window list still has `windows_recorded:
false`; a failed read no longer makes that claim.

The existing client request wrapper rejects failed responses. ThinkingZone
clears its payload and supplies the error to ZoneBody, which hides metrics
and offers Try again. Calendar already handles a request error separately
from missing week windows. No frontend product edit or new layout is needed.

The audit found no other catch-to-empty `.all()` failures in advisor `/me`
count reads. The no-profile calendar branch is an intentional absence rather
than a failed read and stays unchanged. Authentication, role/assignment
gates, owner-bound queries and all writes stay unchanged. #3870's Visibility
addition and its client are outside these two edits.

Synthetic authenticated SQLite/D1 tests cover prepare/all failures for both
reads, genuine empty/populated writing, own-author scope and missing/recorded
week windows. Mounted tests use the real ThinkingZone and ZoneBody logic for
unreadable, retry and empty states. Behavioral mutations restore each removed
fallback and suppress the shelf's error; each makes its regression fail.
Every new assertion is also inverted individually with restored controls.
