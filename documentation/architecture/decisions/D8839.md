## D8839 — Escape closes the public mobile menu and returns focus (#8839)

Part of #7005. The mobile menu now mirrors the public Network menu's document
Escape listener: it is attached only while open and removed on close/unmount.
Escape closes the mobile links and focuses the existing burger through a ref.
The click toggle and pathname effect keep their existing behaviour. No copy,
layout, links or header/footer design changes.

The mounted React regression uses the shared focus-enabled synthetic DOM and
registered keyboard listeners. It checks Escape from the trigger and every
mobile link, focus return and reopening, other keys, click toggle, route changes
and listener cleanup. Mutation checks remove closing, focus return, the ref,
Escape filtering and cleanup independently. Browser/assistive-technology testing
is separate; this test does not claim a real-browser result. Reverting the effect
and ref restores the previous behaviour without state or schema changes.

Validation: 3 mounted tests pass; 7 mutations, 7 caught, 0 equivalent.
