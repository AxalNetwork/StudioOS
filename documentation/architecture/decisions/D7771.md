## D7771 — Deal summary PDF in the header menu (#7771)

The deal's More menu offers **Download summary (PDF)** alongside Copy link and
Open company profile. Each opening clears the previous availability result and
reads `dealSummaryApi.availability(dealId)`. Only `available: true` reveals the
item; pending, failed and refused reads leave it absent. The menu's optional
`onOpen` callback keeps the read tied to opening, including the phone sheet.

Selection calls the existing `pdfBlob(dealId, { signal })` client and downloads
the returned blob under the Worker's filename, then removes the temporary anchor
and revokes the object URL. A refused download displays the Worker's message in
the header's status region and creates no file. Concurrent selections share one
in-flight download. Leaving the route, changing the deal or selected firm, or
unmounting aborts it; late replies cannot create a download. A tab change
reports “Summary download cancelled” in the new tab. Older availability
replies cannot restore access after a newer read or context change.

D6629 remains the authority for paid Investor access, the selected firm's deal
visibility, the active NDA, content masking and audit writes. The header grants
no access and duplicates none of those rules. No Worker, schema or infrastructure
change is needed. The mounted menu regression suite is
`frontend/test/deal_summary_menu_7771.test.mjs`; the existing D6629 client suite
continues to cover transport, selected-firm headers and Worker refusals.
