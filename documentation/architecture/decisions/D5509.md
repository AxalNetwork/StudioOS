## D5509 — Consent for referral links (#5509)

The public handle read returns the page without recording a visit. After it confirms a live handle, Analytics opt-in allows a second read carrying the visit ID. The Worker records only requests with a valid ID. Invalid, unavailable and moved handles do not mint an ID. Marketing opt-in allows first-touch attribution from a referral URL or a live handle. Signup works with no referral attribution.

| Identifier | Purpose | Browser lifetime | Category |
| --- | --- | --- | --- |
| `axal_ref` (first-party cookie) | Credit the first referrer and carry eligible offers through signup and checkout | 30 days for a code, 90 days for a handle, from first touch | Marketing |
| `axal_vid` (session storage) | Count opted-in visits to live handles. The Worker hashes the ID with the day. | The browser tab session, including refresh | Analytics |
| `axal_cookie_consent_v1` (local storage, record version 2) | Remember the visitor's choices | Until cleared or superseded by a new preference version | Essential |

Optional categories default off in every market. The implementation relies on no consent exemption for referral attribution or identifying visit measurement. The EU's [Your Europe online privacy guidance](https://europa.eu/youreurope/business/growing/digitalising/online-privacy/index_en.htm) informs the separate controls and withdrawal path. Essential authentication and session handling retain their existing behavior.

The old preference record predates the new purposes and prompts for a new choice. Startup removes the old persistent visitor ID and any referral cookie without current Marketing consent. Withdrawal clears the relevant identifiers and stops subsequent optional requests. The visit table keeps the daily hash used for deduplication and has no expiry in this code. #5510 owns the server-side retention inventory. Signup funnel measurement can measure the entry link with Analytics consent.

For the public policy review in #5511, the wording to reconcile is: “With Marketing enabled, Axal stores your first referral code for up to 30 days or your first referral handle for up to 90 days to credit referrals and apply eligible offers. With Analytics enabled, Axal uses a random ID for the tab session to count visits to live referral handles. You can change either choice under Cookie preferences.” #5511 owns approval and publication of effective policy text.
