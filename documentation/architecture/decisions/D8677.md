### What the walkthrough found

- Practice showed "4 sources unreadable" with four identical "Try again" buttons. Each of the five sources already loads and retries on its own, so what did not fail survives a retry, but an unreadable source draws a `SourceState` in Needs attention, again in Today and again in each health tile it feeds, every one a `role="alert"` box with "Try again": four sources can draw twelve.
- Expertise put "No profile yet" beside a status-cell "Retry" and a section "Try again" for the same read. "No profile yet" appears only when `GET /api/advisors/me` answers `null`; beside two retries it read as part of the failure.
- Cohorts paired "This did not load" with the selector line's own alert. `guardedRead` sets `data: null` before every read, so Refresh blanks the overview, and a failed week record draws two "Retry" buttons.
- The owner's comment: a later walkthrough rendered Cohorts and Expertise, so the failures were transient. The canvas reproduces failed reads with deterministic fixtures and does not treat the routes as down.

### What the canvas decides

- Each source has one owning section, which shows Unavailable and the only retry for it, named for what it reads: "Retry sessions", "Retry earnings", "Retry proof", "Retry profile", "Retry week record", "Retry cohorts". Other sections that depend on it are marked Partial and link to the owner, with no second button (PFR00, PFR01).
- Two or more failed sources add one status banner with **Retry 2 sources**, accessible name "Retry 2 sources: sessions and earnings" (PFR02). A page that cannot be read at all shows one block with one primary, **Retry Practice** or **Retry cohorts**, and no zeros or setup checklist (PFR02B, PFR05).
- Empty, loading, stale and unreadable are distinct: a measured 0 and $0 is empty; the last good answer shows as Stale after a failed refresh; "no profile recorded", "profile unreadable" and "profile loading" do not look alike; a failed read never shows a creation prompt or a zero (PFR03 to PFR03C, PFR04B, PFR05D). The setup checklist still takes over only when a step is known to be missing.
- Retry leaves every loaded section and the active selection in place. On success focus moves to the section heading with one polite announcement; on failure it stays on the button. One live region, with no per-section alerts on first load (PFR01C, PFR04C, PFR07).
- Diagnostics sit under **Details**: the source route, the HTTP status or "No answer", the time and the attempts.
- Phone 390 × 844 in eight frames (PFR06A to PFR06H), dark (PFR08), handoff (PFR09). Practice and Cohorts keep emerald, Expertise violet; the states follow D5129 with "Unavailable" on screen.
