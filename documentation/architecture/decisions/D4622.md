## D4622 — Studio independent reads, layout half, part 1 (#4622)

### Decision

The Studio's two layout reads, the module catalogue (`GET /api/studio/modules`)
and the saved layout (`GET /api/studio/layout`), start together and settle
separately. Each has its own retry. This is the layout half of #4622. The role
homes, the founder's project reads, the shared progress and queue owner and
the lazy role loading are not part of this change.

1. **Each read commits when it settles.**
   - Before, `useStudioLayout` waited on `Promise.allSettled` for both, so the
     saved layout, which is all the grid needs, was held for the catalogue.
   - Now `layoutRead` is `ready` as soon as the layout answers. A tile whose
     module the catalogue has not named yet draws its fallback title.
   - The catalogue answering first does not wait for the layout either.
   - Customise stays unavailable until the catalogue is ready, because it
     needs the module list to add from.
2. **Each read retries alone.**
   - `reload` (the layout's Try again and Reload layout) re-reads the layout
     only. `reloadModules` re-reads the catalogue only.
   - A catalogue retry is not a layout reload, so it does not end a save or
     reset in flight (D4621's generation is bumped by the layout read only).
3. **A failed catalogue has its own notice.**
   - Before, it had none: Customise just disappeared.
   - `studio-notice-modules` says the module list could not be read and offers
     Try again. The layout above it stays as read.
4. **A late answer is dropped by each read**, whichever profile or retry it
   began under, as before.

### Measured

Both reads were already started together, so the request count is unchanged
(one each, per profile, per retry). What changes is when the first tile can
draw: before, at the later of the two answers; now, at the layout's answer. The
tests assert this order with deferred responses. No production timing was
taken, and none is claimed.

### Tests

`frontend/test/studio_independent_reads_4622.test.mjs`: one request each, the
layout drawing before the catalogue, the catalogue first, a failed catalogue
keeping the layout, each retry reading only its own source, a catalogue retry
leaving a save alone, late answers after a profile change, and the two
notices. Each guarded line was mutated, and each mutation fails a test.
