## D6766 — Delete source branches after merges into main (#6766)

StudioOS uses stacked pull requests. The repository-wide automatic deletion
setting applies even when a PR merges into an intermediate branch. The PR close
workflow therefore removes a same-repository source branch only after its PR
merges into `main`. It keeps the branch if another open PR uses it, if the
branch is protected or reserved, or if the tip has moved. GitHub atomically
compares the recorded head SHA with the ref when deleting it. A later push
to the same branch name stays intact. The merged PR retains the change history.
