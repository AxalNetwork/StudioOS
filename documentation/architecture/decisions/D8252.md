## D8252 — Grow Markets: before-and-after values on History lines (#8252)

- **Status:** built 2026-11-22. Follows D6120, which left History saying only "Market updated" (D6119-p2, option A: before and after marked as backend work).
- **Route-map row:** none changes; the route and its read are the same.

### What this decides

1. **The values live in the existing log line, not a new table.** `updateMarket` writes the changed fields into the `activity_logs` summary: `Market updated: Regulation score 2 → 4; Decision Not decided → Enter`. The log holds 500 characters, which a market's fields fit; a longer list ends in `and N more`, and one long value is clipped to 48 characters. No migration.
2. **What is listed.** State, decision, the four scores and their sources, the attached country, the size (with its currency) and the size source, and only when the stored value changed. A value that was never set reads `Not recorded`, and an unset decision reads `Not decided`. An edit that changed nothing writes `Market updated: no field changed`.
3. **Older lines are not rewritten.** A line that says `Market updated` is read as written. The record's History draws a line with values as the update line with its changes listed under it (`historyLine`, `MarketRecord.jsx`); anything else reads as it did.
4. **Who and when are unchanged:** the actor and the day still come from the activity log.

### Rollback

Revert the commit. Lines written meanwhile keep their `Market updated: …` text, which older code shows as a plain line.
