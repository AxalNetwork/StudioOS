## D6003 — Complete ICP steps and archive active segments (#6003)

The existing segment Add/Edit form exposes Context and Source for the value, carries their recorded values, and sends neither when an Edit did not show the field. The Worker already accepts both. ICP lists advertise Evidence, Name, Strong fit and Interviews, and no longer offer Measured: interview-derived evidence stops at Pattern. Adapter defaults match.

Archive is a confirmed writer-only record action using the existing segment store. It stamps archived_at and logs segment_archived in the same D1 batch, conditional on the row changing. A concurrent losing archive refuses with 404 and writes no duplicate audit row. Interviews retain segment_id and ICP fit as historical evidence; the current segments summary treats a link to an archived segment as unassigned. Active lists, charts and selectors already exclude archived segments. The shared ownership guard refuses archived record/activity/action reads and direct edits with 404; adding the same archived name returns an explicit 409 rather than an invisible archived ID; after a successful archive the existing record controller follows its after-write 404 back to the module page. No migration or second store is introduced.
