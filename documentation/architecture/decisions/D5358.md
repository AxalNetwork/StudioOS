## D5358 — Confirm repricing in Practice Sessions (#5358)

Recording a status on a priced session sends only the status and preserves
the price and fee snapshot. A price change, including clearing the price,
requires a separate confirmation before sending D4679's `reprice: true`.
The editor shows the stored price and explains what happens to the fee rate
and cut. On a billed row, confirming the existing price can restore missing
fee details. Rows marked Collected or Written off lock price controls.

The editor uses fixed messages for billing refusals. A changed booking closes
the stale editor and re-reads the list, with the reason still visible.
No Worker contract change is required.
