### Built

**Companies (C0).**
- **Directory (N).** The Directory tab carries the directory's size: the
  API's `coverage.of`, which counts every company, not the filtered page
  (`directoryTabLabel`, `CompanyDirectoryZone.jsx`). When the page opens on
  Saved analyses, where the directory is not mounted, one row is read for
  it (`limit: 1`). No number is drawn before one is read.
- **A competitor's directory profile.** `GET /api/competitors/:id` now gives
  each competitor a `directory_uid`, and the analysis a `directory_match`
  status. `services/competitorDirectoryLink.ts` works it out on each read and
  stores nothing:
  1. by site: the one directory company whose website has the competitor's
     host, `www.` ignored. Two on one host link neither;
  2. by name, only when no company matched by site: the one company with the
     same name, ignoring case and spacing.

  Anything else links nothing, so a hand-typed name with no profile stays
  plain text, as C0 draws it. The names and hosts are bound as two JSON
  arrays (`json_each`). A failed directory read links nothing and says
  "Directory profiles: Unreadable" on the analysis.
- **Where the link is drawn.** "Directory profile →" sits under the
  competitor's domain on `/research/companies/:id`, and beside the site link
  on the competitor's own page. The name keeps opening the competitor's page
  (D313); C0 predates that page.

**The current zone pill in dark mode.** It took its light tint onto the dark
ground — a pale lozenge the canvases never draw (the Fund dossier canvas
specifies a deep ground, a light ink and a deep border). It now takes the
role's dark pair from `ACCENT`: `tintDark` ground, `deepDark` ink and a
`deepDark` border at 40%. Idle pills keep D403's neutrals. Every Research
page and every other zone row shows the change.

**Funds (F0, F1) and the fund dossier.** Frontend only.
- **Two tabs on `/research/funds`.** "My funds", the default with no
  parameter, is the shortlist with its toolbar, unchanged. "Directory (N)"
  is `?view=directory`, where N is the directory read's `coverage.total`;
  the tab reads "Directory" until a read answers and after one fails. A
  switch replaces the URL and adds no history entry. Both panels stay
  mounted, so N shows on My funds too without a second read. The catalog
  profile's back link and the company page's "See all N in Funds →" now land
  on `?view=directory`.
- **"Where the money is"** on the Directory tab, above the search and the
  list: the overview's own `Money` section (D536), exported and fed by
  `GET /api/research/overview`, read the first time the tab opens. Loading
  draws no figure; a failed request or an unreadable money section says
  Unreadable, never zero.
- **"Add to my funds"** replaces "Add to my list". The row the POST returns
  is kept, so "Open your dossier →" takes the button's place at once; a fund
  already on the list gets the same link. While the founder's own list is
  loading or unreadable the drawer offers no add, which could duplicate a
  row.
- **The dossier.**
  - A source recorded without http(s), such as "acme.vc", is shown as
    written and not linked: "recorded without http(s), so it is not
    linked". It used to read "Not recorded · no source URL on this row",
    which was false.
  - An unassessed stage and any path but Warm path take muted tile ink, as
    the canvas draws them.
  - The draft band's Draft button is disabled up front, with "Record a
    thesis or a note first — there is nothing to draft from.", while the
    row has neither. `ZoneDraft` takes an optional `blocked` reason, so every
    other mount is unchanged; the 409 `nothing_to_draft` handling stays.
  - Below `lg`, a live fund's Pass reason card is hidden, as M1 draws it.
- **Three silent failures on My funds, found on the way.** `SaveNote` reads
  a `{ ok, text }` note and was handed a string as children, so "Added." and
  every failed save drew nothing: a failed stage, path or status edit now
  says so above the list. `ZoneHeading` reads `blurb` and `action` and was
  passed `sub` and `right`, so the zone's line and its "N with a route in"
  pill never rendered. The four tiles read "Not recorded" while the list
  was still loading; they now draw no figure then, and Unreadable when the
  read failed.

**Differs:** N is the live count (2,616 in the repository's build), not the
canvas's 2,032; the band sits under the directory's header and coverage
card, because F1's import has no placement in the repository.

**Markets, sectors and countries (M0 to M3).** Frontend only.
- **Every tracked sector** groups the markets on `/research/markets`: the
  groups come from `GET /api/research/sectors` (`researchSectorsApi.list`,
  which nothing had called), never a list written in the page. Each has
  "Open sector →" to `/research/markets/sector/:slug`. A sector with no
  mapped market says "No market is mapped to this sector yet" and keeps its
  link; that sentence shows only over the full market list, not during a
  search. A failed sector read says so with Retry, and the sectors the
  markets name still group.
- **"Not mapped yet"** labels the markets no tracked sector holds, as M1
  names the group.
- **The country page** (`/research/geographies/:code`) and the
  unmapped-market fallback (`LegacyMarketProfile`) render inside
  `WorkspaceShell`, with the Research zone pills and the crumb
  (Research ‹ Geographies ‹ country). Their data and states are unchanged.
- **A first market reading can be recorded again.** Since `b9557713c`
  replaced `MarketZone` with the directory, nothing offered one, and the
  reading page records only once a reading exists. The "Your market
  readings" card now has a "Record a reading →" form, once the list has
  been read, on every licence: `POST /market-readings` requires only a
  sign-in and `MarketZone` checked no licence, and a founder with no
  service catalog names what the range prices in free text. The form
  reuses the reading page's validation, and a save opens the new reading.
  Each reading row shows its run date, its age and a
  Current/Ageing/Stale pill. The partner's "Re-run stale" action opens the
  form on the first stale reading; "Attach to proposal" stays on the
  reading's own page.

**Open:** the Markets zone's age filter chips are declared in
`partnerZoneFilters.js` and the advisor's, and nothing has drawn them since
`b9557713c` (`profile_zone_filters.test.mjs` still reads `MarketZone.jsx`).
Drawing them over the readings card, or marking them unbuilt, is a
follow-up.

**The market reading page (`/research/markets/:uid`), against its canvas.**
Frontend only.
- **The header line** is the reading's scope, or Not recorded when it has
  none. "Catalog lists $X" is its own muted line, shown only when the
  offering is catalogued. The chip that used to stand for a missing catalog
  price, and so drew a stray Not recorded beside a recorded scope, is gone.
- **A Scope field** on the record form. A blank saves null; the old scope is
  no longer carried forward unseen.
- **The licence's accent** on the primary buttons, the ZONEDRAFT pill, Draft
  and Accept, the focus rings and the back and Signals links, from
  `ACCENT[role]` through CSS variables. They were violet for every licence,
  so a partner's page was half amber and half violet. On the dark ground
  the fills keep their light value, as the canvas's D6 board draws, and ink
  takes `deepDark`.
- **Attach states, in order:** stale ("Re-run before attaching"), attached,
  no proposal, attachable. Proposals are the caller's partner quotes, so a
  licence with no partner profile reads "No proposal to attach to" and never
  Attachable. Once attached, the card shows an Attached pill and the picker
  reads "Attach to another proposal", offering only the quotes the reading
  is not on (the Worker ignores a repeat attach silently).
- **Layout.** Tiles four across, with Age and Proposal at 20px, and the
  record form on one row, both from `xl` (1280px): between 1024 and 1279px
  the sidebar and the rail leave about 450px, which clipped the run-date
  field. High-below-low is a danger box with `role="alert"`; the stale
  sentence is in danger ink, and reads "an October quote".
- **The comparables table** has the canvas's fourth column, "URL or file".
  Its empty state is unchanged.
- **One h1.** `WorkspaceShell` takes `titleAs` (default `h1`, unchanged for
  every other caller); this page passes `p` once its own h1 is on screen, so
  every state has exactly one.

**Differs:** the metric still shows in the shell's title line (now a
paragraph) and as the card's heading; the attached card names the quote's
proposal, where the canvas's "proposal name: Not recorded" would be false;
attaching is a picker and a button.

  one is the company's target is a decision.
