## D4626 — Session deletion owns and removes its parent transcript projection (#4626)

`interview_transcript_segments` remains the source of truth for a recorded
session. When `replaceWithFinal` copies those final segments to the discovery
interview, the parent now also stores the supplying session UID. This is
ownership metadata, not another transcript store.

Whole-session deletion clears the parent transcript, transcription time and
model only when the deleted session still owns the projection and the copied
text still exactly matches its final segments. Deleting an older session
therefore preserves a newer session's projection. If another ingestion path
has rewritten the parent text without session ownership, deletion preserves
that text and only drops the stale owner marker.

When the projected session is deleted while older sessions survive, the parent
is deliberately left empty. Old words are not resurrected implicitly; a
surviving session can become current only through an explicit transcription or
import. Audio-only deletion remains unchanged and keeps all text. Accepted
findings keep D757/D877 behavior: the accepted row survives whole-session
deletion while its source quote is removed.

The migration backfills ownership only where one finalized session's ordered
segments exactly equal the existing parent transcript. Ambiguous, composed or
independently authored parent text remains unowned. Tests cover projection
ownership, whole-session cleanup and public discovery serialization, repeated
deletion, and the rule that deleting an older session cannot erase the newer
projection.
