## D6394 — Preserve a consultation slot when the decision form leaves it blank (#6394)

Only the admin decision route trims slot_at and treats an empty or whitespace
string, null or an omitted field as no replacement. Non-string values and
invalid ISO date-times return invalid_slot_at (400) before any decision write.
Calendar rollover dates and date-only values are rejected; valid local form
date-times and explicit offsets remain accepted. Valid text is stored trimmed.
The existing COALESCE update preserves a recorded slot on a blank input.

The version/transition checks, atomic booking/history batch and actor remain
unchanged. Deliberately clearing a slot remains impossible; #5884 retains
that product question. The owner explicitly assigned this narrow route
repair to s38, leaving #5885's board/detail/history scope intact.
Mounted SQLite tests verify readback, replacement and unchanged booking,
version and history on invalid input. No schema, permission, frontend or
production data operation is added.
