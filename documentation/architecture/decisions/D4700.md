## D4700 — Licences: requests scoped on the server, the ledger read a page at a time (#4700)

**Licences audit 5/7, slot S24 · 2026-11-06.** No migration.

### What was wrong

- **The request panel filtered in the browser.** `LicenceRequestsPanel` read HQ's whole escalation board, one list per kind, each capped at 100, then kept this licence's rows on the client:
  - a request past the cap vanished, and the panel said "No open requests";
  - `AdminLicences` never passed the deployment code, so a request a licence's branch raised never matched;
  - the response's `complete` flag was never read.
- **The ledger read and hydrated every licence.** `GET /api/admin/licences` loaded the whole table, and `hydrate` bound one parameter per licence in four `IN (…)` statements. D1 refuses more than 100 bound values, so the 101st licence would break the page.
- **The totals depended on that full read.** The coverage grid and renewal pipeline were computed from the same full list, so paging it naively would have made them wrong.

### What changed

All new SQL is literal, with its values bound (`services/licenceLedgerReads.ts`).

- **`GET /api/admin/licences/:uid/requests?limit=&cursor=`** — one licence's open requests of the panel's five kinds.
  - **Scope, applied in SQL before the page is cut:** HQ-tier rows whose `subject_ref` is the licence, plus rows whose `branch_code` is the licence's deployment code (from `licence_deployments`, never `hq`).
  - **Response:** the page with a keyset cursor `(created_at, uid)`, `total` over every match, `branch_code` and `branch_readable`.
  - **Unreadable states:** an unreadable deployment register is `branch_readable: false`, so branch requests were not looked for. An unreadable board is `available: false`. Neither is "none".
- **`GET /api/admin/licences?q=&kind=&status=&limit=&cursor=`** — one page of the ledger.
  - The search covers reference, brand, legal entity, or an exact held country code. LIKE's own characters are escaped.
  - Kind and status filter in SQL. The order is the console's (status rank, reference, id), with a keyset cursor over that triple.
  - `total` counts every match. Only the page is hydrated.
- **`GET /api/admin/licences/summary`** — over the whole ledger, apart from the page:
  - **coverage:** every non-terminated licence's held countries. This is bounded, because `country_code` is unique.
  - **renewals:** the 50 soonest, with their total and a `complete` flag.
  - **counts:** by status and by kind.
- **`hydrate` chunks its ids at 90 per statement.** Every caller is bounded, not only the paged list.

### The console

- **The request panel:**
  - reads the scoped route;
  - its heading count is the server's total;
  - a page short of the total says "Showing n of N" and offers Show more;
  - an unlooked branch is said in its own line.
- **When the panel says "none":** only a read that counted 0 and looked at the branch says "No open requests from this licence's Administrator".
- **The browser filter is removed:** the client-side `licenceRequests` filter in `lib/escalationKinds.js` is gone, so nothing can quietly reuse it.
- **The ledger:**
  - is searched (debounced 300 ms) and filtered by kind on the server, with Show more and "Showing n of N";
  - a slower answer to an older search never replaces a newer one;
  - the coverage grid and renewal pipeline draw the summary, and an unreadable summary is said.
- **Revenue:** its ceiling and statement pickers follow every page (`licenceLedgerApi.all`). A run that stops before the cursor ends is unreadable, not a shorter list.

### Tests

- **Worker:** `cloudflare-worker/test/licence_ledger_reads_4700.test.ts`.
  - It runs a fake D1 that refuses more than 100 binds, with the ledger at 100, 101 and 450 licences, at two page sizes, in one order.
  - It covers the requests behind 150 unrelated ones, the HQ- and branch-origin match, the cursor and total, and the unreadable states.
  - Mutations caught: a chunk size past 100, and a dropped branch match.
- **Frontend:** `frontend/test/hq_licence_terms_d801.test.mjs` covers the panel's loader, its partial and branch states, and that only a full read says "none".
