### What the canvas decides

- The section shows the latest quarter with units, a chart with each quarter at its own position, and a history table with Edit and Delete. No reports yet, Loading and Failed to load with Retry are separate states.
- Add quarter opens in the shared Sheet: period, source, then money (US$), rates (%) and the multiple (×). Picking a quarter that already has a report opens it prefilled.
- Editing marks each field Kept, New value or Cleared, with a change summary and one primary action, "Save 1 change". Adding a 4.2% return to 2026 Q2 keeps NAV US$100,000, IRR 9.4%, TVPI 1.4×, the source and the note.
- Metric states are kept apart: a measured 0.0%, a negative −2.1%, Not recorded, No report, Unavailable and Invalid entry. TVPI reads as ×.
- A missing quarter is a gap in the chart and a "No report" row in the table, never a joined line.
- Errors keep what was typed: an error summary, a per-field conflict review, save failed, offline, session expired, and a list re-read that failed after a save.
- Delete goes Scope → Review → Result, with Keep report as the default. Focus returns to the row and the change is announced.
- Phone at 390 and dark mode cover the list, edit, validation and failed load.
