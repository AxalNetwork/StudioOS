## D6993 — /influencers stops promising "every invoice" (#6993)

- **Status:** built by Claude Code for slot S16 at the owner's request, 2026-11-17. Not deployed.
- **Part of:** #6976 (the owner's public website audit, plan key X11). Register P0, `/influencers`.
- **Migration:** none. **Worker:** none; the page reads `GET /api/influencer/tiers` as before (D4297 §1).

### What changed

The hero and the page description said "you earn part of every invoice they pay", while
the tier table on the same page limits earnings to a set number of invoices per member.
The page now says one thing in three places:

1. **Hero line and page description:** "Share your own handle. When someone subscribes
   through it, you earn a share of their subscription for a set period." The sentence is
   `HERO_LINE` in `influencerPublicModel.js`, so the two cannot drift apart.
2. **Beside Apply:** the live rate-and-duration line (`rateLine`), computed from the tiers
   read exactly as the "Earn" card already was ("20–30% of each subscription, for 12
   invoices per member."). It sits inside the hero's actions row, next to the Apply button
   (or next to nothing for a signed-in member whose application is open).
3. **A failed tier read** makes that line, and the "Earn" card, read "Rates unavailable.
   See the tiers below." No rate and no duration appears anywhere on the page. (Before,
   the card fell back to "A share of each subscription, for the paid invoices your tier
   sets.", which had no number either; it now uses the issue's wording.) While the read
   loads, the hero shows no line and the card reads "Reading the tiers…".
4. **A strategic tier in the read** (`strategic_creator` or `strategic_partner`) adds one
   line under the table: "A strategic agreement can differ; its terms are in the
   agreement." It does not show when the read has none, or when it failed.

The programme name "Influencers", the "Apply" label and its sign-up link are unchanged.

### Not changed

- The share-card description in `lib/ogRegistry.js` still carries the old sentence;
  #6988 (X6) owns that file.
- Tier rates and durations (HQ's settings), and the rest of the influencer pages (D4297, #6975).

### Tests

`frontend/test/influencers_earn_copy_6993.test.mjs`: "every invoice" is absent from
`InfluencersPage.jsx` and no rate or duration is typed there; the hero and description use
`HERO_LINE`; `rateLine` per read state; the rate line is a sibling of Apply; the table
agrees on duration; the strategic line appears only with a strategic tier; a failed read
shows no number on the whole page. D4297's own test now expects the failed-read wording.
