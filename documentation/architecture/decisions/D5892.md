## D5892 — Influencers in the Programs shell (#5892)

Influencers uses the six shell sections from D5313. The root remains the
Applications screen and adds the registry's Capability modules. Applications
and Influencers keep their own addresses, which now also match their module
links. Offers and Payouts retain dedicated tabs as a departure from the
registry module list.

Availability & grants and the Settings member-access editor use the registry.
A failed registry read leaves Applications and the existing Settings content
available. Participation says Not recorded because the application and member
lists do not record a program participation measure.
