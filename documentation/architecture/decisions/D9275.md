## D9275 — A slash command in Eadwyn's composer is never an answer or evidence (#9275)

- **Status:** built by S21 on #9275, 2026-11-28.
- **Chosen by:** the #9271 audit, as filed on the issue (part of the Eadwyn plan on #9271).
- **Migration:** none. No Worker change and no new `/api/*` client.

### The problem

`handleSend` in `frontend/src/components/advisor/PersonalAdvisor.jsx` sent only seven slash prefixes (`/tool`, `/find`, `/open`, `/book`, `/schedule`, `/draft`, `/start`) to `api.advisor.toolAuto`. With a question active, any other line, the owner's `/validate/ideal-customer-profile<create-segment>` included, fell through to `submit()` and was saved by `api.advisor.answer` as the answer. When the previous turn had returned `needs_evidence`, the same text was filed as that answer's evidence (`pendingEvidence`).

### What was decided

- `frontend/src/lib/advisor/composerIntent.js` holds one pure classifier, `intentOf(text, { question, pendingEvidence })`, answering `explain`, `tool`, `command` or `answer` (`null` for blank text). `routeComposerSend(text, ctx, handlers)` calls the handler that matches.
- After trimming, a line that starts with `/` is a command, unless it starts with one of the seven prefixes, which stay `tool`. `pendingEvidence` never changes what a line is.
- "explain X" and its siblings still open the tutor; an action verb, or any line with no question active, still goes to `toolAuto`; everything else while a question is active is an answer. A slash inside prose (`and/or`, a URL mid-sentence) is still an answer.
- A command this build does not know makes no request. Its text stays in the box. It adds one assistant line to the transcript, "Nothing was sent. Commands are coming to Eadwyn.", once, however many times send is pressed. The question, the answered ring, the user's transcript line and `pendingEvidence` are not touched. The line is a transcript line because the issue confines the change to `handleSend`'s routing block; #9276 replaces it with the command list's suggestions and #9278 adds the picker.

### Tests

`frontend/test/eadwyn_composer_intent_9275.test.mjs` pins `handleSend`'s wiring in the source and drives `routeComposerSend` with `api.advisor` stubbed: the owner's command with a question active, `/x` with evidence pending, `/find investors`, `explain churn`, prose with a slash, and blank text.
