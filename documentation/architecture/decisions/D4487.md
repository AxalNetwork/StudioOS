## D4487 — Distribution campaigns: a six-step Draft plan, never Launch (#4487)

Part of #3722, using DS3's full-page Goal, Audience, Channels, Budget and
dates, Assets and Schedule steps. MK supplies Name, UTM and No segment.
Distribution stays the existing Grow module and licence-union shell; its
static routes come from D4484. Cards and detail read D4447/D4483's venture
store and client. There is no second campaign store or publishing workflow.

Schedule creates a Draft through the existing create route (which refuses
an explicit status on POST). It does not send a post, launch an ad, spend
money or activate on a date. Only Activate in the detail performs the
explicit status PATCH. Ended offers no restart. End and Archive use the
page's own confirmation dialogs and retain existing records and links.

Budgets stay integer cents; blank amounts remain null/Not set. A missing
spend or attribution figure reads Not recorded. Cards use the read's
status counts, channel/item counts and funnel, never design samples. The
Awareness goal has no fabricated reach/click figure; the recorded funnel
is still shown without relabelling leads as reach. A missing budget-reached
date is Not recorded, never the design's example date.

Manual asset text is saved as a Publish draft and linked to the campaign.
Neither saving nor Schedule invokes Publish preview/confirm or a provider.
The save retains successful campaign/draft identifiers and removed-link
progress, so retrying a later failed request does not duplicate those rows.
Existing work can be linked without copying or sending it. Asset AI drafting
and consent/reachable notes are extension slots for #4488 and Prospects.
Name/Goal Ask field triggers are present only while blank and open the
existing Ask intent; dates, money and UTM have no Ask trigger.

The detail is the shared 480px Sheet, including on direct URLs. Advisor
rendering disables every mutation and explains why. The parent shell's
existing route guard is preserved. New surfaces have paired light/dark
styles, 44px controls, a stacking progress rail and contained table overflow.

Distribution's existing writer-gated form-options read has a campaign mode
for all selectable segment source flags, calendar pieces and unarchived
Distribution Publish drafts. It uses the existing client method, scoped by
the route's checked venture, and does not touch the parallel campaign or
channel services. The channel store has no provider binding: its connection
is explicitly Not recorded, with Open Channels, never guessed from its name
or UTM source. Actual supplied disconnected flags still offer Connect.

Editing an existing non-Draft campaign says Save changes and preserves its
status; the new-campaign Schedule flow always leaves Draft. Refusal sentences
from both campaign and Publish writes use the shared parser, never thrown
messages. Partial saves retain their identifiers and explain that a retry may
still need to finish the links/assets.

The detail’s write controls use a read-gated server permission verdict from
the same route. Account role alone is insufficient: a founder account can
hold an advisor membership on a different venture. While permission is
loading or unreadable, writes stay disabled; an advisor sees the specified
read-only explanation. Writer-only selector data remains behind its gate.
