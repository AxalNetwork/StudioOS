### What it found, and the fixes

1. **The phone's Add feature page lost the venture line** (SFD12C). Below 1024px the form is a page (D695). `CycleRoute`'s phone bar draws only the title and the module that Back returns to, so part 2's line ("Atlas Orchard · Build · Solution design", the dialog's eyebrow) was never shown on a phone. `FormLightbox.jsx` `PageVentureLine` now draws that line at the top of the page's body, only in page mode and only when Studio named the venture. As a dialog, the eyebrow already carries it, so nothing more is drawn there.
2. **The Next card's primary was 40 px on a phone, not 44.** `min-h-11` on an `sm-btn` lost to `.sm-btn { min-height: 40px }`. `studioModules.css` is unlayered, so it beats Tailwind's layered utilities. `founderStudioHome.css` now restores 44 px for `.fs-root .sm-btn.min-h-11`. That covers the primary and the unavailable notice's venture links. Desktop is unchanged, because only the phone asks for `min-h-11`.
3. **The eyebrows failed colour contrast.** "Studio · your venture" and the primary's "Build · Solution design" used `text-axal-faint` (#a1a1aa, about 2.6:1 on white). `StudioVenture.jsx` `EYEBROW` is now `text-axal-muted`, which dark mode already remaps.
4. **The Next card's "Open ›" links did not contain the word they show** in their accessible name (WCAG 2.5.3; axe's `label-content-name-mismatch`). They are now named "Open: <task> in <venture>".

### Departures from the canvas

- **The phone page's venture line** sits at the top of the form's body, under the cycle bar's title, not above an h1 as SFD12C draws it. The bar is `CycleRoute`'s and is shared by every cycle page. Its Back still reads "‹ Solution design", not "‹ Cancel"; the form's own Cancel is in the footer.
- Part 2's departures stand.

### Left out

- **The optional Worker change (#5074, card links with `?project_id=`).** #5074 is closed. Studio rewrites the address itself, so nothing depends on the change, and `?project=<id>` links are written in 29 Worker source files, not only `cycle_build.ts`.
- **Focus back on Switch venture after the shell switcher closes** (part 2's departure 1). The switcher (`ui/CompanySwitcher.jsx`) has no close event or Escape handling of its own to hook into. Adding one changes a shell component that every role uses, so it is outside this issue.
- **The switcher following the address** (part 2's departure 2). `CompanySwitcher.jsx` is the single writer of the active company and project, and the projects read gives `company_id`, not the company UID that the store needs. It stays as part 2 left it.
- **The summary strip's labels** ("Venture progress" and the others in `FounderStudioBody.jsx`) use the same `text-axal-faint` eyebrow. They sit below the first screen and were not scanned here. Fixing them is a one-class change, left for the strip's own pass.
- **No visual baseline.** The spec asserts geometry, focus and axe, and takes no screenshots, so no baseline was added or changed.
