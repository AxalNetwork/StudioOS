## D8508 — A static check of AI gateway and agent settings before a release (#8508)

**Context.** `wrangler.toml` names the AI Gateway slugs and the agent settings in three variable tables, and nothing compared them with each other or with what the code needs. The platform AI audit of 2026-11-25 found the Advisor's gateway answering 404 and no `AGENT_AI_GATEWAY_TOKEN` binding on the live Worker; those live findings are not re-checked here.

**Decision.** Layer 1 of #8508: `scripts/check-ai-gateways.mjs`, with no credential and no Cloudflare call, runs in `npm run test:guards` and as a release preflight step. It fails, naming file, table and key, on:

1. **drift** — a gateway slug or agent setting whose value differs from `[env.production.vars]`, unless the script's `ALLOWED` list names that table, key and exact value with a reason. A changed value fails again.
2. **gateway** — a path switched on whose gateway is empty or malformed in that table: an engine run with no `AGENT_AI_GATEWAY` (refused `gateway_required` unless the inference stub answers it), a malformed `AGENT_AI_GATEWAY` (refused `gateway_misconfigured`), or the provider gateway switched on without its own slug.
3. **price** — an agent account slot whose model has no price in `PROVIDER_MODELS`, `GATEWAY_TEXT_MODELS` or `AGENT_OPENAI_RATES`.

The names it checks (the provider switch and slug variables, the `gateway_required` refusal, the two model lists) are read from the source, so a rename in the code fails the check instead of passing it.

**Accepted differences on `main` at the time of writing.** Each is in `ALLOWED` with its reason; none changes a setting:

- `[env.preview.vars] CF_AI_GATEWAY_SLUG_ADVISOR = ""` — preview must not share production's Advisor gateway (#4566).
- `[env.preview.vars] TEAM_AGENTS_ENABLED` unset — preview enables each surface explicitly (D886); Stage A sets it for its own run.
- `OPENAI_MODEL = "gpt-5.3-codex"` unpriced in all three tables — the OpenAI slot is skipped until the owner sets `AGENT_OPENAI_RATES` (D7073-p2).

**Not decided here.**

- The Personal Advisor without a gateway: the owner's A (warn) or B (stop the release) on #8508. The Advisor's gateway is optional in the code (an empty slug calls Workers AI directly), so the check treats it as optional until then.
- The deck's gateway stays empty by design (D1504, owner question L).
- Layer 2, live and read-only (each gateway exists, the token is bound by name, the aliases resolve), needs a token that can read AI Gateway settings. That is new access and the owner's decision.
