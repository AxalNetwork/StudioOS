### What changed

1. **Window.** EX-12's 7 / 30 / 90-day choice sets `?days=` on the existing read. Booking requests follow it; opens are a lifetime counter, so their tile and list say "since published" whatever the window.
2. **Articles by opens.** The writing block gains `top` (the three most-opened published pieces, by opens) and `others` (the rest, as a count and their opens), so the parts add up to `published` and `opens`.
3. **No booking link yet.** A new read, `unlinked_services`, lists the advisor's active session types that no active booking link sells, at most 20 with `more`. A paused link does not count. Each row offers **Add booking link** (`/practice/sessions#booking-links`). Booking configuration stays with Practice (#4832); this only links there. A failed read is null and `unreadable`, never an empty list.
4. **Next steps.** At most three, each from a recorded fact: a session type with no link → Add booking link; the most-opened piece, when it has opens → Write a follow-up. Nothing is suggested from a failed read or where the data does not support it.
5. **Zone heading.** "Visibility", with EX-12's line "What has actually been recorded about your work being seen and booked." The "Engagements by surface" card is not on EX-12 and is gone; the Worker's `engagements` field stays null with its sentence.
