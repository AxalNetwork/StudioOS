## D547 — Tracked sector pages over live evidence and the taxonomy crosswalk

Task: #1139. Slot S18, Codex. No migration.

The market taxonomy and the twelve tracked market-intelligence sectors describe
different units. `/research/markets/sector/:slug` now opens a tracked sector;
an old market slug resolves through the D533 crosswalk and redirects with that
market highlighted. A market with no tracked sector keeps its existing page.
A failed read never triggers either the redirect or the legacy fallback.

### Worker and data boundary

`routes/research_sectors.ts` is mounted at `/api/research`. Both its list and
detail routes use the same sign-in gate as `research_markets.ts`. Values that
reach SQL are bound. No write, migration or production-data operation is added.

The sector list names all twelve sectors and their directory company/fund
counts. The detail adds twelve calendar months for each of six dimensions,
source rows behind each month, countries, sub-markets, company/fund rows and
signals. Directory membership uses `researchTaxonomy.ts`, including manual
overrides, and funds matching multiple markets in one sector count once.

Indexes must carry the D538 `live` basis and a positive source count. Uncited
observations and stub citations never enter a source mix. Missing months remain
null, with a reason, and charts do not connect across them. The latest recorded
period and `computed_at` are shown; the current month's point is month to date.
Changes are the stored `delta_pct`, never an invented change across a gap.

Source names and dimensions come from the registry. Shares count cited rows
in the calendar month, rather than claiming to reproduce the index's weighted
rolling-window calculation. Unknown source keys are not assigned a dimension.
The response and screen name that basis explicitly.

Fund presentation reuses D535's `presentFund` and its currency boundary. Only
EuroTech's known euro sizes enter the total or size ordering; other sizes are
null with a reason. A successfully counted empty directory has a count of zero;
no recorded size is null. A failed read returns 503 Unreadable, never zero.

Signals resolve through mapped tags, exclude archived rows, and explicitly
select the public fields; `advisor_note` is never selected or returned. A
confidence score equal to the schema's unmeasured default reads Not recorded.
Build opportunities render only recorded text, including the headline, wedge,
customer and risks when supplied.

### Canvas and client

The page follows `design/incoming/Research · Sector.dc.html` from D546's branch
`claude/spinout-lab-workspace-wuyyqd` (the canvas PR is not merged yet).
It sits inside `WorkspaceShell` and uses recharts for six small multiples and
the country bar chart. The section links, signals/sub-market split, company and
fund tables, build cards, loading, empty, Not recorded and Unreadable states
work at desktop and phone widths. Wide tables scroll within their cards.

Departures: no public Sign in/top bar; no fixed "35 sources" or May start date;
twelve months instead of the illustrative six; source mix names the latest
recorded month per dimension; no fabricated "Other countries" remainder.
Company/fund lists show up to fifty rows with their complete counts. Supplied
taxonomy counts and actual directory counts are labelled separately.

`lib/api/researchSectors.js` adds only the two mounted reads and is re-exported
in the alphabetical D527 block. The existing route and role guards are kept.

### Verification

Regression tests run actual SQL over declared migrations, and rendered React
views over fixture responses. They cover sign-in, twelve sectors, mapped counts,
monthly gaps, live/stub filtering, source mix, currency, signal field boundaries,
bound parameters, failures, page states, redirects and the unmapped fallback.
The mutation and full-suite results are recorded on the PR.

Rollback: revert the PR. The Worker and frontend change together; no stored
data, binding or configuration changes.
