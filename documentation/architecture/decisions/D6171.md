- **Status:** built 2026-11-15 for #6171.
- **Migration:** none. It reads `market_figures`, which D6011 (#6011) adds, so this change lands after #6011.
- **Builds on:** D1151 (the NDA-gated deal reads), D1154 (the Market tab, DL5), D6011 (`market_figures`), migration 443 (`markets`, Grow MG6).

- **Test:** `cloudflare-worker/test/deal_market_readiness_6171.test.ts`, `frontend/test/deal_market_readiness_6171.test.mjs`. `cloudflare-worker/test/deal_insights_d1151.test.ts` now also drops `market_figures` before its masked-read check.

### Why

`GET /api/deals/:id/market` returned each market's demand, regulation, partners and cost scores with their sources, but `marketRow()` kept only the name, the decision and the date, so an investor never saw them. The same read hard-coded `source: null` for TAM, SAM and SOM, so every figure said "No source recorded for this figure" and had no date.

### Which store holds what

| Store | What it holds | Holds a figure's source? |
|---|---|---|
| `fill_provenance` (migration 246) | One row per value an Eadwyn fill wrote: the target table, row and column, the fill class, the proposed value and the citation. For market sizing it points at `project_market_assumptions` inputs (population, ACV, CAGR). The fills registry never proposes a TAM. | No. It holds where an AI-filled input came from, not where a founder's figure came from |
| `project_market_assumptions` (migration 247) | The sizing drawer's current inputs, one row per venture: methodology, population, ACV, growth note and so on. | No. It holds how a figure was worked out, with no source and no history |
| `market_sources` (migration 440) | The venture's list of sources: title, link and kind. | No link from a source to a figure |
| `market_figures` (D6011) | One row per change to TAM, SAM or SOM, with its method, the named source (copied from `market_sources`), who set it and when | Yes. This read uses it |

### What changed

**Sizing.** `market()` reads each figure through D6011's `currentMarketFigures`. A row counts only while its value still equals `projects.*`. Each figure is `{ value, source, as_of, reason }`:

| Case | `source` | Drawn as |
|---|---|---|
| A named source (any method; `document` names the document) | the source's title | "From <title>" and "As of <day>" |
| Typed by the founder or an accepted team member, with no source | `typed` | "Typed · the founder's own figure" and "As of <day>" |
| Derived top-down or bottom-up by the team, with no source | null | "The founder's own top-down sizing; no source named" and "As of <day>" |
| Entered by someone outside the team (an admin) | null | "Entered on the founder's behalf; no source named" |
| No current row (saved before D6011, or changed by a writer that records none) | null | "No source recorded for this figure" |
| No figure | null | "Not recorded" |

The source text is either the title of a source the founder chose to list, which the same response already returns under `sources`, or one of the fixed sentences above. It is never the drawer's notes, an input, a fill's proposal or citation, or a prompt. The test plants a growth note and a fill proposal in the stores and checks that neither text appears anywhere in the response. A failed `market_figures` read makes the sizing block Unreadable on its own.

**Readiness.** `marketRow()` now keeps each market's four readiness parts, in the canvas's order: Demand, Regulation, Partners, Cost. A part is its score out of 10 with its source ("Demand 8/10 · From Pilot waitlist"), or "Not recorded" when there is no score. A recorded 0 stays 0. The Where card draws one readiness line under each market.

**Before the NDA.** Nothing changes. The masked answer returns before any section is read. The test checks that it is unchanged, and that it is still unchanged with `market_figures` and `markets` dropped.
