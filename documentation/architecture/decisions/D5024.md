## D5024 — Freeze a package agreement’s catalogue identity (#5024)

The agreement draft route takes its package name and version from one
published `program_packages` row. With no version in the request, it uses
the active version. An explicit version can select a retired edition for a
historical agreement. An unpublished or unknown choice returns 409 before
the route changes any agreement in the slot.

The draft freezes the name in `merge_values_json`, the rendered body and
its hash, and records its version in `licence_program_agreements`. The
Contracts registry reads that saved name. Older agreements without a saved
name retain their existing display fallback. The tests compare the fallback
names with the seeded v1 catalogue and check a signed document across a rename.

This is the catalogue-name work carried over from #5022 and #5049. The
commercial offer, accepted economics, agreement-policy freeze, and atomic
program grants remain on #5024.
