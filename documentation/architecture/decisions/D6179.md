## D6179 — Work founder requests from the deal’s Diligence tab (#6179)

The request card uses the existing case read and request routes. The owner and
the lead can send new requests and open recorded answers. Reminder and
withdrawal controls follow the narrower Worker rule for case owners. A failed
write leaves its refusal in the dialog. An accepted write refreshes the case
in place. Files listed on the answer use the case’s existing single-use,
audited download link. No new route, permission or migration is needed.
