## D7960 — Keep bounded test-file reads on one descriptor (#7960)

The repository guard checks the opened file descriptor before reading its
bounded head. It opens read-only without following a final-component symlink,
uses nonblocking mode for special files, and accepts only a regular file. The
descriptor closes on successful reads, non-file results and read or metadata
errors. Missing paths and unsupported path kinds have explicit outcomes;
unexpected failures stop the check.

The reader requires the platform's secure-open flags when content is requested.
It does not silently fall back to weaker flags. This change leaves the marker
list and the existing name matching unchanged; it adds no production behavior.

The existing guard suite exercises real temporary regular files, directories,
symlinks, path replacement and a FIFO, plus injected I/O failures and unavailable
flags. The FIFO case runs in a bounded child process. Focused mutation checks
cover the accepted and refused cases, read limit, descriptor lifetime and error
propagation. Decision and folder-documentation checks also validate this change.
