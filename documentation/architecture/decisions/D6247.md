## D6247 — The fund page hands its reader to the next page (#6247)

Part of #5994. `/funds/:fundId` (`frontend/src/pages/FundPage.jsx`, D631) ended in a fact sheet: a manager had three links and an LP none. It now hands each reader on, with no new API call. Everything is drawn from the page read (`GET /api/funds/:id/page`), whose `can_manage` is true only when `requireFundGp` passes: the GP of record on the institutional tier, or an admin.

### The rule

- **Each link is shown only to a reader its destination admits** (`fundHandoffs`).
  - **A manager** gets New reporting period, Reporting archive and Open LPs as before, plus Capital calls (`/funds/calls?fund=`) and Ledger and distributions (`/funds/ledger?fund=`). Both pages pick their fund from `?fund=` through `useManagedFund` (D371), and both sit behind the same institutional gate `can_manage` already proved.
  - **An LP** (`can_manage` false) gets My commitment and statements, `/spinout-lab/investor-workspace`, which admits any investor.
  - **Every reader** gets Fund performance, `/funds/performance`: the owner's answer C on #6245 is that LPs and GPs both read it.
- **Edit fund facts.** Fund facts are edited only in the Fund administration console's dialog (`fundFactsEditHref`, the builder D1161's header primary already used), which is admin-only. So an admin (`role` is `admin`) gets the link. A manager who is not an admin sees "Edit fund facts: Not available": `PATCH /api/funds/:id` accepts a GP, but no page outside the console sends it. An admin previewing as an investor has `role` `investor` and sees the same line.
- **The empty LP state.** "No LP has committed yet." carries the canvas CTA Open LPs (`fd-page`, `design/canvases/integrated/ops-data.js`) for a manager only.
- **Reporting periods** print `issued_at` ("Issued 2026-04-15"), or "Issued · date not recorded" when the date is missing. A draft, which only a manager is sent, is marked "Draft · not issued".
- **Status** is drawn as the canvas's violet pill. A missing status stays Not recorded.

### Phone

At 640px and below the links wrap two to a row, and the Not available line takes its own row.

### Tests

`frontend/test/fund_page_handoffs_6247.test.mjs` pins each link by reader: LP, GP who is not an admin, and admin. It also pins the empty-state CTA, the period dates, the draft mark and the pill.
