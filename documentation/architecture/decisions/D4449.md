## D4449 — Recover manual call actions and post-call output jobs (#4449)

D4412's selected-output redirect applies only to automatic processing. A manual or forced digest still runs the requested stages, including the session buttons and MCP summarize_meeting. An explicit empty outputs selection does not disable those actions.

Accepting an interview_summary appends its cited sentence atomically to the existing digest overview and summary. Quotes, decisions, next steps and provenance remain intact across Accept all and overlapping Accept presses.

Output jobs retain controlled failure reasons. Consent withdrawal cancels a job; lost write access, an unavailable transcript or an invalid session state fails it visibly. Failed jobs and queued/running jobs older than fifteen minutes can be retried. Review polling ends after fifteen minutes and offers Try again; reopening the page also reads the server's stale-job indication. Retry never resets a fresh running claim or a completed job.

Each extraction kind belongs to the first selected output that requests it. The estimate and execution use that same partition, so overlapping choices neither quote nor extract a kind twice. An output with no unique kinds needs no model call. A result is Proposals ready only when storePlacements reports newly stored proposals; zero stored is No new proposals.

Recording does not require an AI extraction estimate. An unavailable estimate clears the AI output selection, shows its reason and sends outputs:[]; consent and capture requirements still gate Start. No deployment or rollout switch changes are included.
