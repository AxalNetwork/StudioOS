## D1523 — Deck v2 A24: Linked, Stated and Uncited on every figure (#3775)

- **Status:** built by S09, 2026-11-01 (#3775, part of #3716). The issue gives the D number.
- **Spec:** the issue, and the S1 badge boards it names (pd24 for the tile face and its hover, pd25 for Check claims). It extends S1's files (`figuresModel.js`, `BlockGrid.jsx`, `DeckSheets.jsx`) rather than adding new surfaces.

### 1. Four states, never a zero

`cloudflare-worker/src/services/decks/figures.ts` reads a version's slides as saved and classifies every figure:

| State | What it is |
| --- | --- |
| `linked` | bound to a record (D896's binding: `source_key`, `record_ref`, `as_of`, `grade`) that holds a value: a metric tile, a chart series, a table cell or an older card's field. `source` names the slot, its module and this venture's address (`newDeck.ts`'s `slotHome`). |
| `not_recorded` | bound, but the record holds nothing (the one-click build binds a missing slot with grade "Not recorded"), or a metric tile with no value. It carries no value: never 0, never "". |
| `stated` | typed by the founder: an unbound tile value, a series of typed points, a table cell whose text names a number. |
| `uncited` | a number in free text (a text block, an older card's words) that no record and no tile backs. `figures` lists each number it names. |

`numbersIn` finds the numbers: digits in any script (`\p{Nd}`, as D1506's guard), with a currency sign, separators and a `%` or k/m/b suffix kept on; at most 20 per text.

### 2. The route

`GET /api/decks/:id/figures` (`routes/deck_figures.ts`, mounted at `/api/decks` after `deck_typed_values.ts`) → `{ deck_id, figures, counts }`. Whoever may read the deck (`projectOwned`, as `/:id/typed-values`); 403 otherwise, 404 for no deck. No model, no charge, no write, no SQL beyond the deck read. Its reply is held to `contracts/deckFigures.schema.json` (D1511).

### 3. The editor draws them; nothing an investor sees does

- **Tile faces** (`BlockGrid.jsx`, editor only): a bound tile keeps its source · grade face (D1604); a typed tile reads "✎ Stated" with "Typed by … · not linked to a record"; a text block that names a number reads "! Uncited" with "This number has no source". `figuresModel.badgeOf` is the Worker's rule on the client, so a face changes the moment a tile is edited; a test holds the two to the same answer block by block.
- **Check claims** (`DeckSheets.jsx`'s `FigureCounts`, at the head of the sheet): "▤ Linked n · ✎ Stated n · ! Uncited n" (and Not recorded when any), then each Uncited and Stated figure with "Go to card ›". It reads the saved version through `deckV2Adapter.figures`, now a `SWAPPED` row; a failed read says so and never counts 0.
- **Never in Present, a share link or an export.** Those draw `BlockGrid` with `live`, which draws no badge, and none of them calls the route; `services/decks/figures.ts` has one reader, the route. Tests pin both.

### 4. Not built here

"Link a record ›" and "Remove" on the Uncited hover are exported as words (`LINK_RECORD`, `REMOVE_FIGURE`) for the hover card; the binding flow they open is D896's Add menu, unchanged.
