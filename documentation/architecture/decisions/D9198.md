## D9198 — Signed-in page loads make no failed request (#9198)

Three reads failed on every load by a signed-in person and showed as console errors. Each now either succeeds or is not sent.

- **Pageview.** `fireAnalytics` in `frontend/src/lib/seo.js` sends `POST /api/public/analytics/pageview` only as `fetch` with `credentials: 'omit'` and `keepalive: true`. It no longer uses `navigator.sendBeacon`, which always sends cookies and cannot add the CSRF header, so the CSRF middleware refused it with 403 for every signed-in visitor and their pageviews were lost. With no cookie, the middleware has no reason to check the request. This matches `lib/funnel.js`. The CSRF exemption list is unchanged.
- **My tasks with the agent engine off.** `GET /api/teams/me/tasks` is read on load by Studio, HQ and each licence's workspace. When `agentEngineEnabled` is false, it still requires sign-in but now answers 200 `{ available: false, projects: [], compliance: [], has_more: false }` instead of 404 `agent_engine_off`. `workAdapter.myTasks` turns that answer into the same off block (`WORK_OFF`) that `through()` gives. `through()` still handles the 404, so an older Worker reads the same way. The other engine routes keep their 404. This is a smaller change than adding an engine flag to `/api/auth/me` and checking it in every workspace that mounts My tasks. `wrangler.toml` is unchanged.
- **KYC status on /trust/me.** `TrustCenterPage` calls `api.kycStatus()` only when the role that `/trust/me` returns is in `KYC_ELIGIBLE_ROLES`. That role is `investor`, the same set that decides whether the Verifications tab draws the identity report. If `/trust/me` returns no role, the page falls back to the cached role. `/api/kyc` is a Studio-tier paywall prefix, so a founder without that tier got a 402 for a read the page never drew. Because the call waits for `/trust/me`, a stale cached role cannot skip an investor's read. The call is still part of the settled set.

Tests: `frontend/test/signed_in_console_errors_9198.test.mjs` and `cloudflare-worker/test/my_tasks_engine_off_9198.test.ts`. Mutation check: 10 mutations, 10 caught, 0 equivalent.
