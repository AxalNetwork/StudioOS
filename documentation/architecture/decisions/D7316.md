# D7316 — Worldwide Research company directory

Status: implementation decision for issue #7316.

The worldwide expansion remains additive to `research_company_directory`. `scripts/import-wikidata-worldwide.mjs` queries Wikidata CC0 by ISO country, requires an official website and an industry accepted by the existing Research taxonomy, keeps financial metrics null, and writes migration 419 plus a machine-readable coverage report. No runtime request depends on Wikidata.

The importer uses a per-country target (600 by default) rather than the legacy global 3,000 cap. Selection is deterministic: configured ISO-country order, sitelinks descending, then Q-id. Deduplication is authoritative Q-id first, normalized domain second, normalized name + country third. Similar names alone never merge.

The run fails its acceptance gate unless it produces at least 25,000 accepted rows across at least 50 countries, keeps every required region above its minimum, and keeps the largest country at or below 35%. The JSON report records rows read/rejected, duplicate reasons, country/region/sector/source/licence distributions, and completeness.

Production runbook: run with a fixed `--as-of` date; review the SQL and JSON report; run the focused D7316 test; apply migration 419 through the normal reviewed D1 migration path. Rollback is `DELETE FROM research_company_directory WHERE source_name='Wikidata' AND as_of=<the D7316 pull date>` limited to the generated migration's Q-ids; never delete the earlier 228/403 rows. Before production, measure migration bytes and the existing directory list/facet query on a representative local D1 copy. Phase 2 (100k) is separate and only proceeds if those measurements remain within budget.

Funding, employee count, revenue, investors and valuation are explicitly out of scope until separately licensed, dated sources are approved.
