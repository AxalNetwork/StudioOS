### What is built

- **The Worker.**
  - `services/roomLibrary.ts` gains `roomRefAccess`. It returns, for each of the caller's live references, the end of the grant the reference was added under (`research_room_refs.grant_id`).
  - `routes/research.ts` puts that on the Library row as `room.access`:
    - `{ until }` is the grant's end. `until` is null when the founder set none.
    - Access is null when the reference has lapsed, even if the grant is still active (copies turned off, a file moved or removed).
  - The lookup lives in the service, because that module already owns the investor's grant rule. `research_stores_scoping` pins every `data_room_grants` read in `research.ts` to one founder-owned project.
  - Nothing is compared against the clock here: D6869's reconcile has already lapsed a reference whose grant has ended.
- **An Ask source from a room (`AskZone.jsx`).** The source list matches each citation to its Library row by `document_uid` (`citationRoom`).
  - A live room file reads "▣ From [room] data room · added [day]".
  - A lapsed one reads *No longer available*. Its passage is replaced by the reason, in its own words, and "The passage is no longer shown. The answer keeps its text as it was given on [day]."
  - A file behind an NDA that lapsed is nameless ("A file behind the NDA"), as in the Library.
- **The source sheet (`RoomLibrary.jsx`, `CitationRoomFacts` and `OpenInRoom`).** The sheet shows Source, Added, Access and In Ask:
  - Access reads "Available until [day]" or "No expiry set".
  - In Ask reads "Yes" or "No", or "Not answerable" once lapsed.
  - A live source offers *Open in room*. A lapsed one withholds its passage and offers nothing.
- **The recorded cost** under each answer was already built (D3701 and D4613), and is unchanged.

### Where this departs from the canvas

- **"Staged [day]" reads "added [day]".** The Library row records when the investor added the file, not when the founder staged it in the room. The staging date would need the room file's `created_at` on the row. That is a Worker change this part does not make.
- **Open in room goes to Diligence**, as in part 1. The row holds the venture, not the grant the room page's address uses.
- **A source no longer in the Library is not known to be a room file.** It reads as today: "The document is no longer in your library, so only the passage recorded with this answer remains." This covers an investor who removed it themselves. The citation stores no room. Marking it would need the Worker to record the room in the answer's citations.
