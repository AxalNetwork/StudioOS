## D5946 — Quarterly subscription revenue from the financial ledger (#5946)

The Super Admin revenue summary reads the requested UTC calendar quarter from
the local financial ledger. The existing occurrence index is sufficient.

The gross side reads Stripe's `invoice` rows for the checkout streams `tier`,
`investor` and `mi`. These rows record the invoice's actual amount paid.
Charge and PaymentIntent rows represent the same inflow (D5299). Refunds
are separate outflows read from the ledger's deduplicated `refund` rows,
including those recorded by HQ. Disputes and adjustments have their own
event kinds. Known test-mode rows are excluded. HQ refund rows may have no
mode stamp.

Totals use each currency's integer minor units. Missing amounts and streams
are counted independently, so a row can contribute to both counts. The
reader totals known amounts and marks the result incomplete when a relevant
row has a gap. A currency's amount remains null when the only recorded rows
for that side have no amount. The coverage record distinguishes a wholly
unrecorded quarter from a quarter that overlaps the ledger. A read failure
affects only the subscriptions block.

The ledger records cash events. Recurring contract value and billing
intervals are needed for MRR and ARR, and the ledger has no pre-coverage
customer history for LTV. The API reports all three as not recorded.
