## D6129 — Investor Studio home v2, built from the canvas (#6129)

Builds the Investor Studio Home v2 canvas (D6126, #6126; boards SM16 to SM-H in
`design/incoming/Investor Studio Home v2 Page.dc.html`) on `/studio` for a member
holding the Investor licence. The frame stays as D1419 drew it: the header,
Eadwyn's fixed chat, the locked profile-fit band and the module grid. D6126 marks
no board "build now"; every board that does not wait on a ◇ store or a ⚑ owner
question is built here, in one part (five modules and the band).

### What is built

- **Thesis band (SM16, SM22c, SM25A).** `InvestorThesisBand.jsx` adds the
  profile's own recorded sectors, stages, regions and ticket as chips, and a
  struck-through Excludes group whose chips read "Excluded: …", from the same
  `GET /api/investor-profile/me`. Prose is never parsed into a chip. Recorded
  preferences without prose count as a thesis. With neither, the band reads
  "No thesis set · Set it in Settings to see fit on live deals". On a phone,
  chips after the fifth fold into "+n more".
- **Needs you (SM17), key `needs_you`, full width.** One row per thing:
  capital calls (with the masked account and reference when the fund
  recorded them, or the reason they are unavailable), each fund notice issued
  to the investor (not superseded, not a call's own notice), Trust
  requirements waiting on them, the subscription booklet, an unsigned LPA,
  and one inbox row counting every kind of unread notification
  (`GET /api/notifications/unread-count`, new on this module). Ordered by
  due date, then date added; an undated row sorts after the dated ones and the
  inbox row is last. Overdue is said in words with an icon; "Due date not
  recorded" and "No expiry recorded" are said. Each source that fails is
  Unreadable alone, with Try again; a failed inbox count is never 0. Below
  1024px, Pay opens the payment details in a bottom sheet (SM25D).
- **Funds (SM18), key `fund_commitment` retitled "Funds", full width.**
  Committed, called, received, due now, uncalled, TVPI, DPI and the LPA date
  per fund, with a bar of called of committed and received inside called, and
  an "All funds" row when there is more than one. Nothing paid in reads "No
  paid-in capital yet", never 0.00×. A failed calls read leaves committed and
  TVPI, and every call figure Unreadable. Below 760px of module width, one card
  per fund (SM25, SM26).
- **Returns (SM19), new key `returns`.** IRR, TVPI, MOIC and DPI for the
  accessible book from `GET /api/positions/analytics`, with paid in,
  distributed and NAV, labelled gross and dated, and mark coverage as a
  sentence. Not computed carries D4644's reason; Total loss sits beside −100%;
  a measured 0 shows as 0.
- **Thesis fit on live deals (SM20), new key `thesis_fit`.** The first six
  live deals in `GET /api/deals/flow`, each with four criterion chips from
  `GET /api/deals/fit` (Match, Outside, Not set, Not recorded), the platform's
  reason in each chip's accessible name and shown on tap. "Deal unavailable",
  "Unreadable · Try again" and "Set a thesis…" with four Not set chips. The
  fit read's score is never drawn and nothing is ranked. Both reads sit under
  `/api/deals`, so a plan below Investor Pro sees the module locked (`lockOf`).
- **Arrivals (SM21), new key `arrivals`.** Founder updates
  (`GET /api/portfolio-updates/latest`), capital statements and issued fund
  reports (`GET /api/funds/lp-portal`) in one list, dated and newest first, then
  the count of deals offered (the dashboard's eligible total). No "new" badge,
  and the empty state says a failed report read looks like none.
- **Catalogue and default.** `services/studioModules.ts` now offers 10
  investor modules. The default (owner's pick A on D6126 question 1) is Needs
  you, Funds, Returns, Thesis fit, Arrivals, Upcoming events, Usage & quota
  and Deal lifecycle. Quick stats and Portfolio glance stay placeable;
  Historical match scores was retired by #6622, which drops it from saved
  layouts. This change removes no key, so every saved layout still loads;
  `studioFallback.js` mirrors the table. The home passes the dashboard read to
  the tiles again (#6622 had stopped), because Arrivals counts the deals
  offered from it.
- **States and preview.** Each module is loading, empty, Not recorded,
  Unreadable or ready in the module frame. An administrator's preview
  withholds all ten (D4362). #5129's shared state component is not on
  `main`, so the house words are used ("Unreadable"; the canvas draws the
  same word).

### Where the build departs from the canvas

- "9 of 12 placed": the default the canvas draws holds 8, so the page says 8 of
  12 (the cap), on a catalogue of 11.
- Needs you has no data-room access row. `GET /api/data-room/shared` carries no
  deal id, so the row could not open `/deals/:id`. That is a separate Worker
  issue.
- Needs you's half width shows every row in a compact layout, not four and
  "See all".
- Thesis fit's sub-line is the venture's sector and its stage in your flow. The
  flow read records neither the round's stage nor its region.
- Arrivals counts deals offered to you (the dashboard's total), not deals in
  your flow, so a plan below Investor Pro is not locked out of Arrivals.
- Voice rule: Thesis fit's footnote says "No score and no ranking" instead of
  "Not a recommendation". The module map has no "Recommended for you" group.

### Not built
