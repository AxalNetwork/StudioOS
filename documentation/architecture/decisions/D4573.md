### The decision

- **The memo.** `getCurrentUser` keeps the resolved caller on the request context, keyed on the raw credentials the request carries: the bearer token and the session cookie. `requireAuth` and `requireAdmin` go through it. A second token on the same context never reuses another's answer.
- **Only a user is kept.** A null answer is never cached, and neither is a throw. The next call in the request resolves again, as before H1. A null answer means:
  - no credentials;
  - a refused, revoked or relocked session;
  - a read that failed inside the resolution.

  So a one-off read failure cannot turn into a 401 for the rest of the request.
- **One request only.** Nothing is shared between requests. A session revoked, or a member deactivated, between two requests is refused on the next one.
- **Each caller gets its own shallow copy**, its licence list included. A handler that edits the user it was given changes nothing for another caller.
- **`forgetCurrentUser(c)`** drops the request's memo. A route that changes the caller's own user, session or side-table rows, and then needs the fresh answer in the same request, calls it first. None does today: a scan of every handler that writes `users`, `user_sessions`, `user_recovery_state`, `super_admins`, `mi_pro_subscriptions` or `user_licences` found none that resolves the caller again afterwards.
- **Unchanged:**
  - every check inside the resolution: the token, `jwt_min_iat`, the session's revocation, the step-up relock with its allow-list, and the Super Admin elevation;
  - the rate limit middleware's `currentUser` value, which the observability and last-active middleware still read;
  - every authorization outcome. The budget test pins each flow's status beside its counts.

### Tests

- **`cloudflare-worker/test/caller_memo_4573.test.ts`.** Each assertion is mutation-checked. It covers:
  - one read however many times a request asks, through `getCurrentUser`, `requireAuth` and `requireAdmin`;
  - separate copies;
  - no memo across requests, so a deactivated member is refused;
  - a null answer not kept;
  - `forgetCurrentUser`.
- **`cloudflare-worker/test/perf_budgets_4573.test.ts`:**
  - the budgets are lowered to the counts above;
  - the "known repeat" record is replaced by "every authenticated flow resolves its caller once".
