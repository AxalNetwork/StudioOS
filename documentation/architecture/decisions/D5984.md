## D5984 — One scrubbed GitHub bug per section incident episode (#5984)

Part of D5681. A producer that stored an episode in the D5979 outbox can call
`linkSectionIncidentIssue` with one of D5681's fixed cases and a
classification. Only `ordinary-ui-regression` on the case's own section can be
filed. Security, permission, credential, financial, contract and migration
episodes are refused before any GitHub call and stay in the restricted path
(D5680). The first classification is kept; a different one later is refused.

The public title, body and labels come from `scripts/lib/sectionIncidentIssue.mjs`,
the same template the operator CLI now uses. They hold the case name, its
section key, a count, the source and test paths, and a hashed episode marker.
The Slack channel and thread timestamp, the episode ID, the fingerprint and the
section slug stay on the outbox row. A test asserts none of them is in any
request sent to GitHub.

The episode row holds the link. A durable `filing` intent is written before the
create, which is sent once. A verified answer records the issue number, and
retries and reopened episodes return it. A 401, 403, 422 or 429 releases the
intent and waits. Any other answer leaves it in place, and while it exists no
episode files a new bug. An operator settles it with
`reconcileSectionIncidentIssue`, which requires the marker in the issue body.
Recurrence comments at powers of two above the filing count. An unconfirmed
comment is checked against its receipt and never resent.

#5681's section-to-login map is still an owner decision. `sectionOwners` ships
empty, so every bug is filed unassigned for S01 triage. When the map is
decided, an entry is used only if its login and slot pass validation.

It uses the ticket mirror's `GITHUB_ACCESS_TOKEN`, `GITHUB_REPO_OWNER` and
`GITHUB_REPO_NAME`. It stays off until `AXAL_SECTION_INCIDENT_GITHUB` is
exactly `enabled`. While it is off, on a branch Worker, or without the mirror's
configuration, nothing calls GitHub. The variable is not set in any
environment. The HQ capacity cron runs the pass after the outbox drain. No
producer classifies episodes yet.
