`scripts/local-files.mjs` supplies explicit filesystem effects. Its operations
reject non-private state directories and final symlinks, and reject hard-linked
output files before truncation. New files are created with owner-only mode.
Regular-file edits read, write at offset zero, and truncate through the same
descriptor, so replacing the pathname cannot redirect the edit. Missing files
are distinguished from other access failures. Platforms without no-follow open
support refuse rather than silently falling back to an unsafe open.

Git metadata, with random private backup directories and exclusive journals.
Interrupted runs still restore source from their recorded backups. Operator
verification retains cumulative summaries at its new private default; an
