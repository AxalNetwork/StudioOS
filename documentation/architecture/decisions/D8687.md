### What the walkthrough found

- On desktop /login, Continue with Email → Email me a sign-in link, a prompt press said "Please complete the verification challenge first." with no challenge on screen. A later press of the same button, with nothing else done, sent the email.
- `TurnstileBox` renders with `appearance: 'interaction-only'`, so the widget is invisible while it runs, and handles only `callback` and `expired-callback`. `onFailed` fires only when the script is still missing after about 10 s; there is no `error-`, `timeout-`, `before-`/`after-interactive-` or `unsupported-callback`.
- `sendMagicLink()` refuses any press made before the token arrives (now L767), and Send is disabled only while sending. A widget error or a stall keeps refusing, with no retry. The code step has the same gate with nearly the same sentence (L709).
- `/magic/start` does no Turnstile check of its own (5 per IP per 5 min, 3 per address per 15 min, one delivery per token row under D8536); `/login` verifies Turnstile and fails closed.

### What the canvas decides

- The card and sheet, copy and login artwork stay as Sign In v2 ships them. One readiness line sits under the address and names who must act, in four states: **Checking readiness** ("An automatic check is running. Nothing for you to do."), **Ready to send** ("Check passed. You can send the link."), **Your turn** ("Cloudflare needs you to confirm you're human.", with the widget in a named group) and **Verification unavailable** ("The automatic check didn't finish. This isn't something you did.") (EML02 to EML05).
- Each Turnstile callback maps to one state and to Send, plus a 15 s no-answer timer; token expiry returns to checking (EML00).
- Send carries `aria-disabled` with the readiness line as its description until a token arrives. An early press sends nothing and says "Still checking this browser. You can send in a moment."; Sending ignores further presses, and Sent keeps the 60 s Resend, which stays ungated (#6959) (EML06).
- Unavailable keeps the typed address, with Try the check again (which remounts the widget through `turnstileKey`) and Use a different method next to each other (EML05, EML07).
- A script that never loads keeps main's rule, so Send stays on; when a visible challenge passes, focus moves to Send (EML07).
- Phone 390 in the existing sheet, each state with its announcement (EML08A to EML08F); focus order, headings, every live-region text, focus move and Send state, and states that do not rely on colour alone (EML09, EML09B); tests (EML10) and handoff (EML11). Sign-in forces the light theme, so there is no dark board. EML01 shows main today for comparison.
