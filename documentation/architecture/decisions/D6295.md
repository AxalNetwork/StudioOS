## D6295 — Find and answer diligence requests from Raise (#6295)

The Data room home and Requests tab link to the signed-in subject's requests
after a successful list read finds at least one. A badge counts requests
still waiting in the returned list. An unreadable list produces no badge.

Each project request projects the name and identifiers of the founder's own
venture. The answer form and empty file picker link to that venture's Files
tab. The endpoint retains its existing subject check and explicit fields.
When the requester has an invitation, commitment, or named partner role
on a shared deal for that venture, the card can name the deal-visible firm
or person. A case's linked deal narrows the check. Ambiguous names are omitted.
A request without a recorded sender remains unnamed.

Follow-ups include several files per answer, reply or decline, and answer
history.
