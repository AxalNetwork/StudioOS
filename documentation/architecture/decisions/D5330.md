## D5330 — Working here on founder modules

Founder module headers show Working here when the project roster contains a
Team. The sheet reads the module's agents and tasks using the existing clients.
It joins named Team members to task assignees by UID and uses Work's existing
Team picker to assign a task, preserving its module on the write.

The roster's management capability gates assignment controls. Read failures
offer retry and missing readings remain unrecorded. Existing Worker switches
and write permissions still decide which operations are available.
