### 2. What is live, and what waits

**One read is live:** `GET /api/teams/skills` (D1612 A1, `routes/team_skills.ts`), through the new client method `teamAgentsApi.axalSkills`. Its `hq` list is the "From Axal" skills. It drives:
- the Skills library count on the tab;
- SA3's area tiles and the skill table (name, area · level from the tags, version · status, agents using it, tools);
- the editor's read view of one skill;
- SA0's "Skills published" tile.

A failed read says **Could not be read · Try again**, never an empty library.

Everything else draws its board's frame and says **"Not switched on yet"**, naming the task that switches it on. No control is drawn enabled that the Worker would only refuse:

| Board | Waits on | Drawn now |
|---|---|---|
| SA0 tiles except Skills published; Needs attention; spend by area | H5 #4163 | Each tile reads "Not recorded", never 0. |
| SA1 Roster, SA2 agent detail | H1 #4158, after #4117's catalogue (#4144 / #4148) | The columns and the rules (values fixed; hide and retire take a reason). |
| SA3 bulk actions, golden cases, last eval; SA4 editor and review | H2 #4160 | The buttons are disabled with the reason; the columns read "Not recorded". |
| SA5 Company skills | H3 #4161 | The columns and the rule that HQ never edits a company's skill. |
| SA6 Policies, SA6b the kill switch | H4 #4162 | The three guardrails and their checks; the caps as "Not recorded"; the Pause form (reason, type PAUSE) with its button disabled. |
| SA7 Runs, SA7b Spend, SA8 Audit | H5 #4163 | The columns. Spend links to Platform › AI usage, which has members' AI spend today. |

`aiAgentsModel.js` holds every word and rule, tested now, so wiring a task changes no copy:
- `BUILD`, with each task's issue and `live: false`;
- `viewFor`, mapping each address to its board;
- `shown`, so "Not recorded" is never a 0;
- `skillRow` and `areaTiles` from a D1612 card;
- the guardrails;
- `pauseArmed`: the exact word PAUSE and a reason of at least 10 characters.

When a task lands, its builder flips `BUILD[key].live` and wires the read in the same PR.

### 4. Rules carried from the brief

- People by name, never email.
- "Not recorded" is never 0.
- Never "advisor" or "advice" on AI surfaces.
- Agents propose; a named person accepts.
- Every change needs a reason and is audited.
- Values are fixed.
- No job titles for agents.
