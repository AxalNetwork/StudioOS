## D5919 — Licence ledger filter menus (#5919)

Part of #4819; builds the remaining L01/L02 filter menus from D4819.


Territory, Renewal window and Attention are built as the canvas draws them on L01 and L02. They sit beside Status in the ledger's tools (`LedgerMenus` in `licences/LedgerTable.jsx`; `filterByMenus` and its parsers in `licenceLedgerModel.js`).

- **From the reads the ledger already makes.** Each menu filters the loaded rows. Nothing new is read. If more pages are unread, a line says the filters apply to the loaded rows, and Show more filters the rest. This is the same scope rule as Needs HQ.
- **Territory.** The options are Every territory, each country the loaded rows hold, and No territory. A linked country no loaded row holds stays in the menu, so the link still means what it said. A row whose territories could not be read matches neither a country nor No territory.
- **Renewal window.** The options are Any renewal, Overdue, Next 30 days, Next 90 days, Later than 90 days, and Not recorded. Overdue and the windows read only running licences, as the Renewal column does. Not recorded is a row with no renewal date.
- **Attention.** The options are Any attention, Needs HQ, Nothing needed, and Unknown. They use the Attention column's own rule (`attentionOf`: a renewal approaching, or requests waiting).
  - **Nothing needed** is only a row whose reads all answered with nothing to do.
  - A row whose requests could not be read, or are still being read, and that has no known item is **Unknown**. It is never counted as nothing needed.
- **In the address.** The menus write `?territory=`, `?renewal=` and `?attention=`, so a link reopens the view. Each one combines with the search, the kind, the status and `?needs=`, and two menus narrow together. A value the menu does not know is dropped.
- **Hidden at zero.** The menus are drawn in the populated ledger's tools only, so at zero licences they are hidden, as search and the status filter are.
- **Keyboard.** The menus are native `<select>` elements, each with an `aria-label` and a visible `focus-visible` outline.

Tests: five tests appended to `frontend/test/licences_ledger_d4819.test.mjs`.

- The model: each option, unreadable territories, and Unknown versus Nothing needed, both after a failed read and while reading.
- The menus are hidden at zero licences.
- Each menu filters the table and writes the address; a link reopens the view; clearing them restores every row.
- A failed requests read is Unknown, never Nothing needed.
- The menus are native selects with labels and focus rings.
