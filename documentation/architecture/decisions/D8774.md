### What the walkthrough found

- Overview and Operating systems both said "This project has no company scope for connectors.": with no `projects.company_id`, every part of `operating()` and `codeSystems()` in `cycle_build.ts` returns that reason.
- Connect a tool's `companyBanner` said "This project has no company, so connected tools cannot feed it.", yet for scope state `none` `toolRow` still drew GitHub as Connected, "Feeds <registry list>" and an enabled Disconnect. `servesCompany` and "Use for {company}" run only when there is a company.
- The only writer of `projects.company_id` is `POST /projects/:id/move` (owner or admin, owner a member of the company). Its UI lives only in Account › Companies (`MoveVentureDialog`) with no way back to Build, and `CompanyNotLinked` sends the founder to Company Creation instead.
- Sync log lines carry time, state, repositories and arrivals but no project, so no page can say when this venture was last read.

### What the canvas decides

- One ladder names the three scopes main already records: the connection on your account, the company it is turned on for, and the venture's company with its chosen repositories. A module is said to receive data only when all three hold (BLS00, BLS01).
- With the venture in no company, the GitHub row reads "feeds nothing in [Atlas Orchard] until it is in a company", Disconnect moves into Details, and the one primary action is Link to a company… (BLS01).
- The owner links the venture inside Build on the existing move route and returns to `/build/connect`, then Use GitHub for {company} and Choose repositories, with "What will feed after sync" showing no counts (BLS02, BLS02B, BLS03).
- Healthy shows the last successful read of the venture (date, source, repositories) and each module's count, with No items as a measured zero; failing shows Sign-in expired, Stale with its age, and Reconnect (BLS04, BLS05).
- A co-founder is told that the owner must link the venture; Operating systems › Tools has a read-only view (BLS06, BLS09).
- Stopping is Scope → Review → Result: "Stop using for {company}" first, and an account-wide review that names every company the connection serves (BLS07, BLS07B).
- Five states are drawn across Overview, Connect a tool and Operating systems, plus loading, unreadable company, non-member refusal, `slug_taken` and 409, repository refusals and Super Admin preview, and the phone route at 390 × 844 (BLS08B, BLS10, BLS11A–F).
