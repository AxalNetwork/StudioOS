### 1. What goes out

A saved version, as its version read gives it. It is never the unsaved words in Story: the dialog says so when
Story holds unsaved changes. Version 0, the live deck, has no export.

The first two lines name the export: `Investor narrative · v4`, then
`For seed fund · exported 15 Nov 2026 · revision 7`. An audience nobody recorded reads "an audience not
recorded".

The sections go out in order. A section that is Not recorded is left out, and the checklist names it as left out.
It can never be ticked back in. The positioning one-liner leads when there is one. Audience notes and sources go
out only when chosen.

**Bound figures go out as the page shows them at export time.** A figure inserted into the words (D1114) is
already in them. A bound figure whose value is not in the words is listed under its section, with the record's
current value, source, date and grade. This happens when it was never placed, or when the record changed since
the figure was inserted. A record with no value reads "Not recorded", never 0. When the bindings could not be
read, none is listed, and the export says so.

### 2. Formats

- **Copy text:** the clipboard. When the browser blocks it (RAN27e), the text is shown selected, with how to copy
  it by hand.
- **PDF:** drawn in the browser on jsPDF, as the decision memo and the persona are, on Letter pages. Every page
  carries the watermark (owner pick A on #6067): `Investor narrative v4 · exported 15 Nov 2026 · page 1 of 3`.
  The PDF prints the same blocks Copy puts on the clipboard. The deck's own PDF pipeline renders a deck's print
  page in a browser on the Worker (`deck_exports.ts`, `pdfExport.ts`). It has nothing a narrative's text needs,
  and the canvas's "needs backend" for PDF is met by recording the export, below.
- **DOCX:** shown and not offered ("Not available yet"). Nothing in the repo writes DOCX, and this PR adds no
  dependency for it. It is a question on #6070.

### 3. Each export is recorded first

`POST /api/narrative-exports?project=` with `{ version, format: 'pdf' | 'text' }` writes one `activity_logs` row
(`raise.investor-narrative`, the version as `entity_id`):

- `narrative_exported_pdf`, "Exported v4 as PDF";
- `narrative_copied_text`, "An admin copied v4 as text under read 12".

The row names no words, no figure and not the reason's text. The page makes the PDF, or an admin's copy, only
after this answers 201. A log that cannot be written is a 503 `export_not_recorded`, and nothing is made.

`GET /api/narrative-exports?project=` lists the newest 20, which the dialog shows as its export log. A log that
cannot be read is a 503, never an empty list.

The founder's own Copy text is not logged, as the canvas draws it ("Copy is not logged"). That is the canvas's
open question, carried on #6070.

### 4. Who

The narrative read's rule: the venture's founder or another writer (`canWrite`), and an admin with an unexpired
read reason (`narrativeAdminGate`, D914).

An admin copies the text only (owner pick A on #6067), and the copy is recorded with their read before anything
reaches the clipboard. Their PDF is refused: 403 `admin_copy_only`. Story offers an admin "Copy text" and the
founder "Export and copy". Anyone else gets a 403.
