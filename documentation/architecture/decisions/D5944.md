## D5944 — Advisory negotiation lane limits (#5944)

Part of D4838. Each partner firm can set a separate limit for scoping, terms,
legal and ready to sign. The limit belongs to the caller's verified partner
firm and follows that firm across its company filters. Only the roles already
allowed to write its negotiation pipeline can change the limits.

`GET /negotiations` includes all four keys in `wip_limits`. A missing row is
`null`, while a stored zero means the lane has no capacity. A whole number
sets one lane through `PUT /negotiations/wip-limits/:stage`. Sending
`{"limit":null}` clears it. Closed negotiations have no limit.

Moving a negotiation never consults these limits. The board can use them when
it draws its lane headers.
