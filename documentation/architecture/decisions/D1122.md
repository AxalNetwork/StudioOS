### Built

- `AdminPageHeader` keeps a single copy of each action. A responsive grid
  places the action under the line across the phone width, while More stays
  beside the title. Desktop keeps title and actions together.
- More uses the existing `Lightbox` with `phone="sheet"` below 640px, including
  its backdrop, inert background, scroll lock and focus return. Desktop keeps
  the small menu. Tab/Shift+Tab wrap within the menu; arrows, Home/End and
  Escape work, and action selection returns focus to More.
- Header rows account for the absent breadcrumb on section overviews, so
  scope, facts, notices and tabs stay below the title. The initial Claude
  review independently confirmed this edge case; the corrected layout was
  checked in the desktop browser (title top 18px, facts 101.5px, scope 128.75px,
  notice 166px, tabs 230px) and at 390px in dark mode.
- Tabs retain horizontal scrolling, with a masked edge and enough end padding
  to bring the final tab clear of the fade. Notice Dismiss has a 44px phone target.
- Billing explicitly supplies the `HQ only` pill. Other console wrappers do
  not infer this label from the viewer's role. The existing route's Super Admin
  guard remains authoritative; the pill grants no access.
- Retired the 1,286-line `LegalConsole.jsx`, which no route or product file
  imports. Retired its dedicated mounted tests and signed-document toast case,
  removed it from source and route test inventories, and updated the console
  README. The routed Contracts desk, its registry, redirect and tests remain.
