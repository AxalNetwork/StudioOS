## D4619 — Founder Studio keeps each read to its venture, and IRR is drawn as a percent (#4619)

- **Status:** Built for #4619 (Studio audit 1/5), 2026-11-09. Frontend only.
- **Builds on:** D564 (the founder Studio), D1419 (its cycle modules), #4622 (each read committed as it settles), D321 (the investor Studio's honest states).
- **No migration. No Worker change.** The IRR solver in `cloudflare-worker/src/services/portfolioMetrics.ts` is unchanged.
- **Not in this decision:** the investor access review named in #4619. The owner holds it in the private process in `SECURITY.md`; this PR is "Part of #4619" and the issue stays open for it.

### What was decided

1. **A cycle read belongs to one venture (`frontend/src/pages/founder/useFounderCycleReads.js`).**
   - The founder Studio's per-cycle overview read moved out of `FounderStudioHome.jsx` into its own hook, so a test drives it.
   - The stored answer and the request in flight use the same key: the venture read's state, its ID and the cycle.
   - The page is handed only the answers for the venture it shows now. When the venture changes, every request for the old one is obsolete and nothing read for it is kept.
   - Each request carries a token, and its success or failure commits only while it is still the latest request for its key in the current context. A late answer for venture A after B is selected, a superseded Retry, or an answer after unmount changes nothing.
   - A → B → A asks again for A; B's answer is never drawn under A.
2. **A supplied venture the member cannot open is not swapped for another (`founderStudioReads.js`).**
   - When `project_id` names a venture that is not in the member's projects, the venture read settles as `unavailableProject(id)` (`founderStudioModel.js`): a failed read that says "This venture is not available to your account." and carries the ID.
   - The lifecycle, the scores and the cycle reads say the same and are not requested, so every zone that depends on the venture is Unreadable, not another venture's figures.
   - `FounderStudioBody` draws the unavailable state (`status-founder-project-unavailable`) with a link to Studio without the ID.
   - The first accessible venture is chosen only when no ID was supplied (absent or empty).
3. **One formatter for a fractional rate (`frontend/src/lib/rate.js`).**
   - `formatRate(0.1)` is "10%", `formatRate(-0.25)` is "-25%", `formatRate(0)` is "0%". At most one decimal is shown.
   - A missing or non-numeric rate is `null`, never "0%": the caller draws its own Not recorded (the investor Studio's Portfolio at a glance) or "—" (Portfolio performance).
   - The investor Studio's IRR row used to append "%" to the fraction, so 100 invested and 110 NAV a year later showed "0.1%". It now shows "10%". Portfolio performance's IRR uses the same formatter (it already multiplied by 100; it now drops a trailing ".0").
   - TVPI and MOIC stay multiples.
