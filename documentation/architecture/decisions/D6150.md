### What the file holds

- **Rows:** every row the filters and search match, in the table's sort. It
  writes the page's `shown` rows, not the current page of 25.
- **Columns:** Venture and Sector, then the visible columns in the table's
  order (My stage first). Hidden columns are left out.
- **Scores:** the band with its confidence in words, e.g. "Strong, high
  confidence" or "Low risk, medium confidence". There is never a number: the
  batch read sends bands only, which is the owner's answer on #5900.
- **Scorecard:** how many scopes are scored, e.g. "3 of 11 scopes scored", or
  why there is no scorecard.
- **Absence:** each absence keeps its own word, the one the table uses. It is
  never 0, blank or "—".

  | Case | Word in the file |
  |---|---|
  | Score absent | Not scored, Not enough recorded, Not expected yet, Locked, Not shared or Unreadable (a failed batch is Unreadable) |
  | Fit absent | Thesis not set, Not shared or Unreadable |
  | Ask absent | Ask not recorded |
  | Days, owner or entry missing on a flow row | Not recorded, or Unassigned for the owner |
  | Round not on the member's deals | Not on your deals |

- **Money:** the whole figure with its currency code ("1,500,000 USD"), and the
  instrument when there is one. A missing currency is said, never guessed.
- **Rows the investor may not open:** they carry only what the table already
  shows. No note, pass reason or deal link is written for any row.
- **Formulas:** a cell starting with `=`, `+`, `-`, `@`, a tab or a carriage
  return is written as text, behind a `'`.
- **Writer:** `lib/csvExport.downloadCsv` (RFC 4180 quoting, CRLF, a BOM for
  Excel).
- **File name:** `deal-flow-<saved view name, else my-deals or all-deals>-<YYYY-MM-DD>.csv`.

### When it is offered

Export CSV sits under View settings in the Table view; the board has no table
to export. The button stays visible but disabled in each case below. Its reason
shows on hover and as the line under the button:

- the scores are still being read, or could not be read, and a score column is
  visible;
- the fit is still being read, or could not be read, and the Fit column is
  visible;
- no row matches.

A column the file does not write never holds the export back.
