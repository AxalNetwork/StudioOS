## D8760 — Match model inventory names literally (#8760)

This change addresses grouped trackers #8760, #8761, #8762 and #8739.
Finding evidence remains in their protected Code Scanning links for
authorized reviewers.

The inventory reads declarations with fixed expressions and compares their
names as data. Price-table and constant identifiers may include dollar signs;
similarly named declarations remain distinct. Accessor discovery preserves
the existing word-boundary rules. The generated inventory for the current
source tree remains unchanged.

Focused regressions cover declaration selection, literal keys and accessor
boundaries. The trackers stay open until the fix merges and a subsequent
scan confirms the associated alerts are fixed on `main`.
