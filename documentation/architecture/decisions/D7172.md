### The one Worker change (the ◇ of D7037)

`GET /api/research/listed-companies` adds `in_both`: how many tickers in **this** result, across every page, have a row from each source. The matched signal companies' symbols go in as one bound JSON array (`json_each`), EDGAR's rows are held to the same search, and the count is `COUNT(DISTINCT ticker)`. A ticker counts only when both of its rows are in the result: a search that reaches EDGAR's row by name but not the signal company's does not count it. It is 0 when a Source choice, a sector or a country leaves a source out. A failed read is the existing 503 `listed_companies_unreadable`. The store-wide `sources[1].also_signal_companies` is unchanged.

### What the page does

- **Two tabs, in the URL.** Market directory and Listed companies (`?tab=listed`). Government ownership is a Not recorded note beside them, not a tab (D537). Arrow keys, Home and End move between the tabs; there is one Tab stop.
- **The URL contract (RML-00).** `tab`, `q`, `source`, `sort`, `country`, `sector`, `page`, history replace, with defaults left out. Any change but the page returns to page 1. `q` and `sort` are shared with the directory, as the contract says; a sort one tab does not know falls back to that tab's default. Switching tabs changes only `tab`.
- **Listed companies (`ListedCompaniesPanel.jsx`, `listedCompaniesRead.js`).** "Search name or ticker" (it updates after a pause, Enter commits at once, Esc clears). A Source radio group (All sources, Signal companies, SEC EDGAR) and a Sort select (market cap or name, either way). The count of listing records in the result heading, with each source's share and `in_both`. One row per source, each with its source chip and link ("No link recorded" for a signal company), and "Same ticker, 2 sources" on both rows when the pair is on the page. Details per row. Columns that no row in view records fold into one line, and "Show folded columns" brings them back. A view of SEC EDGAR rows only gets CIK and Other listings columns. The pager, and the two source captions.
- **Focus (RML-09).** After Previous, Next or Retry, the result heading takes focus once the rows arrive. Clear filters focuses the search field.
- **States (RML-08).** Loading ("Counting…" and a skeleton), matches, no match with Clear filters, a failed read (Unavailable, with Retry, and the search kept), nothing recorded yet (None), and retrying ("Reading again…").
- **Country and sector (RML-05).** Read from the URL and sent to the Worker. While either is on, SEC EDGAR is struck through in the Source group with its reason, the heading says "Signal companies only", and the sentence says why EDGAR is left out. Chips remove each filter, and Clear filters removes both.
- **Exports (RML-04B, RML-06, RML-07).** Each is the active tab's own, and it carries the same label and click in the zone's header row (`zoneActionBuilder`'s `view.scoped`) as beside the count.
  - "Export this page · N rows" writes the rows on screen, in the order shown, with all 13 columns of RML-07, folded ones included. The file is `listed-companies-page-<p>-<n>-rows-<date>.csv`.
  - "Export filtered markets · N rows" writes every market the search matches, in the view's sort. When the page's one read holds the whole directory, these are the rows on screen. When it does not, the count is the Worker's `total` for the search, and the file pages `GET /api/research/markets?q=&sort=&dir=`.
  - Loading, zero rows and a failed read each say so in the label and offer no file. Completed names the file. Error ("The file could not be created in this browser.") offers Try again.
  - Before this build, the zone's Export always wrote the first 100 markets read, unfiltered, on either tab.
- **Phone (RML-10).** Below 1024px (the shell's phone rule): cards with company, ticker and source first and the rest behind More details; a sticky bar with Previous / Page p of P / Next and the export; the Filters sheet (Source and Sort; Apply returns to page 1; Reset).
- **Dark (RML-11).** Every surface carries its `dark:` pair. The source chips tell the two sources apart by a filled or outlined letter, not by colour.
