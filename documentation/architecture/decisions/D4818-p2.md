## D4818 part 2 — the interactive checks, run on the built Overview, Positions and Performance (#4818)

**Status:** built by S14, 2026-11-16. D4818's checklist was prepared before anything was built; #5311 has since landed PF-01 (Overview), PF-02 (Positions) and PF-03 (Performance). This part runs the checklist's items that apply to those three boards in a real browser, fixes what failed, and holds the passes so they stay passing. The other boards (Reports, Value-add, the company workspace, the financial actions and the admin preview) are not checked here; they come in later parts.

**How it ran.** `frontend/tests/visual/portfolio.a11y.spec.mjs` runs against the built SPA in Chromium, signed in as an investor. `_portfolio.mjs` answers every `/api` read with made-up data in the shapes the node suites already pin. The bar is the Approvals and Fund Admin passes': zero serious or critical axe violations (WCAG 2.0, 2.1 and 2.2, A and AA) in Portfolio's own frame and in any dialog it opens. The app shell around the frame is not scanned. Widths were 1440, 1280, 834, 390 and 320, in light and dark mode. 18 checks; each one is listed below.

### What failed, and the fix

1. **Dark mode, the primary button (Overview, Positions' Apply date).** White text on the dark-mode violet `#a78bfa` is 2.7:1. `portfolio.css` now draws dark ink (`#0f0e17`, 7:1) on it in dark mode, as `writeFlow.css`'s primary already did.
2. **Positions, the mark-date button (WCAG 2.5.3, label in name).** It showed the date ("31 Mar 2026") but announced "Mark history for Northwind Labs", so a speech user who said what they saw could not press it. The name now starts with the visible text: "31 Mar 2026, mark history for Northwind Labs" (or "Not recorded, mark history for …").
3. **Positions at 834, the mark date and Request… (WCAG 2.5.8, target size).** Below the phone breakpoint both are inline text, and they sat close enough that a tap could hit either one. Each is now a 24 px target with space between them at every width, and stays 44 px on a phone.

### What passed as it was

- **Reflow:** no board scrolls sideways at 1280, 834, 390 or 320. Tables scroll inside their own cards.
- **Landmarks:** one `main` (the app's), none inside the frame; one H1 per board; the local navigation is named and carries all five destinations on every board.
- **Title:** each board sets its own document title (Portfolio, Positions · Portfolio, Performance · Portfolio).
- **Skip link and keyboard:** the skip link is visible when focused and moves focus to the content. Tab then reaches Overview, Positions, Reports, Performance and Value-add without opening Eadwyn, and each shows a visible focus ring.
- **Phone targets:** at 390, every local navigation link is at least 44 px tall.
- **Read recovery:** with the performance read failing, the Overview's other panels still stand (the company table keeps its rows). The failed panel offers Retry, and Retry asks for that read alone.
- **Sheet:** Positions' mark history opens from the keyboard. Tab stays inside the sheet, Esc closes it, and focus returns to the mark date that opened it. axe is clean with the sheet open.
- **Chart alternative:** Performance's quarter-end chart has a labelled table beside it.
