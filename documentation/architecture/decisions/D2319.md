### Policy

Retire only redirect-only addresses with zero opens. Keep every existing
`keep: true`, all five used addresses, every explicit forward, and all fixed
`ADMIN_TAB_REDIRECTS`. Role-specific forwards stay: those addresses still
render real pages for other roles and are not redirect-only entries.

D1440 requires keeping `/lp/founder`, `/lp/customer-discovery`, `/lp/investor`
and `/lp/partner`; each now has `keep: true`.

### Outside-link audit

Searched the email services (including their subfolder), all templates and
textual files under `frontend/public`, then checked Worker-generated links.
A Gmail API URL containing `/messages`, a source import containing `/services`,
and the service worker's `/api/projects` cache comment are not application
links and do not exempt the similarly named aliases. Historical release-note
mentions alone are not live outside links either.

| Additional protected address | Evidence |
|---|---|
| `/dashboard` | Shipped `frontend/public/manifest.webmanifest` shortcuts, including its inbox shortcut. |
| `/refer` | `routes/refer_earn.ts` sends this link through the email channel. |
| `/wellbeing/expert-dashboard` | `routes/wellbeing.ts` uses it as Stripe return/refresh URLs; `services/wellbeing/expertReview.ts` sends it through email. |

These outside-link exceptions also receive `keep: true`. Existing settings,
notifications, ticket-id, support, pricing, OAuth and cohort-notice exceptions
remain. The Grid health page at `/admin/platform/decks/grid` remains; only
its unused `/admin/ai/deck-grid` alias is retired from `routes/hqDecks.jsx`.

The matching routes and beacon keys are removed together. A retired address
no longer silently redirects; normal route matching and fallbacks apply and historical analytics rows are unchanged. Real
destinations, role-gated pages and email/signed/callback links remain.

The home module counter still read two historical shell zones at
`/raise/capital-match` and `/grow/brand`. It now counts their live canonical
tools (`/raise/capital-relationships/match` and `/build/brand`) in the same
set, preserving deduplication without counting unmounted aliases.

The cycle-overview DTOs also emitted the retired Tools, Calls and Updates
addresses. They now link directly to Operating systems (`#tools`), Capital
relationships › Calls and Reporting, preserving the project query.

tests of canonical destinations and of the retained forwarding helpers remain.

exported for their isolated contracts, like the existing HistoryRedirect export;
none is mounted at a retired address.
Commands and mutation results are recorded in the PR. No deployment was made.
