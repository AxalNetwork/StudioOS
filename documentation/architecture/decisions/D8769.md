### What the walkthrough found

- The roster's action was named by the agent's motto. `AgentsCard.jsx` labels ⋯ "Actions for the {roleOrUnrecorded} agent", sets `aria-haspopup="menu"` but opens the profile, and its pill reads only `status`, so an agent shows Active when the team's engine is off or it has no skills.
- The profile put story and values ahead of permissions, skills and cost: `AgentProfileSheet.jsx` runs persona card, story, values, permissions, budget, proposals, activity, and `AgentSkillsCard` comes after all of them.
- The wizard searched 16 personas by name, let a zero-skill setup through, and ended on a flat list of model ids priced per 1M tokens. Step 2's `ready` is always true; the hold reads Not recorded because the models carry no `hold_microusd`; `SkillsStep` calls `draftCostEstimate` only once a model is set, which happens a step later, so the per-run estimate `runCost.ts` already computes (D4121) never shows. Models the team's allowlist (D4422) refuses at add are still listed.
- Coverage claimed every agent category had a person when all eight rows were empty: `TeamCoverageCard.jsx` prints "Every category with an agent on it also has a person on it." whenever there is no people gap, and draws nothing while loading.
