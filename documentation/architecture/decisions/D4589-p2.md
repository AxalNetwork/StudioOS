### What D4589 left for later

Part 1 said that when #4585 (the evidence contract) and #4586 (methodology v2) landed, only the fact readers would change. Both have since landed. This part checks each reader against them.

### Claims: already on v2, no change

`claimFacts` reads `claimsOf` (`services/cycleValidate.ts`), which scores each claim with `verdictFor`. Since D4586 part 3 that is `claimStatusV2`. It scores the population D4585 names as the status basis: interviews reached through pain links (`status_basis: 'interviews'`).

D4585 keeps directly linked interviews, signals, metrics and experiments out of a claim's status until that policy is decided. The next-action policy therefore reads the same statuses as the Experiments list and the board, and it must not count more.

The reader is unchanged. Its comment now says this, and two tests pin it:

- A claim at the bar with material contradiction is `contested`, which is not decided. It asks for a next test (rule 6), never for a decision (rule 7). v1 read the same counts as validated.
- A missing fit that cannot change a supported status leaves the claim decided (D4586 § 3).

### Results: one definition of "observed"

`resultFacts` used its own SQL test, `TRIM(e.result) = ''`. SQLite's `TRIM` strips only spaces, so a result of a tab or a newline counted as observed here but not in `evidenceFor` or the decision's evidence bar.

It now selects done experiments on open claims in SQL and applies D4586 § 4's `experimentObserved` (`services/validateEvidence.ts`). That is the same test those two use, so the three cannot drift apart. Planned and running experiments are still not unfinished results.

### Wording: Not recorded, not "cannot be worked out"

When missing fits could change a claim's status, the claim's status reads Not recorded. Rule 4's why said "H1's status cannot be worked out", which sounds like a failed read. It now says "H1's status reads Not recorded until they do".

"Unavailable" stays only for a fact whose read failed (rule 0), as #4589's 2026-11-07 note asks.
