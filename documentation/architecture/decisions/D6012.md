## D6012 — Set the waitlist target from Demand signals (#6012)

Demand signals shows the saved waitlist target on desktop and phone. Venture
writers use the existing target endpoint to set or clear the value and
reload the chart. The empty state links to the landing-page builder, and
the tool list offers Lovable where it is connected.

If the target read fails while the rest of Demand signals is available,
writers can enter a replacement after seeing that it may overwrite an
existing target. Clearing requires a successful read with a saved value.
