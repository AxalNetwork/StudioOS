### 1. The model

- A **skill** is a named, versioned recipe for an AI agent:
  - a description and ordered steps;
  - taxonomy tags (a /studio `skills.slug` at a level: Aware, Working, Proficient, Advanced or Expert);
  - read-only tools (`*.read` only);
  - an output kind (a draft, a record change or a brief).
- **Roles:**
  - Each skill belongs to one or more **agent roles** from `services/agents/catalogue.ts`.
  - An agent can only be given skills of its own role.
  - What a skill produces is a proposal that a named person accepts, like every agent run.
- **Ownership:**
  - Axal curates skills ("From Axal"; written by a Super Admin).
  - A company's editors write or import their own ("[Company]'s skills"), readable only by that company's members.
- **Versions:**
  - Publishing writes an immutable version.
  - An agent pins a version, so editing a skill never changes a running agent. "Update to vN" moves the pin.
  - A retired Axal skill keeps working at its pin and says so.
- **SKILL.md** is the stored and exported format: YAML frontmatter (`name`, `description`, `roles`, `tools`, `output`, `taxonomy`, `version`) and a body of numbered steps.
  - A pasted SKILL.md is untrusted data. It lands as a draft, a write tool is refused, and nothing runs until an editor publishes it.
  - The frontend draws a SKILL.md as text, never as HTML.
- **The agent's radar** sits on the same 8 axes as a person's. Each axis is the highest tag level among the agent's skills, computed by the Worker (A2). With no skills it reads "Not recorded", never zeros.
- **Values** on the agent profile are the dimensions the company set in the role's rule book, on the /studio scale. Each is labelled "Set by [Company]" and never scored.
- **Team coverage** puts people and agents side by side on the 8 axes. An axis covered only by agents still reads as a people gap.

- The builder of A1 or A2 replaces only the body with `throughSkill(() => teamAgentsApi.<method>(…))` and adds the client method in the same PR.
- `throughSkill` maps the skill refusal codes to words (`skillRefusalWords`).
