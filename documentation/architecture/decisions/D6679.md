## D6679 — Narrow T2: name the source folders, and let a test edit that keeps its counts be T1 (#6679)

- **Status:** built. Part of #5600 (plan key F4). Amends the tier rules of
  D5607 in `merge-control/src/lib/classify.mjs`, the one classifier that
  `scripts/merge-policy.mjs` and the Merge Control Worker share (D5620).
- **Why:** #6469 measured the last 300 merges: T0 4.3%, T1 6.3%, T2 89.3%. The
  feeder (#6481) may queue only T0 and T1, so it would have covered 1 PR in 10.
  The owner chose option A on #6679.
- **Rule 1 — every source folder is named.** A file in any folder of
  `frontend/src/` (`brand`, `contexts`, `data`, `decks`, `hooks`, `lib`,
  `pages`, `routes`, `services`, `templates`, `ui`, `workspaces`; `components`,
  `icons` and `styles` stay T0) or of `cloudflare-worker/src/` (`agents`,
  `contracts`, `data`, `durable-objects`, `integrations`, `mcp`, `models`,
  `probes`, `routes`, `rpc`, `services`, `templates`, `util`) is T1. Its reason
  reads `T1: named source folder`. The protected rules run first and still win:
  `cloudflare-worker/src/middleware/` and every path whose name says auth,
  session, permissions, tenancy, billing, money and the rest of D5607's list
  stay T2. Files at the top of either tree (`index.ts`, `types.ts`, `App.jsx`)
  and a folder added later are still unmatched, so still T2.
- **Rule 2 — an edited test keeps its tier if it keeps its counts.** A modified
  test file (`*.test.*`, `*.spec.*`, `test_*.py`) with a readable diff is T1,
  `T1: edited test, counts checked`. The existing rules still raise it to T2
  when it loses a `test(`/`it(` call or an assertion, or gains a skip, todo or
  only. Lines the diff does not touch count the same before and after, so the
  diff's counts are the file's. These stay T2:
  - a helper, loader or fixture in a test folder (`test helper or fixture`);
  - a test edit with no hunk to read, or a copied test (`existing test without
    a readable diff`);
  - a deleted or renamed test, a timeout change, a baseline, ledger or shard
    change.
- **The landing bot stays off existing tests.** `pathGuard` in
  `scripts/landing-bot/rules.mjs` classifies paths with no diff, and an
  existing test with no diff is T2, so a bot still may not write one.
- **Not changed:** the protected list. Option B's README rows follow
  #6470 and #6472.
- **Measured** with `scripts/merge-policy.mjs`'s `changedFiles` over the same
  300 first-parent merges as #6469 (2026-11-10 22:12Z to 2026-11-14 21:00Z,
  ending at main `97fb0080e4`). The "before" column reproduces #6469 exactly.

  | Tier | Before | After |
  |---|---|---|
  | T0 | 13 (4.3%) | 13 (4.3%) |
  | T1 | 19 (6.3%) | 93 (31.0%) |
  | T2 | 268 (89.3%) | 194 (64.7%) |

  The feeder's eligible share (T0 plus T1) goes from 32 (10.7%) to 106
  (35.3%). 74 PRs moved from T2 to T1; none moved anywhere else.
  What keeps the 194 in T2 (a PR can match several; "sole" means only that rule):

  | Rule | PRs | Sole |
  |---|---|---|
  | Protected path | 142 | 56 |
  | Timeout changed | 62 | 9 |
  | Test helper or fixture | 52 | 7 |
  | Unmatched path | 49 | 10 |
  | Test skip, todo or only added | 18 | 7 |
  | Test or assertion count dropped | 12 | 5 |
  | Test baseline or ledger changed | 10 | 0 |
  | Suite shard declaration changed | 2 | 0 |
  | No changed files | 1 | 1 |

- **Guard:** `frontend/test/landing_policy_6679.test.mjs`, which also walks
  the real folders so a new folder cannot be forgotten silently. The issue's
  three mutation checks each fail a test there:
  - `auth` removed from the protected names;
  - a dropped assertion recorded as T1;
  - an added skip recorded as T1.
