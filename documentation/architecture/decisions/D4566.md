## D4566 — Agent capacity A0: preview isolation is proved by identity, fail closed, before any hosted test (#4566)

- **Status:** built by S15 on `agent/claude-s15/4566-preview-isolation`. Not merged. No resource is created, nothing is deployed, and no production setting changes.
- **Parent:** #4554 (architecture), #3742 (agent product). Reuses D1528 (#3847, the runtime seam and its tests), #3851 (observability) and D4423 (go-live preparation).
- **Migration:** none.

### Decision

1. **Isolation is a comparison of identities, never of names.** `scripts/lib/previewIsolation.mjs` reads each environment's bindings from `wrangler.toml`, compares them with production's table, and compares them with the owner's read-only observation of the deployed preview. The identities compared are:
   - D1 id and name; KV ids; queue and DLQ names (across producer, consumer and DLQ tables);
   - the Workflow name, each Durable Object's owning script, R2 buckets, the AI Gateway slug and the Worker's own name.
2. **Missing evidence is unverified, and unverified is a failure.** Any of these blocks a hosted run:
   - a placeholder id, an absent observation field, or an observation without its token's permissions;
   - an unknown binding kind, which is unsafe rather than skipped;
   - a secret outside the internal allowlist (an allowlist, so a secret added later fails until reviewed);
   - live inference, or the browser used.
3. **Two checks.**
   - `check-preview-isolation.mjs --static` runs in `test:guards` on every PR. It fails when preview declares a production identity, or when production's `AGENT_ENGINE`/`AGENT_AUTONOMY` stop reading `off`/`manual`.
   - `--observed` runs before every hosted test. It exits 0 only on `isolated`.
4. **Preview's advisor AI Gateway slug is now empty.** It named production's `advisor-ongoing` gateway, which would share production's gateway logs, cache and rate limits. Empty is inert: calls go direct (`advisorGatewaySlug`). Preview is deployed by no CI job, so no running system changes.
5. **Fixtures are synthetic-only and cleaned by their marks.**
   - Every row carries `syn-<run>-` and every person an address at `synthetic.invalid`.
   - Ceilings: 10 tenants, 3 agents each (one per role), 5 tasks each; money is integer microusd.
   - Cleanup is idempotent and safe after a partial seed. It runs children first and touches only marked rows.
   - People kept for their append-only ledger rows are switched off and counted.
   - The fixture writer refuses without an `isolated` preflight under a day old.
6. **Two modes, no new engine.**
   - (a) The local simulator: the existing test world, with fake Workflow, queue and `agentRun`, through `AgentRuntime`.
   - (b) An owner-approved preview with its own resources and the inference stub.
   - Their results are labelled simulated, preview platform or production observation, never conflated.

### What this does not prove

That a hosted Workflow completed, a provider call succeeded, or any capacity was reached. Those are #4594's and #4567's evidence classes. Preview's D1 and KV namespaces are still placeholders, so today every hosted preflight reads unverified, which is correct.
