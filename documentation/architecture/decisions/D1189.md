- **Migration:** none. **New route:** none. **No address moved.**

### 1. The record's Feedback section shows the answer

- **Before:** Add feedback stored `answer` beside the objection (`services/raiseWriters.ts`), and the record's Feedback section (`services/records/raise.ts`) never read it.
- **Now:** the section selects `answer`, and each row is `feedbackRow`:
  - the objection, quoted;
  - then "Answer: …", or "No answer recorded" when none was written or it is blank;
  - then the day, when the row has one.
- **Unchanged:** newest first, twenty rows, and the section's Add feedback action.

### 2. Fit copy says sector focus only

- **Before:** Add investor's foot (`pages/cycles/forms.js`) claimed Fit read fund size.
- **Now:** it reads "Fit is read from their sector focus only." That is what `fundFit` (`services/raiseCycle.ts`) reads.

### 3. Investor match counts what its rows show

- **Before:** `/raise/capital-match` (`pages/founder/FounderGrowCapitalMatch.jsx`) counted a linked contact (`contact_id`) as a warm path, while every row's Path said Not recorded.
- **Now:**
  - `hasWarmPath` is a recorded `warm_path` that is not blank;
  - the stat, the Warm filter and each row's Path cell all read it;
  - a row draws its own warm path, or Not recorded;
  - the stat's note says "No prospect names a warm path yet" when none does.
- **The stat stays.** It now counts what the rows show. The page retires in part 6.

### 4. "Open in Contacts hub" opens the contact

- **The door:** the Raise pipeline drawer's link (`pages/RaisePipelinePage.jsx`) is `contactHubPath(contact.uid)`, that is `/network?tab=contacts&contact=<uid>`.
  - The uid comes from `GET /api/contacts/raise-prospects/:id`, which already returns it.
  - With no uid, the link is the hub as before.
- **The hub:** `ContactsPanel` (`pages/ContactsPage.jsx`) opens the drawer that `?contact=` names, through the existing `GET /api/contacts/:uid`.
  - A uid the caller does not own is refused by that route, and the refusal shows in the hub's own error line.
  - The Worker is unchanged.

### 5. The rail names Call for Capital and its history

**Changes** (`lib/railPages.js`):
- **`/raise/call`** is D686's Call for Capital lightbox over Raise's overview. Its alias now answers `Founder · Raise`, the board whose notes already name Call for Capital, and no longer Capital relationships. Its note no longer says "Log a call".
- **`/raise/calls`** is the history of Calls for Capital, on Capital relationships' Calls tab. Its note no longer calls it "a call with an investor".
