#### Column and API mappings

Grow keeps request/row keys `due_at` and `status` for the existing client.
SQL uses `due_date` and `completion_status`; TypeScript translates after reading,
without SQL aliases. Reads include seeded `source = 'auto'` events.

| Incoming kind (stored unchanged in `kind`) | `event_type` |
| --- | --- |
| governance | board_meeting |
| compliance | other |
| risk | risk |
| culture | culture |
| tax (legacy form) | franchise_tax |
| other (legacy form) | other |

For seeded events with no `kind`:

| `event_type` | API kind / label |
| --- | --- |
| board_meeting | governance / Governance |
| annual_report, franchise_tax, registered_agent, other | compliance / Compliance |
| risk, culture | risk / Risk, culture / Culture |

| Repeats body value (added by #1697) | `recurrence` |
| --- | --- |
| once / omitted | one_time |
| monthly | monthly |
| quarterly | quarterly |
| yearly | annual |

Part 1 keeps the existing body fields and always writes `one_time` for a new
obligation; #1697 adds `repeats` and `remind_days`. The annual column default
must never make a manually added one-off obligation recur.

| Stored completion state / due | API `status` / label |
| --- | --- |
| completed | done / Done |
| snoozed | snoozed / Snoozed |
| pending, due before today (UTC date) | overdue / Overdue |
| pending, governance, not past due | scheduled / Scheduled |
| other pending, not past due | upcoming / Upcoming |

| Existing form's incoming `status` | Stored completion state |
| --- | --- |
| done | completed, with `completed_at` and caller's `completed_by_user_id` |
| snoozed | snoozed, completion attribution cleared |
| scheduled, upcoming, overdue, draft, not_set_up | pending, completion attribution cleared |
| omitted on edit | preserve completion state and attribution |

All five read states can round-trip through PATCH. Due is required; missing
Add or Edit due returns 400, “An obligation has a due date.” A collision on
`UNIQUE(project_id, event_type, due_date)` returns 409,
“Another <kind> obligation is already due on <date>. Pick another date.”
A changed due date resets `reminders_sent_json` to `[]`; other edits preserve it.

Entity and jurisdiction follow `routes/compliance.ts`: use the project's
`entity_id`, look up the entity, and store its jurisdiction label; without an
entity or jurisdiction, store `Unspecified`. Do not store a jurisdiction id.
New events explicitly use `source = 'manual'`, and both `created_by_user_id`
and `created_by` identify the caller. Existing `canAccessProject` gates remain.

#### Canvas promise

Add obligation's footer, “Appears on the compliance calendar.” (CO:330), is

write or deployment was performed while building this change.
