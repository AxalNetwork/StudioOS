## D5218 — Reuse the deck renderer for template previews (#5218)

The preview component resolves a renderer by the template's registry key.
It uses the existing thumbnail's viewport-based mounting and fictional sample
data when the caller supplies no deck data. An unknown key has an explicit
unavailable state. The preview can render the cover or a selected slide.

New Deck's option model retains the renderer key, slide count, audience and
category from the existing methods response. Lock state stays separate from
preview rendering so callers can allow a preview on any plan.

The New Deck and Gallery mounts, saved-version previews and chooser behavior
remain part of the screen integration. The rendering test covers the shared
component independently of the layout.
