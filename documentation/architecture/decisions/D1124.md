## D1124 — Programs (D953) gaps: Refer & Earn's funnel, the Queue's referrer role and search, a program page's Download (CSV), webinars in a Learning program, and the Lab's tab doors

- **Status:** filed as #3004, part of #2371. Built by S12. No migration.
- **What it closes:** the D953 program pages' gaps, each drawn on the canvas but held back for want of a read.

### 1. Refer & Earn's funnel

- **Read:** `GET /api/refer-earn/admin/submissions/funnel` (admin). `referralFunnel(env)` in `services/referralSubmissions.ts` answers `{ stages: [{ key, label, count }] }` for Submitted, Under review, Qualified, In conversation, Converted and Reward issued.
- **The rule:** each referral counts at every stage up to the furthest it reached. The furthest stage comes from its status events and its current status together:
  - More info needed sits with Under review; Reward eligible sits with Converted.
  - A draft counts nowhere.
  - A rejected or closed referral keeps the stage it had reached.
- **Nothing recorded** is six real zeros. A failed read, or a stage with no count, is "unreadable", never a zero (`referFunnelChart`).
- **The page:** the Overview draws the funnel as bars, with its window line saying what it counts. The tags under it still count where referrals stand now.

### 2. The Queue: the referrer's role and a search on the Worker

- `GET /api/refer-earn/admin/submissions` gains two parameters:
  - `role`: one of founder, advisor, investor, partner, exploring or admin. Anything else is 400 `bad_role`.
  - `q`: up to 100 characters, else 400 `bad_search`.
- **The search:** lowercased and matched with `instr`, so `%` and `_` are literal. It covers the referred person, their organisation, and the referrer's name and email. Every value is bound. The list and its total apply the same clauses.
- **The role:** admin rows and the single read carry `referrer_role` (`users.role`). The page draws it as "[Name] · Founder" (`referrerLine`) in the column and in the dialog. The referrer's stated relationship (`your_role`) stays apart, in the dialog only.

### 3. A program page's Download (CSV)

- **Route:** `POST /api/admin/programs/:key/export` (admin), body `{ weeks }`.
- **Which programs:**
  - It is open for Mentor cohort access, Refer & Earn, Perks and Learning.
  - Another known program is 409 `nothing_to_export`; an unknown one is 404.
- **The rows** (`services/programExport.ts`): the catalogue read's figures and needs for that program, its joins per week where the catalogue counts them, and, for Refer & Earn, the funnel.
  - The file holds numbers only. A string value is never copied.
  - An unread block is a row reading "Unreadable" or "Not read here yet", never a zero.
  - A formula never starts a cell.
- **D893's rule applies in order:**
  1. `refusesCountsOnly` checks the file before it is stored (500 `export_not_counts_only`).
  2. The file goes out as an R2 FILES signed link (24 hours) or a data URL.
  3. One `admin_audit_log` row is written, `program_export`, holding the weeks and never a figure. If that row cannot be written, the answer is 503 `export_not_logged` and no link is returned.
- **The page:** the ⋯ menu on those four pages opens a dialog. It sends one POST and shows the link, or the refusal's sentence.

### 4. Webinars in a Learning program

- The contents route takes a webinar from D560's store (`learning_webinars`). A webinar that does not exist is `unknown_content`. The `webinar_not_built` refusal is gone.
- **The contents read** describes a webinar with its title, status, start and where it opens.
- **A learner's standing** comes from the host's attendance (`learning_webinar_registrations.attended`): attended, did not attend, registered or not registered, with `registered_at`.
  - A registration counts as activity on the program.
  - A webinar is Done when it was attended.
- **Who can open a program-only webinar:** a member enrolled in a published program that holds it can see it, list it and register for it (`enrolledSql('webinar', …)`, as for D558's other kinds). Nobody else can, and neither can a member whose enrolment was removed or whose program is a draft.
- **The picker** offers webinars and leaves out cancelled ones.
