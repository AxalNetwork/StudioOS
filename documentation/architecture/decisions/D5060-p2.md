## D5060 part 2 — Read lifecycle history for one user licence (#5060)

The Super Admin registry detail now reads D5058's `user_licence_events`
through its existing `eventsOf` reader. The licence UID fixes the scope even
when its holder has several licences. The response returns the latest 500
events in descending ID order as `history.items`.

A successful read can return an empty list. An older database without the
event store reports `not_recorded`. A failed history read reports
`unreadable` while the rest of the detail remains available.

The remaining UI work depends on #5059 for user-licence program entitlements.
Boards L36–L37 and CT-17–CT-20 landed in #5406.
