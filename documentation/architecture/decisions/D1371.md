## D1371 — The Pitch acceptance gate: one named revision, synthetic accounts, and "Not tested" until someone runs it

- **Status:** asked for by the owner (#3662). The harness, fixtures, live script and matrix were built by S33 in #3671 and merged on 2026-10-29. Its draft decision text was filed by S1 under this number.
- **Builds on:** D898 (the deck block model), D901 (the HTML and PowerPoint writers) and D1370 (preflight, used in the matrix).
- **Migration:** none. Tests, a script and documentation only.

### What was decided

A Pitch release is verified only at one named revision that contains every Pitch implementation task, and only when all of the following hold:

1. **The offline content-loss harness passes.**
   - What runs: `cloudflare-worker/test/pitch_acceptance_exports_3662.test.ts` and `frontend/test/pitch_acceptance_render_3662.test.mjs`, over `frontend/test/fixtures/pitch_acceptance_decks.mjs`.
   - What must pass: the complete, sparse and multilingual fixtures, and the harness must report exactly the lossy fixture's two dropped blocks.
   - What it checks: no reader-visible word goes missing from the HTML, the PowerPoint or the print page that the PDF photographs. An unrecorded figure reads "Not recorded", never 0.
2. **The live run passes.**
   - What runs: `scripts/pitch-acceptance-live.mjs`, against a synthetic test account the owner confirmed (`PITCH_TEST_ACCOUNT=synthetic`).
   - What a person checks: they compare the screenshots against PD1–PD28 and open the three exports in their own applications.
   - Exit codes: a run that is not configured exits 2, which verifies nothing and is never treated as 0.
3. **Every manual row is run** with test accounts and synthetic recipients. Admin preview alone never counts.

The rules around the matrix:
- **The matrix** is `documentation/operations/PITCH_ACCEPTANCE.md`. A row nobody ran reads **Not tested**, never Pass.
- **Blocking:** any export defect or content-loss defect blocks the release.
- **Evidence:** it holds no private production data. No real investor link is published and no message is sent. The live script creates no share and accepts no terms.
- **Who runs it:** the live run is run by hand from a machine that can reach `axal.vc`. An agent sandbox cannot reach it, and no workflow runs it.
