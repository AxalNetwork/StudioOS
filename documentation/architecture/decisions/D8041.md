## D8041 — Preserve literal rendered text in assertions (#8041)

Presentation tests flatten rendered markup before checking visible copy.
That normalization must preserve entity spellings deliberately written as
text while decoding the characters escaped by the renderer once.

Keep the existing local helper and decode ampersands after quote and
apostrophe entities. Tag separation and whitespace normalization retain
their existing behavior; production rendering and program content do not
change.

A regression renders actual React text containing literal and nested
entity spellings, ordinary quote/apostrophe/ampersand characters and words
in adjacent elements. It compares the normalized result with the original
text and expected word boundaries. Existing presentation assertions remain
unchanged.

Validation uses the complete affected suite, direct helper mutations and
correct/restored controls, plus the decision and folder guards. No shared
helper, dependency or workflow is added.
