## D1558 — The narrative coach and the "Deck ready to send" readiness item (#3805)

- **Status:** Built for #3805 (deck v2 C10, part of #3716), 2026-11-03, to the issue's final canvas revision (2026-11-01).
- **Builds on:**
  - D1114 (the section draft beside which the coach's route sits);
  - D1516 (A5, the narrative a deck is built from);
  - D1604 (The Grid's selection, `gridSelection.js`);
  - D4271 (the editor's `?card=` link).
- **No migration.** No board draws either piece, so the UI is the smallest that lets them be used: one panel beside Story, and the editor's link.

### What was decided

1. **"Deck ready to send" is computed, free, area by area.** `GET /api/cycles/raise/deck-ready` reads the venture's current deck version and lists what still blocks sending it, one row per area:
   - a card with no title (the row points at its heading area);
   - an empty text area;
   - placeholder text (`[…]`, "Lorem ipsum", TODO, TBD, XXX);
   - an image area with no image;
   - a figure no record backs: an unbound text area that states an amount or a percentage, or an unbound metric tile. A bare count ("two founders") is not flagged, and a bound area never is.

   No rows is `ready`; no deck is `no_deck`. A deck whose cards cannot be read answers 503 and is never called ready. `DataReady.jsx` is not used or extended.
2. **Every row deep-links to its card and Grid area.** The `href` is `/raise/pitch/edit?project_id=…&card=<uid, else place from 1>&area=c<c1>-<c2>r<r1>-<r2>`. `PitchEditor.jsx` opens the card through `cardFromLink`, which takes a uid first and then D4271's place. It then selects the area once through `areaFromLink`: the area with exactly that range, else an area id, else the area that holds the range's top-left cell. A link that matches nothing selects nothing.
3. **The coach returns findings, never a conversation.** `POST /api/cycles/raise/narrative/:version/coach` is one `rail_write` run under the new rail option `review:narrative-coach` (job DK8, deck review, the same job as Check wording; page "Founder · Raise · Investor narrative"). It reads the version's sections and the current deck's cards with every figure masked (`maskFigures`), and answers findings: `missing`, `unclear`, `contradicts` or `order`, each with a message and a proposal. There is no thread and no composer.
4. **A finding is kept only when it checks out.** Its section must be one of the narrative's, its card (when named) on the deck, and its area on that card. Only `missing` may name no card. Its message and proposal may hold no digit, no masked figure, no link and no promise of a return. Anything else is counted in `dropped` with its reason. A kept finding that names a card carries the same `href` as a readiness row.
5. **Nothing is written.** The founder changes the deck in the editor or the narrative in Story. Version 0 (the live deck's wording) is refused (409), a version with no words is 422 `nothing_to_read`, and no deck is 409 `no_deck`, each before any run.

### Not in this decision

- A board for the item and the coach. When one is drawn, the panel moves to it; the route and the link stay.
