## D4595 — Pitch deck access and disclosure controls (#4595)

Pitch has one management permission contract, implemented in
`services/decks/access.ts` and used by every deck route.

| Operation | Owner | Accepted cofounder | Advisor | HQ | Super Admin | Support session |
|---|---:|---:|---:|---:|---:|---:|
| Read managed decks and history | yes | yes | no | yes | yes | yes, read only |
| Draft, edit, save, restore, share, export | yes | yes | no | no | yes, audited | no |
| Public share-token view | token contract | token contract | token contract | token contract | token contract | token contract |
| Investor deal grant view | recipient grant | recipient grant | recipient grant | recipient grant | recipient grant | no |

The shared project-content gate still applies venture membership and active
company scope. The deck gate additionally excludes advisor-only accounts and
advisor memberships, refuses every support-session write before mutation, and
records a Super Admin actor authorization before the write. Public links and
investor grants do not inherit management access; they keep their existing
token, deal, expiry, revocation, NDA, download and forwarding checks.

A saved deck version is the complete render snapshot. The Spin-Out template's
flat render fields are derived from that version's stored cards for founder,
print, export and share views. Rendering no longer re-reads current Lab records
or template overrides, so later source changes cannot alter history or a frozen
link.

Shared template fields pass through the same disclosure classification as
ordinary card fields and blocks. Internal scores and bank data never leave;
quotes require recorded consent; figures and cap-table values require their
respective inclusion switches. A template field removed by the contract is
also absent from the template render map, so a visual template cannot restore
content excluded from the ordinary card payload.

The live Pitch acceptance helper now verifies that the browser remains on the
expected authenticated route and draws an eligible Pitch state. Login,
plan-gate, load-error and unrelated pages fail even when they return HTTP 200
and enough text.
