## D588 — A scoring report is shared with one named account

**A founder shares the latest official scoring run with one existing account,
for a stated audience, until an expiry or an open limit, and can revoke it.**
The owner's answers on #1215 (from #1009, D350), moved from S07 to S06:

- **1A.** Scoring reports only. Profiling, Office Hours and the agreement draft stay unshared.
- **2B.** Only a signed-in account the founder names can open the link. An unknown, expired, used-up, revoked or wrong-account token is the same 404.
- **3A.** If Profiling is shared later, it shows the archetype only when published (D357). This decision does not share Profiling.

Migration 401. The raw token is returned once, at creation, and stored only as a SHA-256 hash. `audience` is `summary` (total and tier) or `dimensions` (those plus the six dimension scores). Neither audience receives the raw inputs, the notes, or who scored it. A practice run is not shared. The run is frozen when the link is created, so a later rescore does not change it. The founder must agree, in the request, before the link exists.
