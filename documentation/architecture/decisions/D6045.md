### A choice this issue makes

The canvas notes on #4863 call the primary-action rule, the journey strip and the investor activity counts "frontend only". This issue puts the stage and the primary action in the Worker instead, so the page draws them and never works them out: one rule, tested once, and the same answer on every surface that reads the overview.

### The rule (RA-03)

Most advanced first; readiness scores never choose.

| Recorded state | Stage | Primary action | Where it goes |
|---|---|---|---|
| At least one prospect not passed | Run the raise | Add investor | Capital relationships › Add |
| The current deck passes `/deck-ready` | Prepare diligence | Share with investor | Pitch Studio › Share |
| A saved narrative version | Build the story | Build pitch | Pitch Studio |
| None of these | Prepare | Prepare to raise | Fundraising readiness |

The four stages map one to one onto the canvas's four CTA states. A deck that is shared but fails `/deck-ready` still reads Build pitch, because the rule is the canvas's and the preflight says what is left. A staff (admin) read gets the stage but `primary_action: null`: the page's actions are the venture's.

### RA-C: the Worker can tell a draft from a saved deck

Yes, from stores already on main. A saved version is the current `pitch_decks` row (Save version). Before the first save, a deck being built is the venture's one unkept `pitch_deck_proposals` row. After it, unsaved work is the working copy on the current version (`pitch_deck_cards`, `pitch_deck_draft_doc`, D1501/D4596). So `pitch_state` is `no_deck`, `draft` (Working draft only), `saved` (Saved, not reviewed), `reviewed` (Reviewed, ready to send) or `shared` (a live link: not revoked, expired or used up). Reviewed means `/deck-ready` passes, as the canvas's "Preflight · Reviewed" does, not an AI deck review. `unsaved_changes` is null when it could not be read.

### Investor activity (RA-02)

Counts from `raise_prospects` (in the pipeline, in conversation), `deck_share_views` (views in the last eight weeks) and `round_call_recipients` (call-for-capital responses this month, only while round calls are on, otherwise `not_applicable`), plus the three latest events with investor names for the venture's own readers (never for staff). Each source carries its own `OperationalReadMeta` (D4858): status, read time and the last time the source changed.

### Unavailable, never guessed

Each answer reads only the sources that can change it. An unreadable one makes that answer `{ state: 'unreadable', reason }` (#5129: Unavailable on screen) and its figures null. With an investor in the pipeline the deck cannot change the stage, so an unreadable deck leaves the stage known.
