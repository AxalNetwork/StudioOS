## D6136 — Correct the onboarding answers from "My thesis" (#6136)

Account › Security and privacy's "My thesis" card now shows the five
investor-onboarding answers that only the wizard could set before: firm or
family office, accreditation status, country of residence, LP commitment
intent and target LP commitment. Each reads its stored value in the wizard's
own wording, or "Not recorded" when there is none (never a blank or `$0`).

Each field has its own Edit and Save. A save sends that one field on top of
the shared full-replace payload (D6288), never the other four, because
`PUT /api/investor-profile/me` keeps an onboarding field it is not sent and
clears one sent blank. A blank target clears it; a target that is not a whole,
non-negative number is refused in the card before any request.

Accreditation is labelled self-declared, with a line that it is not a
verification and a link to Trust Center › Verifications
(`/trust/me?tab=verifications`). The `#my-thesis` anchor and the Investor
Home band's `THESIS_HREF` to it had already landed in #6300 (#6289).

The Account v2 canvas (#5858, D4955) does not draw this card or these
fields, so nothing here is drawn twice; when that canvas is built, the
fields move with the card. No Worker behaviour changed; a Worker test pins
the preserve-if-absent contract per field.
