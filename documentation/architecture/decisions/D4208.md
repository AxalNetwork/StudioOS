### 1. What is kept

A founder may dismiss a "Worth a look" finding from the preflight panel. Until now the dismissal lived only in the open editor, so it was lost on reload and other editors never saw it.

- **The table:** `deck_preflight_dismissals(deck_id, version, finding_id, dismissed_by, dismissed_at)`, primary key `(deck_id, version, finding_id)`. It is additive: one new table, and no existing table changes. A row goes with its deck version (`ON DELETE CASCADE` from `pitch_decks`, D1508), and the table has its row in `DATA_RETENTION.md`.
- **The id only:** `finding_id` is the model's `"<check>:<card>:<block>:<n>"` (`runPreflight` in `preflightModel.js`), at most 120 characters, and the check must be one of the model's ten. No title, detail or fix is stored.
- **By version:** rows are read and written for one version, so a new version starts clean. A dismissal names a version the deck has, or it is refused 404 `version_not_found`.
- **A repeat** keeps the first dismissal and who made it. **Undo** (`dismissed: false`) removes the row.

### 2. Who

The same access as `GET /api/decks/:id` (`projectOwned` in `decks.ts`). A reader, such as an admin who is not a Super Admin, may read. Only an editor may write (`{ write: true }`), and a reader's Dismiss or Undo is 403 with nothing written.

### 3. Blocking is never dismissed

The export-blocking findings are `layout`, `overflow`, and `image` when the block has no image. The server does not take the client's word for a warning:

- **`layout` and `overflow`** are refused by their check key.
- **`image`** is read from the version's own card. An image block with no image blocks. One that has an image but is soft is a warning. An `image` finding whose block is not on that card is treated as blocking, since nothing shows it is a warning.
- **A client that sends `severity: 'blocking'`** is refused too.

Each case is 422 `finding_blocking`: "This finding blocks export, so it cannot be dismissed. Fix it on the card."

### 4. The panel (wired 2026-11-03)

The Worker half merged first (#4214); the wiring followed once the preflight panel was on main (#4229).

- **On:** `BUILD.P1.live = true` in `preflightUiModel.js`.
- **Read on open:** `usePreflight` reads the version's dismissals through `deckPreflightApi.dismissals` whenever the editor opens a version. Another version starts clean.
- **Written on Dismiss and Undo:** the set changes at once and the write follows (`setDismissed`, with the finding's severity). A write the Worker refuses is taken back, and the panel says "That was not kept. Try again."
- **A reader** reads them and writes nothing; the panel draws no Dismiss for one. The "Dismissed here only" line is gone, since nothing is held only in the editor now.
