## D4629 — Bounded verdict history keeps temporal boundary state (#4629)

Validate history reads the newest 2,000 project observations in deterministic
`(observed_at, id)` order. When that slice is truncated, the reader also keeps
the immediately preceding state for each requested claim, the latest state for
quiet requested claims, and one state at each explicitly requested as-of
boundary. This makes the first retained transition comparable and lets an
as-of view answer from the state actually in force at its boundary without
materialising an unbounded project history.

Coverage is part of the result. `complete` means the project fit in the newest
slice; `partial` names both the oldest recorded instant and the start of the
continuous loaded slice; `unavailable` means the history read failed. A change
window is available only when its opening instant falls inside that continuous
slice. An exact as-of boundary remains available when its bounded snapshot was
read successfully. The UI says an earlier view is unavailable instead of
rendering an incomplete empty result.

Project scoping stays on every query. Same-second observations use their
append-only id as the tie-breaker. The reader accepts at most 2,000 requested
claim ids and four explicit boundaries, and every materialised query is capped.
It does not rewrite past observations or change verdict methodology.

History recording still happens only after the strict required-source reads in
the current Cycle Validate path complete. #4585 owns the equivalent explicit
unavailable contract for the legacy founder-board/export reads; this decision
does not turn a failed evidence read into an empty state or introduce another
history writer.

Verification covers 1,999, 2,000 and 2,001 observations, multiple projects and
claims, a claim first seen beyond the former cap, the predecessor needed for a
change at the retained boundary, same-timestamp id ordering, and an as-of state
older than the newest slice. Existing Validate temporal-filter and presentation
suites remain green.
