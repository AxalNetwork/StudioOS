## D5310 part 2 — Network › Relationships built to NW2 and NW2.1: the own book as a table, and the Person Sheet (#5310)

Part 2 of #5310, after part 1 in `D5310.md` (NW1, NW1.2, NW5). It builds board NW2 and NW2.1 of the approved Network workspace canvas (`design/incoming/network-workspace/NW2-Relationships.dc.html`, D4799) on a founder's `/network/relationships`. No new route: `workspaces/NetworkWorkspace` keeps the crumb, heading, zone pills and rail, and mounts `FounderRelationshipBook` where `NetworkContacts` was, for a founder only. Every other licence keeps `NetworkContacts`.

### What each part reads

| Board part | Read | Store |
|---|---|---|
| My relationships (table, count, range, paging) | `GET /api/contacts/book?q=&source=&follow_up=open&page=` | `network_connections`, the member's own book (D1352) |
| Open follow-ups column | the same read: `open_tasks`, `overdue_tasks`, `next_due_on` (**new**) | `network_contact_tasks` |
| Last activity column | the same read: `last_note_at`, `last_done_at` (**new**), `created_at` | notes, follow-ups, the row |
| Person Sheet: follow-ups, private notes | `GET`/`POST /api/contacts/book/:id/tasks`, `PATCH …/tasks/:uid`, `GET`/`POST …/notes` | the member's own rows (D1351) |
| Who on my team knows them | `WhoKnowsStrip` (`GET /api/relationships/who-knows?person=`) | shared books only (D1356) |
| Leads from your pages | unchanged: `FounderNetworkRelationships` below the book (`GET /api/contacts?project_id=`) | `contacts`, the venture's landing-page sign-ups |

**The Worker change.** `bookOf` in `services/linkedinCsvImport.ts` adds four fields to each row, every subquery bound to the owner:
- `overdue_tasks`: open follow-ups due before today (UTC). An undated one is never overdue (B1).
- `next_due_on`: the earliest due date among open follow-ups.
- `last_note_at` and `last_done_at`.

No route, filter or response key is removed.

### Rules

- **Last activity** is the latest of the last note, the last finished follow-up and the row's entry into the book (imported or added), compared on the full stamp. No stamp at all reads Not recorded, never today.
- **Open follow-ups** reads "N overdue" when any is overdue, else "N · due YYYY-MM-DD", else "N open · no due date", else None.
- **A failed book read** says so, with Try again. It is never "your book is empty".
- **The sheet** never loses an unsaved note to ×, Escape or the scrim. The first close shows "Unsaved note" with Save note and Discard, and a second close discards.

### Departures from the canvas

| Board | Departs | Why |
|---|---|---|
| NW2 | No Rows/Cards toggle. From 640px up the book is the table; below 640px each row is a stacked card, so the page never scrolls sideways. | The phone board (NW8) is checked in a later part of #5310; the switch follows the width, not a control. |
| NW2 | No **Invite to Axal**. | No read or write invites a person from the own book; the invite flow is the venture's contacts (`contacts.ts`). |
| NW2 | **Add person** is disabled, with its reason. | The book has no hand-added writer. Backend required: #6558 (as in part 1). |
| NW2 | **Role / context** is the record's title; no relationship kind ("investor", "customer"). | No kind is recorded on a book row. |
| NW2 | **Last activity** never reads "intro made" or "intro requested". | Introductions are not joined to a book row. They are in Introductions. |
| NW2 | 50 rows a page, not 25. | The Worker's page size (`BOOK_PAGE`). |
| NW2 | **Leads from your pages** stays the existing venture contacts list below the book, not a two-row preview. | The full leads page (NW2.2) is not drawn. The two counts are never combined. |
| NW2.1 | **Interaction history** lists notes, finished follow-ups, entry into the book and the LinkedIn connection date. It lists no introduction. | As above. |
| NW2.1 | **Relationship strength:** Not recorded. | No strength score is stored (D4799). |
| NW2.1 | No **E Ask** on "Who on my team knows them". | `WhoKnowsStrip` carries its own Ask, the one the warm-path search uses. |

    - the open count without the next due date;
    - a missing organization drawn blank;
    - last activity not the latest;
    - no activity drawn as today;
    - the range counted from 0.
  - **Sheet:**
    - a follow-up due today drawn overdue;
    - a done follow-up drawn overdue;
    - history not newest first;
    - the connection date dropped.
  - **The mounted page:**
    - the source filter not sent;
    - open-only not sent;
    - a failed read drawn as the empty book;
    - Add person enabled;
    - notes read for another contact;
    - an unsaved note closing at once;
    - a follow-up added without its due date.
  - **Worker:**
    - an undated follow-up counted overdue;
    - the next due date taken from a done follow-up;
    - the last note taken as the first;
    - another member's follow-up counted.
