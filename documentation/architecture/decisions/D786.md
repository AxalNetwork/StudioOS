## D786 — One /pricing page with Founder, Investor, Advisors, Operating Partners and Models tabs; /plans-and-pricing redirects to it

- **Status:** S07, 2026-10-20 (#2211; part of D785, #2210, its D-a, D-b and D-c). Part 1 (this file's §1–§5) needs no canvas. Part 2 builds the page to the "Pricing" canvas and amends this file.
- **Basis:** `origin/main` at `84f6e33b`. Worker paths are relative to `cloudflare-worker/src/`; frontend paths to `frontend/src/`.

### 1. `GET /api/public/ai/models` (the Models tab's read)

- **Public and cached.**
  - No session.
  - Per IP, 60 a minute, fail-open (`public_ai_models` in `middleware/rateLimit.ts`), like the other public reads.
  - `Cache-Control: public, max-age=300, s-maxage=300`, and a per-isolate copy keyed by the owner's two catalogue switches.
  - No D1 and no binding, so it is on the anonymous reads that skip the role-schema bootstrap (`index.ts`).
- **What it answers:** `{ ok, models: [{ id, name, kind, billed: { <unit>: usd }, unit_words: { <unit>: words }, pages: [canvas page names], is_new, paid_only }] }` (`services/ai/publicModels.ts`).
  - The models are those `catalogue.isOffered` offers under `AI_PARTNER_MODELS`, in the catalogue's order, the same set `/api/ai/catalogue` gives a member.
  - `billed` is each unit's price as a member pays it: `billedUnitPrice(unitPrice(id, unit), AI_MARKUP)`, D762's cost × 1.25. No other price is answered.
  - `pages` are D764's matrix rows, pages and options, whose models name the model, by their page names.
  - `is_new` is the rail's "New" pill. `NEW_MODEL_IDS` holds the catalogue ids of the twelve display names in `ui/railModels.js` `NEW_MODELS`, and a test reads both.
- **Only public fields.** No cost price, neurons, licence, multiplier, status, partner flag, docs URL, context window, capability or route. The test checks every key at every depth.

### 2. The redirects, each keeping its query and hash

- `/plans-and-pricing` → `/pricing` (`pages/pricingRedirects.jsx`).
- `/plans-and-pricing/:productId` → `/pricing/products/:productId` (`ParamRedirect`).
- `/pricing/investor` → `/pricing?for=investor`, with any other query kept. A `for` in the old address is replaced: the address names the Investor tab.
- `/products` and `/products/:productId`, D755 §13's legacy redirects, go to `/pricing/products` (and `/:productId`).
- `InvestorPricingPage.jsx` is no longer routed. Part 2 replaces `PricingPage.jsx` and removes both.

### 3. The catalogue at `/pricing/products`

- `ProductsPage` (plans, catalogue, add-ons, licences, Token packs and the cart) is unchanged at `/pricing/products` and `/pricing/products/:productId`, with the same guards: visitors read the catalogue, and a product's page and checkout need sign-in.
- **Links that moved there:** every internal link to buy, to the cart and to the Token packs. `TOKEN_PACKS_PATH` is `/pricing/products#token-packs`, and checkout's Back and its confirmation go there too.
- **Links that moved to `/pricing`:** links to plans and pricing in general. That covers the account menu, the phone's account sheet, D700's A10m account row, the Perks claim's upgrade link, and every "Compare investor plans" link (`/pricing?for=investor`).
- **The rail's member route** (D689 D-j, `lib/railPages.js`) is `/pricing`, which covers `/pricing/products` under it.
- **`isPublicPath`:** `/pricing` and `/pricing/*` are public, except `/pricing/products/:id`, which keeps D755 §13's sign-in.

### 4. `lib/pricingModel.js`, the data layer for the five tabs

- **The tabs:** `PRICING_TABS`, in the canvas's order. Each tab's `?for=` key is `founder`, `investor`, `advisor`, `operating-partner` or `models`.
- **Landing:** `?for=` wins. Otherwise the tab is `landingTab(useViewMode().shellRole)` (`useLandingTab`):
  - investor → Investor;
  - advisor → Advisors;
  - partner → Operating Partners;
  - anyone else, and a visitor (no view-mode provider), → Founder.
- **A role tab** keeps the plans of its family (`aiCredits.planOf`'s families) from `GET /api/public/plans-and-packs`.
  - This is the catalogue mirror a visitor may read. `GET /api/catalog/products` needs sign-in, and this is one page for both visitors and members (D-a).
  - A role the catalogue sells no plan returns `{ none: true }`, and the page says "No plan: top up AI tokens as you go" (D783). It never shows an invented plan (D-b).
  - Today Advisors and Operating Partners have no plan.
  - An unreadable read is `{ unreadable: true }`, never "none".
- **The Models tab** reads §1 through `publicPricingApi.aiModels`.
