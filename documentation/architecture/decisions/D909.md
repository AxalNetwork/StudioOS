| Field | What it holds |

### 2. Read by is a binding, never a guess

A card of the venture's **current** pitch deck reads version N only when one of its bindings names that version's record, `narrative_version_meta:vN`. That is the `record_ref` D896's narrative slot writes (`services/narrative/readers.ts`). A binding counts on the slide, a field or a block, the three places D896's `bindingsOf` walks.

- **What does not count.** The marker's `deck_version` is the newest deck at save time (bug 4 of #2454), and it never counts. Neither does an older deck's binding.
- **The sentence** reads "Pitch deck v6 · cards 1, 2, 5", or "No deck reads this version." The version's own record says the same in its sub-line and in its "Read by" fact, which replaces "Deck use".
- **Today every version reads "No deck reads this version."** `routes/decks.ts`' `sanitizeSlides` keeps no `binding`, so a saved deck carries none (D896 §6). That is true, and Read by follows the first deck that keeps one.
- **The footer** follows Read by. It says "The Pitch deck studio reads your narrative." only when a card binds a version. Until then it says that no card does. The canvas's first sentence ("Positioning now lives here.") waits for part 5 (#2695), which moves positioning.
- **The binding walk is local.** `readers.ts` walks the bindings itself rather than importing `bindingsOf`, because `decks/sources.ts` reads `raiseCycle.ts`, which reads `readers.ts`.

### 3. Spin-Out wording for Spin-Out ventures only

Owner question 5 on #2454 was read as A. The live wording, `spinout_deck_overrides` version 0, is the Spin-Out deck's.

- **Who is a Spin-Out venture.** A venture whose current deck is the Spin-Out deck (`axal_spinout_demoday`), or which holds that deck's wording.
- **What it changes.** Only such a venture is offered "The Spin-Out deck wording". Form-options lists `live` only for it and carries `spinout`.
- **Every other venture** starts from a saved version or Blank. With none saved, Blank is chosen. The form's fallback is Blank, never the live wording.
- **Earlier versions.** A version a non-Spin-Out venture saved from the live wording before this reads "The live deck", today's name.
