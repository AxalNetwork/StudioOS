### Data and state semantics

- **Measured zero:** display the real zero with unit, definition and date. Do not use `||` defaults for financial values.
- **Not recorded:** a successful read establishes no record. State why a value is absent; do not draw a zero or a trend.
- **Unreadable / Unavailable:** follow the approved shared contract for the failed source. Name it and offer a retry; preserve valid neighbouring panels and retained input. Never infer a state by parsing exception text.
- **Stale:** keep the recorded value and its actual source/as-of date, with a clear stale modifier. A stale update is not an overdue reporting obligation.
- **Not enough evidence:** derive it only from the supported source-state response, not from a green default or a guessed score. A stored older health snapshot remains dated evidence, not a newly computed score.
- **Private in preview / read-only:** permission state; do not request, cache, expose or write the private data merely to draw a withheld state.
- **No obligation / empty / not held:** distinct successful reads. If the company identity is not readable, titles and empty copy cannot reveal its name.
- **Financial basis:** D4644's current gross calculations and at-cost treatment remain authoritative. Mark date, book as-of, report period and current operating-signal date are distinct.

### Interactive accessibility acceptance checklist

All items below remain to be executed against the #5311 implementation; they are not represented as passes by this preparation PR.

- [ ] Keyboard: reach all five local destinations, company links, filters, sorting, details and every supported action without opening Eadwyn.
- [ ] Landmarks: one `main` landmark per route; one meaningful H1; local navigation is named; a visible-on-focus skip link moves focus to Portfolio content. Do not nest a second main in an application-owned main.
- [ ] Headings/labels: fields, icon-only actions, tabs, grouped filters and each Sheet have programmatic names; help/errors are associated with their controls.
- [ ] Focus visibility/order: 2px-or-equivalent visible focus, sensible DOM order, no obscured focus under sticky bars; visible action targets are at least 44px on phone.
- [ ] Sheets: focus enters, Tab/Shift+Tab stay inside, background is inert, Escape safely closes, and focus returns to a still-valid trigger or the affected record after a refresh replaces the trigger.
- [ ] Read recovery: fail each Overview source separately; only that source changes state; retry does not reset filters, company context or valid sibling panels.
- [ ] Company navigation: open a company directly, change tabs, reload and use Back; route, heading and document title stay aligned. Unknown/unreadable identity does not expose a private name.
- [ ] Money journeys: prepare, cancel, retain/discard unsaved changes, review, confirm and read the receipt. Simulate conflict/server failure and a company switch during a delayed response; original target and input remain bound.
- [ ] Reporting journeys: Ask and Waive confirmations name company/period; pending and delivery-unknown responses do not claim exactly-once external delivery; a losing/conflicting action does not update another row.
- [ ] Support journeys: log, fail/retry, deliver, withdraw and read history using supported states; async messages name the affected entry and preserve all values.
- [ ] Tables/cards: desktop tables have captions/header relationships; phone cards retain labels, source/date/reason and actions; nested details have named controls and state.
- [ ] Charts: keyboard-reachable table/text equivalents, identical dates/units/gaps/corrections, clear legends and non-colour-only distinctions.
- [ ] Contrast and zoom: measure text/UI contrast in light/dark; test 200% text and 400% page zoom/reflow at 320px, long names, long amounts and increased text spacing.
- [ ] Motion: reduced-motion preserves content and focus without unnecessary movement; async success/error/conflict states are announced without repeated or misleading live regions.
- [ ] Preview: one banner, compact private states, no private request made, no hidden data in DOM/accessibility tree, no late response from another account/preview context.
- [ ] Regression: #4849 route/context test, focused shared-component/critical-journey tests, root build/drift and cross-vendor review all pass; record actual test commands and exits.
