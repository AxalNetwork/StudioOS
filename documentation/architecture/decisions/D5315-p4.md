## D5315 part 4 — Private draft and explicit publication for profile edits (#5315)

The Expertise editor can load, save and discard a private draft, or publish a specific draft revision. The draft lives apart from the public advisor row and uses the existing profile field validation. Omitted fields retain their draft values. An explicit clear survives publication.

Publication checks the draft revision and the public revision it was based on. The public update and draft removal happen in one database statement. If another writer changes the public profile first, the editor can discard the stale draft and restart from the current profile. Existing callers of the legacy profile-save API keep their current behavior until they move to the draft API.
