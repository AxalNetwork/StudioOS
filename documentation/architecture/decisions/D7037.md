### What the canvas decides

- Listed companies has one "Search name or ticker" field, a Source filter (All sources, Signal companies, SEC EDGAR) and Sort, with the total stated as listing records and each source's count beside it.
- A ticker found in both sources returns two records, each labelled with its source and never merged. Details on an EDGAR row shows the CIK, other listings, read date, licence and source link.
- Columns that are Not recorded on every row fold into one line on screen. The export keeps them.
- If a country or sector filter is offered, the page says it leaves out SEC EDGAR, because EDGAR records neither.
- The export says its scope: "Export this page · N rows" on Listed companies, "Export filtered markets · N rows" on the directory, in the current sort. A view with zero rows or a failed read offers no file.
- `tab`, `q`, `source`, `sort`, `country`, `sector` and `page` live in the URL with history replace. Any change returns to page 1. After paging, focus moves to the result heading.
- States use the Platform States words: loading, matches, no matches with Clear filters, failed read (Unavailable) with Retry, nothing recorded yet, and the export's ready, completed and error states.
