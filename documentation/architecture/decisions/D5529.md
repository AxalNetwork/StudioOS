## D5529 — Pin the changelog gate to the PR event (#5529)

The changelog gate compares the event's head with its merge base with the
event's base commit. It uses the local checkout's Git objects during normal
operation. Later changes to either branch do not affect that comparison.

A shallow checkout or a missing event commit triggers one 60-second recovery
fetch from origin for both exact commit IDs. The gate returns exit 2 when
it still cannot compare complete history. A successful comparison continues
to allow an untouched changelog or a labelled edit and to reject an
unlabelled edit.
