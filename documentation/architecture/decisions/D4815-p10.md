### The states

`dealWorkModel.roomStateOf` and the Documents view in `DealWorkTabs.jsx`:

| | State | Label | Line | Action |
|---|---|---|---|---|
| A | `not_opened` | Not opened to you | The founder has not opened the data room to you. (Or the request's own line: asked on, declined on, ended.) | Ask for access, unless a request is open |
| B | `behind_nda` | NDA required | You have access. 6 files require an NDA. | Sign NDA (opens the existing dialog) |
| C | `nda_pending` | Waiting for signatures | Waiting for signatures. "6 files open once every party has signed." | None: the NDA is never asked for twice |
| D | `open`, `nda_on_file` | Open to you | You have access. … | The listing: folders, search, files |
| E | `unreadable` (access) | Unreadable | Data room access could not be confirmed. "That is not a claim that the room is closed to you." | Try again (reads the access again); never Ask for access |

**When C applies.** C is the NDA's status `out_for_signature` while at least one file is withheld. With nothing withheld there is nothing to wait for, so the room is D.

**A room read that fails.** A room that cannot be read after access was confirmed keeps the shared Unreadable ("The data room could not be read."). It is a different failure from E.

**DE10's signed count.** DE10 draws a signed count on C ("2 of 3 signed"). The access read carries the NDA's status and end date only (`ventureNdaStatus`, #6267), so no count is drawn.

### D's file rows

Each row reads `Type · Size · Added` and Open.

**The Type comes from `fileTypeOf`:**
- the stored content type, in a reader's word: PDF, Spreadsheet, Document, Slides, Archive, Image, Video, Audio or Text;
- else the file name's extension;
- a stored type with no word is "File";
- neither recorded is "Not recorded".

DE10 writes "Excel"; this build writes "Spreadsheet", because a CSV or a Numbers file is the same kind of thing and not Excel.

**The note under the files** now reads "Search looks inside every file listed here. Each file opens through a one-time link."
