## D8003 — Pin the meeting runtime build inputs (#8003)

The meeting runtime's Node 22 Bookworm base is selected by its immutable image
digest. The verification and runtime stages inherit that same base. The Zoom
binding install explicitly requires hashes from its existing requirements file;
the binding version and accepted wheel hash stay the same.

The container command contract, image publication gates and deployment boundaries
are unchanged. Existing image, deployment and fake-adapter command tests provide
offline coverage. An actual Docker build and native SDK loading still require the
existing image pipeline; Docker is unavailable in this local validation session.
