### Built

- **What Export checked (PTF05).** The gate in `ExportDialog.jsx` opens with "Checked: v7 · the saved version Export sends" (`exportGateModel.js` `scopeLine`): the dialog's own check reads a saved version, never the draft.
- **Show in your draft (PTF05).** With the editor open, each row of Export's gate has "Show in your draft" (accessible name "Show metric MRR $34.2k in your draft", `showInDraftLabel`), offered only when the draft still has that card (`inDraft`, by the card's uid). It closes Export and, in the editor (`PitchEditor.jsx`, the `show_in_draft` action), opens the draft's own finding about the same element on its slide with the strip and its repair, when the draft's check is current and still finds it; otherwise it selects the card and the block. Findings are compared by card uid, block, check and headline (`findingKey`), because Export numbers its slides without hidden cards and the editor does not. `GateBody` takes the button's word and name (`show: { word, label, can }`); the editor's own gate is unchanged.
- **The confirmation (PTF05, PTF15E).** "Export anyway" is now a checkbox, "Export v7 with these 3 warnings", with the line "The export history records the version, the format, the file's fingerprint and the 3 warnings you confirmed." (`confirmWords`). It can be unticked, which takes the confirmation back (`useSendCheck`'s `confirm(false)`; Share's "Send anyway" calls it as before). Until it is ticked, "Export PDF waits for the confirmation above." is shown and is the run button's `aria-describedby`; once ticked, the status says "Exporting v7 with the 3 warnings above confirmed."
- **How the draft differs (PTF05).** With unsaved edits on the version being exported, a note under the gate says how the draft differs, from the editor's own draft check (`draftDiffers`, the editor's `draft` action returning `draftSummary`): "Your draft differs from v3. It has fixed 1 finding v3 still has (Slide 3 · Metric · MRR $34.2k) and has 1 blocker v3 doesn't have (Slide 2 · Title). Save version to export your draft." With no current draft check it says only that the unsaved edits are not in this export and were not checked here; for another version, or with no edits, nothing.
- **The ledger (◇).** Migration `202611271712_8772_deck_exports_confirmed.sql` adds `warnings_confirmed` and `confirmed_findings` to `deck_exports`. Every export route (PDF and PowerPoint through the ledger middleware, HTML, .odp, Google Slides) reads the body's `confirmed`, the finding ids the dialog confirmed (`routes/deck_exports.ts` `confirmedOf`: ids shaped like `preflightModel.js`'s, once each, at most 200; an empty array is 0; no array is null, not recorded), and `GET /api/decks/:id/exports` returns both. The dialog sends `confirmed` on every export (`exportGateModel.js` `confirmedIds`; `api.deckExport*` take it), and under "Last exported …" the history line says "Exported with 3 warnings confirmed" (`confirmedLine`) when the last export confirmed any. It is the dialog's statement: the Worker does not run the check. A row from before the migration says nothing, never "no warnings".

### ExportDialog.jsx, exactly

Changed: the gate block (the scope line, `GateBody` with "Show in your draft", the checkbox in place of the "Export anyway" button, the waiting line, the confirmed status); a new note after it (the draft-differs line); `run()` passes `confirmed` to the four export calls; the run button gains `aria-describedby` while it waits; one ledger line after `pitch-export-last-settings`; two new props, `draft` and `onShowInDraft`. Nothing of D8771's copy picker, preview, acknowledgment, completed panel or failure is changed.

### Departures from the canvas

- The confirmation's small line names the confirmed warnings, which the canvas left out only because the ledger did not keep them; it does now.
- "Save version to export your draft." rather than "Save v8": the next version's number is not known before it is saved.
- The note names what was fixed by its row ("Slide 3 · Metric · MRR $34.2k"), not "the MRR tile", and compares the draft's own current check, so it never claims a fix the draft check has not seen.
- The scope line has no saved time or slide count; the version picker above it carries the time.
- On a phone (PTF15E) the rows keep "Show in your draft"; the canvas drew them without buttons.
- "Exported with 3 warnings confirmed" is under the dialog's last-export line, the one history the dialog shows.
