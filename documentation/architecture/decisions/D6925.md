## D6925 — Program readiness, member requests and catalogue boundaries (#6925)

### Investor cohort access

HQ can assign a verified investor to a cohort and send or resend a cohort NDA. A current assignment and a signed NDA gate the cohort summaries and weekly progress. A usable NDA template is an operational prerequisite. The registry correction marks the original unopened global row as partly built. It preserves reviewed member access and studio decisions. An exact match on the original purpose protects editorial changes. The investor overview shows the registry’s operating state separately from feature readiness.

### Referrals and Lab activities

The member’s Refer & Earn request applies to strategic and capital introductions. The returned access decision determines the request status and the strategic category’s availability. HQ enrolls formal referral partners separately. The Lab playbook links to host review, Office Hours, the shared matching workflow and published events for announced showcases. D679’s retired illustrative series have no event records. The public Events page continues to use its event feed and the separate cohort card.

### Regional content, campaigns and package versions

Courses and regional programs are managed in Learning. HQ manages individual testing campaigns in the Product testing console. Operators can navigate between those tools and Programs. HQ can inspect franchise package versions from the catalogue. Each published version names its own program keys under D5022. The package regression creates a registry program before reading all four seeded versions and checking their item lists.
