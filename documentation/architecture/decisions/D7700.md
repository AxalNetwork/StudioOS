## D7700 — Selected-document passage citations for SAFE qualification (#7700)

### Independent citation foundation

SAFE qualification must cite the selected data-room document's stable `data_room_passage:<uid>:<seq>` references rather than a typed instrument. The evaluator previously recognized only dotted record paths, so those requested references could not form a valid case.

Add stable passage references alongside dotted paths. Resolve one only inside `data_room.index` when its document status is `read`, the selected file UID and file reference match, and that document contains a passage with the exact reference, sequence and nonempty text. A reference merely mentioned in another field is not evidence. Unknown output references fail qualification; missing and duplicate expected citations remain refusals. Existing dotted paths and the citation cap are preserved.

The evaluator advances from version 4 to 5 because recognized citations change its semantics. Existing evaluation evidence must be refreshed under the new evaluator; this change neither runs a model nor edits production evaluation rows.
