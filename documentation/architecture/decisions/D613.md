## D613 — Validate theme labels and partnership status views read stored data

Issue #1317 · S18 · Codex. Frontend only; no migration.

Validate's board returns pain-group titles and a project-wide evidence-base
interview total, but no per-theme interview counts or interview memberships.
The link dialog therefore shows each theme's title without an interview count.
It does not substitute a fabricated zero for the missing count.

Grow Partnerships groups stored co-marketing statuses with one table: Signed
contains approved and published; In motion contains proposed; Dormant contains
rejected and withdrawn. Rows and filter counts derive from the same grouped
arrays. All retains every project-linked pitch, including unknown statuses.
Dormant now renders its matching records. The separate dormant-age statistic
remains unavailable because pitch status supplies no last-contact timeline.

Rendered frontend fixtures cover theme option labels and every view's partner
rows and filter count. Mutations verify that wrong labels, status memberships,
counts, and the old Dormant rendering gate are caught.
