## D5720 — Keep scanner-clean notification fixtures and policy locals (#5720)

The notification integration test bundles a static Worker fixture instead of
constructing JavaScript source from runtime values. The test clock and receipt
key enter through Miniflare data bindings. The fixture still imports the real
delivery actor, uses local SQLite persistence and replaces the Slack transport
with a synthetic acknowledgement. Its restart and receipt checks remain active.

An additional real-runtime check passes quote, newline and line-separator
characters as a receipt-key binding. They remain data and return no matching
receipt. The original hardcoded generated Worker fails that check.

Explicit semicolons remove the test file's automatic-insertion findings.
Platform sensor policy locals are assigned by their existing branches, without
unused initial values. Sensor state and reason behavior are preserved.

No scanner suppression, route, migration, provider activation or production
configuration is added. Scanner run evidence identifies the affected paths;
current-head CodeQL validation must confirm that their findings disappear.
