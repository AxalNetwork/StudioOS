## D573 — Advisor practice facts and working booking links (#1184)

Partial profile saves preserve omitted core fields as well as expanded profile
fields; explicit null still clears nullable values. The directory reads the
Worker's display name, rate, expertise and active flag. An unknown rate is Not
recorded rather than Free; expertise and rate filters reach the Worker.

Migration 394 adds nullable due date, manual work status, included flag,
booking type/link attribution and link-open count. No legacy fact is invented
or backfilled. Manual status is planned/in_progress; sent/opened/accepted come
from version receipts. Only the engagement's client can accept a sent version,
and its first acceptance is retained. An advisor cannot sign off for a client.

Public profiles whitelist away contact email and internal account IDs, publish
active session types and public enabled links, and leave private/cohort links
unlisted. `/b/*` reuses the approved Ops A5 profile and existing directory
booking dialog. Visitors sign in to request a time. Type, link, advisor,
duration, membership and payout gates are checked before booking. Active
type/link and once-per-client checks are also in the atomic INSERT predicate.
This records a request; it does not charge a published catalogue price.

Cohort references resolve only to recorded numeric cycle IDs, never loose
labels. A cohort member can bypass the subscription gate as migration 240
specifies; an unrelated user cannot. Payout-required links refuse an
unverified account. Link resolution has an IP bucket on both router mounts.

Own practice reads and link toggles use the authenticated advisor. Link writes,
deliverable updates and client acceptance record the actor. The access reader
returns only the caller's existing receipt rows, with no document content.
Titles were not snapshotted with receipts and remain Not recorded rather than
reading a private document after access ended.

Counts describe non-cancelled attributed bookings, not the complete legacy
history. Opens count accepted page-open requests, including repeats, since
instrumentation began. Failed reads remain Unreadable. Nullable legacy fields
remain Not recorded. Validation covers 11 real-router Worker regressions and
5 frontend regressions, all failing against current main, plus the profile
omission regression. 333 active implementation/assertion mutations were caught
and restored; two pre-existing conditional assertions were not reached by
their fixtures. Seven real-component screens passed at 1440px and 390px, with
attributed booking, due/status save, link toggle and client acceptance probes.
The literal full gate is recorded in the PR STATUS. No production data or deploy
was accessed. Deployment remains held at migration 375 for the owner.
