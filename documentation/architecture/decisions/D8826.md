## D8826 — who published each company version, and when, on Compare with Axal (#8826)

`D5963.md` lists "Who published each company version and when" under "Backend required", and `D4538-p9.md` leaves version authors under "Not built here". The History section of Compare with Axal (`SkillExtension.jsx`) has drawn "Published by, when: Not recorded" (reason "Not built yet"). The columns already exist: `agent_skill_versions.published_by` and `published_at` (`759_agent_skills.sql`). This is a partial PR of #4538.

### What this decides

1. **The base read carries it.** `GET /api/teams/skills/:uid/base` returns each item of `lineage.versions` as `{ version, based_on_version, published_at, by_name }`. It is one `LEFT JOIN users` on `published_by`.
   - The page does not join `GET /skills/:uid`'s `versions` instead. History is built from the lineage alone, and the card read's adapter (`fromWorkerSkillPage`) drops `by`. One read keeps History from mixing two answers that could differ.
   - The gate is the same `mayRead` that already guards the read. Readers do not change, and nothing here writes. Members and HQ admins stay read-only.
2. **No uid, no email.** Only the display name is sent. History names a person and links nowhere, so `by_uid` is not needed. Leaving it out keeps the read to what the screen shows. (`GET /skills/:uid` still sends `by: { uid, name }` to the same readers, as before.)
   - A name that is blank, or that holds "@", is sent as `null`. The Worker never relays an address that sits in a name field. The frontend applies the same rule again.
   - A version whose publisher has no user row is `null` too.
3. **How it reads.** Each History row ends "Published by <name>, <day>". The day is `published_at` as "12 Nov 2026", formatted by the same `day()` the skill page's version list uses.
   - A missing name or day reads "Not recorded" in its place, for example "Published by Not recorded, 3 Nov 2026". This uses the `D4538-p9` wording, never a guessed name.
   - The line sits where the canvas draws "Published by, when". On desktop it is the row's right-hand column, muted and small. On a phone it wraps under the version.
