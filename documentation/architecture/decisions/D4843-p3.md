### The catalogue (OF-02)

The page opens on "Catalog" with "The services your firm sells through Axal." The toolbar keeps its primary + New service, its model chips (All, Fixed, Retainer, Seat) and Export.

One table, in OF-02's columns:

| Column | From | When the read has none |
|---|---|---|
| Service | the title, with its category beneath | — |
| Engagement model | `engagement_model` (migration 227) | Not recorded |
| Price | `price_cents` with its basis: "$48,000 fixed", "$6,500 / month" | No price yet |
| Listing | `catalogState`: Draft (no price yet), Live, Unlisted | — |
| Requests | the per-row counts the read serves (#4696) | Not recorded ⓘ |
| (actions) | Edit, then ⋯ with List or Unlist, and Delete apart | — |

- **Listing switch:** All, Live, Draft and Unlisted, each with its count over the whole page of rows; it narrows with the model chips.
- **Footnote:** "Price is today’s listed price, not revenue earned. Draft means no price has been set yet."
- **The state rule is unchanged.** `catalogState` stays where it was: no price is a Draft, whatever the listing flag says; priced and listed is Live; priced and not listed is Unlisted.
- **Money is formatted once,** through `formatMinor` (`lib/money.js`), in `partner/offers/catalogModel.js`. The page's own `usd` helper went with the tiles, so `money_manual_conversion_5373` lists one manual conversion on the page where it listed two.

### The editor (OF-02b)

The dialog now defines a service: "New service" / "Edit service", "Service name", "How is it sold?" for the engagement model, and "What do you deliver?" for the summary (also in `lib/fillFields.js` and its Worker copy `cloudflare-worker/src/services/fills/fields.ts`, which the fill tests hold equal). ### Phone

The table becomes one card per service: the name and category with the state, the model and price, the requests, then Edit and ⋯ as 44px targets. The listing switch's options are 44px.
