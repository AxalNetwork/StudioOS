## D7999 — Scope workflow tokens to their jobs (#7999)

Workflow defaults should grant no write access to a future job. The reviewed
workflows now declare empty or read-only defaults, with explicit complete
permission maps on the jobs that upload reports, manage releases, import
research or perform authorized automation. A job permission map replaces the
workflow map, so required read scopes stay alongside each required write scope.

Existing job overrides and operational permissions are preserved. Triggers,
authorization conditions, upload gates, dispatches and steps are unchanged.
The static workflow regression suite checks safe defaults and the complete
permissions of each affected job. The research import guard checks that only
its import job receives its contents scope. Validation compares every job's
effective permission map and the remaining YAML structure, runs the affected
offline suites, and mutation-checks the new assertions.
