## D7682 — Preserve literal entities in rendered text assertions (#7682)

The Research Markets tests read visible text from React's rendered markup.
Their text helper must decode punctuation while preserving entity-like text
that a person would see literally. Decode the ampersand last, after apostrophes
and quotation marks, so an encoded ampersand cannot expose a second entity to
a later replacement.

The existing helper stays local to the test file. A regression renders both
punctuation and literal entity strings through React and checks the resulting
text, including a nested ampersand. No production rendering changes.

Validation: the affected Research Markets suite, a mutation restoring the old
replacement order, and the repository's build and test gates are recorded in
the pull request.
