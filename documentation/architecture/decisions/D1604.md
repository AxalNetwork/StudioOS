**A generator fix the art exposed.** `measureChromeOffset()` compared the screenshot's size with the window size. On Chromium 1194, which is the build in the agent containers, a 1200×630 window gives a full 1200×630 screenshot, but the viewport is 543px tall and the bottom 87px are unpainted. The comparison measured no offset, and every card lost its footer. CI never renders (it runs `--check`), so nothing caught it. The probe now paints a block exactly `100vh` tall and counts its rows, which gives the right answer on both kinds of build, still without an inline `<script>`.
