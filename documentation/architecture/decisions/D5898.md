### 1. Address

`/admin/licences/packages/compare`. The canvas gives no address; this is the one the issue proposed. It is a literal segment, so it outranks `/admin/licences/:uid`; the test matches it against every declared route. It sits under `guard(['admin'])` and `hqOnly`, like the catalogue.

The query carries the page's state:
- `?licence=<uid>` is the licence chosen under "Price for".
- `?package=<key>&version=<n>` narrows the page to one version. This is where a catalogue row's Preview pricing leads, and it works for a draft too, because the Worker's GET prices any named version.

### 2. The program grid is composed, as L30 says

No matrix read exists. The columns are the **active version of every package**, cheapest base fee first (L30's order), or the one named version. The rows are every program any column lists, read from each version's items (`GET /:key/versions/:version`).

A cell reads one of:
- ✓, included by default;
- **Optional**, listed but not included by default;
- —, not in that version;
- **! Unreadable**, when that column's items failed (that column alone).

Programs are listed by key. As in D5896, no frontend client reads program names.

### 3. Prices are the Worker's

Under the grid are five rows: base price, country-adjusted price, standalone sum, bundle saving and warnings. All except the base price come from the pricing read for the chosen licence, matched by package key and version. The browser computes no price.

When the Worker returns null, the cell reads **Not recorded** with the Worker's own sentence (for example, the `missing_program_price` sentence under the standalone sum). It never reads 0, and never a sum of only the priced programs.

- **A version the Worker could not price** (`available: false`, for example a currency mismatch) shows its `unavailable_reason` in each cell.
- **A bundle dearer than its programs** (`bundle_value_warning`) shows "No saving". Its sentence is said in money ("by €2,700"), not in the Worker's raw cents.
- **Provenance** sits above the table: the country recommendation's date, whether it is the latest, the pricing model version and the country index (ppm shown as 1.180).
- **Standalone sum and saving** count the programs included by default, as `recommendPackage` does. The note under the table says so.

### 4. States

- **No licence chosen:** the grid and base prices are drawn, and every priced cell says to choose a licence. Nothing is priced.
- **A licence with no country recommendation** (409 `no_licence_snapshot`) is said as that, with the Worker's sentence. It is not a failed read.
- **A failed pricing read** is Unreadable with Try again. No priced figure is drawn.
- **A failed licence list** is Unreadable with Try again, in place of the picker.
- **A failed catalogue read** is Unreadable with Try again, never "no package".
- **No active package** reads "No Axal VC package is active yet", and says that a draft is priced from its catalogue row.

The picker lists every licence the ledger returns (`licenceLedgerApi.all`). When that list was cut, the page says so.
