## D682 — Founder tools reached from their cycle module, and one way back from the old editors

Issue: #1539. Part of #1440. Built in #1557 (S18 · Codex, merged 2026-10-12). Number assigned by S1, 2026-10-12.

### What was built

- **Doors from a module to its tools.** #1520 retired the four founder desks, which linked every tool in their cycle. Five tools were then reachable only by URL. Each module page now offers a quiet "Open …" link in the place its existing tool links sit:

  | Tool | Path | Module |
  | --- | --- | --- |
  | Landing-page builder | `/grow/brand` | Grow › Distribution |
  | Launch calendar | `/grow/launch` | Grow › Distribution |
  | Liquidity | `/raise/liquidity` | Raise › Cap table |
  | Legal documents | `/legal` | Build › Company creation |
  | E-signature | `/legal/send` | Build › Company creation |
  | Investor match | `/raise/capital-match` | Raise › Capital relationships |

- **One way back from each older editor.** The tab bars of sibling tools that `FounderWorkspaceTabs.jsx` drew are gone, with the component itself. Each editor shows one return link to its module, for example "← Raise › Pitch deck".
- **One map for both directions.** `frontend/src/pages/cycles/founderToolNavigation.js` (`FOUNDER_TOOLS`) drives the doors in and the returns out, so the two always name the same module.

### The decisions

- **No new panel, card or pill.** A door is a plain link in the module's existing tool-link position, as the owner asked on 2026-10-10.
- **A link appears only where the tool's own access rule admits the founder.** Liquidity keeps its Studio tier gate. The legal pages keep their roles.
- **The project travels, nothing else does.** A door or a return keeps `project_id`, and drops an editor's own mode, tab and filter parameters.
- **Investor match belongs to Raise.** It moves from Grow to `/raise/capital-match`, under Capital relationships. `/grow/capital-match` redirects, keeping its query and hash. Grow no longer lists it.
- **Each editor returns to the module it serves.** S1 reviewed the map on 2026-10-12:
  - `/build/discovery`, `/build/marketplace` and `/advisory` → Validate › Customer research. Marketplace and Advisory sat in the old Discovery tab set, so this keeps their grouping.
  - `/execution` → Build › Product roadmap.
  - `/build/metrics` → Build › Operating systems.
  - `/build/team` → Grow › Team expansion.
  - `/comarketing` → Grow › Distribution.
  - `/network-effects` → Grow › Partner network.
  - `/raise/pitch` → Raise › Pitch deck, and `/raise/pitch/positioning` → Raise › Investor narrative.
  - `/raise/capital` → Raise › Use of funds; `/raise/capital/cap-table` → Raise › Cap table; `/raise/capital/pipeline` → Raise › Capital relationships.
  - `/raise/data-room` → Raise › Data room.
  - `/raise/legal-engine` → Build › Company creation.

### What was dropped, and why

- **The sibling-tool tab bars.** They listed tools from desks that no longer exist. Their tests were rewritten around module navigation, not deleted.
