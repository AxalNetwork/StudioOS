### 1. A change starts from what is recorded

`POST /api/deals/:id/commitments` sets `amount` and `notes` from the body, so a dialog that opens at
the deal minimum with an empty note erases the note on save. Change amount now opens
"Change your commitment" with the live commitment's amount and note. Saving without touching the
note sends it back unchanged. A new commitment still opens at the minimum with no note.

### 2. One commitment action, from recorded state

| Deal | Your commitment | Header | Commitment tab |
|---|---|---|---|
| active | none (or only withdrawn) | Commit | Commit |
| active | Pending | Change amount | Change amount, Withdraw |
| active | Confirmed | nothing | Withdraw; "changes only by withdrawing" |
| not active | any | nothing | the reason, in the deal's status word |
| any | loading or unreadable | nothing | the tab's own reading / Unreadable state |

### 3. Refusals in words

Each Worker refusal (KYC, not invited, below the minimum, not open, a confirmed commitment, a
concurrent change) is drawn in the dialog as a sentence ending "Nothing was recorded." The dialog
stays open.
