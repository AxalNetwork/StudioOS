### What is built

- **Activity** (`pages/raise/dataroom/activityModel.js`). The log uses the page's own words for the two D6869 actions:
  - "Added [file] to their Library";
  - "Removed [file] from their Library".

  A file that is no longer in the room reads as the log already names it: "a file no longer in the room". The event filter gains *Added to their Library* and *Removed from their Library*, which the Worker's `action` filter and CSV already take. The week's figures stay as before: opened, links issued and blocked.
- **Access: the switch** (`LibrarySwitch.jsx`, `librarySwitchModel.js`). A card titled "Investors' own Ask" sits under the NDA strip and reads `GET /api/room-library/settings/:projectUid`.
  - It shows "Off · the default for every room" or "On", and says what the switch allows. NDA files follow the NDA, and this switch never opens them.
  - **Turning it off** goes Scope → Review → Result:
    - Scope is the card.
    - Review lists what changes before anything is sent, with the Worker's own count of live copies (`live_references`): how many files in investors' Libraries lose their reach now, that past answers keep their text while their citations read No longer available, and that the founder's files and the investors' room access do not change.
    - *Turn off* sends `PUT` with `allow_library: false`.
    - Result says how many copies lost their reach, from the PUT's own `lapsed`.
  - **Turning it on** is one confirm.
  - Only the room's owner changes it (`can_change`). A co-founder reads the state and the line "Only the room's owner turns this on or off."
  - A read that fails says Unreadable, with Try again. It never says Off.

### Where this departs from the canvas

- **No "turned on by you on [day]".** RS-17 B draws "On · turned on by you on 10 Oct 2026". D6869's settings read carries no change date, so the card says "On".
- **No investor count in Review.** The canvas reads "4 files in 1 investor's Library". The settings read counts live references and not investors, so Review names the files only.
