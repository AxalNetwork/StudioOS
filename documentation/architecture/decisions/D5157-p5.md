## D5157 part 5 — Save Ask answers to a Research Project (#5157)

An answered exchange in the founder workspace can be linked to an active
Research Project from Ask. The existing project picker lets the member choose
or create a project and confirms the link only after the Worker accepts it.
This uses the existing owner-scoped answer link. The project's Ask history
then reads the answer and its recorded citations without copying the exchange.

The citation regression now locates the grouped source container, rather than
the removed direct citation-map expression. Its former -1 offset included the
later Save to project condition and reported a false failure. A mounted check
keeps the exact recorded passage visible for both answered and model-unavailable
rows, while only the answered row offers Save to project.
