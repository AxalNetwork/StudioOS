## D5952 — Recorded quarterly figures in Revenue v2 (#5952)

Status: draft implementation; #5719 is closed at the publication check. Part of #5038.

## Contract

Use the existing `/api/admin/revenue/summary` `metrics` from D5950; no new
route, data collection, migration, setting or payment write. The selected
quarter must exactly match each envelope. Complete figures are Recorded (a
measured 0 is Zero), incomplete figures retain an amount+ and their gap in
coverage, pre-coverage figures stay Not recorded, failed reads are Unavailable.
Absent values never become zero and currencies are never added together.

Subscription revenue is net receipts after refunds, with gross and refunds
beside it in Revenue streams; these paid invoice cash events are not relabelled
as all invoices raised. Subsidiary gross is each reported stream's measurement,
not the separate statement's HQ claim. Current-quarter branch reports older
than seven days stay Stale, using the existing D5039 threshold. Unmeasured
streams remain Not recorded; missing branch reports are Not reported.

AI billed, cost and margin are per licence only if the read model has them;
HQ's missing attribution is not manufactured from local branch databases. Counts
of unattributed and pre-migration runs remain visible even when values are
absent. Scope narrows only licence rows; platform AI totals keep their label.

Promotions prefer the automatic report over legacy ceiling copies, including
when the metric read failed. Issued requires a dated reported/stale figure.
Remaining is the nonnegative difference from that report's ceiling, only if
the displayed ceiling still matches, and retains Stale. No report, no Remaining.

Coverage records source, period, currencies, last reconciliation and basis,
coverage start and basis, missing-row count and detail. Reasons live in the
coverage drawer, not duplicated on the page. A monthly trend is still absent.
