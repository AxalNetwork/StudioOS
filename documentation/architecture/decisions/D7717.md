## D7717 — Eurostat structural business statistics: enterprise counts, persons employed and net turnover by activity, size class and country (#7717)

**Decision date:** 2026-11-23. **Scope:** one importer (`services/marketObservations/eurostatSbs.ts`) and its registry
entry, one data-only migration (`202611231518_7717_eurostat_sbs_source.sql`: source `eurostat-sbs` and three catalogue

### Reuse terms relied on

The Eurostat copyright notice, `https://ec.europa.eu/eurostat/en/help/copyright-notice` ("Copyright notice and free
re-use of data"), read 2026-11-23 15:14 UTC, says: "Reuse of statistical data, metadata, publications, and other
dissemination tools published on this website for commercial or non-commercial purposes is authorised provided the
source is acknowledged", implementing the Commission Decision of 12 December 2011. Its exceptions that bind here:
data for countries other than EU Member States, EFTA Member States and official acceding and candidate countries may
not be reused commercially; modified data must say so and carry a disclaimer of Eurostat's non-responsibility; a
dataset is cited as "Source: [DOI], [access date]". The candidate list was read the same day from Eurostat's
glossary (`https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:Candidate_countries`): BA, ME,
MD, MK, GE, AL, RS, TR, UA.

Hence: the source row lands **enabled**. Its usage note carries the citation (DOI, access date = each row's retrieval
date), the reuse basis with the date read, the statement that codes are converted and values are not modified, and
the non-responsibility disclaimer. The importer accepts only `SBS_GEOGRAPHIES` (EU27 with `EL`, IS, LI, NO, CH, the
nine candidates, and `EU27_2020`). `export_allowed` stays unset, so the D7716 export leaves these rows out: the notice
allows it, but D7716 made export a per-source decision for the owner (see Open question).

### The series and the break

Only `sbs_sc_ovw` is imported, reference years 2021 and later (`from` below 2021 is refused). The 2005–2020 table is
never joined to it; every row's limitations say so. The 2021 cells Eurostat flags `b` carry "break in time series".

### Flags

- `e` → status `estimate`. `f` → `forecast` (in the codelist; not seen in this table).
- No flag → `unspecified` (D7318: not labelled Actual, since Eurostat does not say so).
- `p` provisional, `b` break in series, `d` definition differs, `u` low reliability, and also `n` not significant and `i`
  imputed → appended to `limitations`.
- `m` (missing; data cannot exist), a missing cell, and a confidential cell (`|C`, `|N`, `|P`) store **no row**, never a
  zero and never a row with a null value; each is counted in the reply's `skipped`. A measured zero is stored as 0.
- A flag the codelist does not define is skipped and counted (`unknown_flag`), never guessed.
- **A changed flag with an unchanged value is a revision.** The shared writer (`write.ts`) compared only value and
  status, so a flag that moves only the limitations (for example `p` dropped) would have counted as unchanged. It now
  also compares `limitations` (null-safe) in its prior read, its in-batch duplicate check and its insert guard. World
  Bank rows have null limitations, so their behaviour is unchanged (the D7709 suite passes as it was).
  Consequence: `SBS_LIMITATIONS` is part of each cell's identity. Editing that text later makes the next import of an
  edition already held an `edition_conflict` (refused, nothing written) and of a newer edition a revision of every
  cell, so the text is changed only deliberately, with a decision.

### Geography

Eurostat's two-letter codes go through #7716's `ISO2_TO_ISO3`, after Eurostat's own `EL` → GRC and `UK` → GBR. The
United Kingdom is mapped but not importable: its data falls outside the notice's commercial-reuse grant and the table
holds none. `EU27_2020` is the provider's own aggregate and is stored as a `region` row (D7716 `REGION_CODES`). Any
other aggregate (`EU…`, `EA…`, `EEA`, `EFTA`) is skipped and counted as `aggregate_geography`; any other unmapped code,
or a code the batch did not ask for, as `unknown_geography`. The importer never sums countries.

### Batch parameters and caps

`from`, `to` (2021–2100, at most 4 years), `indicators` (up to the 3 above, default all), `activities` (1–4 NACE codes,
section letter B–S with an optional 2- or 3-digit division or group), `size_classes` (1–4 of the four above),
`geographies` (1–10 from `SBS_GEOGRAPHIES`). Duplicates are refused. The cube must be at most 40 cells (the writer's
`MAX_BATCH_ROWS`), or the request is refused with `sbs_batch_too_large` before any run or provider call; other invalid
parameters are `invalid_sbs_parameters`, and any cursor is `invalid_cursor` (one request per batch, no continuation).
The provider read is the D7709 bounded fetch (`providerJson`, now exported): 250,000 bytes, 12 seconds, no redirects.
A provider failure records a failed run with only its class and HTTP status and keeps every earlier row.

### Open question for the owner

Whether `eurostat-sbs` rows may leave in the D7716 CSV export: (a) keep unset (this PR); (b) set `export_allowed` in a
later migration, relying on the same notice and keeping the citation column. Recommendation: (b) once the owner
confirms the export channel is covered; nothing in this issue needs it.

### Rollback

Revert the PR. The source and catalogue rows stay in D1 and can be disabled with an operator migration setting
`enabled = 0`; imported rows (none until the owner's first import) are append-only and remain readable.
