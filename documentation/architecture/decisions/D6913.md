## D6913 — Research › Library: a data-room file in the Library, part 1, the investor's side (#6913)

- **Status:** part 1 built by S10, 2026-11-20. It covers RS-13, RS-14 and RS-16 over D6869's routes. No Worker change and no migration.
- **Canvas:** `design/incoming/Investor Research v2 Data Room to Library Page.dc.html`, boards RS-13 to RS-20.
- **Builds on:** D6869 (the routes, the lapse rule, `from_rooms` and `room` on `GET /api/research/documents`) and the client `frontend/src/lib/api/roomLibrary.js`.

### What is built

- **RS-13: the room file row** (`pages/research/DiligenceRoom.jsx`, `RoomLibrary.jsx`).
  - Each open file gets a Library cell. A file already in the investor's Library reads *In your Library*, with *Open*, which goes to its Library row. Any other file offers *Add to my Library*.
  - A room whose founder has not allowed Library copies offers no button, and says so once: "The founder has not allowed Library copies of this room's files."
  - Files behind an NDA stay a count only. They are not listed, so they have no cell.
  - *Add to my Library* opens a confirm sheet before anything is added. The sheet shows five lines:
    - the file;
    - the room it comes from;
    - the access and when it ends;
    - Read-only;
    - the cost: "Indexing: no charge. Each Ask answer is charged as today."
  - *Add to Library* posts `POST /api/room-library/items`. A second add (409 `already_added`) is treated as done, using the existing row. Each other refusal gets its own sentence.
- **RS-14: the Library** (`LibraryZone.jsx`, `researchStates.js`).
  - **Source filter.** It offers All sources, Ours, Shared by clients and From data rooms. It sits beside the kind filters, is stored in the URL as `source`, and narrows the list already read.
  - **A room row.** It carries "From [room] data room" in the source mark. It reads "Read-only · Added [day]" under its title, and offers *Open in room* and *Remove from Library*. It is never downloaded from the Library, because that download answers 409 `open_in_room`.
  - **Header counts.** With room files in the Library, the header adds "N answerable in Ask · M not answerable · K from data rooms". These are the Worker's own counts, with room rows included.
- **RS-16: Source no longer available.**
  - A lapsed row keeps its place and its title, and shows one reason in its own words:
    - `revoked`: the founder ended your access to this room;
    - `expired`: your access to this room expired;
    - `removed`: the founder removed this file from the room;
    - `moved`: the file is no longer in the folders your access opens;
    - `nda_lapsed`: the NDA for this room is no longer active;
    - `library_off`: the founder no longer lets investors keep this room's files in their Library.
  - In the Answerable in Ask column it reads *Not answerable*, with "Source no longer available" as the reason.
  - It offers only *Remove from Library*.
  - A file behind an NDA that lapsed is nameless: it reads "A file behind the NDA", as the room's own log does not name it.

The words live in `roomLibraryModel.js`, a pure module that the room, the Library and the test all read.

### Where this departs from the canvas

- **Open in room goes to Diligence.** The Library row carries the room's project uid, not the grant uid that the room page's address uses. *Open in room* therefore opens `/research/diligence`, the list of the investor's rooms, rather than the one room.
- **The Library cell is a column, not an overflow.** RS-13 draws *Add to my Library* in the row's overflow menu. The room's table has no overflow yet, so the action sits in its own Library column, labelled with the same words.
