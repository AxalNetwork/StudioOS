## D9111 — HQ › AI agents › Operations › Spend: the agent budgets panel, built to the canvas (#9111)

Builds the landed canvas `HQ AI Agents Execution Budgets` (D4137-p3, boards SA15 to SA19, handoff SAB-H) over
D8071's routes (#8071). Gap g28 of the 2026-11-27 UI audit.

### What was built
- **Spend switch (SAB-H).** `/hq/ai-agents/operations/spend` switches between Platform spend (today's `Spend`,
  kept as `PlatformSpend` in `Operations.jsx`) and Agent budgets (`pages/hq/aiAgents/Budgets.jsx`).
- **Agent budgets (SA15, SA18, SA19).** One workspace at a time: its four ceilings in force (the workspace's own,
  else the platform figure, never above it), each agent's four meters (used / cap, period, share; ■ At cap,
  ▲ 80% and over, ○ No cap, ∅ Not applicable, ? Unavailable) sorted by the highest share, and the runs halted for
  budget, each in its own refusal's words. At 390 px one agent per card, ceilings two by two, halted runs one tap
  away. Rules live in `budgetsModel.js`.
- **Edit caps (SA16, SA17F).** A side panel, a bottom sheet below 640 px: each cap with its unit, this period's use
  and who set it when; Save needs a reason and a change, sends only the changed fields, and the row takes the
  Worker's answer. A refusal is worded by `policyRefusal`. Edit ceilings does the same for the workspace's four
  ceilings, where the platform figure is shown and a figure above it is refused inline before it is sent.
- **Sponsor view (SA17D, SA17E).** `SponsorBudgetCard` (`BudgetParts.jsx`) in Team's agent profile reads
  `GET /api/teams/agents/:uid/budget`: the four meters and halted runs, read only; 404 and 403 draw Refused.
- **Client.** `frontend/src/lib/api/aiAgentBudgets.js` (the five D8071 policy routes) and
  `teamAgentsApi.agentBudget(uid)`.
- **Worker read.** `GET /api/admin/ai-agents/policy/budgets` now also carries each agent's `name`, `scope_id` and
  `scope_name`, and a `workspaces` list of each scope's own ceilings (`workspaceOwnCaps`, null meaning the
  platform figure) and its use this month (`workspaceUsage`). `agentBudgetView` adds `set_by`, the setting
  admin's name, so the sponsor's read carries it too. No schema change.

### Where it departs from the canvas
- The ceiling refusal is main's `above_platform_ceiling`, not the canvas's `above_ceiling`.
- No `budgets_unwritable`: main never sends it; a failed save shows the Worker's refusal in words, and a failed read
  is 503 `budget_unreadable`.
- No platform ceiling beside an agent's four caps: main has none for them. The ceiling and Above the ceiling apply to
  the workspace's ceilings.
- A halted run opens its detail in Operations › Runs (`RunDetail`), not Audit: the admin audit has no run filter
  and lists no runs.
- A failed read says Unavailable (AGENTS.md § Honesty, D5129, the `DataState` vocabulary), where the canvas and the
  issue say Unreadable.
- Retries on one task: the read carries no use, so the meter shows the cap and "Use not recorded".
- ∅ Not applicable is in the vocabulary but not drawn: the budgets read does not say which agents hold a GitHub
  capability.
- Not built: the cost column and its link to AI usage (the budgets read carries no cost per agent), the CSV export,
  the agent search, Eadwyn's proposed caps (#5130), and the warning when a cap is set below this month's use.
- The phone's Edit caps is an editable sheet as SA18B draws it; D4137-p3's open question (SA9h made the HQ phone a
  read-only summary) is built as SA18B draws it.
