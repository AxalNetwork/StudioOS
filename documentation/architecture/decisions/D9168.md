## D9168 — Hashed /assets/* files leave the Worker as immutable (#9168)

**Date:** 2026-11-27. **Status:** Built.

### Context

`/assets/*` is in `run_worker_first` (`wrangler.toml` `[assets]`), so `cloudflare-worker/src/index.ts` answers every hashed chunk from the assets binding, and `frontend/public/_headers` has no effect on it. The binding's default is `public, max-age=0, must-revalidate`. Every page load therefore revalidated about 70 modulepreloaded chunks through the Worker, on both hosts. `HEAD` on a hashed file also answered 404, because the branch accepted `GET` only.

### Decision

`serveHashedAsset`, a local function in `cloudflare-worker/src/index.ts`, shapes the binding's answer for `/assets/*`, for both `GET` and `HEAD`. It is inline, not a module of its own, because `index.ts` is a frozen hub (D5615) and a new import there fails `hub_freeze_5615`:

- **200 or 304:** `Cache-Control: public, max-age=31536000, immutable`. A hashed name never changes content. Body, type and `etag` are unchanged.
- **The SPA fallback's `text/html`, or any 404:** a plain-text 404 with `no-store`, as Task #37 decided. A stale tab's boot watchdog and stale-chunk reload still move it onto the current build.
- **Any other status:** passes through unchanged.

The 72-hour old-bundle window is untouched. Retained files are still in the binding, so they answer 200 with `immutable` too.

`scripts/check-spa-live.mjs` now fails when a hashed file the shell references, the entry module first, does not leave as `immutable` (`assetProblem` in `scripts/lib/spaChunks.mjs`).

### Not done here

- **OG images.** `/og/*.png` are not served by the Worker: they are not in `run_worker_first`, and the assets binding answers them with `max-age=0`. A `_headers` rule cannot see `?v=`, so it could only set a moderate `max-age`. `frontend/public/_headers` is being edited by #9127 (its comment) and #9166 (the CSP), so this follow-up waits for both: a `/og/*` rule with a moderate `max-age`.
- **The `_headers` comment** that says an `/assets/*` rule there would be inert stays as written. It is still true, and #9127 is rewriting that block.
