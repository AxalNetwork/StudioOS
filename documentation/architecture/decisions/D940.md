### 1. SHL7a: the HQ-only card

`pages/hq/SuperAdminOnlyNotice.jsx` is what `hqOnly` in `App.jsx` draws for an admin who is not the Super Admin. It is now the canvas's dashed card:
- the eyebrow "HQ only";
- one h1, "This page belongs to the Super Admin";
- the line;
- the links "Go to Studio" (`/studio`) and "My licence" (`/admin/my-licence`).

The "Admin Console" link is gone.

**The line's first sentence names what HQ manages on the page.** `hqOnly` passes no subject and part 1 (#2743) edits the same routes, so the notice reads its own path (`hqNoticeModel.js` `hqLine`):
- **Funds** reads the canvas's sentence, "HQ manages bank accounts.";
- **every other HQ-only page** reads "HQ manages this page.". No other page's subject is in the canvas, so none is invented.

### 2. SHL7b: a member who is not an admin on an admin page

`RoleGuard` sent every refused role to its home with no word. Now, on an `/admin` address (the console or any page under it), a signed-in member whose own account is not an admin sees `pages/hq/AdminOnlyNotice.jsx` in their own shell:
- "This page is for studio admins";
- "If you run a studio, ask HQ for admin access.";
- the button "Go to your home", which goes to their role's home (`ROLE_DEFAULT_PATH`).

**Who keeps today's redirect** (`hqNoticeModel.js` `adminRefusal`):
- **A real admin previewing another role (View as).** The card's "ask HQ" would be wrong for them.
- **An admin impersonating a member.** The redirect also carries the impersonation handoff (Task #102), so it must win.
- **Every route outside `/admin`.**

**Where it sits.** The branch sits after D914's route boundaries and after the handoff target is read, and before the redirect.

**`/admin/kyc` is not a route.** The issue's example, "a member on `/admin/kyc`", answers the 404 page for everyone, because no route has that address. The card shows on every `/admin` route RoleGuard refuses, for example `/admin/spinout-lab`.

### 3. Access

- **One h1 per card**, and the links are plain links in the page: no dialog, so nothing traps focus.
- **The glyph** is `aria-hidden`.
- **Light and dark** come from the same tokens as the admin shell.
