### What the canvas decides

- **Six value states:** Value (a measured 0 is a Value), None, Not recorded, Not applicable, Unavailable, Refused. **Three modifiers:** Stale (always with an age), Partial (one banner per block), Provisional (one shape for "Modelled"). Loading is a skeleton in the real layout's shape.
- Each state has its own glyph, border style and word; none relies on colour (greyscale check on ST-01).
- **Charts:** a Not recorded gap breaks the line, an Unavailable period is an outlined slot, a measured 0 sits on the baseline, a stale last point shows its age, and a delta is shown only when both ends are Values.
- **Partial composites:** figures that depend on the missing source read Unavailable and the totals they feed are withheld with a reason.
- **Raise v2's words are settled** on ST-12 (Partial, Stale, Changed, Refused, Founder only, Modelled, Backed, Mismatch) as platform states, modifiers or surface labels, and the per-surface lists (#4864, #4863, #4828, #4834, #4844, #4816 to #4818) are folded in. Once approved, this canvas supersedes Raise v2's RA-08 board.
