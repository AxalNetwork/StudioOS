### 1. The page

`RoundCallPageView` hands an investor's read to `InvestorCallView`. The founder's and counsel's views are the same code as before.

- **The header:** "Deals › Round calls › [company]", where Deals links `/deals`. Then "A private round call from [company]", the call's name, "sent to you on" its send date, its close date, and a chip that reads Open, Closed or Paused.
- **Terms:**
  - instrument, target, the instrument's own key term (cap, or a note's cap and discount, or equity's pre-money), minimum cheque and close date;
  - then "In plain words", built only from the terms the call records;
  - then the counsel-approved terms text.

  A missing term reads Not recorded, never a zero.
- **Pitch deck:** "v[n] · frozen with this call", with "Open the deck" opening the frozen slides' text in place (`RecordedCallDeck`, unchanged).
- **Data room.** It opens only when the NDA is signed **and** the founder has granted access. The three states:
  - no NDA: a lock, "Sign the NDA to ask for access", and Request the NDA;
  - the NDA with no grant: Ask for access, then the date it was asked for;
  - both: Open the data room.

  With no room linked, it reads Not recorded.
- **Indicate an amount.** Gives the minimum cheque and "This records your intention. It is not a payment or a signed investment." The button stays off outside the minimum cheque and the target, the range the Worker enforces. A recorded amount reads "Indicated · $X". The investor's page never shows the word Commit.
- **Ask a question.** The placeholder is "Your question for [company]". The investor sees their own questions as "You asked on [date]", never with a name.
- **A read-only call:**
  - Closed: "This call is closed. You can still read the terms and the deck. You can no longer indicate an amount or ask a question." There are no inputs and no buttons.
  - Paused: an extension waiting on counsel, or a deck that changed after approval. Each says which.

**No other investor is named.** The investor's read carries no recipients. The page draws none, and it draws no name on a question. The test plants both and checks neither renders.

### 2. Departures, for review

- **`company.name` on the investor's read.** CLS13's header names the company, and the read did not carry it. It is one bound statement: the project's name only, and none for a deleted project. It is not the founder's name or email.
- **The NDA button reads "Request the NDA", not the canvas's "Sign the NDA".** This page has no signing flow. The pairwise NDA is an envelope the founder sends, so the button keeps D653's request, which lands in the founder's questions. The canvas's line "Sign the NDA to ask for access" stays as the explanation.
- **"Frozen with this call", not a date.** The read carries the deck version, and no date it was frozen on, so no date is drawn.
- **The action is still `commit` on the wire.** Only the words change: the API and the pipeline's soft commitment are D653's.
- **The evidence block** (another canvas) is not drawn here.
