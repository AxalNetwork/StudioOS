## D5721 — Census public Help for every signed-in rail profile (#5721)

D4637 deliberately makes Help home and guide URLs public. The rail census
previously inferred member audiences only from explicit guard arrays or
authOnly, so these two routes acquired an empty audience and failed the
whole-app parity assertion after #5574.

The test helper now recognizes exactly those two public Help patterns as
also admitting the existing signed-in member roles. The existing census
continues to require each profile's real Help page key. Anonymous catalogue
and routing behavior remain covered by D4637's public Help contract tests.
Admin paths, ticket guards, redirects and other unguarded routes keep their
existing inference. No product route, authorization rule or no-rail exemption
is changed.

Regression tests check both public paths, every member audience, current page
keys and the narrow boundary around admin/ticket/redirect paths. Removing the
fallback, omitting a public path, dropping a member role or widening it to the
whole Help prefix must fail. This is the single main repair for #5721; #5702
receives it through main after landing.
