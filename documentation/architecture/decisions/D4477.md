## D4477 — Learning videos library filters and open-at-time (#4477)

Part of #3726, implementing LR7 in `design/incoming/Learning Stream Page.dc.html`.
The existing catalog is the source for videos, topics, levels, lengths and
transcript matches. This task adds no Worker route, client method or migration.

The Videos tab keeps topic, level and maximum minutes in the URL so browser
history restores the selection. Options come from recorded catalog values;
unknown lengths say “Length not recorded”, and an unknown total is omitted
from the count. No profile filter or fabricated metadata is introduced.

The first transcript match is shown with React text and a `mark` element,
never injected HTML. A recorded time links to `/learning/videos/:uid?t=N`.
The item container accepts only a nonnegative whole number within a recorded
duration. That initial time takes precedence over saved progress; the existing
player performs its initial seek once. Invalid times keep normal resume.

Cards use a plain play tile unless the catalog already has a poster. Signed
Stream previews are still read only after the existing 400 ms pointer hover,
never minted for each catalog row. The layout uses the existing theme tokens,
one column through tablet widths and 44px phone controls. Learning keeps its
Account-menu entry, with no AI rail, Ask or assistant panel added.

Shared-file boundaries with #4478 and #4481 are coordinated on #4477. The
library component and its pure helpers are isolated so their lesson/footer
and home-action changes can remain independent.
