### 1. A Worker route, not the zone-header export

The issue asked to reuse `kind: 'export'` (`founderZoneActions.js`) before
adding a route. That mechanism writes the rows a page has loaded, and a module
table loads one page of at most 100 rows (`pageOf`). The file has to hold
every row the table's search, filters and sort select, so the export is a
route: `GET /api/cycles/grow/modules/:slug/export?project=&q=&filter=&sort=`.
It runs the module read's own `recordsFor` and `shapeRecords` with no page, so
the file and the table agree on which rows they hold.

### 2. Four modules, writers only

Team expansion (roles), Partner network (partners), Market expansion (markets)
and Durable company-building (obligations) export. Any other slug is a 404.
The route gates the venture for writing, so a reader (an advisor, an
investor) gets a 403 before anything is read. The module read sets
`records.exportable: true` only for a writer on one of the four, and the page
draws Export beside Add only then, and only when the table has rows. On the
phone, Export sits under the rows.

### 3. What the file holds

The table's columns, then `Source` (the module's store, as its card names it)
and `As of` (the day of the export). Stored words read as the table labels
them (`not_now` → `Not now`). Partner revenue is in dollars with two decimals,
and the column says USD. A missing value is an empty cell, never 0. A count
that was read is a number, including 0. The roles export carries counts of
applicants, never who applied. The markets export leaves out the update-ask
replies the page draws beside a market, and their senders' names. No module
here lists deal customers, so the issue's "deal customers only for writers"
holds because the route is writers-only. A typed cell that a spreadsheet would
run as a formula (starting `=`, `+`, `-`, `@`, a tab or a carriage return, and
not a plain number) gets a leading apostrophe, as the cap table's export does
(D1020).

### 4. A failed read is refused

If the store cannot be read, the route answers 503 with
`Unreadable: <source> could not be read, so nothing was exported`. It never
sends a file with a header and no rows. The button shows the Worker's sentence
for any refusal.
