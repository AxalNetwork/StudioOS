## D6291 — Diligence Cases and case actions on phones

DDL18a uses one card per case below the medium breakpoint. It reads the
same row cells and actions as the desktop table, with the same search,
filters, sorting and paging. The age and decision charts size to the
available width.

DDL18b stacks case record cells with their headings. Checklist status
and request actions open sheets on phones. The selected action keeps its
existing confirmation and permissions. Flag details and their actions
use the shared dialogue in its phone sheet format.

D1252 already covers the reviewer view and My reviews. Templates is a
separate list tab and is outside the Cases and nine case tabs checked here.

### Browser verification

At 390 × 844 in Chromium 141.0.7390.37, synthetic deal-team records loaded
on Cases and each of the nine case tabs in light and dark mode. Document
width stayed at 390px on all 20 views. The Cases screen showed cards and the
checklist and request action sheets opened and dismissed in both themes.
The initial Cases check exposed chart overflow at 806px, which the chart
sizing fix resolved.
