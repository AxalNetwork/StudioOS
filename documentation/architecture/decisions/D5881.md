## D5881 — Debounce Approvals search and cancel superseded reads (#5881)

The Inbox search field updates immediately and commits its trimmed query to
the URL after 300 ms. Changes to the URL's search term and clearing filters
cancel pending edits. The URL continues to own filters and pagination.

Inbox, Decided and lane board reads pass an AbortSignal to the request client.
On replacement or unmount, cancellation stops the request and prevents its
late completion from changing the page. Genuine failures and partial Inbox
results still use the existing messages. Assignments and decisions reload the
current view without changing its filters or page.
