## D4388 — The 16 personas carry the canvas's values and two areas, as stored data (#4388)

- **Status:** decided by the owner on 2026-11-04; built by S24. Part of #4137 and #4116. It amends D4117 §1 (the values) and §3 (natural fit).
- **Migration:** none. The personas are code (`cloudflare-worker/src/services/agents/personas.ts`), so the values are not stored in D1.

### 1. What changed

The owner revised the HQ › AI agents canvas (`design/incoming/HQ AI Agents Page.dc.html`, artifact `LxnWj8iKZPZyfvLYJoeFT9`). Each persona's three values are now Axal values (`FIT_V2_VALUES`: Integrity, Collaboration, Stewardship, Resilience, Curiosity, Ambition). The canvas also names two areas per persona.

- **Values:** each seed's `top` is the canvas's three values, **in the canvas's order**. Value scores still follow D4117 §2: 0.9, 0.8 and 0.7 in that order, then 0.5, 0.4 and 0.3 for the rest.
- **Areas:** each seed gains `areas`, the canvas's two areas. A persona's `natural_fit`, on the catalogue and in every persona read, **is** those two areas.
  - It is no longer worked out from the values.
  - `AgentCard`, `skillsModel` and `personaModel` already read `natural_fit`, so the frontend needs no change.
- **Unchanged:** the 16 keys, names, gender, risk, tagline, goal, personality, story, avatar and `ROLE_PERSONA`.

### 2. D4117 §3's rule stays, as a suggestion only

`naturalFit()` (pairs of values → the two highest areas) stays for custom agents and for hints, as an advisory "suggested fit". It never decides a persona's areas: on the canvas the rule and the stored areas name the same pair for only 2 of the 16 (Vesta and Elara), and in the same order only for Elara.

### 3. Distinct profiles

D4117 §1 held that no two personas share a top-3 list. With the canvas's values, three personas share one set of values in different orders (Vesta, Seren and Solen), and two share another (Kade and Corin). Their **ordered** lists still differ, so their scores still differ, and no two profiles are equal. The catalogue test now checks ordered lists.
