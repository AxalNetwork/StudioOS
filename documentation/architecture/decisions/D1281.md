## D1281 — Program grants: one studio's "In use" reads D1156's reports (#3339)

- **Status:** S11, 2026-10-26 (#3339, part of #2376). Moved from S04 on the owner's instruction.
- **The gap:** on HQ › Licences › Program grants › one studio, every live grant's "In use" cell read "Not recorded · This studio has not reported program figures yet.", unconditionally. D1156 (#3061) had already stored the studios' dated, count-only program reports (migration 601) and serves them at `GET /api/admin/program-grants/licences/:uid/in-use`, but no page called `programGrantsApi.inUse`.
- **Basis:** `origin/main` at `90f63e3`.
- **Migration:** none. **Worker:** none; the read is D1156's.

### 1. What the studio view reads

`StudioView.jsx` reads `programGrantsApi.inUse(uid)` once per studio, beside the licence read. It reads again after a grant, change, pause, resume or end, because which programs are live can change.

### 2. What each cell says (`grantsModel.js` `inUseOf`)

| The read says | The cell |
|---|---|
| The program was reported | Its recorded counts, e.g. "People 9 · Claims 1,204", then "Reported 25 Oct 2026 for 2026-10." A report the Worker marks stale adds "· more than two days old". |
| A figure is unreadable at the studio | "Claims unreadable", beside the recorded ones |
| A report with no recorded measure | "Not recorded · This studio has no recorded measure for this program.", with the report's date |
| No report for this program | "Not recorded · This studio has not reported this program yet.", plus "Its last report was on [date]." when the studio has reported another program |
| The read failed | "Unreadable · Program figures could not be read." in each cell, and one "This studio's program figures could not be read." block with Try again under the table |
| Still reading | "Reading…" |

- **Never a zero for a missing report.** A figure the report does not hold is left out, never drawn as 0.
- **The rest of the view still draws** when this read fails: the tiles, the rows, the deal types, the requests and the history.
- **Counts only:** the read carries no person, and the foot line says so.
- **The CSV** carries the same words as the cell.

### 3. What was removed

- `IN_USE_WAIT`, and the unconditional `{ text: NOT_RECORDED, reason: IN_USE_WAIT }` on every live row.
- The "#3061" lines in `grantsModel.js`'s and `StudioView.jsx`'s header comments, and the foot line "In use waits for the studios' program figures".
- ROUTE_MAP's "In use reading Not recorded until the studios report figures (#3061)".
