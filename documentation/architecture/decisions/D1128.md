### Creation

HQ’s header and Advisors card link `/admin/persona-segments/new`. SEG13’s
ordinary-Admin refusal is drawn in the page; the Worker enforces Super Admin
and refuses a branch. The form uses SEG6’s existing name, profile, status and
who fields, with a permanent bounded key and an in-page confirmation. Needs,
typical members and offers start empty, rather than fabricated. Editing those
fields remains #2821.

`POST /api/personas/segments` validates through D1000’s bounded field checks.
Profile and first history version are one batch, with the actor. A duplicate
key is a conflict. Migration 559’s existing `edited` action records the first
authored version, before=NULL, plus the admin audit’s `segment_profile_created`
action; this needs no new enum or migration.

The public sign-up catalog offers only Active stored profiles, with stored
names and descriptions. Finalize, answer and retag validate stored IDs;
Draft and Retired rules remain D1000’s. A stored-only segment has no code
question bank or sidebar links; it reads Not recorded and can actually be
selected/finalized without entering a blank question screen. No profile role
is changed by segment selection.

### Moved members and completion

The member’s own `/api/personas/me` includes missing code questions only when
their primary segment was set by an admin. Existing answers for that segment
are retained; another segment’s answers do not count. Profile opens the existing
question screen. Failure leaves the rest of Profile available, with retry.
“Not now” defers that visit and its navigation state survives the canonical
`/account/profile` → `/account` hop. Explorers can reach the same question
route. Follow-up saves answers with an expected-primary check, never finalizing
again or replacing the admin’s source/manual override. A stale move is refused.

`GET /api/personas/segments/:key/completion`, admin only, supplies SEG2’s
“Answered every question” contract, with a matching client for #2820. It counts
active non-admin primary members whose every code question has a nonblank
stored answer. It returns only counts. Both a small 1–4 cell and its complement
are suppressed; a measured zero is zero. No bank is Not recorded; a failed read
is Unreadable (503). Rendering SEG2’s full page remains #2820.

### Events

Authenticated `/api/personas/audience-segments` returns stored key, name,
profile and status only (Active choices for members; admins may read all statuses), independently of the admin profile reads. Events’
editor has its own reading/unreadable/retry/empty states. Saved audience rules
validate stored IDs; a read failure never opens registration to everyone.
Retagged-away historical rows do not grant access. The legitimate code-defined
Founder/Operator secondary overlap still does. Existing members of a retired
segment retain their audience membership until moved.
