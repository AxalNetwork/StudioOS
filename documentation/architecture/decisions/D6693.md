## D6693 — Formation: order gates, the signed-in catalogue read, and pausing a form (#6693)

- **Status:** built 2026-11-16.
- **Plan key:** C3 (Phase 2) of #6680.
- **Builds on:**
  - D6689 (C1): the catalogue tables;
  - D6692 (P1): formation partners, credentials, coverage and prices;
  - D4811: counsel's legal reviews, bound to a version's SHA-256;
  - D4357: today's incorporation price;
  - owner decision 19 (answer A, on #6682): the allowed fact age is a config value, default 183 days.

### The problem

"Can this form be ordered?" was remembered: a price in the catalogue, plus one hard-coded Wyoming rule. The global catalogue needs it computed from the facts, partners, templates and switches that stand behind each form. The founder flow also needs a small read of the published catalogue that does not wait for the editor (#6699, #6700).

### What is built

**`services/formationGates.ts`** computes each gate on every read and returns it with pass or fail and, when it fails, why. Nothing is cached.

- **Legacy forms** (`legacy_gate = '1'`, the six forms the version-1 seed carries over, #6690) keep today's rule:
  - **price:** `resolveIncorporationPrice`, the price `POST /incorporation/order` charges;
  - **counsel:** for `us_wy_ccorp`, an active, non-stub body of `articles_of_incorporation_wy`. `LEGACY_COUNSEL` must equal `routes/legal.ts` `COUNSEL_REQUIRED_TEMPLATES`, and a test pins that;
  - **not_paused**, which applies to every form.
- **Every other form** is orderable only when all of these hold:

| Gate | Passes when |
| --- | --- |
| `published` | its version is the current published one |
| `offer_mode` | the form's offer mode is `orderable` |
| `partner` | a `verified` partner has `formation` coverage switched on for the form's country and key |
| `credential` | such a partner holds a credential for the country valid on or after today |
| `data_agreement` | such a credentialed partner has `dpa_signed_on` |
| `price` | the catalogue has a price for the form: an active product with `metadata.formation_form_key` equal to the key. The lookup is injectable for tests |
| `templates` | every pack item with `counsel_required = 1` and a template has an active body, and an `approved` legal review bound to that body's current SHA-256 whose jurisdiction is the form's country (`GB`, or a place within it such as `US-WY`). An approval with conditions, or one of an older version, does not count |
| `facts` | every blocking fact has a source and a `checked_on` within the allowed age, and none is `disputed` |
| `not_paused` | HQ has not paused the form |

- **The default partner** for a quote before payment is the coverage row with the lowest `priority` number among those passing partner, credential and data agreement. Ties go to the oldest row.
- **The allowed age** is `FORMATION_FACT_MAX_AGE_DAYS` when set to 1 to 3,650 days, and otherwise `DEFAULT_FACT_MAX_AGE_DAYS`, 183.

**Migration `202611161430_6693_formation_form_pause.sql`:** `formation_form_switches`, with one row per form key: `paused`, `reason`, `changed_by`, `changed_at`. A pause outlives a new catalogue version until it is resumed. No row means not paused.

**`GET /api/formation/catalogue`** (`routes/formation_catalogue.ts`, signed in):
- **What it returns:** the current published version, and each form not switched `off`, with:
  - its jurisdiction;
  - its facts, with source, `checked_on` and whether each is fresh;
  - its fee lines, where an amount not recorded is null, never 0;
  - `quote`: the default partner's current founder price, when the form is orderable.
- **Availability** is collapsed:

| Offer mode | Gates | `availability` |
| --- | --- | --- |
| `orderable` | all pass | `orderable` |
| `orderable` | any fails | `information_only` |
| `guided` | any | `guided` |
| `information_only` | any | `information_only` |
| `off` | any | not listed |

- **It never returns** a partner's identity, its cost (`cost_minor`), HQ's version notes, or which gate failed.

**`POST /api/admin/formation/catalogue/forms/:key/pause` and `/resume`** (`routes/admin_formation_catalogue.ts`):
- **Who:** the Super Admin, past the write bar, as D6692. A plain Admin is refused.
- **What it needs:** a reason, at most 500 characters, and a key some catalogue version has.
- **Record:** the change is logged in `admin_audit_log` (`formation_form_paused` or `formation_form_resumed`).
- **Effect:** on the next read.

**Client:** `frontend/src/lib/api/formationCatalogue.js` (`get`, `pause`, `resume`).

### Choices made here

- **`legacy_gate` is text.** The seed issue writes `'1'`; anything else is not legacy.
- **A non-legacy form's price** is a catalogue product tagged `formation_form_key`. The legacy forms keep their `jurisdiction_id` tag through `resolveIncorporationPrice`.
- **A failing orderable form reads `information_only`, not `guided`.** Guided is an offer HQ chooses, not a fallback.
- **The pause applies to legacy forms too.** It is HQ's switch for any form.

### Not built here

Editing and publishing the catalogue (#6699, #6700) and any screen.

### Tests

`cloudflare-worker/test/formation_gates_6693.test.ts` covers each Done-when case:
- a stale blocking fact names `facts`;
- suspending partners closes the form with no catalogue edit;
- a US review does not open a GB form;
- a legacy form is orderable on price alone;
- a pause closes the form on the next read and a resume restores it;
- the signed-in read never returns `cost_minor`.

It also covers disputed and unsourced facts, an expired credential and an unsigned agreement, the default partner, the offer mode, a missing price, a draft version, and the pause route's refusals and log.

**Mutation checks**, each of which turns a named case red:
- the jurisdiction check dropped;
- the fact age check dropped;
- the pause gate dropped;
- the priority order reversed.
