### Team agents part 1: the registry and the rule books (D1496, #3840)

Worker routes in `routes/team_agents.ts`, mounted at `/api/teams`, backed by `services/agents/catalogue.ts`, `services/agents/rulebook.ts` and migration 712 (`team_agents`, `team_rulebooks`, `team_agent_events`; `agent_id` and `decided_by_user_id` on `ai_rail_proposals`, `agent_id` on `ai_usage_logs`). The client is `lib/api/teamAgents.js` (`teamAgentsApi`). No page yet: S1's Team page integrates it (#3727 part 6). Every route is 404 `team_agents_off` unless `TEAM_AGENTS_ENABLED` is `"true"` (off in both `wrangler.toml` blocks). `:scope` is `company` (its uid) or `project` (its id). Read: a company's `user_company_links` row, or `canAccessProject`. Manage: the company's `canEdit`, or `isProjectManager`. A person is `{ uid, name }`, never an email or a numeric id. Part 2 (#3842) adds the run below, through `services/agents/agentRun.ts` (the gates, the rule book and the spend are `services/agents/teams.ts`'s); part 3 (#3843) adds the approvals queue, through `services/agents/queue.ts`.

| Route | Who | What it answers |
| --- | --- | --- |
| `GET /api/teams/roles` | signed in | `{ roles: [{ key, name, mission, works_in: [{ key, label }], default_rules }], models: [{ id, label, kind, beta, plan_locked }] }`, the eleven roles; General counsel also carries `disclaimer_key` (the wording is the owner's or counsel's). `models` (part 2) are the text models an agent may run on; `plan_locked` is true when the add route would refuse it or the caller's plan cannot add agents. |
| `GET /api/teams/:scope/:id/agents?include=projects&module=` | read | `{ can_manage, plan_ok, agents: [Agent] }`, live agents only. `include=projects` adds the agents of the company's projects for its editors only; `module=` keeps the agents whose effective `works_in` holds it. 403 `not_member`, 404. |
| `POST /api/teams/:scope/:id/agents` | manage + paid Founder plan | Takes `{ role_key, persona_key?, first_name?, last_name?, model_id, tool_grants?, monthly_cap_microusd }` (D4117); 201 `{ agent }`, sponsored by the caller. 400 `invalid_role` / `invalid_cap` / `invalid_name` (over 40 characters); 403 `not_manager` / `plan_required`; 409 `role_taken` (one live agent per role per scope); 422 `model_not_offered`; 422 `tool_not_approved` unless each grant is the caller's own connected D852 server and an approved, pinned read tool (part 5, #3844; never the mail send tool, never while `CUSTOM_MCP_ENABLED` is off). |
| `GET /api/teams/agents/:uid` | read | `{ agent, can_manage, rulebook: { effective, version }, matrix: [{ module, label, read, propose, auto: false }], cap_microusd, month_spend, proposals: { proposed, accepted, edited, discarded, withdrawn } \| null, events }` (the last 50). |
| `PATCH /api/teams/agents/:uid` | manage | Takes `{ status?: 'active' \| 'paused', monthly_cap_microusd?, first_name?, last_name? }`; `{ agent }`. Pausing records `paused_reason: 'manual'`. 409 `removed`. |
| `DELETE /api/teams/agents/:uid` | manage | `{ ok: true }`: status `removed`, rows kept, open proposals withdrawn; the role is free again. |
| `GET /api/teams/:scope/:id/rulebooks/:role` | read | `{ role_key, default, effective, version, versions: [{ version, by: { uid, name }, at }], diff: [{ section, added, removed }], floor }`. Version 0 is the catalogue's default; the diff is against it. |
| `PUT /api/teams/:scope/:id/rulebooks/:role` | manage | Takes `{ rules }`; `{ effective, version }`, a new row (never an update). 422 `rule_floor` (drops one of the seven floor asks, or names anything automatic) or `invalid_rules`, each with `section`. |
| `GET /api/teams/agents/:uid/run/quote?module=&option=` | the sponsor | Part 2. `{ quote: { available, value_microusd } }`: what a run would hold, an upper bound; `available: false` when the price cannot be worked out, never 0. Same refusals as the run, before it. |
| `POST /api/teams/agents/:uid/run` | the sponsor + paid Founder plan | Part 2. Takes `{ module, option, record?, prompt }`; `{ proposal, charged: { available, value_microusd } }`. Charged to the sponsor, logged with `agent_id`. 403 `not_sponsor` / `agent_paused` / `module_not_allowed` / `option_not_allowed` / `sponsor_lost_access` (pauses it `sponsor_left`) / `plan_required`; 402 `agent_cap_reached` (pauses it `cap`); 422 `option_not_text`; 503 `agent_spend_unreadable`; every AI run refusal in its own words. Part 5 (#3844): also takes `tool_reads: [{ integration_uid, tool, arguments? }]`, at most five, each through a granted tool, metered, cut to 8 KB and given to the model only as untrusted data; 400 `invalid_tool_reads`; 403 `tool_not_granted`; 422 `too_many_tool_reads`; 409 `tool_disconnected` with `{ server: { uid, name } }` (pauses it `tool_disconnected`). |
| `GET /api/teams/:scope/:id/queue?role=&module=&option=&status=proposed&cursor=&include=projects` | read | Part 3. `{ items: [Item], counts: { proposed: { available, value } }, next_cursor }`: the scope's agents' proposals, newest first, 25 a page. `include=projects` adds the company's projects for its editors only. `counts.proposed` is `{ available: false }` when unread, never 0. 400 `invalid_status` / `invalid_cursor`; 403 `not_member`; 404. |
| `GET /api/teams/queue/:proposalUid` | read the agent's scope | Part 3. `{ item: Item, inputs: [{ source, read_only: true, summary }] }`. 403 `not_member`; 404 (also for a member's own proposal, which no queue holds). |
| `POST /api/teams/queue/:proposalUid/decide` | manage, or the agent's sponsor | Part 3. Takes `{ decision: 'accept' \| 'edit' \| 'discard', payload? }`; `{ item }`, once, with `decided_by_user_id` and a `proposal_decided` event. 400 `invalid_decision` / `payload_required`; 403 `not_manager`; 409 `not_open` with `{ decided_by: { uid, name }, decided_at }`; 422 `never_fill`. |
| `GET /api/teams/tools` | signed in + paid Founder plan | Part 5 (#3844). `{ servers: [{ integration_uid, name, status: 'connected' \| 'disconnected', tools: [{ name, description: null }] }] }`: the caller's own approved read tools (D852) that an agent may be granted. 404 `custom_mcp_off`; 403 `plan_required`. |

`Agent` is `{ uid, role_key, persona, first_name, last_name, model_id, tools: [{ integration_uid, tool, server: { uid, name }, status: 'connected' | 'disconnected' }], sponsor: { uid, name }, status, paused_reason, monthly_cap_microusd, month_spend, last_activity_at, scope_kind, project: { id, name } | null }`. `month_spend` is `{ available: true, value_microusd }` for this month's runs, or `{ available: false }` when the read fails or a run's charge is unrecorded: the page says "Not recorded", never 0. `last_activity_at` is the newest event, or `null`.

`Item` (part 3) is `{ uid, kind, option, module, headline, payload, status, agent: { uid, role_key, persona, first_name, last_name }, sponsor: { uid, name }, cost: { available, value_microusd }, created_at, decided_by: { uid, name } | null, decided_at }`; `cost` is `{ available: false }` when the run's charge is unrecorded, never 0.
