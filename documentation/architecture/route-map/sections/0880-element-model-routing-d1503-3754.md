### Element model routing (D1503, #3754)

`routes/deck_element_models.ts`, mounted at `/api/decks` beside `deck_grid.ts`, before `decks`. The routes are in `services/decks/elementModels.ts` (pure: `ELEMENTS`, `ELEMENT_ROUTES`, `resolveElementModel`, `sizeFor`, `estimateDeck`, `expected_ms`; `OUTPUT_RULES` in `elementOutputRules.ts`). Each element's models come from its #3721 job in `services/ai/modelUseCases.ts` over `catalogue.ts`. Picks are kept in `deck_model_picks` (migration 717). Client: `lib/api/deckElementModels.js`, read through `deckV2Adapter.elementModels` (a `SWAPPED` row). The pitch pages' AIRail groups read it on a deck (`deckRailGroups.js`).

| Route | Who | What it answers |
| --- | --- | --- |
| `GET /api/decks/:id/element-models` | whoever may read the deck (`projectOwned`) | `{ deck_id, project_id, billing, plan_rank, elements: [{ element, group, job, kind, task, plan_min, expected_ms, per_run_microusd, suggested: [≤ 3], more, pick, resolved: { model, name, source, locked, notice } }], groups: [{ group, elements, lead, suggested, more, pick, resolved, free? }], free: [{ element, group, line: 'No model · free' }] }`. `suggested`, `more` and `pick` use #3741's shape. Stale deck, area and member picks are cleared by the read, and `notice` says "A model retired · Using …". |
| `PUT /api/decks/:id/element-models` `{ scope: 'deck' \| 'member', key, model \| null }` | whoever may write the deck | Stores the deck's pick (scope id: the project) or the caller's own. `key` is a routed element or `group:<group>`, and `null` clears the pick. Refusals: 400 `invalid_scope`, `invalid_key` or `model_not_offered`; 403 `role_locked` when HQ locked the key, and 403 `plan_locked` (with `plan`) for a model the caller's plan does not include. D1509 (#3760): an element HQ switched off answers 404 `not_switched_on`, a switched-off model 400 `model_not_offered`. GET marks such an element `switched_on: false` with `reason` "Not switched on yet." and no models, leaves it out of its group, and leaves switched-off models out of every list; a pick of one is kept and `notice` says "<C> is unavailable. Using <B>.". |
| `GET /api/admin/feature-flags` | admin | D1509 (#3760, migration 723): every `feature_flags` row (`key`, `scope`, `scope_id`, `enabled`, `updated_by`, `updated_at`), the `keys` a row may name (`grid_generate`, `element:<id>`, `model:<catalogue id>`) and `cache_s` (60). 503 `flags_unreadable` when the table cannot be read. |
| `PUT /api/admin/feature-flags` `{ key, scope: 'global' \| 'role' \| 'user', scope_id?, enabled: true \| false \| null }` | admin | Writes one flag row (`null` deletes it: back to the default, on) and drops the 60 s KV copy. 400 `invalid_key`, `invalid_scope`, `invalid_scope_id` (a role name, or a user's numeric id) or `invalid_enabled`, each before any write. |

Generation: `POST /api/decks/generate`, `POST /api/decks/new/quote` (build and card) and `POST /api/decks/proposals/:id/regenerate-card` run their words on Body's resolved model, and the build names it in `element_models`. `POST /api/decks/:id/images(/quote)` runs on the photo or illustration element's model. If no pick sits above the row default, a run keeps its rail option's own resolution, as before. `GET /api/ai/rail?page=Founder · Raise · Pitch deck&option=grid:<element>` answers the element's generated row.

D1519 (#3771), one voice: every run above takes its system prompt from `services/decks/prompts` (`promptFor`: the resolved model's family file, else `default`, opened with the house voice and the deck theme's `voice`). `POST /api/decks/outline` answers `outline.prompt_version`; `POST /api/decks/generate` and `/proposals/:id/regenerate-card` answer `wording.prompt_version` (`build.<family>@v<n>`); `POST /api/decks/:id/cards/:card/assist` answers `prompt_version` on a text press. A model string out of the house voice (the glossary: hype, `!`, emoji, "I"/"my", "the company") is dropped and counted in `wording.dropped`, like one that names a number. The UI does not draw `prompt_version`.
