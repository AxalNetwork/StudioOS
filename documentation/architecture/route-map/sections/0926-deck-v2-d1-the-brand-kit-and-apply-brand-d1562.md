### Deck v2 D1: the brand kit and Apply brand (D1562, #3809)

The read stays in `routes/decks.ts`; the write and Apply brand are `routes/deck_brand_kit.ts`, mounted at `/api/decks` before `decks` through the route registry (`mount`, #4105). Rules in `services/decks/brandKit.ts` (the view, the pure pick, Apply brand) and `services/decks/brandKitLists.ts` (the Google Fonts (OFL) list and the image styles); storage is migration 737 (`deck_brand_kits`, `deck_brand_kit_images`), read over the venture's live landing page. Client: `lib/api/deckBrandKit.js` (`deckBrandKitApi.read`, `save`, `apply`); the pd7 sheet is `BrandKitSheet` in `DeckSheets.jsx`, opened from ⋯ › Brand kit in the editor and on the studio home.

| Route | Who | What it answers |
| --- | --- | --- |
| `GET /api/decks/brand-kit?project_id=` | whoever may read the venture's decks (`projectOwned`) | `{ project_id, kit, choices }`. `kit` is null with no landing page and no deck kit; otherwise D898's fields plus `roles` (five palette roles), `font_pair`, `image_style`, `references`, `library`, `deck_kit` and `pick` (`{ theme, reason, adjustments }`). `choices` holds the font list, the image styles, the roles and the caps. 503 `unreadable` when a read fails, never an empty kit. |
| `PUT /api/decks/brand-kit?project_id=` `{ fonts, logo_url, palette, image_style, library }` | write access to the venture (`projectOwned` `write`); never a support session | `{ project_id, kit, choices }`, the whole kit replaced in one batch. 400 `font_not_listed`, `invalid_palette`, `invalid_colour`, `invalid_image_style`, `invalid_library`, `too_many_images` (24), `too_many_references` (3); 422 `unsafe_url` for a logo or image that is not a public https address; 403; 503 `unwritten`. A refusal writes nothing. |
| `POST /api/decks/:id/apply-brand` `{ cards?, theme? }` | write access to the venture | `{ deck_id, theme, cards, changed, tokens, problems: [], reason, adjustments }`: the deck as posted (or the stored version) restyled in one answer, which the editor applies as one op, one undo step. 409 `no_kit`, 400 `too_many_cards` (100), 422 `unreadable_result`, 403, 404, 503 `unreadable`. No model; writes nothing. |
