### Usage console (D789, #2214)

B1 and B2 of `design/incoming/Usage Page.dc.html` draw `/account/usage` (`UsageOverview.jsx`) and `/account/usage/cost` (`CostPage.jsx`), for every signed-in role, on desktop and phone. Overview has the month's spend, token balance and allowance, auto-reload/card pills, last-30-day stacked model cost and token lines, limits and recent invoices. Cost has range/group filters, a model chart/table filter, per-kind totals, the daily chart, a responsive table and the authenticated D787 CSV download. Range totals and CSV explicitly cover all models. `lib/modelColours.js` owns the stable categorical map for both pages and HQ's future chart. All reads are the member's; switching company changes no scope.

**Preserved:** the allowance, held runs, top-up balance/history, days, where it went by page/task/charge, models, rate card, last receipt and storage are on Cost in its open detailed section (`AccountUsage.jsx`). Old overview hashes forward to Cost. **Invoices:** Recent invoices reads the newest three rows from D806's mounted `/api/billing/invoices` through `billingInvoicesApi.list({ page: 1, per: 3 })`. Missing data stays Not recorded; failed and degraded Stripe reads stay visible. Order PDFs use the authenticated blob client; Stripe PDFs use safe HTTPS links. D787's page/option groups do not return Cloudflare cost or other units, so those cells say Not recorded with the reason. No new API method is invented. The canvas remains in incoming for its other boards.
