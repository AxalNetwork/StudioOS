### Eadwyn AI rail Worker contract (D720)

`routes/ai.ts`, mounted at `/api/ai`, and one route of `routes/ai_budget.ts`, mounted at `/api/ai-budget`. Every route is signed in (`requireAuth`). Except for the HQ catalogue explicitly gated below, these routes read and write the caller's own rows only and take no user id from the body or the query. The owner's runbook is `documentation/operations/AIRAIL.md`.

A page is a page key, `<Profile> · <Section>[ · <Module>]` (D720 §5): the browser's page map (`frontend/src/lib/railPages.js`, D768) gives a route its key, and the matrix (`cloudflare-worker/src/services/ai/railMatrix.json`, D764) gives a key its kind, whose job (`RAIL_KIND_JOBS`) gives it its models (D4313: no page row stores a list). A key can hold a `/`, so it travels in the query or the body, never in the path. A run carries no route of its own: every request names the page in `X-Rail-Page`, the open option in `X-Rail-Option` and the record in `X-Rail-Record` (`util/railContext.ts`, D765 and D770), and `run()` records the run under them and checks the page's switch, answering 403 `assist_off` in the switch's words when it is off.

Prices are selected by `billingMode` in `services/ai/pricing.ts`, which currently returns `cost`. D762 (#2019) will make it read `AI_BILLING` (`wrangler.toml`, both blocks): `"charged"` will bill Cloudflare's cost × `AI_MARKUP` (1.25), and anything else cost. The admin licence always pays cost. Every route below that quotes a price gives `cost` and `billed` for the caller's licence, and `billing` says which one a run is settled at.

| `GET /api/ai/me/spend` | signed in | The caller's month-to-date and today figures, the caps the router enforces, and their last run. `?surface=<path>` narrows it to one page's month and last run (D552); a value that is not an app path exactly as the router records one is refused with 400. |
| `GET /api/ai/pricing` | signed in | The router's own tables: `unit` (`usd_per_1m_tokens`), `prices` (`PRICE_USD_PER_1M_TOKENS`), `audio_prices` (per audio minute), and `routes`, each task's `model`, `fallback_chain` and `alternates`. The rail draws "Default" only on a task's `model` (D400). |
| `GET /api/ai/rates` | signed in | The Usage page's rate card (D641): `billing`, and one row per model a price table holds, with its name, its unit prices at `cost` and `billed`, `retired: true` on a model kept only so past runs keep their cost, and `image: true` on a model priced by size and steps (D766). Read from the tables on every request. |
| `GET /api/ai/catalogue` | signed in | The models Workers AI offers today (D760): status `ga` or `partner`, with a price, past the partner gate. Each with its `kind`, `status`, `paid_only`, `partner`, `context_window` and unit prices. Ordered by kind, the safety model last. Also `billing`, and `guard.every_run`. |
| `GET /api/ai/rail?page=<key>[&option=<key>]` | signed in | One page's matrix row (D764): its `crumbs`, `kind`, `models` (each with `name`, `role`, `line` and unit prices), its `options` with their own models and picks (D1478: an `image` option's models are the image models, FLUX.1 Schnell first, and a transcription option's are the `transcribe` task's three; the image and transcription runs read that option's pick), the member's `pick` and `mode` for the page, `billing`, and `guard` (the safety model, `every_run: true`). A key the matrix has no row for is 404 `unknown_page`; an option key that is not `<verb>:<object>` is 400 `invalid_option`. A stored pick the row no longer offers is deleted and reads as none. D1509 (#3760): a model HQ switched off for the caller (`model:<id>` flags) leaves `models`, `more` and every option's lists; a stored pick of it is kept, reads as none, and `notice` says "<C> is unavailable. Using <B>."; `PUT /api/ai/rail/pick` refuses it 400 `model_not_offered`. |
| `PUT /api/ai/rail/pick` | signed in | `{ page, option?, model }`: the member's model for the page, or for one of its options. A model the row does not offer is 400 `model_not_offered`, with the row's `models`; `null` clears the pick. |
| `PUT /api/ai/rail/mode` | signed in | `{ page, mode: 'eadwyn' \| 'manual' \| null }`: the page's switch (D769). Anything else is 400 `invalid_mode`; `null` clears it. |
| `GET /api/ai/rail-preferences` | signed in | The caller's rail `modes` and `models`, by section (D698, migration 465's `ai_rail_preferences`). |

| `PUT /api/ai/rail-preferences/:section/:task` | signed in | `{ model: string \| null }`: one of the task's `alternates`, else 400 `model_not_offered`; a task with no choice is refused. `null` clears the pick. |
| `POST /api/ai/workspace/explain` | signed in | `{ workspace, zone?, coverage: string[], model?, page? }`: reads back one workspace zone from the coverage lines the rail already draws, never the rows behind them. `workspace` is required (400). The run goes through `run()`, which owns the model allow-list, the budget and Llama Guard (D763), and records `page` as its surface. |
| `GET /api/ai-budget/runs?group=page\|option\|record&month=YYYY-MM` | signed in | Where the member's own runs went this month, or the month named (D776): one row per page, per option within a page, or per record, at most `MAX_CONSUMPTION_ROWS`, with `runs`, `charged_microusd` (null when no run recorded a charge), the `allowance_microusd` and `tokens_microusd` it came from, and `not_recorded`; then `truncated` and the month's `totals`. | `GET /api/ai-budget/cost?range=mtd\|30d\|prev_month&group=model\|page\|option` | signed in | The member's own cost (D787): `range` (`from` and `to`, UTC days, inclusive), `totals` (`runs`, `input_tokens`, `output_tokens`, `cost_usd`, `charged_microusd`, `refused`, `not_recorded`; D805 (#2243) adds `by_kind`, `{ tokens, audio_speech, image, other }` each with `cost_usd` and `charged_microusd` by the model's catalogue kind (`KIND_GROUP`), `other_models`, every model counted in `other` including one the catalogue does not know, and `output_not_recorded`, runs on an output-token-priced model that recorded no output count), `days` (every day in the range, each with its `by_model`), `models` (each with its catalogue `name`, its tokens, its non-token `units`, `cost_usd` and `charged_microusd`), `groups` by `group`, and `truncated`. At most `MAX_COST_RUNS` (10,000) runs, newest first. `range` defaults to `mtd`, `group` to `model`; anything else is 400 `invalid_range` or `invalid_group`. |
| `GET /api/ai-budget/cost.csv` | signed in | The same query and read as CSV, one row per day and model with a run: `day,model,name,kind,runs,input_tokens,output_tokens,cost_usd,charged_microusd` (`kind` from D805). |
| `GET /api/ai/catalogue/hq` | HQ Admin or Super Admin | D776 PR 2 (#2093), the one route here that is not the caller's own: the billing mode (`billingMode`), `AI_MARKUP`, and each offered model priced at cost and billed per unit, with `paid_only` and the D764 matrix pages that name it. |
