### Retrying a run's failed areas, and the return banner (D1600, #3879)

Three more routes in `routes/deck_batches.ts`, over migration 752's `seen_at`, `notified_at` and `parent_batch_uid` on `deck_area_batches`, with the work in `services/decks/batchFollowUp.ts`. A retry is a new run admitted through `admitDeckRun`, linked to the first run of its family by `parent_batch_uid`, and it sits under the `deck_generate` rate bucket. The deck's `DeckGenRoom` also streams `area_retrying { area_id, attempt, next_at }` before each automatic retry of a busy model (at most 3 per step), and writes one in-app notice (`deck_build_done`, category `fundraising`, link `/raise/pitch?project_id=<id>&proposal=<batch_uid>`, no figures) when a run ends `done` with no stream attached. Client: `lib/api/deckBatches.js`, read through `deckV2Adapter.retryFailed`, `unseenBatches` and `markSeen` (`SWAPPED` rows; contracts `deckRetryFailed`, `deckUnseenBatches`, `deckMarkSeen`).

| Route | Who | What it answers |
| --- | --- | --- |
| `POST /api/decks/areas/batches/:uid/retry-failed` | the member who started the run, with an `Idempotency-Key` of 8 to 64 characters | `{ batch_uid, retried: [area_id], quote: { microusd } }`: a new run of only the failed areas (or the failed ones among `{ areas }`), each with its model, request and rail option. Its quote is the sum of those lines' quotes and must fit what the family has not charged of the first run's quote. 409 `nothing_to_retry`; 402 `hold_exhausted` with `{ quote: { microusd }, hold_remaining_microusd }`; 400 `invalid_idempotency_key` or `invalid_areas`; 404 `run_not_found` for anyone else. The same key again is the first answer and charges nothing. |
| `GET /api/decks/:id/batches?state=done&unseen=1` | the deck's writers (`projectOwned` with write) | `{ batches: [{ batch_uid, finished_at, cards_waiting }] }`: finished runs nobody opened from the banner, newest first, at most 5. `cards_waiting` counts the cards with a proposal from the run. 400 `unsupported_filter` for any other filter; 404 `deck_not_found`. |
| `POST /api/decks/areas/batches/:uid/seen` | the deck's writers | `{ ok: true }`. Sets `seen_at` once; repeating it changes nothing. 404 `run_not_found` for anyone else. |
