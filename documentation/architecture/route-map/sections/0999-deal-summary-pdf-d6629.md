### Deal page › the investor's deal summary PDF (D6629, #6629)

- **`deal_summary.ts`** (over `services/dealSummary.ts`): `GET /api/deals/:id/summary` says whether this investor may download the summary now and the stamp it would carry (`for <name>, <firm>`), or the one reason why not; `GET /api/deals/:id/summary/pdf` sends the file. Both check, on every request: the Investor licence and no support session, the deal visible to this investor for the chosen firm, a paid Investor plan, an active NDA with the venture. The file holds the key strip, the terms, the investor's stage, the scorecard's bands (only while the founder shares it) and the evidence shared with them; never another investor's name or amount, a firm's notes, or evidence outside their access. Each file sent writes one `data_room_access_log` row (`download_deal_summary`). Canvas: the deal header's More menu (#6175, D4815).
- **Frontend:** `lib/api/dealSummary.js` (`dealSummaryApi.availability`, `pdfBlob`); the More menu item is wired by S33 (owner answer A on #6629).
