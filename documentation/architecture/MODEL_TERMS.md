D1504 (#3755, deck v2 A11). Every model a run can reach, and what its provider's terms say about using what it makes. The register's data is `cloudflare-worker/src/services/ai/modelTerms.ts`; `cloudflare-worker/test/ai_model_terms_d1504.test.ts` fails when this file and that one disagree, or when a routed model is missing here.

**Owner question X** (S1's pick A): each provider is accepted after a counsel summary. Until then no model is reviewed, so every field the review fills reads "Not recorded". It is never guessed.

**Grandfathered.** The 61 models main could run before this register existed (every `ga` or `partner` catalogue row with a price, the partner gate open, catalogue read 2026-10-31) keep running. The list is frozen. A model the catalogue gains later runs only once its row below has a review: `reviewed_on` and `reviewed_by` in `REVIEWED`. Until then the router refuses it with `model_terms_unreviewed`.

**Routed.** 58 of these are routed: a task's model, alternate or chain, or a deck element's model, chain or pipeline step (`services/ai/routedModels.ts`). The rest are reachable only as a member's pick under All models.
