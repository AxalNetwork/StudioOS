# ROUTE_MAP.md — canvas → route → backend, with implementation status

Produced by the P−1 audit (§16 step 2). Every "Live route today" cell was read
from `frontend/src/App.jsx` with its guard; every backend cell names a file that
exists under `cloudflare-worker/src/routes/`. CURRENT vs UPGRADE calls come from
reading the live page component side by side with the canvas, not from name
matching. Comparisons are source-level; the app was not run.

**Corpus:** 107 canonical `*.dc.html` canvases at `Axal VC platform/` (top level
only). `uploads/` holds 3 stale duplicates and `scraps/` holds images — both
excluded. Also at the root, not counted in the 107: 2 standalone pitch-deck
HTMLs, 4 shared JS modules (`support.js`, `doc-page.js`, `deck-stage.js`,
`fund-model.js`) and `assets/`.

## Status taxonomy

| Status | Meaning |
| --- | --- |
| `CURRENT` | A live route implements this canvas and the shipped UI matches. Do not rebuild. |
| `UPGRADE` | A live route exists but the canvas evolved past it. Diff and re-integrate — never skip as "already done". |
| `RESKIN` | Backend/services are live; the shipped UI predates the canvas. |
| `NEW` | No live equivalent. |
| `OUT OF SCOPE` | Spin-Out Lab canvas. The Lab is live and plugged; not a work item. |
| `DEFERRED` | Persona hub canvas. Held until `/studio`'s future iteration. |
