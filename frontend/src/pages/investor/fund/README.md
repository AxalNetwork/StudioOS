# Axal VC Fund workspace

The route owns the existing reads and action handlers. These components render its sections.

| File | Purpose |
|---|---|
| `FundFirstScreen.jsx` | The first screen by standing (D6130 part 2): What is due, What to sign, What arrived for a committed LP |
| `FundOnboardingSection.jsx` | Recorded onboarding status and compliance disclosures |
| `FundOverviewSection.jsx` | Fund figures, terms and participation tiers |
| `FundParticipationSection.jsx` | LP application, commitment, notices and proof of funds |
| `FundReportsSection.jsx` | Underwriting figures, report archive and investor relations |
| `FundWorkspaceNavigation.jsx` | Keyboard-accessible section links |
| `FundWorkspaceSupport.jsx` | Shared labels, access-state copy and display constants |
| `GpReportDesk.jsx` | Existing GP report generation controls |
| `LpApplicationForm.jsx` | Existing application form and submission |
| `LpSkeleton.jsx` | Workspace loading state |
| `useFirstScreenReads.js` | The booklet and notices reads the first screen adds, each failing on its own |
