# components/cofounder — the co-founder agreement builder

Pieces of the co-founder agreement flow, composed by
`frontend/src/pages/CofounderAgreementPage.jsx` and its Spin-Out Lab twin.

| File | What it is |
| --- | --- |
| `ClauseEditors.jsx` | Per-clause editing controls. |
| `ClauseRow.jsx` | One clause in the document outline. |
| `CriticalTermsSnapshot.jsx` | The terms a reader must not miss, pulled to the top. |
| `RolesAndReservedMatters.jsx` | Who decides what. |
| `IpRider.jsx` | The IP assignment rider. |
| `DisputeCard.jsx` | Dispute-resolution terms. |
| `SoloDeclaration.jsx` | The single-founder path. |
| `ExecutionConsole.jsx` | Sending for signature and tracking it. |
| `StatusPill.jsx` | Draft / sent / signed. |

The document itself is generated by the worker
(`POST /api/legal/cofounder-agreement`) from templates in
`cloudflare-worker/src/templates/legal/`. These components collect the inputs;
they do not assemble the legal text.

**A signed agreement is immutable.** Once executed it is stored with an
object-lock and a hash — the editors must not offer a path that implies
otherwise.
