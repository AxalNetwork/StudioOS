Raise — one fundraising operating workflow

Revised for the browser-audited prompt (8 Nov). Raise is four stages: Prepare (Evidence, Readiness) · Build the story (Narrative, Pitch) · Prepare diligence (Data room, Cap table, Use of funds) · Run the raise (Capital relationships, with Calls, Commitments and Closing inside). One desktop nav plus each tool’s own tabs; the Module select is compact-only. A mature tool owns its page, with no generic Cycle layer under it and a header action that fits it. A refused source stops the page; an unreadable one makes the page say what it could not check, never zero or all-clear. Recorded and Modelled never look alike. Eadwyn starts with the page’s own tasks. Every tool has a purpose-built empty state, a conflict state and a mobile layout.
