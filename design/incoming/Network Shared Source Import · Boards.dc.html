Axal VC · Network Sources — import shared investor sources, review identity, publish with provenance

An operator console in the HQ shell (Admin console › Network sources) that turns source records from Airtable, Folk and NFX Signal into reviewable people, organizations and affiliations in the shared Network directory. It runs in nine steps: source, snapshot, classify, map, validate, review, plan, publish, result. Every screen names its actor, snapshot, visibility, contract, side effect and recovery. A source record is not a person; a firm is never a fund vehicle; a name never decides identity. Staging, review and publishing contact nobody and create no account, tie, invitation, consent or diligence approval. The LinkedIn CSV importer on main writes a member’s private book and is not reused. It keeps the Network look of #6256 (nwi.js) and Platform States (D5129). It shares its operator steps with the Research Funds import console (FND-I, #7738) and cites FND-I11 for Research promotion. None of this exists on main: the schema is in the open PR #7687 (#7672), the routes are #7674, the NFX adapter is #7681.
