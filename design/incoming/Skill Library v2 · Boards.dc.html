Skill Library — discover, author, qualify and publish skills you can trust

Two audiences. HQ Super Admins author, evaluate, review, publish and retire Axal's skills in HQ › AI agents › Skills library. Teams discover and assign skills in Grow › Talent › AI agents › Skills. One readiness model runs through both: Draft, Missing cases, Needs evaluation, Failing, Stale, In review, Changes requested, Ready to publish, Published, Retired. The evaluation is a golden case × model matrix with Pass, Fail, Not run, Stale and Missing, reported as “x of y” against the 9-of-10 bar, never as a percentage. Publish is a checklist the server re-checks; refusals show its own words and code. Relation to existing canvases: this builds on Agent Skills (D1612) and Agents Skills v2 (D4116) and does not replace them. The Team page keeps its areas, directories, SKILL.md, version pins, read-only tools and no roles; this canvas adds the HQ qualification workspace plus search, filters and assign reasons for Teams. Re-checked against main: the brief's P0s (HQ lifecycle, Team authoring stubs) are already built (D4160, #4739, D4733), so those boards draw working flows.
