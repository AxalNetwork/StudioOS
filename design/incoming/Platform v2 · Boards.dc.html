Platform — an operator’s control plane

One overall health state that takes telemetry confidence into account, not just cron. Below it, a severity-ranked queue where every item has a state, an observed time and a fix-it action. Then four compact system blocks (status, key metric, freshness, console), active controls, capability coverage, a significant-events feed and consoles grouped by domain. The status vocabulary is fixed (Healthy, Degraded, Critical, Unknown, Disabled, Not configured, Stale, Partial, Available) and always pairs a symbol with words. Unknown never reads as zero. This console uses an emerald and neutral system palette with ink primary buttons — no violet accent. Eadwyn stays collapsed unless it has an insight, is asked or is pinned.
